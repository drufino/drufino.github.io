5.8.8 Measurable Functions

Definition 5.8.39

Let (Ω1,ℱ︀1) and (Ω2,ℱ︀2) be measurable spaces. A function 𝑓:Ω1→Ω2 is said to be measurable if

𝐸∈ℱ︀2⟹𝑓−1(𝐸)∈ℱ︀1

We may write ℱ︀1/ℱ︀2-measurable in order to make the 𝜎-algebras explicit.

Similarly a function 𝑓:Ω→𝑋 from a measurable space to a topological space is said to be measurable if it is ℱ︀/ℬ︀(𝑋) measurable.

Proposition 5.8.40

The following properties hold

  1. The composition of measurable functions is measurable

  2. Suppose ℱ︀2=𝜎(𝒞︀) then a function 𝑓:Ω1→Ω2 is ℱ︀1/ℱ︀2-measurable iff

    𝐸∈𝒞︀⟹𝑓−1(𝐸)∈ℱ︀1
  3. A function 𝑓:Ω→𝑋 is measurable precisely when the inverse image of an open set (resp. closed set) is measurable.
Corollary 5.8.41 (Criteria for measurablity of a real-valued function)

Let (Ω,ℱ︀) be a measurable space and 𝑓:Ω→ℝ♯ a function. Then the following are equivalent

  1. 𝑓 is ℱ︀/ℬ︀(ℝ♯)-measurable
  2. 𝑓−1((𝑥,∞])∈ℱ︀ for all 𝑥∈𝐷
  3. 𝑓−1([𝑥,∞])∈ℱ︀ for all 𝑥∈𝐷
  4. 𝑓−1([−∞,𝑥))∈ℱ︀ for all 𝑥∈𝐷
  5. 𝑓−1([−∞,𝑥])∈ℱ︀ for all 𝑥∈𝐷

where 𝐷⊂ℝ is an additive subgroup containing ℚ.

Proof. We may combine (5.8.40).b) and (5.8.31). ∎
Proposition 5.8.42 (Measurable Space Isomorphism)

Let (Ω1,ℱ︀1) and (Ω2,ℱ︀2) be measurable spaces and 𝑓:Ω1→Ω2 a bijective function. Then the following are equivalent

  1. 𝑓 and 𝑓−1 are measurable
  2. 𝑓 induces a bijection ℱ︀1→ℱ︀2
  3. 𝑓−1 induces a bijection ℱ︀2→ℱ︀1

In this case we say that 𝑓:(Ω1,ℱ︀1)⟶∼(Ω2,ℱ︀2) is a measurable space isomorphism.
