2.3 Matroids

The theory of bases of vector spaces (the Vector Spaces subsection) and transcendence bases of field extensions (the Transcendental Field Extensions subsection) have some formal similarities, as noted in [Wae91]. Here we use the theory of Matroids to formalise this precisely so that the proofs need not be repeated in each case.

Definition 2.3.1 (Matroid)

Consider a set 𝑋 together with a closure operator 𝑐:𝒫︀(𝑋)→𝒫︀(𝑋) (“span” operator) such that 𝑐(∅)=∅. We say

  • 𝑆⊆𝑋 is independent if 𝑥∈𝑆⟹𝑥∉𝑐(𝑆∖{𝑥})
  • Γ⊆𝑋 is spanning if 𝑐(Γ)=𝑋.

Note by definition 𝑋 is spanning and ∅ is independent. Moreover all singletons {𝑥} are independent.

We call the pair (𝑋,𝑐) a matroid if it also satisfies the following properties

  • Finitary 𝑥∈𝑐(Γ)⟹𝑥∈𝑐(Γ′) for some finite subset Γ′ of Γ.

  • Exchange Property For all 𝑥,𝑦∈𝑋 and 𝑌⊆𝑋 we have

    𝑥∈𝑐(𝑌∪{𝑦})∖𝑐(𝑌)⟹𝑦∈𝑐(𝑌∪{𝑥})

We say (𝑋,𝑐) has finite rank if it has a finite spanning set.

Finally we say ℬ︀⊆𝑋 is a basis if it is both spanning and independent.

We begin with some elementary characterizations of independent sets

Lemma 2.3.2

Suppose 𝑆⊆𝑋 is a subset

  1. 𝐴⊆𝑐(𝑆)⟹𝑐(𝑆∪𝐴)=𝑐(𝑆)
  2. 𝑆 is independent if and only if no proper subset has the same span.

Proof. We prove each in turn

  1. By monotonicity

    𝑐(𝑆)⊆𝑐(𝑆∪𝐴)⊆𝑐(𝑐(𝑆)∪𝐴)=𝑐(𝑐(𝑆))=𝑐(𝑆)

  2. Suppose 𝑆 is independent and 𝑆′⊊𝑆 is a proper subset such that 𝑐(𝑆′)=𝑐(𝑆). Choose 𝑥∈𝑆∖𝑆′ then by definition 𝑥∈𝑆⟹𝑥∈𝑐(𝑆)=𝑐(𝑆′)⊆𝑐(𝑆∖{𝑥}) contradicting independence.

    Conversely suppose for some 𝑥∈𝑆 we have 𝑥∈𝑐(𝑆∖{𝑥}). Define 𝑆′≔𝑆∖{𝑥}. Then 𝑥∈𝑐(𝑆′) implies 𝑐(𝑆)=𝑐(𝑆′) by a). As 𝑆′ is a proper subset this contradicts the hypothesis.

 ∎

Lemma 2.3.3
Every subset of an independent set is independent. Furthermore the family of independent sets has finite character.
Proof. The first statement is straightforward. Suppose 𝑆 a dependent set such that every finite subset is independent. Then there exists 𝑥∈𝑆 such that 𝑥∈𝑐(𝑆∖{𝑥}). Then by the finitary property there exists a finite subset 𝑆′⊆𝑆∖{𝑥} such that 𝑥∈𝑐(𝑆′). Therefore by definition 𝑆′∪{𝑥} is not independent, a contradiction. ∎

The finitary condition ensures that ℰ︀ is “inductively ordered”

Corollary 2.3.4
Let {𝑆𝑖}𝑖∈𝐼 be a chain of independent subsets. Then 𝑆=⋃𝑖∈𝐼𝑆𝑖 is also independent.

Proof. Drafted by Claude Sonnet 5, reviewed by David Rufino.

Let 𝐹⊆𝑆 be a finite subset. For each 𝑥∈𝐹 choose 𝑖𝑥∈𝐼 with 𝑥∈𝑆𝑖𝑥. As {𝑆𝑖}𝑖∈𝐼 is a chain and 𝐹 is finite, the sets {𝑆𝑖𝑥}𝑥∈𝐹 are totally ordered by inclusion and so admit a maximum 𝑆𝑖0, whence 𝐹⊆𝑆𝑖0. By (2.3.3) 𝐹 is independent, being a subset of the independent set 𝑆𝑖0. As 𝐹⊆𝑆 was an arbitrary finite subset, 𝑆 is independent by (2.3.3). ∎

Lemma 2.3.5 (Extension Property)
Suppose 𝑆 is an independent set and 𝑥∉𝑐(𝑆), then 𝑆∪{𝑥} is independent.
Proof. We require to prove that for all 𝑦∈𝑆 we have 𝑦∉𝑐(𝑆∪{𝑥}∖{𝑦}). By independence of 𝑆 we have 𝑦∉𝑐(𝑆∖{𝑦}), so by the Exchange Property 𝑦∈𝑐(𝑆∪{𝑥}∖{𝑦}) would imply 𝑥∈𝑐(𝑆), contradicting the hypothesis. ∎
Proposition 2.3.6

Let ℱ︀ be a family of independent sets which satisfies the following properties

  • ∅∈ℱ︀
  • extension property 𝑆∈ℱ︀ and 𝑥∉𝑐(𝑆)⟹𝑆∪{𝑥}∈ℱ︀
  • ℱ︀ has finite character

then ℱ︀ consists of all independent sets.

Proof. It’s enough to show that ℱ︀ contains all finite independent sets, which follows by induction on #︎𝑆. For given an independent set 𝑆 and 𝑥∈𝑆, then by definition 𝑥∉𝑐(𝑆∖{𝑥}). By the induction hypothesis 𝑆∖{𝑥}∈ℱ︀ whence by the extension property 𝑆∈ℱ︀ as required. ∎
Proposition 2.3.7 (Basis exists)

Let (𝑋,𝑐) be a matroid, 𝑆 independent and Γ a subset such that 𝑆⊆Γ. Then there exists an independent set ℬ︀ such that 𝑆⊆ℬ︀⊆Γ and 𝑐(ℬ︀)=𝑐(Γ).

In particular if Γ is spanning then ℬ︀ is a basis.

Proof. Consider the collection

ℐ︀={𝑇independent|𝑆⊆𝑇⊆Γ}

By (2.3.4), ℐ︀ is chain-complete. Therefore it has a maximal element ℬ︀ by Zorn’s Lemma. Suppose 𝑥∈Γ∖𝑐(ℬ︀) then ℬ︀∪{𝑥} is independent by (2.3.5), contradicting maximality. Therefore Γ⊆𝑐(ℬ︀)⟹𝑐(Γ)⊆𝑐(ℬ︀). The reverse inequality is clear so that 𝑐(Γ)=𝑐(ℬ︀). ∎

Corollary 2.3.8 (Criteria for bases)

Let (𝑋,𝑐) be a matroid. Then the following are equivalent

  1. ℬ︀ is a basis
  2. ℬ︀ is a minimal spanning set
  3. ℬ︀ is maximally independent (possibly in some spanning set Γ)

Proof. a) ⟹ b). Let ℬ︀ be a basis and Γ⊆ℬ︀ a spanning set. Then by (2.3.2) b) Γ=ℬ︀.

b) ⟹ a). Let ℬ︀ be a minimal spanning set, then by (2.3.7) there exists a subset ℬ︀′ which is a basis, and in particular spanning. By minimality ℬ︀=ℬ︀′.

c) ⟹ a). By (2.3.7) there exists a basis ℬ︀′ containing ℬ︀. By maximality ℬ︀′=ℬ︀.

a) ⟹ c). Suppose ℬ︀⊆𝑆 where 𝑆 is independent. Then 𝑆 is spanning too, and so by (2.3.2) b) ℬ︀=𝑆. ∎

Definition 2.3.9 (Sub-matroid)
A subset 𝑌⊆𝑋 is a sub-matroid if 𝑐(𝑌)=𝑌. In this case 𝑆⊆𝑌⟹𝑐(𝑆)⊆𝑌 and so we have an induced matroid structure (𝑌,𝑐).
Lemma 2.3.10 (Mini Exchange Lemma)

Let 𝑆⊆Γ be finite sets and 𝑥∈𝑋∖𝑆 such that

  • 𝑆 is independent
  • 𝑥∈𝑐(Γ)∖𝑐(𝑆)

Then there exists 𝑦∈Γ∖𝑆 such that 𝑐(Γ∖{𝑦}∪{𝑥})=𝑐(Γ).

Proof. We may assume without loss of generality that 𝑥∉Γ.

Consider Γ̃⊆Γ minimal subject to 𝑆⊆Γ̃ and 𝑥∈𝑐(Γ̃). If 𝑆=Γ̃ then 𝑥∈𝑐(𝑆) a contradiction. Therefore we may choose 𝑦∈Γ̃∖𝑆. By minimality we have 𝑥∈𝑐(Γ̃)∖𝑐(Γ̃∖{𝑦}). Therefore by the Exchange Property we have 𝑦∈𝑐(Γ̃∖{𝑦}∪{𝑥}). Then by (2.3.2) applied twice

𝑐(Γ∖{𝑦}∪{𝑥})=𝑐(Γ∪{𝑥})=𝑐(Γ)

as required. ∎

Proposition 2.3.11 (Exchange Lemma)

Let 𝑆 be an independent set and Γ be a finite set such that 𝑆⊆𝑐(Γ). Then there exists a subset 𝑇⊆Γ such that

  • #︎𝑇=#︎𝑆
  • 𝑐(Γ∖𝑇∪𝑆)=𝑐(Γ).

In particular #︎𝑆≤#︎Γ.

Proof. By considering the sub-matroid (𝑐(Γ),𝑐) we may assume without loss of generality that 𝑋=𝑐(Γ).

Let 𝑛=#︎Γ and consider the set of pairs

ℱ︀≔{(𝐴,𝐵)|𝐴⊆𝑆,𝐵⊆Γ,#︎𝐴=#︎𝐵,𝑐(Γ∖𝐵∪𝐴)=𝑋}

Essentially ℱ︀ is the set of swaps we may perform from 𝑆 to Γ whilst preserving the span. It is non-empty because (∅,∅)∈ℱ︀ and we wish to show that (𝑆,𝐵)∈ℱ︀ for some 𝐵.

Observe that for all (𝐴,𝐵)∈ℱ︀ we have #︎𝐵≤𝑛 so choose a pair such that #︎𝐵 is maximal. We wish to show that in this case 𝐴=𝑆, so we suppose to the contrary that 𝐴⊊𝑆.

We claim that 𝐵⊊Γ, for 𝐵=Γ implies by construction 𝑐(𝐴)=𝑋 which would imply 𝑐(𝐴)=𝑐(𝑆), contradicting the criteria for independence of 𝑆 given by (2.3.2) b).

Define Γ′≔Γ∖𝐵∪𝐴. Then by assumption 𝑐(Γ′)=𝑋 and 𝐴⊆Γ′ is independent. Choose 𝑥∈𝑆∖𝐴 then by definition of independence 𝑥∉𝑐(𝐴). By (2.3.10) there exists 𝑦∈Γ′∖𝐴 such that

𝑐(Γ′∖{𝑦}∪{𝑥})=𝑐(Γ′)=𝑋

Note by construction that 𝑦∉𝐵, so we see that (𝐴∪{𝑥},𝐵∪{𝑦})∈ℱ︀ has greater length, which contradicts maximality. ∎

Corollary 2.3.12 (Bases have the same cardinality)
Every base of a finite rank matroid is finite and of the same size. Denote this by 𝑟(𝑋).
Proof. There is a finite basis by (2.3.7). Then apply (2.3.11). ∎
Corollary 2.3.13
Let (𝑋,𝑐) be a finite-rank matroid and 𝑆⊆𝑋 an independent subset, then #︎𝑆≤𝑟(𝑋). Similarly a spanning subset Γ satisfies #︎Γ≥𝑟(𝑋).
Proof. Apply (2.3.7) and (2.3.12). ∎
Corollary 2.3.14 (Basis Criteria)

Let ℬ︀ be a subset of a finite-rank matroid (𝑋,𝑐). Then the following are equivalent

  1. ℬ︀ is a basis
  2. ℬ︀ is independent and #︎ℬ︀≥𝑟(𝑋)
  3. ℬ︀ is spanning and #︎ℬ︀≤𝑟(𝑋)
Proof. Apply (2.3.7) and (2.3.12). ∎
Proposition 2.3.15
Let 𝑌⊆𝑋 be a sub-matroid of a finite-rank matroid. Then 𝑌=𝑋⟺𝑟(𝑌)=𝑟(𝑋).
Proof. Let ℬ︀ be a basis for 𝑌 then #︎ℬ︀=𝑟(𝑌)=𝑟(𝑋) and is a-fortiori independent in 𝑋. Therefore by (2.3.14) ℬ︀ is a basis for 𝑋 and hence 𝑋=𝑐(ℬ︀)=𝑌. ∎
