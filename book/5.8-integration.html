5.8.1 Algebras of Sets

Definition 5.8.1

Let Ω be a set and ℱ︀ a family of subsets of Ω. We consider the following types of families

  1. ℱ︀ is a semi-ring if the following properties hold

    1. ∅∈ℱ︀
    2. 𝐴1,…,𝐴𝑛∈ℱ︀⟹𝐴1∩…∩𝐴𝑛∈ℱ︀

    3. For all 𝐴,𝐵∈ℱ︀ there is a family of disjoint subsets 𝐶1,…,𝐶𝑛∈ℱ︀ such that

      𝐵∖𝐴=𝐶1⊔…⊔𝐶𝑛

  2. ℱ︀ is a ring (resp. algebra) if the following properties hold

    1. ∅∈ℱ︀ (resp. Ω∈ℱ︀)
    2. 𝐴1,…,𝐴𝑛∈ℱ︀⟹𝐴1∪…∪𝐴𝑛∈ℱ︀
    3. 𝐴,𝐵∈ℱ︀⟹𝐴∖𝐵∈ℱ︀

  3. ℱ︀ is a 𝜎-ring (resp. 𝜎-algebra) if the following properties hold

    1. ∅∈ℱ︀ (resp. Ω∈ℱ︀)
    2. 𝐴1,…,𝐴𝑛,…∈ℱ︀⟹⋃𝑖=1∞𝐴𝑖∈ℱ︀
    3. 𝐴,𝐵∈ℱ︀⟹𝐴∖𝐵∈ℱ︀

Evidently 𝜎-ring ⟹ ring ⟹ semi-ring.

Example 5.8.2

The family of half-open intervals ℱ︀={[𝑎,𝑏)|𝑎<𝑏} forms a semi-ring on ℝ.

More generally the family of products of half-open intervals {[𝑎1,𝑏1)×…×[𝑎𝑛,𝑏𝑛)|𝑎𝑖<𝑏𝑖} forms a semi-ring on ℝ𝑛.

Lemma 5.8.3

Let Ω be a set and {ℱ︀𝛼}𝛼∈𝒜︀ a family of rings (resp. algebras, 𝜎-rings, 𝜎-algebras). Then the family of subsets

⋂𝛼∈𝒜︀ℱ︀𝛼

is a ring (resp. algebra, 𝜎-ring, 𝜎-algebra). In particular every family of subsets is contained in a smallest ring (resp. algebra, 𝜎-ring, 𝜎-algebra).

Definition 5.8.4 (Borel Algebra)
Let 𝑋 be a topological space. We say that the family of borel sets ℬ︀(𝑋) is the smallest 𝜎-algebra containing the family of open sets.
Proposition 5.8.5

Let ℛ︀ be a semi-ring (resp. semi-algebra). Then the family of finite disjoint unions

ℱ︀≔{𝐴1⊔…⊔𝐴𝑛|𝐴1,…,𝐴𝑛∈ℛ︀pairwise disjoint}

is a ring (resp. algebra), and indeed the smallest ring (resp. algebra) containing ℛ︀.

Lemma 5.8.6 (Semi-Ring Extended Set Difference)

Let ℛ︀ be a semi-ring and 𝐴0,𝐴1,…,𝐴𝑛∈ℛ︀. Then

𝐴0∖⋃𝑖=1𝑛𝐴𝑖=⨆𝑘=1𝑚𝐵𝑘

for some disjoint sets 𝐵𝑘∈ℛ︀.

Proof. We proceed by induction, the case 𝑛=1 holding by definition. Suppose the relation holds for 𝑛. Then

𝐴0∖⋃𝑖=1𝑛+1𝐴𝑖=(⨆𝑘=1𝑚𝐵𝑘)∖𝐴𝑛+1=⨆𝑘=1𝑚(𝐵𝑘∖𝐴𝑛+1)

and by definition of ℛ︀ we have

𝐵𝑘∖𝐴𝑛+1=⨆𝑗=1𝑁𝐶𝑘𝑗𝑘=1…𝑚

and 𝐶𝑘𝑗∈ℛ︀. As 𝐵𝑘 are disjoint we see that the 𝐶𝑘𝑗 are disjoint for all 𝑗,𝑘 and the result follows immediately. ∎

5.8.2 Set Functions

Definition 5.8.7 (Finitely Additive Set Function)

Let ℱ︀ be a family of subsets of Ω containing ∅. A set function

𝜇:ℱ︀→[0,∞]

is finitely additive if it satisfies

  1. 𝜇(∅)=0
  2. 𝜇(𝐴1⊔…⊔𝐴𝑛)=∑𝑖=1𝑛𝜇(𝐴𝑖) whenever this is well-defined

We say a set 𝐴∈ℱ︀ is finite if 𝜇(𝐴)<∞, and 𝜇 is finite if 𝜇(ℱ︀)<∞.

We say that 𝜇 is 𝜎-finite if for every set 𝐴∈ℱ︀ there exists a sequence 𝐴𝑖 such that 𝐴⊂⋃𝑖=1∞𝐴𝑖 and 𝜇(𝐴𝑖)<∞. If Ω∈ℱ︀ then it is sufficient for this condition to hold for Ω.

Proposition 5.8.8 (Extension Theorem I)

Let ℛ︀ be a semi-ring, and ℱ︀ the ring generated by ℛ︀. Given a finitely additive set function 𝜇:ℛ︀→[0,∞] there exists a unique extension to ℱ︀ given by

𝜇(𝐴1⊔…⊔𝐴𝑛)=∑𝑖=1𝑛𝜇(𝐴𝑖)

which is finitely additive.

Proof. In order to ensure the definition is well-defined suppose

𝐴1⊔…⊔𝐴𝑛=𝐵1⊔…⊔𝐵𝑚

Then in particular

𝐴𝑖=(𝐴𝑖∩𝐵1)⊔…⊔(𝐴𝑖∩𝐵𝑚)

We may deduce by the additive property that

∑𝑖=1𝑛𝜇(𝐴𝑖)=∑𝑖=1𝑛∑𝑗=1𝑚𝜇(𝐴𝑖∩𝐵𝑗)

Evidently this is symmetric in 𝐴 and 𝐵 so this also equals ∑𝑗=1𝑚𝜇(𝐵𝑗). This shows that the measure 𝜇 is well-defined. The additivity property is straightforward. ∎

Proposition 5.8.9 (Properties of finitely-additive set functions)

Let (Ω,ℛ︀) be a semi-ring and 𝜇:ℛ︀→[0,∞] a finitely additive set function. Then

  1. 𝜇 is monotone, that is for sets 𝐴⊂𝐵 we have

    𝜇(𝐴)≤𝜇(𝐵)

  2. Suppose 𝐴1⊔…⊔𝐴𝑛⊂𝐴0 for 𝐴𝑖∈ℛ︀ then

    ∑𝑖=1𝑛𝜇(𝐴𝑖)≤𝜇(𝐴0)

  3. Suppose 𝐴0⊂𝐴1∪…∪𝐴𝑛 for 𝐴𝑖∈ℛ︀ then

    𝜇(𝐴0)≤∑𝑖=1𝑛𝜇(𝐴𝑖)

Proof.

  1. By definition 𝐵∖𝐴=𝐶1⊔…⊔𝐶𝑛 and therefore by finite additivity

    𝜇(𝐵)=𝜇(𝐶1⊔…⊔𝐶𝑛⊔𝐴)=𝜇(𝐶1)+…+𝜇(𝐶𝑛)+𝜇(𝐴)≥𝜇(𝐴)

  2. By (5.8.6)

    𝐴0∖⨆𝑖=1𝑛𝐴𝑖=⨆𝑘=1𝑚𝐵𝑘

    for some 𝐵𝑘∈ℛ︀ disjoint. Observe they are by construction disjoint from 𝐴𝑖 therefore

    𝐴0=𝐴1⊔…⊔𝐴𝑛⊔𝐵1⊔…⊔𝐵𝑚

    The result follows from finite additivity.

  3. By replacing 𝐴𝑖 with 𝐴𝑖∩𝐴0 we may assume that 𝐴0=𝐴1∪…∪𝐴𝑛 by a). Observe that by (5.8.6)

    𝐴̂𝑖≔𝐴𝑖∖⋃𝑗=1𝑖−1𝐴𝑗=⨆𝑘=1𝑚𝐶𝑖𝑘

    for 𝐶𝑖𝑘∈ℛ︀ (if necessary padding out by ∅). Therefore

    𝐴0=⨆𝑖=1𝑛𝐴̂𝑖=⨆𝑖,𝑘𝐶𝑖𝑘

    and by finite additivity

    𝜇(𝐴0)=∑𝑖=1𝑛∑𝑘=1𝑚𝜇(𝐶𝑖𝑘)

    By b)

    ∑𝑘=1𝑚𝜇(𝐶𝑖𝑘)≤𝜇(𝐴𝑖)

    from which the result follows.

 ∎

Definition 5.8.10 (Simple Functions)

Let (Ω,ℱ︀) be a family of subsets and 𝑋 a normed vector space over ℝ. We define the space of simple functions to be

Simple(ℱ︀,𝑋)≔{∑𝑖=1𝑛𝜆𝑖𝟏𝐴𝑖|𝐴1⊔…⊔𝐴𝑛=Ω,𝜆1,…,𝜆𝑛∈𝑋}
Proposition 5.8.11 (Integration of Simple Functions)

Let (Ω,ℱ︀) be a ring and 𝜇 a finitely additive measure and 𝑋 a vector space over ℝ. There is a well-defined linear map

∫d𝜇:Simple(ℱ︀,𝑋)→𝑋∑𝑖=1𝑛𝛼𝑖𝟏𝐴𝑖→∑𝑖=1𝑛𝛼𝑖𝜇(𝐴𝑖)

Proof. Suppose that ∑𝑖=1𝑛𝛼𝑖𝟏𝐴𝑖=∑𝑗=1𝑚𝛽𝑗𝟏𝐵𝑗 where both {𝐴𝑖} and {𝐵𝑗} are disjoint partitions of 𝑋. Then

𝐴𝑖=(𝐴𝑖∩𝐵1)⊔…⊔(𝐴𝑖∩𝐵𝑚)

whence

𝜇(𝐴𝑖)=∑𝑗=1𝑚𝜇(𝐴𝑖∩𝐵𝑗)

Therefore

∑𝑖=1𝑛𝛼𝑖𝜇(𝐴𝑖)=∑𝑖=1𝑛∑𝑗=1𝑚𝛼𝑖𝜇(𝐴𝑖∩𝐵𝑗)

By the same argument

∑𝑗=1𝑚𝛽𝑗𝜇(𝐵𝑗)=∑𝑖=1𝑛∑𝑗=1𝑚𝛽𝑗𝜇(𝐴𝑖∩𝐵𝑗)

Evidently {𝐴𝑖∩𝐵𝑗} is a disjoint partition of 𝑋. If 𝐴𝑖∩𝐵𝑗≠∅ then the first equality requires that 𝛼𝑖=𝛽𝑗. This shows that the integrals are equal as required. ∎

Proposition 5.8.12

Let (Ω,ℱ︀) be a ring, 𝜇 a finitely additive measure and 𝑋 a normed vector space over ℝ. Then we have the following properties

  1. ∫(𝑓+𝑔)d𝜇=∫𝑓d𝜇+∫𝑔d𝜇
  2. ∫𝜆𝑓d𝜇=𝜆∫𝑓d𝜇

5.8.4 Measure Spaces

To create a robust theory of integration it is necessary to replace finite additivity with countably additivity, and further show that such set functions can be defined over 𝜎-algebras and not just algebras.

Definition 5.8.22 (Countably Additive Set Function)

Let ℱ︀ be a family of subsets of Ω containing ∅. A function

𝜇:ℱ︀→[0,∞]

is a countably additive set function (or measure) if it satisfies

  1. 𝜇(∅)=0
  2. 𝜇(⨆𝑛=1∞𝐴𝑛)=∑𝑖=1∞𝜇(𝐴𝑖) whenever this is well-defined

We say it is countably subadditive if it satisfies

𝜇(⋃𝑖=1∞𝐴𝑖)≤∑𝑖=1∞𝜇(𝐴𝑖)

whenever this is well-defined. We show in (5.8.25) that these conditions are almost equivalent.

Definition 5.8.23 (Measurable Space)
Let (Ω,ℱ︀) be a measurable space and 𝜇:ℱ︀→[0,∞] a measure. Then the triplet (Ω,ℱ︀,𝜇) is a measurable space.

The following are standard results which are somewhat more awkward to prove in the case of semi-rings. However the proofs follow precisely the same lines and semi-ring extension theorem may be more directly applicable.

Proposition 5.8.24 (Continuity of Measures)

Let ℛ︀ be a semi-ring of subsets of Ω and 𝜇:ℛ︀→[0,∞] a countably additive measure. Then for any sequence of sets 𝐴1,𝐴2,…∈ℛ︀ we have

lim𝑛→∞𝜇(⋃𝑖=1𝑛𝐴𝑖)=𝜇(⋃𝑛=1∞𝐴𝑛)

whenever this is well-defined.

Proof. Define the increasing sequence

𝐵𝑛≔⋃𝑖=1𝑛𝐴𝑖

then wish to show

lim𝑛→∞𝜇(𝐵𝑛)=𝜇(⋃𝑛=1∞𝐵𝑛)

By definition we have (with the convention 𝐵0=∅)

𝐵𝑖∖⋃𝑗=1𝑖−1𝐵𝑗=𝐵𝑖∖𝐵𝑖−1=⨆𝑘=1𝑁𝑖𝐶𝑖𝑘𝑖=1,2,…

for 𝐶𝑖𝑘∈ℛ︀ whence

𝐵𝑛=⨆𝑖=1𝑛𝐵𝑖∖𝐵𝑖−1=⨆𝑖=1𝑛⨆𝑘=1𝑁𝑛𝐶𝑖𝑘

for 𝑛=1,2,…,∞. Then by additivity

lim𝑛→∞𝜇(𝐵𝑛)=lim𝑛→∞∑𝑖=1𝑛∑𝑘=1𝑁𝑖𝜇(𝐶𝑖𝑘)=∑𝑖=1∞∑𝑘=1𝑁𝑖𝜇(𝐶𝑖𝑘)

and

𝜇(⋃𝑛=1∞𝐵𝑛)=𝜇(⨆𝑖=1∞⨆𝑘=1𝑁𝑖𝐶𝑖𝑘)=∑𝑖=1∞∑𝑘=1𝑁𝑖𝜇(𝐶𝑖𝑘)

 ∎

Proposition 5.8.25 (Finitely Additive + Countably Subadditive ⟺ Countably Additive)

Let ℛ︀ be a semi-ring of subsets of Ω and 𝜇:ℛ︀→[0,∞] a finitely additive set function. Then

𝜇(⨆𝑖=1∞𝐴𝑖)≥∑𝑖=1∞𝜇(𝐴𝑖)

whenever this is well-defined. In particular 𝜇 is a measure iff it is countably subadditive.

Proof. By (5.8.9).b) we have

∑𝑖=1𝑛𝜇(𝐴𝑖)≤𝜇(⨆𝑖=1∞𝐴𝑖)

and the result follows by taking 𝑛→∞ (5.1.21).

Therefore if 𝜇 is countably subadditive it must also be countably additive. Conversely if 𝜇 is countably additive then we aim to show

𝜇(⋃𝑖=1∞𝐴𝑖)≤∑𝑖=1∞𝜇(𝐴𝑖)

for a not necessarily disjoint sequence 𝐴𝑖∈ℛ︀. By assumption 𝜇 is finitely additive, so by (5.8.9).c)

𝜇(⋃𝑖=1𝑛𝐴𝑖)≤∑𝑖=1𝑛𝜇(𝐴𝑖)≤∑𝑖=1∞𝜇(𝐴𝑖)

Using continuity of measures (5.8.24) we deduce that

𝜇(⋃𝑖=1∞𝐴𝑖)=lim𝑛→∞𝜇(⋃𝑖=1𝑛𝐴𝑖)≤∑𝑖=1∞𝜇(𝐴𝑖)

as required. ∎

5.8.8 Measurable Functions

Definition 5.8.39
