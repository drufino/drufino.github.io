2.2.1 Integers

We suppose the existence of a set ℤ with distinguished elements 0≠1 together with

  • A binary operation

    +:ℤ×ℤ→ℤ

    and an involution

    (−):ℤ→ℤ

    satisfying

    • −0=0
    • −(−𝑥)=𝑥
    • 𝑥=−𝑥⟺𝑥=0
    • 𝑥+0=0=0+𝑥
    • 𝑥+𝑦=𝑦+𝑥
    • (𝑥+𝑦)+𝑧=𝑥+(𝑦+𝑧)
    • 𝑥+(−𝑥)=0=(−𝑥)+𝑥
    • −(𝑥+𝑦)=(−𝑥)+(−𝑦)

  • A subset ℕ such that

    • 0,1∈ℕ
    • 𝑥,𝑦∈ℕ⟹𝑥+𝑦∈ℕ
    • 𝑥∈ℤ⟹(𝑥∈ℕ)∨(−𝑥∈ℕ)
    • 𝑥∈ℕ∧−𝑥∈ℕ⟹𝑥=0

    which also satisfies the principle of induction

  • Let 𝑆⊆ℕ be a set such that

    • 0∈𝑆
    • 𝑥∈𝑆⟹𝑥+1∈𝑆

    then 𝑆=ℕ

It’s possible to use these to show the existence of multiplication

Proposition 2.2.1 (Multiplication exists)

There exists a binary operation

·:ℤ×ℤ→ℤ

such that

  • 𝑥·0=0=0·𝑥
  • 𝑥·1=𝑥=1·𝑥
  • 𝑥𝑦=𝑦𝑥
  • (𝑥𝑦)𝑧=𝑥(𝑦𝑧)
  • 𝑥(𝑦+𝑧)=𝑥𝑦+𝑥𝑧
  • (𝑦+𝑧)𝑥=𝑦𝑥+𝑧𝑥
  • (−𝑥)(𝑦)=−(𝑥𝑦)=𝑥(−𝑦)

We may also show the existence a partial ordering

Proposition 2.2.2 (Order exists)

There exists a relation ≤ on ℤ given by

𝑥≤𝑦⟺𝑦−𝑥∈ℕ

which satisfies

𝑥≤𝑦∨𝑦≤𝑥𝑥≤𝑦∧𝑦≤𝑥⟹𝑥=𝑦

Define 𝑥<𝑦 in the obvious way then it satisfies the usual trichotomy law, namely precisely one of the following holds

𝑥<𝑦,𝑥=𝑦,𝑦<𝑥

and further

  • 𝑧>0 then 𝑥<𝑦⟺𝑥𝑧<𝑦𝑧
  • 𝑧<0 then 𝑥<𝑦⟺𝑦𝑧<𝑥𝑧
  • 𝑦>1 and 𝑥>0 then 𝑥<𝑥𝑦

Finally we can construct an absolute value function

Proposition 2.2.3

There exists an absolute value function

|·|:ℤ→ℕ

such that

|𝑥|={𝑥0<𝑥0𝑥=0−𝑥𝑥<0

It satisfies

  • |𝑥|=0⟺𝑥=0
  • |𝑥|=|𝑦|⟺𝑥=±𝑦
  • |𝑥𝑦|=|𝑥||𝑦|
  • |𝑥+𝑦|≤|𝑥|+|𝑦|

Proposition 2.2.4 (Well-Ordering Principle)
Let 𝑆⊂ℕ be a non-empty subset. Then it contains a minimal element 𝑑.
