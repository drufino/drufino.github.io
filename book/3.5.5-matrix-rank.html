3.5.5 Matrix Rank

Definition 3.5.36 (Column and Row Rank)

Let 𝑘 be a field and 𝐸 an 𝑚×𝑛 a matrix over 𝑘. Consider the canonical vector spaces 𝑘𝑛 and 𝑘𝑚. Then define the column rank of 𝐸 to be

rank𝑘(𝐸̂)

and the row rank of 𝐸 to be

rank𝑘(𝐸𝑡̂)
Proposition 3.5.37 (Row Rank = Column Rank)

Let 𝐸 be a matrix over 𝑘, then row rank and column rank are equal, and denote this by rk(𝐸).

It is also the maximal number of linearly independent rows, or columns, and furthermore rk(𝐸)≤min(𝑚,𝑛).

We say 𝐸 is full rank if rk(𝐸)=min(𝑚,𝑛).

Proof. By (3.3.144) rank𝑘(𝐸̂)=rank𝑘(𝐸̂∨) and by (3.3.121) this equals rank𝑘(𝐸𝑡̂) as required.

The columns (resp. rows) clearly span Im(𝐸̂) (resp. Im(𝐸𝑡̂)). By (3.3.126) there are 𝑟≔rk(𝐸) columns (resp. rows) constituting a basis, and therefore linearly independent. For any other subset of linearly independent columns (resp. rows) we must have the order is less than 𝑟 by (3.3.126). Therefore rk(𝐸) is the maximal number of linearly independent rows or columns. ∎

Proposition 3.5.38 (Criteria for Full Rank Square Matrix)

Let 𝐸 be an 𝑛×𝑛 matrix over a field 𝑘. Then the following are equivalent

  1. 𝐸 is invertible
  2. rk(𝐸)=𝑛 (i.e. 𝐸̂ is surjective or 𝐸 is full-rank)
  3. 𝐸𝑣=0⟹𝑣=0 for all column vectors 𝑣 (i.e. 𝐸̂ is injective).
  4. The columns of 𝐸 are linearly independent
  5. det(𝐸)≠0

Finally 𝐸 is full rank if and only if 𝐸𝑡 is full rank.

Proof. Consider 𝑘𝑛 with canonical basis, then by (3.3.115) 𝐸 is invertible if and only if 𝐸̂ is an isomorphism. By definition rk(𝐸)=rank𝑘(𝐸̂). Furthermore c) is equivalent to 𝐸̂ being injective, and is also equivalent to d). Therefore the equivalence follows from (3.3.137).

Finally it’s clear from either a), b) or e) that this property is self-dual. ∎

Definition 3.5.39 (Minor of a matrix)
Let 𝐸 be an 𝑚×𝑛 matrix, we say a 𝑘-minor (for 𝑘≤min(𝑚,𝑛)) is the determinant of a 𝑘×𝑘 submatrix obtained by deleting 𝑚−𝑘 rows and 𝑛−𝑘 columns.
Proposition 3.5.40 (Criteria for rank)

Let 𝐸 be an 𝑚×𝑛 matrix over 𝑘. Then the following are equivalent

  1. rk(𝐸)≥𝑟
  2. There exists an 𝑟×𝑟 sub-matrix with full rank
  3. There exists a non-zero 𝑟-minor

Proof. We see b) ⟺ c) by (3.5.38) e).

Suppose b) holds, then a-fortiori 𝐸 has 𝑟 linearly independent columns. Therefore by (3.5.37) rk(𝐸)≥𝑟 and a) holds.

Conversely suppose rk(𝐸)≥𝑟 then by (3.5.37) there are certainly 𝑟 linearly independent columns. We consider the 𝑚×𝑟 sub-matrix 𝐸′ consisting of these columns. By (3.5.37) rk(𝐸′)=𝑟 and there are 𝑟 linearly independent rows. Choosing these rows yields an 𝑟×𝑟 submatrix 𝐸″ which has 𝑟 linearly independent rows, and so by (3.5.38) is full rank as required. ∎

Corollary 3.5.41

Let 𝐸 be an 𝑚×𝑛 matrix over 𝑘 and 𝑟 an integer. Then the following are equivalent

  1. rk(𝐸)=𝑟
  2. 𝑟 is the maximal dimension of a full-rank square sub-matrix
  3. 𝑟 is the maximal dimension of a non-zero minor
