3.2 Groups

Definition 3.2.1 (Group)

A group is a monoid (𝐺,⋅) in which every element is invertible.

A group 𝐺 is said to be abelian if the binary operation is commutative. In this case we typically write the group operation additively

𝑔+ℎ
Definition 3.2.2 (Subgroup, Normal Subgroup)

A subgroup 𝐻≤𝐺 is a subset with the following properties

  • 𝑒𝐺∈𝐻
  • 𝑥,𝑦∈𝐻⟹𝑥𝑦∈𝐻
  • 𝑥∈𝐻⟹𝑥−1∈𝐻

A subgroup 𝐻 is said to be normal in 𝐺 if in addition it satisfies

𝑔𝐻𝑔−1≔{𝑔ℎ𝑔−1|𝑔∈𝐺}=𝐻

for all 𝑔∈𝐺. NB it is easily verified that in an abelian group every subgroup is normal.

Proposition 3.2.3 (Subgroup is a group)
Let 𝐻 be a subgroup of (𝐺,⋅) then (𝐻,⋅|𝐻×𝐻) is a group.
Example 3.2.4

Definition 3.2.5

Let (𝐺,⋅) and (𝐻,⋅) be groups. A function 𝜑:𝐺→𝐻 is a group homomorphism if

  • 𝜑(𝑒𝐺)=𝑒𝐻
  • 𝜑(𝑥⋅𝑦)=𝜑(𝑥)⋅𝜑(𝑦)

Define the image of 𝜑 to be

Im(𝜑)={𝜑(𝑔)|𝑔∈𝐺}

and the kernel to be

ker(𝜑)≔{𝑔∈𝐺|𝜑(𝑔)=𝑒𝐻}

It may be verified that Im(𝜑) is a subgroup of 𝐻 and ker(𝜑) is a normal subgroup of 𝐺.

(𝑔𝑛)𝑚=𝑔𝑛𝑚

For 𝑔∈𝐺 define the order of 𝑔 to be 𝑜(𝑔)≔inf{𝑛≥0|𝑔𝑛=𝑒} where inf∅=∞.

We say 𝑔 has finite order if 𝑜(𝑔)≠∞.

The subgroup generated by an element 𝑔∈𝐺 is defined to be ⟨𝑔⟩={𝑔𝑛|𝑛∈ℤ}

It may be shown that when 𝑔 has finite order 𝑛 we have

3.2.1 Cyclic Groups

Definition 3.2.19

A group 𝐺 is said to be cyclic if there is a surjective group homomorphism

equivalently if there is 𝑔∈𝐺 such that ⟨𝑔⟩=𝐺. Such a 𝑔 is called a generator for 𝐺.

  1. By (2.2.6) every subgroup is of the form 𝑑ℤ. Multiplication map [𝑑]:ℤ→𝑑ℤ shows it is itself cyclic.
  2. By the division algorithm (2.2.5) 𝑆 is a complete set. Given 𝑖,𝑗∈𝑆 we note that |𝑖−𝑗|<𝑑. And 𝑖∼𝑑𝑗⟹𝑑∣|𝑖−𝑗|⟹|𝑖−𝑗|=0⟹𝑖=𝑗. Therefore the set 𝑆 consists of distinct coset representatives.
  3. This is clear from the previous step

  4. The first equivalence is clear. By (3.2.12)

    [ℤ:𝑑ℤ]=[ℤ:𝑒ℤ][𝑒ℤ:𝑑ℤ]

    and the result follows.

 ∎

Let 𝑝+𝑞=𝑛 be positive integers. There is a bijection

Sh(𝑝,𝑞)→𝑆𝑛/(𝑆𝑝×𝑆𝑞)

Furthermore #︎Sh(𝑝,𝑞)=(𝑝+𝑞)!𝑝!𝑞!. By a similar argument #︎Sh(𝑝,𝑞,𝑟)=(𝑝+𝑞+𝑟)!𝑝!𝑞!𝑟!.

Proof. Let 𝜎∈𝑆𝑛. Then there exists an order isomorphism 𝑢:[1,𝑝]→𝜎([1,𝑝]) and 𝑣:[1,𝑞]→𝜎([𝑝+1,𝑝+𝑞]). Define 𝜎1(𝑖)≔𝑢−1(𝜎(𝑖)) and 𝜎2(𝑗)≔𝑣−1(𝜎(𝑗+𝑝)). Then we may verify that 𝜎1∈𝑆𝑝, 𝜎2∈𝑆𝑞 and

(𝑢⋆𝑣)∘(𝜎1⋆(𝜎2+𝑝))=𝜎

so the map is surjective.

Suppose 𝜎,𝜎′∈Sh(𝑝,𝑞) are such that

𝜎=𝜎′∘(𝜎1⋆(𝜎2+𝑝))

for 𝜎1∈𝑆𝑝 and 𝜎2∈𝑆𝑞. If 𝜎1≠𝑒 then there exists 1≤𝑖<𝑗≤𝑝 such that 𝜎1(𝑗)<𝜎1(𝑖). Then by monotonicity of 𝜎′ we have 𝜎(𝑗)=𝜎′(𝜎1(𝑗))<𝜎′(𝜎1(𝑖))=𝜎(𝑖), which contradicts monotonicity of 𝜎. So we conclude 𝜎1=𝑒 and similarly 𝜎2=𝑒. Therefore 𝜎=𝜎′, and the map is injective. By the Orbit-Stabilizer theorem we have

#︎Sh(𝑝,𝑞)=#︎𝑆𝑛/#︎(𝑆𝑝×𝑆𝑞)

from which the result follows. ∎

Definition 3.2.42 (Circulant Permutation)

Let 𝑛 be an integer, and write 𝜌𝑛∈𝑆𝑛 for the permutation

{1,…,𝑛}→{2,3,…,𝑛,𝑛+1}

Note that 𝜀(𝜌𝑛)=(−1)𝑛+1.

Proposition 3.2.43 (Symmetry of Shuffling)

Let 𝑝+𝑞=𝑛 be positive integers. Then there is a bijection

Sh(𝑝,𝑞)→Sh(𝑞,𝑝)𝜎→𝜎∘𝜌𝑝+𝑞𝑝

Note that 𝜀(𝜌𝑝+𝑞𝑝)=(−1)𝑝𝑞 by (3.2.42).

Proposition 3.2.44 (Associativity of Shuffling)

The following map is a bijection

𝜋:Sh(𝑝+𝑞,𝑟)×Sh(𝑝,𝑞)→Sh(𝑝,𝑞,𝑟)(𝜎1,𝜎2)→𝜎1∘(𝜎2⋆(1𝑟+𝑝+𝑞))

Similarly so is

𝜋′:Sh(𝑝,𝑞+𝑟)×Sh(𝑞,𝑟)→Sh(𝑝,𝑞,𝑟)(𝜎1,𝜎2)→𝜎1∘(1𝑝⋆(𝜎2+𝑝))

Proof. It is straightforward to verify that 𝜋(𝜎1,𝜎2) is injective and satisfies the ordering properties. Therefore 𝜋 is well-defined and we claim it is surjective.

Given 𝜎∈Sh(𝑝,𝑞,𝑟) let 𝑢:[1,𝑝+𝑞]→𝜎([1,𝑝+𝑞]), 𝑣:[1,𝑟]→𝜎([𝑝+𝑞+1,𝑝+𝑞+𝑟]) be the unique order isomorphisms. Define 𝜎1=𝑢⋆𝑣 and 𝜎2≔𝑢−1∘𝜎|[1,𝑝+𝑞]. We may verify that 𝜎1∈Sh(𝑝+𝑞,𝑟) and 𝜎2∈Sh(𝑝,𝑞), and furthermore that 𝜋(𝜎1,𝜎2)=𝜎. By counting 𝜋 is injective.

For the second case let 𝑢:[1,𝑝]→𝜎([1,𝑝]), 𝑣:[1,𝑞+𝑟]→𝜎([𝑝+1,𝑝+𝑞+𝑟]) be the unique order isomorphisms. Define 𝜎1=𝑢⋆𝑣 and 𝜎2(𝑗)≔𝑣−1(𝜎(𝑗+𝑝)). The verification follows as before. ∎

3.2.5 Totally Ordered Abelian Group

Definition 3.2.45 (Ordered Abelian Group)

An abelian group (𝐺,+) together with a total order ≤ is an ordered abelian group if it satisfies

𝑥≤𝑦⟹𝑥+𝑧≤𝑦+𝑧∀𝑥,𝑦,𝑧∈𝐺

Define 𝐺+≔{𝑔∈𝐺|(0≤𝑔)∧(𝑔≠0)} and 𝐺−≔{𝑔∈𝐺|(𝑔≤0)∧(𝑔≠0)}.
