3.6.3 Ideals

Recall the notion of extended and contracted ideals in Definition (3.3.48).

Definition 3.6.17 (Localisation of an ideal)

Let 𝐴 be a ring and 𝑆 a multiplicative set and 𝔞◃𝐴 define

𝑆−1𝔞≔{𝑎𝑠|𝑎∈𝔞}

then this is an ideal of 𝑆−1𝐴.

Proposition 3.6.18 (Extension and Contraction)

Let 𝐴 be a ring with multiplicative set 𝑆 and canonical morphism 𝑖𝑆:𝐴→𝑆−1𝐴.

  1. 𝔞𝑒=𝑖𝑆(𝔞)𝑆−1𝐴={𝑎𝑠|𝑎∈𝔞,𝑠∈𝑆}=𝑆−1𝔞

  2. 𝔟𝑐={𝑎|𝑎1∈𝔟}

  3. An ideal 𝔞 in 𝐴 satisfies

    𝔞ec=⋃𝑠∈𝑆(𝔞:𝑠)={𝑎∈𝐴|𝑎𝑠∈𝔞some𝑠∈𝑆}

    In particular 𝔞 is contracted if and only if 𝑎𝑠∈𝔞∧𝑠∈𝑆⟹𝑎∈𝔞

  4. 𝔟proper⟺𝔟𝑐proper⟺𝔟𝑐∩𝑆=∅

  5. 𝔞𝑒proper⟺𝔞∩𝑆=∅

  6. Every ideal 𝔟◃𝑆−1𝐴 is extended (equiv. 𝔟=𝔟ce=𝑆−1𝔟𝑐).

  7. A prime ideal 𝔭 is contracted if and only if 𝔭∩𝑆=∅. In this case 𝔭𝑒 is prime.

  8. 𝔮prime⟹𝔮𝑐 is prime and satisfies 𝔮𝑐∩𝑆=∅.

Proof.

  1. 𝑆−1𝔞 is an additive subgroup because 𝑎1𝑠1+𝑎2𝑠2=𝑎1𝑠2+𝑎2𝑠1𝑠1𝑠2. It contains 𝑖𝑆(𝔞) and is closed under multiplication by 𝐴, therefore 𝔞𝑒⊆𝑆−1𝔞. Similarly as 𝔞𝑒 is an ideal containing 𝑖𝑆(𝔞), we have 𝑎𝑠=1𝑠⋅𝑎1∈𝔞𝑒, i.e. 𝑆−1𝔞⊆𝔞𝑒 as required.

  2. This is clear

  3. Observe that

    𝔞ec={𝑎∈𝐴|𝑎1∈𝔞𝑒}={𝑎∈𝐴|𝑎1=𝑎′𝑠𝑎′∈𝔞𝑠∈𝑆}={𝑎∈𝐴|𝑠𝑎∈𝔞some𝑠∈𝑆}

    By (3.3.49) an ideal 𝔞 is contracted if and only if 𝔞=𝔞ec. Furthermore it always satisfies 𝔞ec⊆𝔞. The reverse inclusion is precisely the condition given.

  4. This first equivalence is true in general, see (3.3.49). Clearly 𝔟𝑐=𝐴⟹𝔟𝑐∩𝑆≠∅. Similarly if 𝑆∩𝔟𝑐≠∅ then 𝑠∈𝔟𝑐⟹𝑠1∈𝔟⟹1∈𝔟⟹1∈𝔟𝑐.

  5. By d) 𝔞𝑒 is proper if and only if 𝔞ec is proper. By c) we see 1∈𝔞ec if and only if 𝑆∩𝔞≠∅ and the result follows.

  6. By (3.3.49) we need only show 𝔟ce⊆𝔟. Note 𝑎𝑠∈𝔟ce⟹𝑎𝑠=𝑎′𝑠′ with 𝑎′∈𝔟𝑐. By 2. 𝑎′1∈𝔟 and therefore so is 𝑎𝑠=𝑎′𝑠′=𝑎′1⋅1𝑠′∈𝔟 as required.

  7. If 𝔭∩𝑆=∅ then by primality it automatically satisfies the conditions in c) and is therefore contracted. Conversely if a prime ideal 𝔭 is contracted then 𝔭=𝔮𝑐. It is by definition proper so by d) it satisfies 𝔭∩𝑆=∅ as required.

    Suppose 𝔭 is prime and 𝑎𝑠⋅𝑏𝑡∈𝔭𝑒 then 𝑎𝑏𝑠𝑡=𝑥𝑢 for 𝑥∈𝔭⟹𝑣(𝑎𝑏𝑢−𝑥𝑠𝑡)=0⟹𝑢𝑣𝑎𝑏∈𝔭⟹𝑎∈𝔭or𝑏∈𝔭. Therefore 𝑎𝑠∈𝔭𝑒 or 𝑏𝑡∈𝔭𝑒 as required.

  8. Generically 𝔮𝑐 is a contracted prime ideal and we’ve already shown in d) that 𝔮𝑐∩𝑆=∅.

 ∎

Corollary 3.6.19 (Ideal Structure Localisation)

Let 𝐴 be a ring and 𝑆 a multiplicative set then there is an order-preserving bijection of proper ideals

{𝔞◃𝐴|𝔞contracted}↔{𝔟◃𝑆−1𝐴}

which restricts to a bijection of prime ideals

{𝔭◃𝐴|𝔭∩𝑆=∅}↔{𝔮◃𝑆−1𝐴}
Proof. From (3.6.18) every ideal of 𝑆−1𝐴 is extended. Therefore the bijection of proper ideals follows from (3.3.52). For prime ideals each direction is well-defined by (3.6.18) g). ∎
