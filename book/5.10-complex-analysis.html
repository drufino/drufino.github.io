5.10.2 Holomorphic Functions

Definition 5.10.3 (Holomorphic Function)

Let 𝑈⊂ℂ be an open subset and 𝑓:𝑈→ℂ a function. Then we say that 𝑓 is holomorphic if it is infinitely (complex) differentiable (5.10.2). For a holomorphic function every derivative is automatically continuous (5.5.3).

If 𝑓 is injective and 𝑓(𝑈) is open we say that 𝑓 is biholomorphic if its inverse is also holomorphic. A biholomorphic functions is a homeomorphism onto its image (5.5.3).

Trivially if 𝑓 is holomorphic then so is 𝑓|𝑉 for any open subset 𝑉⊂𝑈. Conversely if 𝑈=⋃𝛼∈𝒜︀𝑉𝛼 and 𝑓|𝑉𝛼 are holomorphic for all 𝛼∈𝒜︀, then so is 𝑓.

Proposition 5.10.4

Let 𝑈⊂ℂ be an open subset. Then the set of holomorphic functions on 𝑈 forms a ℂ-algebra.

For 𝑓:𝑈→ℂ non-constant then 𝐷(𝑓)≔{𝑥∈𝑈|𝑓(𝑥)≠0} is an open subset and (𝑓|𝐷(𝑓))−1 is a holomorphic function.

Proof. This follows from (5.5.4), provided we show that 𝐷(𝑓) is open. For ℂ is Hausdorff (5.4.5) so {0} is closed (4.1.48). Therefore by (4.1.27) 𝐷(𝑓)=𝑈∖𝑓−1({0}) is open. ∎
