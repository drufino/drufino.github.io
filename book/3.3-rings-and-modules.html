3.3 Rings and Modules

3.3.1 Commutative Rings

Definition 3.3.1 (Ring)

A ring consists of a triple (𝐴, +, ⋅) where 𝐴 is a set and + and ⋅ are laws of composition (“additive” and “multiplicative” respectively) such that the following holds

  • (𝐴,+) is an abelian group, whose identity element we refer to as 0𝐴.
  • (𝐴,⋅) is a monoid, whose identity element we refer to as 1𝐴

  • + and ⋅ satisfy the distributive property, that is for all 𝑥,𝑦,𝑧∈𝐴

    𝑥⋅(𝑦+𝑧)=𝑥⋅𝑦+𝑥⋅𝑧(𝑥+𝑦)⋅𝑧=𝑥⋅𝑧+𝑦⋅𝑧

For 𝑥∈𝐴 we write the additive inverse as −𝑥, and abbreviate multiplication 𝑥⋅𝑦≕𝑥𝑦.

We say that 𝐴 is a zero-ring (or trivial) if 0𝐴=1𝐴⟺𝐴={0}.

𝐴 is commutative if in addition 𝑥𝑦=𝑦𝑥 i.e. (𝐴,⋅) is abelian.

Example 3.3.2
The set of integers ℤ (see the Integers subsection) is the canonical example of a ring with operations of addition and multiplication.
Definition 3.3.3 (Subring)

A subring of a ring 𝐴 is a subset 𝐵 such that

  • 0𝐴,1𝐴∈𝐵
  • 𝑥∈𝐵⟹−𝑥∈𝐵
  • 𝑥,𝑦∈𝐵⟹𝑥+𝑦∈𝐵
  • 𝑥,𝑦∈𝐵⟹𝑥⋅𝑦∈𝐵

Then (𝐵,+|𝐵×𝐵,⋅|𝐵×𝐵) is a ring.

Definition 3.3.4 (Multiplicative set)

A subset 𝑆⊂𝐴 is said to be multiplicative if

  • 1∈𝑆
  • 𝑥,𝑦∈𝑆⟹𝑥𝑦∈𝑆

Further it is said to be saturated if in addition

𝑥,𝑦∈𝑆⟺𝑥𝑦∈𝑆
Definition 3.3.5 (Integral Domain)

A commutative ring 𝐴 is said to be an integral domain if it is not a zero-ring and it is cancellative, that is

𝑎𝑏=𝑎𝑐,𝑎≠0⟹𝑏=𝑐.
Definition 3.3.6 (Reduced)

A commutative ring 𝐴 is said to be reduced if for all 𝑎∈𝐴

𝑎𝑛=0⟹𝑎=0
Definition 3.3.7 (Unit / Group of Units)

An element 0≠𝑎 of a ring 𝐴 is called a unit if it has a two-sided multiplicative inverse.

For 𝐴 not a zero-ring, the set of units 𝐴⋆ forms a group under multiplication, called the group of units.

Definition 3.3.8 (Field)
A field 𝐾 is a commutative non-zero ring such that every non-zero element is a unit, so that 𝐾⋆ is a group under multiplication and 𝐾⋆=𝐾∖{0}.
Proposition 3.3.9
Every subring of a field 𝐾 is an integral domain.
Proof. Suppose 𝐴⊂𝐾 is a subring. Suppose that 𝑎,𝑏∈𝐴 such that 𝑎𝑏=0. Suppose 𝑎≠0 then 𝑎−1𝑎𝑏=0⟹𝑏=0. ∎

Definition 3.3.11 (Ring homomorphism)

A ring homomorphism 𝜑:𝐴→𝐵 is a mapping which is both a multiplicative (monoid) and additive (group) homomorphism

  • 𝜑(0𝐴)=0𝐵
  • 𝜑(1𝐵)=1𝐵
  • 𝜑(𝑥+𝑦)=𝜑(𝑥)+𝜑(𝑦)
  • 𝜑(𝑥𝑦)=𝜑(𝑥)𝜑(𝑦)

The kernel of 𝜑 is defined to be

ker(𝜑)={𝑎|𝜑(𝑎)=0𝐵}
Definition 3.3.12 (Ideal)

A (two-sided) ideal 𝔞 of a ring 𝐴 is a subset of 𝐴 which is an additive subgroup and closed under multiplication by 𝐴 :

  • 0𝐴∈𝔞
  • 𝑥,𝑦∈𝔞⟹𝑥+𝑦∈𝔞
  • 𝑥∈𝔞⟹−𝑥∈𝔞
  • 𝑥∈𝔞,𝑎∈𝐴⟹𝑎𝑥,𝑥𝑎∈𝔞

𝔞 is said to be proper if 𝔞≠𝐴.

Lemma 3.3.13 (Proper ideal)

An ideal 𝔞 is proper if and only if 1∉𝔞 if and only if 𝔞∩𝐴⋆=∅.

Alternatively 𝔞=𝐴 if and only if 1∈𝔞 if and only if 𝔞∩𝐴⋆≠∅.

Proposition 3.3.14

Let 𝜑:𝐴→𝐵 be a ring homomorphism, then

  1. The kernel ker(𝜑) is a two-sided ideal of 𝐴
  2. The image 𝜑(𝐴) is a subring of 𝐵
  3. 𝜑 is injective if and only if ker(𝜑)={0}
Proposition 3.3.15 (Krull's Theorem)

Let 𝐴 be a ring and 𝔞 a proper ideal. Then it is contained in a proper maximal ideal 𝔪.

In particular any non-unit 𝑎∉𝐴⋆ is contained in a maximal ideal.

Proposition 3.3.16 (Criteria to be a Field)

Let 𝐴 be a ring. Then the following are equivalent

  1. 𝐴 is a field
  2. 𝐴 is not the zero-ring and the only proper ideal is {0}.

Proof. a) ⟹ b). By definition 𝐴 is not the zero-ring. Let 𝔞 be a proper ideal. By (3.3.13) 𝔞∩𝐴⋆=∅⟹𝔞={0} as required.

b) ⟹ a). Suppose 0≠𝑎∈𝐴 then the ideal 𝐴𝑎=(𝑎) is either {0} or 𝐴. However 𝑎=1⋅𝑎∈(𝑎) which implies (𝑎)≠{0} and therefore (𝑎)=𝐴. In particular there exists 𝑎−1∈𝐴 such that 𝑎−1𝑎=1𝐴 and 𝑎 is invertible. ∎

3.3.2 Modules I

Definition 3.3.17 (Module)

Let 𝐴 be a ring. A left 𝐴-module (𝑀,+,⋅) is an abelian group (𝑀,+) together with a “multiplication” operation

⋅:𝐴×𝑀→𝑀

which satisfies the following properties

  • (𝑎×𝐴𝑎′)⋅𝑥=𝑎⋅(𝑎′⋅𝑥)
  • (𝑎+𝐴𝑎′)⋅𝑥=𝑎⋅𝑥+𝑎′⋅𝑥
  • 𝑎⋅(𝑥+𝑦)=𝑎⋅𝑥+𝑎⋅𝑦

Similarly a right 𝐴-module (𝑀,+,⋅) is an abelian group (𝑀,+) together with a multiplication operation

⋅:𝑀×𝐴→𝑀
  • (𝑎×𝐴𝑎′)⋅𝑥=(𝑥⋅𝑎′)×𝐴𝑎
  • (𝑎+𝐴𝑎′)⋅𝑥=𝑎⋅𝑥+𝑎′⋅𝑥
  • 𝑎⋅(𝑥+𝑦)=𝑎⋅𝑥+𝑎⋅𝑦

Considering the first property 𝑀 is a left 𝐴-module iff it is a right 𝐴op module in the obvious way. Therefore in the usual case that 𝐴 is commutative the concepts coincide and we may speak simply of an 𝐴-module, though we almost always write the action on the left.

Similarly almost all results for left 𝐴-modules carry over unchanged for right 𝐴-modules. In this case we may simply by refer to 𝐴-modules rather than state the result for both cases separately.

Definition 3.3.18 (Submodule)

Let (𝑀,+,⋅) be a left 𝐴-module. Then a subset 𝑁⊂𝑀 is called an 𝐴-submodule if

  • 𝑁 is a subgroup of (𝑀,+)
  • 𝑚∈𝑁,𝑎∈𝐴⟹𝑎𝑚∈𝑁

Then (𝑁,+|𝑁×𝑁,⋅|𝐴×𝑁) is a left 𝐴-module. Similar definition applies for a right 𝐴-module.

Definition 3.3.19 (Module homomorphism)

Let (𝑀,+,⋅),(𝑁,+,⋅) be left 𝐴-modules. A function 𝑓:𝑀→𝑁 is an 𝐴-module homomorphism if

  • It is an (additive) group homomorphism (𝑀,+)→(𝑁,+).
  • It is 𝐴-linear; ∀𝑎∈𝐴,𝑚∈𝑀𝑓(𝑎⋅𝑚)=𝑎⋅𝑓(𝑚)

It may be verified that 𝑓 is bijective if and only if it’s an isomorphism. In this way we have the following categories

  • 𝐴-𝐌𝐨𝐝 the category of modules over a commutative ring 𝐴
  • 𝐌𝐨𝐝𝐴 the category of left 𝐴-modules
  • 𝐌𝐨𝐝𝐴 the category if right 𝐴-modules
Definition 3.3.20 (Kernel and Image)

The kernel of a module homomorphism 𝑓 is given by

ker(𝑓)≔{𝑚∈𝑀|𝑓(𝑚)=0}

and the image is given by

Im(𝑓)=𝑓(𝑀)
Example 3.3.21 (Trivial Examples)
A ring 𝐴 is a left 𝐴-module over itself, denoted 𝐴𝑠.

For this section we assume 𝐴 is a commutative ring.

Let 𝐴 be a ring and ℐ︀(𝐴) the set of ideals. Then ℐ︀(𝐴) forms a complete lattice ordered by inclusion with join and meets given by

The product of two ideals 𝔞𝔟 is

Definition 3.3.30 (Coprime)

We say two elements 𝑥,𝑦 of a commutative ring 𝐴 are co-prime if (𝑥,𝑦)=(1)⟺𝑎𝑥+𝑏𝑦=1 for some 𝑎,𝑏∈𝐴

(𝑎)≔⟨{𝑎}⟩=𝐴𝑎

A principal ideal (𝑎) is proper if and only if 𝑎∉𝐴⋆
Definition 3.3.33 (Maximal Ideal)
An ideal 𝔪◃𝐴 is maximal if it is both proper and not contained in another proper ideal.
Definition 3.3.34 (Prime Ideal)

An ideal 𝔭◃𝐴 is prime if it is both proper and satisfies the following property

𝑥𝑦∈𝔭⟹𝑥∈𝔭∨𝑦∈𝔭

An ideal 𝔞◃𝐴 is radical if it satisfies the following property

𝑥𝑛∈𝔞⟹𝑥∈𝔞
Proposition 3.3.36 (Maximal ideals exist)

Let 𝐴 be a ring and 𝔞◃𝐴 a proper ideal. Then it is contained in some maximal ideal 𝔪.

In particular there always exists a maximal ideal by considering 𝔞=(0).

Proof. Simple application of Zorn’s Lemma. ∎
Proposition 3.3.37 (Properties of prime ideals)

Let 𝔭 be a prime ideal and 𝔞, 𝔟 be ideals then the following are equivalent

  1. 𝔞⊆𝔭or𝔟⊆𝔭
  2. 𝔞∩𝔟⊆𝔭
  3. 𝔞𝔟⊆𝔭

Proof. a) ⟹ b) Follows because 𝔞∩𝔟⊆𝔞

b) ⟹ c) Follows because 𝔞𝔟⊆𝔞∩𝔟

c) ⟹ a) If 𝔞⊈𝔭, then choose 𝑎∈𝔞∖𝔭. By hypothesis 𝑎𝔟⊆𝔭 and since 𝔭 is prime 𝔟⊆𝔭. ∎

Corollary 3.3.38 (Ideal version of primality)

Let 𝔭 be a proper ideal. Then 𝔭 is prime if and only if the following condition holds for all ideals 𝔞, 𝔟

𝔞𝔟⊆𝔭⟹𝔞⊆𝔭or𝔟⊆𝔭

In particular for all 𝑘>0 we have

𝔞⊆𝔭⟺𝔞𝑘⊆𝔭
Proof. One direction has been shown in (3.3.37). Conversely suppose 𝑓𝑔∈𝔭 then apply the condition to the ideals (𝑓) and (𝑔) we find 𝑓∈𝔭 or 𝑔∈𝔭. ∎
Lemma 3.3.39 (Prime ideals are meet-prime)

Let 𝔭 be a prime ideal. Then

⋂𝑖=1𝑛𝔞𝑖⊆𝔭⟹𝔞𝑖⊆𝔭some𝑖=1…𝑛

in other words 𝔭 is meet-prime in the lattice of ideals.

Proof. Suppose 𝔞𝑖⊈𝔭 for all 𝑖 then there exists 𝑥𝑖∈𝔞𝑖∖𝔭. Then 𝑥1…𝑥𝑛∈⋂𝑖=1𝑛𝔞𝑖⊆𝔭 by hypothesis, so by primality 𝑥𝑖∈𝔭 for some 𝑖, a contradiction. ∎
Lemma 3.3.40 (Generate prime ideals)

Let 𝐴 be a ring, 𝑆 a multiplicative set and 𝔟◃𝐴 such that 𝔟∩𝑆=∅ then

ℐ︀={𝔞|𝔟⊆𝔞𝔞∩𝑆=∅}

has a maximal element, which is prime.

Proof. Since 𝔟∈ℐ︀ it is non-empty. By Zorn’s Lemma it has a maximal element, 𝔭. We claim it is prime, for suppose 𝑥𝑦∈𝔭 and 𝑥,𝑦∉𝔭. Then by maximality 𝔭+(𝑥) and 𝔭+(𝑦) intersect 𝑆. Therefore 𝑆 intersects (𝔭+(𝑥))(𝔭+(𝑦))⊆𝔭, a contradiction. ∎
Definition 3.3.41 (Minimal prime)

Let 𝐴 be a ring and 𝔞◃𝐴 a proper ideal. A prime ideal 𝔭 is a minimal prime over 𝔞 if it contains 𝔞, and every other such prime ideal contains 𝔭.

We say it is simply a minimal prime if it is minimal over (0).

Proposition 3.3.42 (Prime ideals are chain complete)
Let {𝔭𝑖}𝑖∈𝐼 be a chain of prime ideals, then ⋂𝑖𝔭𝑖 and ⋃𝑖𝔭𝑖 are prime ideals.
Proof. By (3.3.36) ⋃𝑖𝔭𝑖 is an ideal, and it’s easily verified to be prime. Clearly ⋂𝑖𝔭𝑖 is an ideal. Suppose 𝑎,𝑏∉⋂𝑖𝔭𝑖 then 𝑎∉𝔭𝑗 and 𝑏∉𝔭𝑘 with 𝑗≤𝑘. Then 𝑏∉𝔭𝑗, and 𝑎𝑏∉𝔭𝑗 by primality, whence 𝑎𝑏∉⋂𝑖𝔭𝑖. ∎
Corollary 3.3.43 (Minimal primes exist)

Let 𝐴 be a ring and 𝔞◃𝐴 be a proper ideal contained in a prime ideal 𝔭. Then there exists a minimal prime over 𝔞 contained in 𝔭.

In particular there always exists a minimal prime over 𝔞 and every prime ideal contains a minimal prime ideal.

Proof. We may use (3.3.42) together with Zorn’s Lemma. ∎
Proposition 3.3.44

𝔞≔⋂𝔞⊆𝔯𝔯={𝑥|𝑥𝑛∈𝔞𝑛>0}

⋁𝑖∈𝐼𝔞𝑖=∑𝑖𝔞𝑖

  1. 𝔞⊆𝔞
  2. 𝔞⊆𝔟⟹𝔞⊆𝔟

Proof. The set of radical ideals is closed under arbitrary intersections (which are meets in the lattice ℐ︀(𝐴)). Therefore by (2.1.41) it forms a complete sub-lattice with meet given by intersection of ideals.

It also shows that − as defined is a closure operator with image Rad(𝐴), which demonstrates the required properties.

Finally we just need to show that 𝐼′≔{𝑥|𝑥𝑛∈𝔞𝑛>0} is equal to 𝔞. Firstly it’s an ideal for if 𝑥,𝑦∈𝐼′ then 𝑥𝑛∈𝔞 and 𝑦𝑚∈𝔞, so we may show that (𝑥+𝑦)𝑛+𝑚∈𝔞 whence 𝑥+𝑦∈𝐼′. Let 𝔯 be another radical ideal containing 𝔞 then 𝑥∈𝐼′⟹𝑥𝑛∈𝔞⟹𝑥𝑛∈𝔯⟹𝑥∈𝔯. Therefore the reverse inclusion follows. ∎

Let 𝜑:𝑉→𝑊 be a linear map and 𝜑∨:𝑊∨→𝑉∨ then

ker(𝜑∨)=Im(𝜑)∘Im(𝜑∨)⊆ker(𝜑)∘
