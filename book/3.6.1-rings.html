3.6.1 Rings

Definition 3.6.3 (Localisation of a ring)

Let 𝐴 be a ring and 𝑆 a multiplicative set. Define the set

𝑆−1𝐴={𝑎𝑠|𝑎∈𝐴𝑠∈𝑆}

under the equivalence relation

𝑎𝑠=𝑏𝑡⟺𝑢(𝑎𝑡−𝑏𝑠)=0some𝑢∈𝑆.

then this is a ring in the obvious way

Proposition 3.6.4

The set 𝑆−1𝐴 is a ring under the obvious ring operations. It is non-zero precisely when 𝑆 is proper. There is a canonical homomorphism

𝑖𝑆:𝐴→𝑆−1𝐴𝑎→[𝑎1]
  1. ker(𝑖𝑆)=Ann(𝑆)
  2. 𝑆−1𝐴 is the zero-ring if and only if 0∈𝑆 if and only if there exists 𝑠,𝑡∈𝑆 such that 𝑠𝑡=0.
  3. 𝑖𝑆(𝑠) is invertible for all 𝑠∈𝑠
  4. 𝑖𝑆 is injective if and only if 𝑆 has no zero-divisors
  5. This is an isomorphism if and only if 𝑆⊆𝐴⋆ already consists only of invertible elements (e.g. 𝑆={1}).

Proof.

  1. This follows by the definitions
  2. 11=00⟺𝑠=0 for some 𝑠∈𝑠 by the definitions
  3. 𝑠1⋅1𝑠=𝑠𝑠=11
  4. This follows from the first part.
  5. If 𝑆⊆𝐴⋆ then it contains no zero-divisors and 𝑖𝑆 is injective. Further it’s clear that 𝑎𝑠=𝑎𝑠−11 so that the map is surjective. Similarly if the map is bijective 𝑆 does not contain zero-divisors and 1𝑠 is in the image. Therefore there is 𝑎 such that 𝑡𝑎𝑠=1 for some 𝑡, which implies 𝑠 is invertible.

 ∎

Note when 𝐴 is an integral domain and 𝑆 is proper then the equivalence relation may be weakened to 𝑎𝑡−𝑏𝑠=0.

Proposition 3.6.5 (Universal Property)

Let 𝜙:𝐴→𝐵 be a ring homomorphism and 𝑆 a multiplicative set. Then

  1. There is a unique morphism 𝜙̃ making the diagram commute

    if and only if 𝜙(𝑆)⊆𝐵⋆. In this case it’s given by

    𝜙̃(𝑎𝑠)=𝜙(𝑎)𝜙(𝑠)−1

  2. ker(𝜙̃)=𝑆−1ker(𝜙)

Proof.

  1. If 𝜙̃ exists then 1=𝜙̃(1)=𝜙̃(𝑠1⋅1𝑠)=𝜙̃(𝑠1)𝜙̃(1𝑠)=𝜙(𝑠)𝜙̃(1𝑠). Which shows that 𝜙(𝑆)⊆𝐵⋆ and 𝜙(𝑠)−1=𝜙̃(1𝑠).

    Conversely suppose 𝜙(𝑆)⊆𝐵⋆ then we claim that the given mapping is well-defined. For

    𝑎𝑠=𝑎′𝑠′⟹𝑠″(𝑠′𝑎−𝑠𝑎′)=0⟹𝜙(𝑠″)𝜙(𝑠′)𝜙(𝑎)=𝜙(𝑠″)𝜙(𝑠)𝜙(𝑎′)

    Multiply by the appropriate inverses to find

    𝜙(𝑎)𝜙(𝑠)−1=𝜙(𝑎′)𝜙(𝑠′)−1

    It’s clearly a multiplicative homomorphism. Further it’s additive because

    𝜙̃(𝑎𝑠+𝑏𝑡)=𝜙̃(𝑎𝑡+𝑏𝑠𝑠𝑡)=𝜙(𝑎𝑡+𝑏𝑠)𝜙(𝑠𝑡)−1=𝜙(𝑎)𝜙(𝑡)𝜙(𝑠)−1𝜙(𝑡)−1+𝜙(𝑏)𝜙(𝑠)𝜙(𝑠)−1𝜙(𝑡)−1=𝜙(𝑎)𝜙(𝑠)−1+𝜙(𝑏)𝜙(𝑡)−1=𝜙̃(𝑎𝑠)+𝜙̃(𝑏𝑡)

  2. Suppose 𝜙̃(𝑎𝑠)=0 then clearly 𝑎∈ker(𝜙)⟹𝑎𝑠∈𝑆−1ker(𝜙). The converse is clear.

 ∎

In the case that 𝐴 is an integral domain then generally everything becomes a lot simpler.

Example 3.6.6 (Quotient Field)

Let 𝐴 be an integral domain then 𝐴∖0=𝐴⋆ and we define the quotient field

Frac(𝐴)≔(𝐴∖0)−1𝐴
Proposition 3.6.7 (Quotient Field contains all localisation)

Let 𝐴 be an integral domain, and Frac(𝐴) the quotient field. Define another model for 𝑆−1𝐴 as follows

𝑆−1𝐴≔{𝑎𝑠∈Frac(𝐴)|𝑎∈𝐴𝑠∈𝑆}

The canonical map 𝐴→𝑆−1𝐴⊂Frac(𝐴) is injective, and satisfies the universal property for localisation.

Proof. It’s injective because 𝐴 has no zero-divisors. That it satisfies the universal property is very similar as before. ∎
Proposition 3.6.8 (Directed Limit)

Let 𝑆𝑖 be a family of multiplicatively closed sets directed by inclusion, such that 𝑆=⋃𝑖𝑆𝑖 is multiplicatively closed. Then there is a canonical isomorphism

lim⟶𝑖𝑆𝑖−1𝐴→𝑆−1𝐴

induced by the canonical maps

𝑆𝑖−1𝐴→𝑆−1𝐴

Proof. The canonical maps 𝑖𝑆𝑖𝑆 induce a unique morphism

lim⟶𝑖𝑆𝑖−1𝐴→𝑆−1𝐴[𝑎𝑖/𝑠𝑖]→𝑎𝑖/𝑠𝑖

by the universal property. An element on the right hand side is written 𝑎/𝑠 for some 𝑠∈𝑆. By hypothesis 𝑠∈𝑆𝑖 for some 𝑖, therefore it is surjective. Suppose we have two elements [𝑎𝑖/𝑠𝑖] and [𝑎𝑗/𝑠𝑗] on the left hand side which become equal in 𝑆−1𝐴. Then by definition 𝑠𝑘(𝑠𝑗𝑎𝑖−𝑎𝑗𝑠𝑖)=0 for some 𝑠𝑘∈𝑆𝑘. Since it’s a directed system we can find 𝑆𝑙 containing 𝑆𝑖,𝑆𝑗,𝑆𝑘. Then by definition 𝑎𝑖/𝑠𝑖=𝑎𝑗/𝑠𝑗 in 𝑆𝑙−1𝐴 and we see that [𝑎𝑖/𝑠𝑖]=[𝑎𝑗/𝑠𝑗]. Therefore the given morphism is also injective as required. ∎

Lemma 3.6.9 (Localisation Respects Contraction of Multiplicative Sets)

Let 𝐴⊆𝐵 be subrings of a common ring 𝐶, and 𝑇⊂𝐵 a multiplicative set. Writing 𝑆≔𝑇∩𝐴 (a multiplicative set of 𝐴), and realising both localisations as subrings of 𝐶 (or of a common ring of fractions), 𝑆−1𝐴⊆𝑇−1𝐵.

In particular, for 𝔮 a prime ideal of 𝐵 and 𝔭≔𝔮∩𝐴, taking 𝑇≔𝐵∖𝔮 (so 𝑆=𝐴∖𝔭) gives 𝐴𝔭⊆𝐵𝔮.

Proof. For 𝑎/𝑠∈𝑆−1𝐴 (𝑎∈𝐴, 𝑠∈𝑆⊆𝑇), viewing 𝑎,𝑠∈𝐵 (as 𝐴⊆𝐵), 𝑠∈𝑇 directly gives 𝑎/𝑠∈𝑇−1𝐵. ∎

Combining the previous two results, for a directed union of subrings rather than a single fixed ring:

Lemma 3.6.10 (Localisation Commutes with Directed Unions of Subrings)

Let (𝐴𝑖)𝑖∈𝐼 be a directed system of subrings of a common ring 𝐶, with union 𝐴≔⋃𝑖𝐴𝑖, and 𝑇⊂𝐴 a multiplicative set. Writing 𝑇𝑖≔𝑇∩𝐴𝑖, and realising all localisations as subrings of 𝐶 (or of a common ring of fractions),

𝑇−1𝐴=⋃𝑖𝑇𝑖−1𝐴𝑖

In particular, for 𝔭◃𝐴 a prime ideal and 𝔭𝑖≔𝔭∩𝐴𝑖, taking 𝑇≔𝐴∖𝔭 (so 𝑇𝑖=𝐴𝑖∖𝔭𝑖) gives 𝐴𝔭=⋃𝑖(𝐴𝑖)𝔭𝑖.

Proof. If 𝑎/𝑠∈𝑇−1𝐴 (𝑎∈𝐴, 𝑠∈𝑇), then 𝑎,𝑠∈𝐴𝑖 for some 𝑖 (directed union), with 𝑠∈𝑇∩𝐴𝑖=𝑇𝑖, so 𝑎/𝑠∈𝑇𝑖−1𝐴𝑖. Conversely if 𝑎/𝑠∈𝑇𝑖−1𝐴𝑖 (𝑎,𝑠∈𝐴𝑖, 𝑠∈𝑇𝑖⊆𝑇), then viewing 𝑎,𝑠∈𝐴𝑖⊂𝐴, 𝑠∈𝑇, so 𝑎/𝑠∈𝑇−1𝐴. ∎
