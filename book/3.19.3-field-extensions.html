Definition 3.19.12 (Field Extension)

Let 𝑘 be a field. A field extension 𝐾/𝑘 is a 𝑘-algebra 𝐾 which is also a field. Every field 𝐾 is an extension over its prime subfield (or, over ℚ or 𝔽𝑝).

We typically denote the structural morphism by 𝑖𝑘𝐾:𝑘→𝐾, and it is automatically injective (3.3.60). We may write (𝐾/𝑘,𝑖𝑘𝐾) if we need to stress the relevance of the structural morphism to the argument.

These objects form a category 𝐅𝐢𝐞𝐥𝐝𝑘 in the obvious way. The morphisms may be called 𝑘-embeddings and we denote them by

Mor𝑘(𝐾,𝐿)≔{𝜓:𝐾→𝐿|𝜓∘𝑖𝑘𝐾=𝑖𝑘𝐿}

and the set of automorphisms by

Observe every extension 𝐾/𝑘 may be viewed as a 𝑘-vector space so we define the degree of an extension field to be the vector space dimension

Definition 3.19.32 (Simple (Algebraic) Extension)
A field extension 𝐾/𝑘 is simple if 𝐾=𝑘({𝛼})≕𝑘(𝛼) for some 𝛼∈𝐾. It is a simple algebraic extension if 𝛼 is also algebraic over 𝑘.
Definition 3.19.33 (Algebraic Element)

We say an element 𝛼∈𝐾/𝑘 is algebraic if it is a root of a polynomial 𝑓∈𝑘[𝑋] (i.e. 𝛼 is integral, since we can always ensure 𝑓 is monic). Otherwise we say that 𝑥∈𝐾 is transcendental.

We say 𝐾/𝑘 is an algebraic extension if every element 𝛼∈𝐾 is algebraic over 𝑘.

Proposition 3.19.35 (Endomorphisms are automorphisms)

Let 𝜎∈Mor𝑘(𝐾,𝐾) be an endomorphism of an algebraic extension. Then it is an isomorphism. In other words

Proof. As field morphisms are injective (3.3.60) we only need to show that 𝜎 is surjective. Given 𝛼∈𝐾 let 𝑇 denote the set of roots of 𝑚𝛼∈𝑘[𝑋] in 𝐾. Note by (3.17.35) 𝑇 is finite. Further by (3.19.20) 𝜎 maps 𝑇 to itself. Since 𝜎 is injective it is also surjective on 𝑇. In particular 𝛼 is in the image of 𝜎 as required. ∎
