3.3.6 Irreducible and Reduced rings

We say an element 𝑥 is nilpotent if 𝑥𝑛=0. By (3.3.44) these form an ideal.

Definition 3.3.63 (Nilradical)

Define the nilradical to be the set (ideal) of nilpotents

𝑁(𝐴)≔(0)=(3.3.45)⋂𝔭𝔭

Clearly 𝐴 is reduced if and only if 𝑁(𝐴)={0}.

We also make the following definition

Definition 3.3.64 (Irreducible)
Let 𝐴 be a ring. We say 𝐴 is irreducible if 𝑁(𝐴) is prime.

The notion of irreducible ring is related to the notion of minimal primes

Proposition 3.3.65
A ring 𝐴 is irreducible if and only if it has a unique minimal prime ideal. In this case it is equal to 𝑁(𝐴).

Proof. First we note that every prime ideal contains 𝑁(𝐴). If 𝐴 is irreducible then by definition 𝑁(𝐴) is prime and it is therefore the unique minimal prime ideal.

Conversely if 𝔭0 is the unique minimal prime ideal then by (3.3.43) it is contained in every prime ideal. Therefore (3.3.63) 𝑁(𝐴)=⋂𝔭𝔭=𝔭0 is prime and 𝐴 is irreducible. ∎

Proposition 3.3.66 (Integral Domain ⟺ Reduced and Irreducible)

Let 𝐴 be a ring. Then the following are equivalent

  1. 𝐴 is an integral domain
  2. 𝐴 is reduced and has a unique minimal prime
  3. (0) is prime
  4. 𝐴 is reduced and irreducible.

The following may be useful

Proposition 3.3.67

Let 𝐴 be a ring then the sum of an invertible and nilpotent element is again invertible

𝐴⋆+𝑁(𝐴)⊆𝐴⋆

Proof. For if

𝑎=𝑢+𝑛=𝑢(1−(𝑢−1)(−𝑛))

with 𝑛∈𝑁(𝐴) and 𝑢∈𝐴⋆. Then way may reduce to the case 1−𝑛 and observe that

(1−𝑛)−1=∑𝑖=0∞𝑛𝑖

which by assumption is a finite sum. ∎
