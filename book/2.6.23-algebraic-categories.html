2.6.23 Algebraic Categories

Drafted by Claude Sonnet 5, reviewed by David Rufino.

The categories of groups, rings and modules all share a common shape: their objects are sets equipped with some finitary operations, subject to some equational axioms. The following makes this precise, following the classical treatment of universal algebra [Bir35] [BS81] and its later categorical formulation [ARV10].

Definition 2.6.179 (Signature)
A signature Ω is a set of operation symbols, each 𝜔∈Ω assigned a natural number 𝑛𝜔, its arity.
Definition 2.6.180 (Ω-algebra)

Let Ω be a signature. An 𝛀-algebra is a set 𝑆 together with, for each 𝜔∈Ω, a function 𝜔𝑆:𝑆𝑛𝜔→𝑆 (when 𝑛𝜔=0 this is simply a distinguished element of 𝑆, since 𝑆0 is a singleton).

A homomorphism of Ω-algebras 𝑓:𝑆→𝑇 is a function such that

𝑓(𝜔𝑆(𝑠1,…,𝑠𝑛𝜔))=𝜔𝑇(𝑓(𝑠1),…,𝑓(𝑠𝑛𝜔))∀𝜔∈Ω,𝑠1,…,𝑠𝑛𝜔∈𝑆

This determines a concrete category Ω-𝐀𝐥𝐠 (2.6.9).

Example 2.6.181
Taking Ω={·(2),−1(1),𝑒(0)} (writing the arity of each symbol in brackets), Ω-algebras are exactly sets equipped with a binary, a unary and a nullary operation; the subcategory of those satisfying the group axioms, (2.6.184) below, is the category of groups.
Definition 2.6.182 (Terms)

Let Ω be a signature and 𝑋 a set, whose elements we call variables. The set 𝑇Ω(𝑋) of Ω-terms over 𝑋 is defined recursively by

  • every 𝑥∈𝑋 is a term;
  • if 𝜔∈Ω and 𝑡1,…,𝑡𝑛𝜔∈𝑇Ω(𝑋) then 𝜔(𝑡1,…,𝑡𝑛𝜔)∈𝑇Ω(𝑋).

Given an Ω-algebra 𝑆 and a function 𝜃:𝑋→𝑆, there is a unique evaluation 𝜃―:𝑇Ω(𝑋)→𝑆 such that 𝜃―(𝑥)=𝜃(𝑥) for 𝑥∈𝑋 and

𝜃―(𝜔(𝑡1,…,𝑡𝑛𝜔))=𝜔𝑆(𝜃―(𝑡1),…,𝜃―(𝑡𝑛𝜔))
Remark 2.6.183 (The term algebra)

𝑇Ω(𝑋) is itself an Ω-algebra, via 𝜔𝑇Ω(𝑋)(𝑡1,…,𝑡𝑛𝜔)≔𝜔(𝑡1,…,𝑡𝑛𝜔); with this structure, the defining recursion for 𝜃― is exactly the condition that 𝜃―:𝑇Ω(𝑋)→𝑆 is a homomorphism, and it is the unique homomorphism 𝑇Ω(𝑋)→𝑆 restricting to 𝜃 on 𝑋.

Consequently, for any homomorphism ℎ:𝑆→𝑆′ and 𝜃:𝑋→𝑆, both ℎ∘𝜃― and ℎ∘𝜃― are homomorphisms 𝑇Ω(𝑋)→𝑆′ restricting to ℎ∘𝜃 on 𝑋, so by uniqueness

ℎ∘𝜃―=ℎ∘𝜃―
Definition 2.6.184 (Identity, Algebraic category)

Let Ω be a signature. An Ω-identity is a pair 𝑝,𝑞∈𝑇Ω(𝑋) for some set of variables 𝑋, written 𝑝=𝑞. An Ω-algebra 𝑆 satisfies 𝑝=𝑞 if 𝜃―(𝑝)=𝜃―(𝑞) for every 𝜃:𝑋→𝑆 (2.6.182).

Given a set 𝐸 of Ω-identities, the algebraic category determined by (Ω,𝐸) – also called an equational category or variety in the literature – is the full subcategory of Ω-𝐀𝐥𝐠 of those Ω-algebras satisfying every identity in 𝐸, again concrete over 𝐒𝐞𝐭.

Example 2.6.185
𝐆𝐫𝐩,𝐀𝐛𝐆𝐫𝐩,𝐑𝐧𝐠 are algebraic categories, taking 𝐸 to consist of the usual group, abelian group and ring axioms respectively, each expressed as an identity. By contrast, the category of fields is not an algebraic category: the axiom that every nonzero element has an inverse cannot be expressed as an identity holding at every element, since it fails at 0.
Example 2.6.186 (𝐴-𝐌𝐨𝐝 as an algebraic category)

Fix a ring 𝐴. Take Ω={+,−,0}∪{𝜆𝑎}𝑎∈𝐴, with + binary, − unary, 0 nullary and each 𝜆𝑎 unary; note Ω is infinite (one symbol per element of 𝐴) but every operation remains finitary. Take 𝐸 to consist of the abelian group axioms for (+,−,0) together with, for all 𝑎,𝑎′∈𝐴,

𝜆𝑎(𝑥+𝑦)=𝜆𝑎(𝑥)+𝜆𝑎(𝑦),𝜆1(𝑥)=𝑥,𝜆𝑎+𝑎′(𝑥)=𝜆𝑎(𝑥)+𝜆𝑎′(𝑥),𝜆𝑎𝑎′(𝑥)=𝜆𝑎(𝜆𝑎′(𝑥))

Setting 𝜆𝑎(𝑚)≔𝑎·𝑚, these are exactly the 𝐴-module axioms, so 𝐴-𝐌𝐨𝐝 is the algebraic category determined by (Ω,𝐸).

Example 2.6.187 (𝐀𝐥𝐠𝑘 as an algebraic category)

Fix a commutative ring 𝐴 (so 𝐀𝐥𝐠𝑘 is the case 𝐴=𝑘 a field). Take Ω={+,×,−,0,1}∪{𝜆𝑎}𝑎∈𝐴, with +,× binary, − unary, 0,1 nullary and each 𝜆𝑎 unary, and take 𝐸 to consist of the ring axioms for (+,×,−,0,1) (not imposing commutativity of ×) together with the four identities above and, in addition,

𝜆𝑎(𝑥)=𝜆𝑎(1)×𝑥∀𝑎∈𝐴

Given such an Ω-algebra 𝐵, set 𝑖𝐵(𝑎)≔𝜆𝑎(1). Additivity and unitality of 𝑖𝐵 are immediate from the identities above at 𝑥=1, and multiplicativity follows from the last two identities,

𝑖𝐵(𝑎𝑎′)=𝜆𝑎𝑎′(1)=𝜆𝑎(𝜆𝑎′(1))=𝜆𝑎(1)×𝜆𝑎′(1)=𝑖𝐵(𝑎)𝑖𝐵(𝑎′)

so 𝑖𝐵 is a ring homomorphism, and the final identity reads 𝜆𝑎(𝑏)=𝑖𝐵(𝑎)·𝑏 for all 𝑏∈𝐵: this is exactly an 𝐴-algebra structure on 𝐵. Conversely every 𝐴-algebra satisfies these identities, and a ring homomorphism commutes with every 𝜆𝑎 if and only if it respects the structural morphisms (apply the final identity at 𝑏=1), so 𝐀𝐥𝐠𝐴, and in particular 𝐀𝐥𝐠𝑘, is the algebraic category determined by (Ω,𝐸).

Remark 2.6.188
Birkhoff’s theorem characterises the algebraic (equational) subcategories of Ω-𝐀𝐥𝐠 as exactly those closed under homomorphic images, subalgebras and products [Bir35]; see [BS81] for a modern account, and [ARV10] for the categorical perspective via algebraic theories.
Proposition 2.6.189 (Properties of Algebraic Categories)

Let 𝒞︀ be an algebraic category determined by (Ω,𝐸) (2.6.184), with forgetful functor 𝑈:𝒞︀→𝐒𝐞𝐭. Then

  1. 𝑈 reflects isomorphisms
  2. 𝑈 creates limits and directed colimits
  3. 𝑈 has a left adjoint (i.e. free algebras exist)

In particular 𝑈 also preserves limits and directed colimits by (2.6.87).

Proof. Drafted by Claude Sonnet 5, reviewed by David Rufino.

Throughout, for 𝜔∈Ω we write 𝑟=1,…,𝑛𝜔 for the arguments of 𝜔, reserving 𝑖,𝑗,𝑘 for diagram indices.

𝑈 creates limits. Let 𝐹:𝐼→𝒞︀ be a diagram and suppose 𝐿≔lim(𝑈∘𝐹) exists in 𝐒𝐞𝐭, with structure maps 𝜋𝑖:𝐿→𝑈(𝐹(𝑖)); explicitly, by (2.6.85), 𝐿={(𝑥𝑖)𝑖∈𝐼∈∏𝑖𝑈(𝐹(𝑖))|𝑈(𝐹(𝛼))(𝑥𝑖)=𝑥𝑗∀𝛼:𝑖→𝑗}.

For 𝜔∈Ω and 𝑥(1),…,𝑥(𝑛𝜔)∈𝐿, define 𝜔𝐿(𝑥(1),…,𝑥(𝑛𝜔))𝑖≔𝜔𝐹(𝑖)(𝑥𝑖(1),…,𝑥𝑖(𝑛𝜔)) for each 𝑖∈𝐼. This again lies in 𝐿: for 𝛼:𝑖→𝑗, since 𝐹(𝛼) is a homomorphism, 𝐹(𝛼)(𝜔𝐹(𝑖)(𝑥𝑖(1),…))=𝜔𝐹(𝑗)(𝐹(𝛼)(𝑥𝑖(1)),…)=𝜔𝐹(𝑗)(𝑥𝑗(1),…), using that each 𝑥(𝑟)∈𝐿. So 𝐿 is an Ω-algebra and each 𝜋𝑖 is, by construction, a homomorphism; this is the unique such structure on 𝐿, since 𝜔𝐿(…) is pinned down coordinatewise by the requirement that every 𝜋𝑖 be a homomorphism, and 𝐿⊆∏𝑖𝑈(𝐹(𝑖)).

Given 𝑝=𝑞∈𝐸 with variables in a set 𝑋, and 𝜃:𝑋→𝐿: for each 𝑖, 𝜋𝑖∘𝜃:𝑋→𝑈(𝐹(𝑖)), and by (2.6.183), 𝜋𝑖(𝜃―(𝑡))=𝜋𝑖∘𝜃―(𝑡) for every term 𝑡. As 𝐹(𝑖)∈𝒞︀ satisfies 𝑝=𝑞, 𝜋𝑖𝜃―(𝑝)=𝜋𝑖𝜃―(𝑞), so 𝜋𝑖(𝜃―(𝑝))=𝜋𝑖(𝜃―(𝑞)) for every 𝑖∈𝐼, hence 𝜃―(𝑝)=𝜃―(𝑞) as elements of 𝐿⊆∏𝑖𝑈(𝐹(𝑖)). So 𝐿∈𝒞︀.

Finally (𝐿,{𝜋𝑖}) is a limit for 𝐹 in 𝒞︀: given a cone (𝑀,{𝜇𝑖}) in 𝒞︀, the unique 𝐒𝐞𝐭-map 𝜑:𝑈(𝑀)→𝐿 with 𝜋𝑖∘𝜑=𝜇𝑖 (afforded by 𝐿=lim(𝑈∘𝐹)) is a homomorphism, since for 𝜔∈Ω, 𝑚(1),…,𝑚(𝑛𝜔)∈𝑈(𝑀) and every 𝑖,

𝜋𝑖(𝜑(𝜔𝑀(𝑚(1),…)))=𝜇𝑖(𝜔𝑀(𝑚(1),…))=𝜔𝐹(𝑖)(𝜇𝑖(𝑚(1)),…)=𝜔𝐹(𝑖)(𝜋𝑖𝜑(𝑚(1)),…)=𝜋𝑖(𝜔𝐿(𝜑(𝑚(1)),…))

using that 𝜇𝑖 is a homomorphism, so 𝜑(𝜔𝑀(𝑚(1),…))=𝜔𝐿(𝜑(𝑚(1)),…). As 𝒞︀ is a full subcategory of Ω-𝐀𝐥𝐠, 𝜑 is the unique morphism of 𝒞︀ with 𝜋𝑖∘𝜑=𝜇𝑖, so (𝐿,{𝜋𝑖}) is a limit for 𝐹 in 𝒞︀ with 𝑈(𝐿)=𝐿, as required.

𝑈 creates directed colimits. Let 𝐼 be a directed preorder and 𝐹:𝐼→𝒞︀ a diagram, and suppose 𝐿≔lim⟶(𝑈∘𝐹) exists in 𝐒𝐞𝐭 (2.6.128), with structure maps 𝜇𝑖:𝑈(𝐹(𝑖))→𝐿.

For 𝜔∈Ω and ℓ(1),…,ℓ(𝑛𝜔)∈𝐿: as 𝐼 is directed and 𝑛𝜔 is finite, there is a common 𝑖∈𝐼 and 𝑦(1),…,𝑦(𝑛𝜔)∈𝑈(𝐹(𝑖)) with 𝜇𝑖(𝑦(𝑟))=ℓ(𝑟) for all 𝑟 (each ℓ(𝑟) is represented at some stage, and finitely many stages admit a common upper bound); define 𝜔𝐿(ℓ(1),…,ℓ(𝑛𝜔))≔𝜇𝑖(𝜔𝐹(𝑖)(𝑦(1),…,𝑦(𝑛𝜔))). This is independent of the choice of 𝑖 and the 𝑦(𝑟): given another such 𝑖′,(𝑦′(𝑟)), for each 𝑟 there is, by (2.6.128), a stage 𝑘𝑟⪰𝑖,𝑖′ with 𝐹(𝑖→𝑘𝑟)(𝑦(𝑟))=𝐹(𝑖′→𝑘𝑟)(𝑦′(𝑟)); as 𝐼 is directed and there are finitely many 𝑟, there is a common 𝑗⪰𝑘1,…,𝑘𝑛𝜔, and applying 𝐹(𝑘𝑟→𝑗) to each equality gives 𝐹(𝑖→𝑗)(𝑦(𝑟))=𝐹(𝑖′→𝑗)(𝑦′(𝑟)) for every 𝑟 simultaneously. As 𝐹(𝑖→𝑗),𝐹(𝑖′→𝑗) are homomorphisms,

𝜇𝑖(𝜔𝐹(𝑖)(𝑦(1),…))=𝜇𝑗(𝜔𝐹(𝑗)(𝐹(𝑖→𝑗)(𝑦(1)),…))=𝜇𝑗(𝜔𝐹(𝑗)(𝐹(𝑖′→𝑗)(𝑦′(1)),…))=𝜇𝑖′(𝜔𝐹(𝑖′)(𝑦′(1),…))

So 𝐿 is an Ω-algebra and each 𝜇𝑖 is, by construction, a homomorphism; as the 𝜇𝑖 are jointly surjective (2.6.128), this is again the unique such structure.

Given 𝑝=𝑞∈𝐸 with (finitely many) variables 𝑋, and 𝜃:𝑋→𝐿: as 𝑋 is finite and 𝐼 directed, there is 𝑖∈𝐼 and 𝜃𝑖:𝑋→𝑈(𝐹(𝑖)) with 𝜃=𝜇𝑖∘𝜃𝑖 (as above); by (2.6.183), 𝜃―=𝜇𝑖∘𝜃𝑖―, so 𝜃―(𝑝)=𝜇𝑖(𝜃𝑖―(𝑝))=𝜇𝑖(𝜃𝑖―(𝑞))=𝜃―(𝑞), using 𝐹(𝑖)∈𝒞︀. So 𝐿∈𝒞︀.

Finally (𝐿,{𝜇𝑖}) is a colimit for 𝐹 in 𝒞︀: given a cocone (𝑀,{𝜈𝑖}) in 𝒞︀, the unique 𝐒𝐞𝐭-map 𝜓:𝐿→𝑈(𝑀) with 𝜓∘𝜇𝑖=𝜈𝑖 is a homomorphism (for ℓ(𝑟)=𝜇𝑖(𝑦(𝑟)) at a common 𝑖, 𝜓(𝜔𝐿(ℓ(1),…))=𝜓(𝜇𝑖(𝜔𝐹(𝑖)(𝑦(1),…)))=𝜈𝑖(𝜔𝐹(𝑖)(𝑦(1),…))=𝜔𝑀(𝜈𝑖(𝑦(1)),…)=𝜔𝑀(𝜓(ℓ(1)),…), using that 𝜈𝑖 is a homomorphism), and is the unique morphism of 𝒞︀ with this property as 𝒞︀ is full in Ω-𝐀𝐥𝐠.

𝑈 reflects isomorphisms. Let 𝑓:𝑋→𝑌 in 𝒞︀ with 𝑈(𝑓) bijective. For 𝜔∈Ω and 𝑦(1),…,𝑦(𝑛𝜔)∈𝑈(𝑌), writing 𝑥(𝑟)≔𝑈(𝑓)−1(𝑦(𝑟)), since 𝑓 is a homomorphism 𝑓(𝜔𝑋(𝑥(1),…))=𝜔𝑌(𝑓(𝑥(1)),…)=𝜔𝑌(𝑦(1),…), so applying 𝑈(𝑓)−1,

𝑈(𝑓)−1(𝜔𝑌(𝑦(1),…,𝑦(𝑛𝜔)))=𝜔𝑋(𝑈(𝑓)−1(𝑦(1)),…,𝑈(𝑓)−1(𝑦(𝑛𝜔)))

so 𝑈(𝑓)−1 is a homomorphism 𝑌→𝑋, hence a morphism of 𝒞︀ (full subcategory), inverse to 𝑓 on underlying sets; as 𝑈 is faithful, it is a two-sided inverse to 𝑓 in 𝒞︀, so 𝑓 is an isomorphism.

𝑈 has a left adjoint. Fix a set 𝑋. Define a relation ∼ on 𝑇Ω(𝑋) by 𝑡∼𝑡′ if 𝜃―(𝑡)=𝜃―(𝑡′) for every 𝐴∈𝒞︀ and 𝜃:𝑋→𝑈(𝐴); this is manifestly an equivalence relation, and a congruence: if 𝑡(𝑟)∼𝑡′(𝑟) for 𝑟=1,…,𝑛𝜔, then for every 𝐴,𝜃, 𝜃―(𝜔(𝑡(1),…))=𝜔𝐴(𝜃―(𝑡(1)),…)=𝜔𝐴(𝜃―(𝑡′(1)),…)=𝜃―(𝜔(𝑡′(1),…)), so 𝜔(𝑡(1),…,𝑡(𝑛𝜔))∼𝜔(𝑡′(1),…,𝑡′(𝑛𝜔)).

Let Free(𝑋)≔𝑇Ω(𝑋)/∼, with 𝜔Free(𝑋)([𝑡(1)],…,[𝑡(𝑛𝜔)])≔[𝜔(𝑡(1),…,𝑡(𝑛𝜔))] (well-defined as ∼ is a congruence), and let 𝜋:𝑇Ω(𝑋)→Free(𝑋), 𝑡↦[𝑡], an (evidently surjective) homomorphism. Write 𝜄:𝑋→𝑈(Free(𝑋)), 𝜄(𝑥)≔[𝑥].

Free(𝑋)∈𝒞︀: let 𝑝=𝑞∈𝐸 with variable set 𝑌, and 𝜓:𝑌→𝑈(Free(𝑋)); choose 𝜓̃:𝑌→𝑇Ω(𝑋) with 𝜋∘𝜓̃=𝜓 (possible as 𝜋 is surjective). Viewing 𝑇Ω(𝑋) as an Ω-algebra (2.6.183), 𝜓̃―:𝑇Ω(𝑌)→𝑇Ω(𝑋) is a homomorphism, and for every 𝐴∈𝒞︀, 𝜃:𝑋→𝑈(𝐴), (2.6.183) gives 𝜃―∘𝜓̃―=𝜃―∘𝜓̃―; as 𝜃―∘𝜓̃:𝑌→𝑈(𝐴) and 𝐴⊧𝑝=𝑞, 𝜃―𝜓̃―(𝑝)=𝜃―𝜓̃―(𝑞), so 𝜃―(𝜓̃―(𝑝))=𝜃―(𝜓̃―(𝑞)). As 𝐴,𝜃 were arbitrary, 𝜓̃―(𝑝)∼𝜓̃―(𝑞), that is 𝜋(𝜓̃―(𝑝))=𝜋(𝜓̃―(𝑞)). Again by (2.6.183), 𝜋∘𝜓̃―=𝜓― (both extend 𝜋∘𝜓̃=𝜓 on 𝑌), so 𝜓―(𝑝)=𝜓―(𝑞). As 𝜓 was arbitrary, Free(𝑋)⊧𝑝=𝑞; as 𝑝=𝑞∈𝐸 was arbitrary, Free(𝑋)∈𝒞︀.

Universal property: given 𝐴∈𝒞︀ and 𝜃:𝑋→𝑈(𝐴), define 𝜃̂([𝑡])≔𝜃―(𝑡); this is well-defined (𝑡∼𝑡′⟹𝜃―(𝑡)=𝜃―(𝑡′), by definition of ∼) and a homomorphism, since 𝜃̂(𝜔Free(𝑋)([𝑡(1)],…))=𝜃̂([𝜔(𝑡(1),…)])=𝜃―(𝜔(𝑡(1),…))=𝜔𝐴(𝜃―(𝑡(1)),…)=𝜔𝐴(𝜃̂([𝑡(1)]),…), and satisfies 𝑈(𝜃̂)∘𝜄=𝜃. If 𝜑:Free(𝑋)→𝐴 is any morphism of 𝒞︀ with 𝑈(𝜑)∘𝜄=𝜃, then 𝜑∘𝜋 is a homomorphism 𝑇Ω(𝑋)→𝐴 restricting to 𝜃 on 𝑋, so 𝜑∘𝜋=𝜃― by (2.6.183); as 𝜋 is surjective, 𝜑=𝜃̂. So Free(𝑋) is free on 𝑋, and 𝑋↦Free(𝑋) is left adjoint to 𝑈 by (2.6.74). ∎

Remark 2.6.190 (Limits are computed pointwise)
Unwinding the construction in the proof of (2.6.189): for a diagram 𝐹:𝐼→𝒞︀ admitting a limit, 𝑈(lim𝐹)=lim(𝑈∘𝐹) (2.6.85), and each 𝜔∈Ω acts on lim𝐹 coordinatewise, 𝜔lim𝐹(𝑥(1),…)𝑖=𝜔𝐹(𝑖)(𝑥𝑖(1),…) for 𝑖∈𝐼. In particular this applies to products.
Corollary 2.6.191 (Inverse Limits in Algebraic Categories)

Let 𝒞︀ be an algebraic category determined by (Ω,𝐸) (2.6.184), with forgetful functor 𝑈:𝒞︀→𝐒𝐞𝐭, 𝐼 a directed preorder, and 𝐹:𝐼op→𝒞︀ an inverse system. Then lim⟵𝑖𝐹(𝑖) exists in 𝒞︀, with

𝑈(lim⟵𝑖𝐹(𝑖))=lim⟵𝑖𝑈(𝐹(𝑖))={(𝑥𝑖)𝑖∈𝐼∈∏𝑖𝑈(𝐹(𝑖))|𝑈(𝜌𝑖𝑗)(𝑥𝑗)=𝑥𝑖∀𝑖≺𝑗}

(2.6.130), and each 𝜔∈Ω acts coordinatewise: 𝜔lim⟵𝑖𝐹(𝑖)(𝑥(1),…)𝑖=𝜔𝐹(𝑖)(𝑥𝑖(1),…) for every 𝑖∈𝐼.

Proof. Drafted by Claude Sonnet 5, reviewed by David Rufino.

By (2.6.189), 𝑈 creates limits, and lim𝐼op(𝑈∘𝐹)=lim⟵𝑖𝑈(𝐹(𝑖)) exists in 𝐒𝐞𝐭 for every diagram, being computed as in (2.6.130) (a special case of (2.6.85)); so lim⟵𝑖𝐹(𝑖)≔lim𝐼op𝐹 exists in 𝒞︀ too, with 𝑈 carrying it to this set-level description. The coordinatewise formula for 𝜔∈Ω is then the case lim𝐹≔lim⟵𝑖𝐹(𝑖) of (2.6.190). ∎

Definition 2.6.192 (Subalgebra)
Let 𝐴 be an Ω-algebra. A subset 𝑆⊆𝑈(𝐴) is a subalgebra if 𝜔𝐴(𝑠1,…,𝑠𝑛𝜔)∈𝑆 for all 𝜔∈Ω and 𝑠1,…,𝑠𝑛𝜔∈𝑆.
Proposition 2.6.193 (Subalgebra criterion)

Let 𝐴 be an Ω-algebra and 𝑆⊆𝑈(𝐴) a subalgebra (2.6.192). Then 𝑆 carries a unique Ω-algebra structure making the inclusion 𝜄:𝑆↪︎𝐴 a homomorphism, namely 𝜔𝑆≔𝜔𝐴|𝑆𝑛𝜔.

If moreover 𝐴 satisfies an identity 𝑝=𝑞, then so does 𝑆; in particular, if 𝐴 lies in the algebraic category 𝒞︀ determined by (Ω,𝐸), then so does 𝑆.

Proof. Drafted by Claude Sonnet 5, reviewed by David Rufino.

Existence and uniqueness of 𝜔𝑆 are immediate: 𝑆 being closed under 𝜔𝐴 means 𝜔𝐴|𝑆𝑛𝜔 takes values in 𝑆, and this is forced by the requirement that 𝜄 be a homomorphism.

Let 𝑝=𝑞 be an identity with variables 𝑌, satisfied by 𝐴, and 𝜃:𝑌→𝑆. Writing 𝜄∘𝜃:𝑌→𝑈(𝐴), (2.6.183) gives 𝜄(𝜃―(𝑝))=𝜄𝜃―(𝑝)=𝜄𝜃―(𝑞)=𝜄(𝜃―(𝑞)), using that 𝐴 satisfies 𝑝=𝑞; as 𝜄 is injective, 𝜃―(𝑝)=𝜃―(𝑞), so 𝑆 satisfies 𝑝=𝑞. ∎

Proposition 2.6.194 (Injective ⟺ Monic)
Let 𝒞︀ be an algebraic category. Then a morphism 𝑓:𝑋→𝑌 is a monomorphism if and only if 𝑈(𝑓) is injective.

Proof. If 𝑈(𝑓) is injective and 𝑓∘𝑔=𝑓∘ℎ then 𝑈(𝑓)∘𝑈(𝑔)=𝑈(𝑓)∘𝑈(ℎ) whence 𝑈(𝑔)=𝑈(ℎ) and by faithful-ness 𝑔=ℎ as required.

Conversely if 𝑓:𝑋→𝑌 is monic, consider the left adjoint 𝐹 to 𝑈 (2.6.189), then by definition we have a natural bijection

Ψ𝑋:Mor(𝐹({⋆}),𝑋)→∼𝑈(𝑋)

Suppose 𝑈(𝑓)(𝑥)=𝑈(𝑓)(𝑦) for 𝑥,𝑦∈𝑈(𝑋). Let 𝑔,ℎ be morphisms corresponding to 𝑥 and 𝑦 under this bijection, that is 𝑥=Ψ𝑋(𝑔) and 𝑦=Ψ𝑋(ℎ).

Then by naturality of Ψ

𝑈(𝑓)(𝑥)=Ψ𝑌(𝑓∘𝑔)

and

𝑈(𝑓)(𝑦)=Ψ𝑌(𝑓∘ℎ)

so by assumption 𝑓∘𝑔=𝑓∘ℎ. As 𝑓 is monic we have 𝑔=ℎ whence 𝑥=𝑦. Therefore 𝑈(𝑓) is injective. ∎

Proposition 2.6.195 (Regular Epimorphism ⟺ Surjective)
Let 𝒞︀ be an algebraic category (2.6.184) and 𝑒:𝑋→𝑌 a morphism of 𝒞︀. Then 𝑒 is a regular epimorphism if and only if 𝑈(𝑒) is surjective.

Proof. Drafted by Claude Sonnet 5, reviewed by David Rufino.

(⟹) Since 𝑒 is regular, there are 𝛼,𝛽:𝑊⇉𝑋 such that 𝑒 is the coequaliser of (𝛼,𝛽) (2.6.158).

The image is a subalgebra. Let 𝐼≔𝑈(𝑒)(𝑈(𝑋))⊆𝑈(𝑌). For 𝜔∈Ω and 𝑦1,…,𝑦𝑛𝜔∈𝐼, writing 𝑦𝑟=𝑈(𝑒)(𝑥𝑟) for 𝑥𝑟∈𝑈(𝑋), since 𝑒 is a homomorphism 𝜔𝑌(𝑦1,…)=𝜔𝑌(𝑈(𝑒)(𝑥1),…)=𝑈(𝑒)(𝜔𝑋(𝑥1,…))∈𝐼; so 𝐼 is a subalgebra (2.6.192). By (2.6.193), 𝐼 carries an Ω-algebra structure making the inclusion 𝜄:𝐼↪︎𝑌 a homomorphism, and 𝐼∈𝒞︀ (as 𝑌∈𝒞︀); as 𝒞︀ is full in Ω-𝐀𝐥𝐠, 𝜄 is a morphism of 𝒞︀.

Write 𝑒′:𝑋→𝐼 for the corestriction of 𝑒, that is 𝑈(𝑒′)≔𝑈(𝑒) regarded as a map into 𝐼; since 𝜔𝐼 is just 𝜔𝑌 restricted to 𝐼, 𝑒′ is again a homomorphism, hence a morphism of 𝒞︀, with 𝜄∘𝑒′=𝑒 and 𝑈(𝑒′) surjective onto 𝐼 by construction.

(𝐼,𝑒′) is a coequaliser of (𝛼,𝛽). Since 𝜄∘(𝑒′𝛼)=𝑒𝛼=𝑒𝛽=𝜄∘(𝑒′𝛽) and 𝜄 is monic (2.6.194), 𝑒′𝛼=𝑒′𝛽. Given ℎ:𝑋→𝑍 with ℎ𝛼=ℎ𝛽, the universal property of 𝑒 gives a unique 𝑘:𝑌→𝑍 with 𝑘∘𝑒=ℎ; then 𝑘′≔𝑘∘𝜄 satisfies 𝑘′∘𝑒′=𝑘∘𝜄∘𝑒′=𝑘∘𝑒=ℎ. If 𝑘″ also satisfies 𝑘″∘𝑒′=ℎ, then 𝑈(𝑘′)∘𝑈(𝑒′)=𝑈(ℎ)=𝑈(𝑘″)∘𝑈(𝑒′); as 𝑈(𝑒′) is surjective, 𝑈(𝑘′)=𝑈(𝑘″), so 𝑘′=𝑘″ (𝑈 faithful). So (𝐼,𝑒′) is a coequaliser of (𝛼,𝛽) (2.6.140), in particular 𝑒′ is epic (2.6.135).

𝜄 is an isomorphism. Applying the universal property of 𝑒 to 𝑒′ (which satisfies 𝑒′𝛼=𝑒′𝛽) gives a unique 𝜓:𝑌→𝐼 with 𝜓∘𝑒=𝑒′. Then (𝜄∘𝜓)∘𝑒=𝜄∘𝑒′=𝑒=1𝑌∘𝑒, and as 𝑒 is epic (2.6.135), 𝜄∘𝜓=1𝑌. Also (𝜓∘𝜄)∘𝑒′=𝜓∘𝑒=𝑒′=1𝐼∘𝑒′, and as 𝑒′ is epic, 𝜓∘𝜄=1𝐼. So 𝜄 is an isomorphism, with inverse 𝜓.

So 𝑈(𝜄) is bijective; but 𝑈(𝜄) is, by construction, the inclusion 𝐼↪︎𝑈(𝑌), so 𝐼=𝑈(𝑌). As 𝐼=𝑈(𝑒)(𝑈(𝑋)) by definition, 𝑈(𝑒) is surjective.

(⟸) Suppose 𝑈(𝑒) is surjective.

Construction of the quotient. Write ∼ for the relation 𝑎∼𝑏:⟺𝑈(𝑒)(𝑎)=𝑈(𝑒)(𝑏) on 𝑈(𝑋), an equivalence relation, and 𝑄≔𝑈(𝑋)/∼ with quotient map 𝜋:𝑈(𝑋)→𝑄, 𝑎↦[𝑎]; 𝜋 is surjective by construction. For 𝜔∈Ω and 𝑎1,…,𝑎𝑛𝜔,𝑏1,…,𝑏𝑛𝜔∈𝑈(𝑋) with 𝑎𝑟∼𝑏𝑟 for every 𝑟: since 𝑒 is a homomorphism, 𝑈(𝑒)(𝜔𝑋(𝑎1,…))=𝜔𝑌(𝑈(𝑒)(𝑎1),…)=𝜔𝑌(𝑈(𝑒)(𝑏1),…)=𝑈(𝑒)(𝜔𝑋(𝑏1,…)), that is 𝜔𝑋(𝑎1,…)∼𝜔𝑋(𝑏1,…); so ∼ is a congruence, and 𝜔𝑄([𝑎1],…,[𝑎𝑛𝜔])≔[𝜔𝑋(𝑎1,…,𝑎𝑛𝜔)] is well-defined, making 𝑄 into an Ω-algebra with 𝜋 a homomorphism.

𝑄∈𝒞︀. Let 𝑝=𝑞∈𝐸 with variables 𝑊, and 𝜃:𝑊→𝑄; as 𝜋 is surjective, choose 𝜃̃:𝑊→𝑈(𝑋) with 𝜋∘𝜃̃=𝜃. Since 𝑋∈𝒞︀, 𝑋 satisfies 𝑝=𝑞, that is 𝜃̃―(𝑝)=𝜃̃―(𝑞) in 𝑈(𝑋); applying the homomorphism 𝜋 and (2.6.183) (𝜋∘𝜃̃―=𝜋∘𝜃̃―=𝜃―),

𝜃―(𝑝)=𝜋(𝜃̃―(𝑝))=𝜋(𝜃̃―(𝑞))=𝜃―(𝑞)

As 𝜃 was arbitrary, 𝑄 satisfies 𝑝=𝑞; as 𝑝=𝑞∈𝐸 was arbitrary, 𝑄∈𝒞︀, and 𝜋:𝑋→𝑄 is a morphism of 𝒞︀ (full subcategory of Ω-𝐀𝐥𝐠).

The kernel relation is a subalgebra. Let 𝑅≔{(𝑎,𝑏)∈𝑈(𝑋)2|𝑎∼𝑏}. For 𝜔∈Ω and (𝑎1,𝑏1),…,(𝑎𝑛𝜔,𝑏𝑛𝜔)∈𝑅, since 𝑒 is a homomorphism, 𝑈(𝑒)(𝜔𝑋(𝑎1,…))=𝜔𝑌(𝑈(𝑒)(𝑎1),…)=𝜔𝑌(𝑈(𝑒)(𝑏1),…)=𝑈(𝑒)(𝜔𝑋(𝑏1,…)), so (𝜔𝑋(𝑎1,…),𝜔𝑋(𝑏1,…))∈𝑅; as 𝑈(𝑋×𝑋)=𝑈(𝑋)2 (2.6.190), 𝑅 is a subalgebra of 𝑋×𝑋 (2.6.192). By (2.6.193), 𝑅∈𝒞︀, and 𝛼≔𝜋1|𝑅, 𝛽≔𝜋2|𝑅 (restrictions of the product projections) are morphisms of 𝒞︀.

(𝑄,𝜋) is a coequaliser of (𝛼,𝛽). For (𝑎,𝑏)∈𝑅, i.e. 𝑎∼𝑏, 𝜋(𝛼(𝑎,𝑏))=𝜋(𝑎)=[𝑎]=[𝑏]=𝜋(𝛽(𝑎,𝑏)); as 𝑈 is faithful, 𝜋∘𝛼=𝜋∘𝛽. Suppose ℎ:𝑋→𝑍 satisfies ℎ∘𝛼=ℎ∘𝛽; then for every (𝑎,𝑏)∈𝑅 (i.e. every 𝑎∼𝑏), 𝑈(ℎ)(𝑎)=𝑈(ℎ)(𝑏), so ℎ―:𝑄→𝑈(𝑍), [𝑎]↦𝑈(ℎ)(𝑎), is a well-defined map, and a homomorphism, since ℎ―(𝜔𝑄([𝑎1],…))=ℎ―([𝜔𝑋(𝑎1,…)])=𝑈(ℎ)(𝜔𝑋(𝑎1,…))=𝜔𝑍(𝑈(ℎ)(𝑎1),…)=𝜔𝑍(ℎ―([𝑎1]),…), using that ℎ is a homomorphism. So ℎ― is a morphism of 𝒞︀ with ℎ―∘𝜋=ℎ (𝑈 faithful). If 𝑘:𝑄→𝑍 also satisfies 𝑘∘𝜋=ℎ, then 𝑈(𝑘)∘𝑈(𝜋)=𝑈(ℎ)=𝑈(ℎ―)∘𝑈(𝜋); as 𝑈(𝜋) is surjective, 𝑈(𝑘)=𝑈(ℎ―), so 𝑘=ℎ― (𝑈 faithful). So (𝑄,𝜋) is a coequaliser of (𝛼,𝛽) (2.6.140), in particular a regular epimorphism.

Conclusion. Define 𝑒―:𝑄→𝑌, [𝑎]↦𝑈(𝑒)(𝑎); well-defined as 𝑎∼𝑏⟹𝑈(𝑒)(𝑎)=𝑈(𝑒)(𝑏), and a homomorphism by the same computation as for 𝜋, hence a morphism of 𝒞︀, with 𝑒―∘𝜋=𝑒. As 𝑒―([𝑎])=𝑒―([𝑏])⟹𝑈(𝑒)(𝑎)=𝑈(𝑒)(𝑏)⟹𝑎∼𝑏⟹[𝑎]=[𝑏], 𝑈(𝑒―) is injective; as 𝑒=𝑒―∘𝜋 and 𝑈(𝑒) is surjective (hypothesis), 𝑈(𝑒―) is surjective. So 𝑈(𝑒―) is bijective, hence 𝑒― is an isomorphism, as 𝒞︀ is algebraic and 𝑈 reflects isomorphisms (2.6.189).

Since 𝜋 is the coequaliser of (𝛼,𝛽) and 𝑒― is an isomorphism, 𝑒=𝑒―∘𝜋 is again a coequaliser of (𝛼,𝛽), as colimits are preserved under isomorphism (2.6.90); hence 𝑒 is a regular epimorphism (2.6.158). ∎

Proposition 2.6.196 (Algebraic Categories have Regular Epi-Mono Factorisations)

Let 𝒞︀ be an algebraic category (2.6.184). Then 𝒞︀ has regular epi-mono factorisations for every morphism (2.6.173).

More precisely, let 𝑓:𝑋→𝑌 be a morphism of 𝒞︀ and 𝐼≔𝑈(𝑓)(𝑈(𝑋))⊆𝑈(𝑌) the (underlying-set) image of 𝑓. Then 𝐼 is a subalgebra of 𝑌, and 𝑓=𝑚∘𝑒 is a regular epi-mono factorisation of 𝑓, where 𝑒:𝑋→𝐼 is the corestriction of 𝑓 and 𝑚:𝐼↪︎𝑌 is the inclusion.

Proof. Drafted by Claude Sonnet 5, reviewed by David Rufino.

𝐼 is a subalgebra. For 𝜔∈Ω and 𝑦1,…,𝑦𝑛𝜔∈𝐼, writing 𝑦𝑟=𝑈(𝑓)(𝑥𝑟) for 𝑥𝑟∈𝑈(𝑋), since 𝑓 is a homomorphism 𝜔𝑌(𝑦1,…)=𝜔𝑌(𝑈(𝑓)(𝑥1),…)=𝑈(𝑓)(𝜔𝑋(𝑥1,…))∈𝐼; so 𝐼 is a subalgebra (2.6.192). By (2.6.193), 𝐼 carries a (unique) Ω-algebra structure making the inclusion 𝑚:𝐼↪︎𝑌 a homomorphism, with 𝐼∈𝒞︀ (as 𝑌∈𝒞︀); as 𝒞︀ is full in Ω-𝐀𝐥𝐠, 𝑚 is a morphism of 𝒞︀, and monic by (2.6.194) (being injective).

Write 𝑒:𝑋→𝐼 for the corestriction of 𝑓, that is 𝑈(𝑒)≔𝑈(𝑓) regarded as a map into 𝐼; since 𝜔𝐼 is just 𝜔𝑌 restricted to 𝐼, 𝑒 is again a homomorphism, hence a morphism of 𝒞︀, with 𝑚∘𝑒=𝑓 and 𝑈(𝑒) surjective onto 𝐼 by construction. By (2.6.195), 𝑒 is therefore a regular epimorphism, so 𝑓=𝑚∘𝑒 is a regular epi-mono factorisation of 𝑓 (2.6.173). ∎

Proposition 2.6.197 (Equalisers in Algebraic Categories)

Consider a commutative diagram in an algebraic category 𝒞︀

Then 𝑒 is an equaliser for (𝑑0,𝑑1) if and only if 𝑈(𝑒) is injective and Im(𝑈(𝑒))={𝑦∈𝑈(𝑌)|𝑈(𝑑0)(𝑦)=𝑈(𝑑1)(𝑦)}.

Proof. Drafted by Claude Sonnet 5, reviewed by David Rufino.

Write 𝐹:𝟐→𝒞︀ for the diagram 𝑑0,𝑑1:𝑌⇉𝑍, so that 𝑒 being an equaliser for (𝑑0,𝑑1) means precisely that (𝑋,𝑒) is a limit for 𝐹.

(⟹) Suppose (𝑋,𝑒) is a limit for 𝐹. Since 𝒞︀ is algebraic, 𝑈 creates limits (2.6.189), so by (2.6.87), using that 𝐒𝐞𝐭 has all limits, 𝑈 preserves limits. Hence (𝑈(𝑋),𝑈(𝑒)) is a limit for 𝑈∘𝐹 in 𝐒𝐞𝐭, that is, an equaliser for (𝑈(𝑑0),𝑈(𝑑1)). By (2.6.139), 𝑈(𝑒) is injective and Im(𝑈(𝑒))={𝑦∈𝑈(𝑌)|𝑈(𝑑0)(𝑦)=𝑈(𝑑1)(𝑦)}, as required.

(⟸) Suppose 𝑈(𝑒) is injective and Im(𝑈(𝑒))={𝑦∈𝑈(𝑌)|𝑈(𝑑0)(𝑦)=𝑈(𝑑1)(𝑦)}.

By (2.6.139) the diagram 𝑈(𝑌)⇉𝑈(𝑍) has an equaliser in 𝐒𝐞𝐭, that is lim(𝑈∘𝐹) exists. Since 𝑈 creates limits (2.6.189), lim𝐹 exists in 𝒞︀; write (𝑋′,𝑒′) for this limit, so that 𝑒′ is an equaliser for (𝑑0,𝑑1). By the (⟹) direction applied to 𝑒′, 𝑈(𝑒′) is injective and

Im(𝑈(𝑒′))={𝑦∈𝑈(𝑌)|𝑈(𝑑0)(𝑦)=𝑈(𝑑1)(𝑦)}=Im(𝑈(𝑒))

using the hypothesis on 𝑒 for the second equality.

As 𝑑0∘𝑒=𝑑1∘𝑒, the universal property of the equaliser (𝑋′,𝑒′) yields a unique morphism 𝜑:𝑋→𝑋′ with 𝑒′∘𝜑=𝑒.

We claim 𝑈(𝜑) is a bijection. If 𝑈(𝜑)(𝑥)=𝑈(𝜑)(𝑦) then applying 𝑈(𝑒′) gives 𝑈(𝑒)(𝑥)=𝑈(𝑒′)(𝑈(𝜑)(𝑥))=𝑈(𝑒′)(𝑈(𝜑)(𝑦))=𝑈(𝑒)(𝑦), so 𝑥=𝑦 as 𝑈(𝑒) is injective; hence 𝑈(𝜑) is injective. Given 𝑥′∈𝑈(𝑋′), we have 𝑈(𝑒′)(𝑥′)∈Im(𝑈(𝑒′))=Im(𝑈(𝑒)), so 𝑈(𝑒′)(𝑥′)=𝑈(𝑒)(𝑥) for some 𝑥∈𝑈(𝑋), that is 𝑈(𝑒′)(𝑥′)=𝑈(𝑒′)(𝑈(𝜑)(𝑥)), whence 𝑥′=𝑈(𝜑)(𝑥) as 𝑈(𝑒′) is injective; hence 𝑈(𝜑) is surjective.

So 𝑈(𝜑) is a bijection, hence an isomorphism in 𝐒𝐞𝐭. Since 𝒞︀ is algebraic, 𝑈 reflects isomorphisms (2.6.189), so 𝜑 is an isomorphism in 𝒞︀.

Since (𝑋′,𝑒′) is an equaliser for (𝑑0,𝑑1) and 𝜑:𝑋→𝑋′ is an isomorphism with 𝑒′∘𝜑=𝑒, by (2.6.137) (𝑋,𝑒) is also an equaliser for (𝑑0,𝑑1), as required. ∎

Proposition 2.6.198 (Every Object has a Zero Element)

Let 𝒞︀ be an algebraic pointed category. Then a zero object 𝟎 consists of precisely one element, denoted by 0𝟎.

Every object 𝐴 has a unique element 0𝐴 such that 𝑈(0𝟎,𝐴)(0)=0𝐴 for any (resp. all) zero objects 𝟎.

Proof. Drafted by Claude Sonnet 5, reviewed by David Rufino.

Since 𝒞︀ is an algebraic category, 𝑈 creates limits (2.6.189), so by (2.6.87) 𝑈 preserves limits, and this holds unconditionally as the target category is 𝐒𝐞𝐭. In particular 𝑈 preserves terminal objects, these being the limit over the empty diagram.

As 𝟎 is a zero object it is in particular a terminal object of 𝒞︀ (2.6.55), so 𝑈(𝟎) is a terminal object of 𝐒𝐞𝐭. A terminal object of 𝐒𝐞𝐭 is a singleton, so 𝑈(𝟎) consists of precisely one element, which we denote 0𝟎.

Now fix an object 𝐴 and a zero object 𝟎, and set

0𝐴≔𝑈(0𝟎,𝐴)(0𝟎)∈𝑈(𝐴)

where 0𝟎,𝐴:𝟎→𝐴 is the unique morphism afforded by 𝟎 being an initial object (2.6.48), and 0𝟎∈𝑈(𝟎) is the unique element found above.

It remains to check that 0𝐴 does not depend on the choice of zero object. Let 𝟎′ be another zero object, with associated element 0𝐴′≔𝑈(0𝟎′,𝐴)(0𝟎′). Since 𝟎,𝟎′ are both initial objects (2.6.55), by uniqueness of initial objects (2.6.48) there is a (unique) isomorphism 𝜑:𝟎→𝟎′. As Mor(𝟎,𝐴) is a singleton, being initial, we have

0𝟎′,𝐴∘𝜑=0𝟎,𝐴

so applying 𝑈 and evaluating at 0𝟎

𝑈(0𝟎,𝐴)(0𝟎)=𝑈(0𝟎′,𝐴)(𝑈(𝜑)(0𝟎))

Now 𝑈(𝜑):𝑈(𝟎)→𝑈(𝟎′) is a map between singletons, so it necessarily sends 0𝟎 to the unique element 0𝟎′ of 𝑈(𝟎′). Hence

0𝐴=𝑈(0𝟎,𝐴)(0𝟎)=𝑈(0𝟎′,𝐴)(0𝟎′)=0𝐴′

so 0𝐴 is independent of the choice of zero object, as required. ∎

Proposition 2.6.199 (Kernels in Algebraic Categories)

Let 𝒞︀ be an algebraic pointed category, and consider a diagram

ker(𝛼)⟶𝑖𝑌⟶𝛼𝑍

Then (𝑖,ker(𝛼)) is a kernel for 𝛼 if and only if

  1. 𝑈(𝑖) is injective
  2. Im(𝑈(𝑖))={𝑦∈𝑈(𝑌)|𝑈(𝛼)(𝑦)=0𝑍}

Proof. Drafted by Claude Sonnet 5, reviewed by David Rufino.

Since 𝒞︀ is pointed, by (2.6.150) (𝑖,ker(𝛼)) is a kernel for 𝛼 if and only if 𝑖 is an equaliser for (𝛼,0𝑌,𝑍), where 0𝑌,𝑍:𝑌→𝑍 denotes the zero morphism (2.6.54).

As 𝒞︀ is algebraic, (2.6.197) (applied with 𝑑0=𝛼, 𝑑1=0𝑌,𝑍) shows this holds if and only if 𝑈(𝑖) is injective and

Im(𝑈(𝑖))={𝑦∈𝑈(𝑌)|𝑈(𝛼)(𝑦)=𝑈(0𝑌,𝑍)(𝑦)}

It remains to identify 𝑈(0𝑌,𝑍)(𝑦) with 0𝑍 for every 𝑦∈𝑈(𝑌). Write 0𝑌,𝑍=0𝟎,𝑍∘!𝑌, where !𝑌:𝑌→𝟎 and 0𝟎,𝑍:𝟎→𝑍 are the unique morphisms afforded by 𝟎 being terminal, resp. initial (2.6.54). By (2.6.198), 𝑈(𝟎) is a singleton {0𝟎}, so 𝑈(!𝑌)(𝑦)=0𝟎 for every 𝑦∈𝑈(𝑌), and therefore

𝑈(0𝑌,𝑍)(𝑦)=𝑈(0𝟎,𝑍)(𝑈(!𝑌)(𝑦))=𝑈(0𝟎,𝑍)(0𝟎)=0𝑍

using the definition of 0𝑍 from (2.6.198). Hence

{𝑦∈𝑈(𝑌)|𝑈(𝛼)(𝑦)=𝑈(0𝑌,𝑍)(𝑦)}={𝑦∈𝑈(𝑌)|𝑈(𝛼)(𝑦)=0𝑍}

so combining with the above, (𝑖,ker(𝛼)) is a kernel for 𝛼 if and only if 𝑈(𝑖) is injective and Im(𝑈(𝑖))={𝑦∈𝑈(𝑌)|𝑈(𝛼)(𝑦)=0𝑍}, as required. ∎
