3.5.1 Rings

Definition 3.5.3 (Localisation of a ring)

Let 𝐴 be a ring and 𝑆 a multiplicative set. A ring homomorphism 𝜙:𝐴→𝑅 is a localisation of 𝐴 at 𝑆 if

  1. 𝜙(𝑆)⊆𝑅⋆
  2. every element of 𝑅 has the form 𝜙(𝑎)𝜙(𝑠)−1 for some 𝑎∈𝐴, 𝑠∈𝑆
  3. ker(𝜙)={𝑎∈𝐴|𝑠𝑎=0for some𝑠∈𝑆}

We write 𝑎𝑠≔𝜙(𝑎)𝜙(𝑠)−1, so that every element of 𝑅 is a fraction. A localisation is unique up to unique isomorphism (3.5.5), so we write 𝑆−1𝐴 and 𝑖𝑆:𝐴→𝑆−1𝐴 for a localisation of 𝐴 at 𝑆, which exists by (3.5.7).

Proposition 3.5.4 (Universal Property)

Let 𝜙:𝐴→𝑅 be a localisation of 𝐴 at 𝑆 and 𝜓:𝐴→𝐵 a ring homomorphism. Then

  1. There is a unique morphism 𝜓̃ making the diagram commute

    if and only if 𝜓(𝑆)⊆𝐵⋆. In this case it’s given by

    𝜓̃(𝑎𝑠)=𝜓(𝑎)𝜓(𝑠)−1

  2. ker(𝜓̃)=𝑆−1ker(𝜓)≔{𝑎𝑠|𝑎∈ker(𝜓),𝑠∈𝑆}

Proof. Drafted by Claude Sonnet, reviewed by David Rufino.

  1. If 𝜓̃ exists then 1=𝜓̃(1)=𝜓̃(𝜙(𝑠)𝜙(𝑠)−1)=𝜓(𝑠)𝜓̃(𝜙(𝑠)−1). Which shows that 𝜓(𝑆)⊆𝐵⋆ and 𝜓(𝑠)−1=𝜓̃(𝜙(𝑠)−1). Hence 𝜓̃(𝑎𝑠)=𝜓̃(𝜙(𝑎))𝜓̃(𝜙(𝑠)−1)=𝜓(𝑎)𝜓(𝑠)−1, so 𝜓̃ is unique since every element of 𝑅 is a fraction.

    Conversely suppose 𝜓(𝑆)⊆𝐵⋆ then we claim that the given mapping is well-defined. For

    𝑎𝑠=𝑎′𝑠′⟹𝑠″(𝑠′𝑎−𝑠𝑎′)=0⟹𝜓(𝑠″)𝜓(𝑠′)𝜓(𝑎)=𝜓(𝑠″)𝜓(𝑠)𝜓(𝑎′)

    where the first implication is because 𝜙(𝑎𝑠′−𝑎′𝑠)=0 after multiplying by the unit 𝜙(𝑠)𝜙(𝑠′), so 𝑠″(𝑠′𝑎−𝑠𝑎′)=0 for some 𝑠″∈𝑆 by the third condition. Multiply by the appropriate inverses to find

    𝜓(𝑎)𝜓(𝑠)−1=𝜓(𝑎′)𝜓(𝑠′)−1

    It’s clearly a multiplicative homomorphism, as (𝑎𝑠)(𝑏𝑡)=𝑎𝑏𝑠𝑡 in 𝑅. Further it’s additive because 𝑎𝑠+𝑏𝑡=𝑎𝑡+𝑏𝑠𝑠𝑡 in 𝑅 and

    𝜓̃(𝑎𝑠+𝑏𝑡)=𝜓̃(𝑎𝑡+𝑏𝑠𝑠𝑡)=𝜓(𝑎𝑡+𝑏𝑠)𝜓(𝑠𝑡)−1=𝜓(𝑎)𝜓(𝑡)𝜓(𝑠)−1𝜓(𝑡)−1+𝜓(𝑏)𝜓(𝑠)𝜓(𝑠)−1𝜓(𝑡)−1=𝜓(𝑎)𝜓(𝑠)−1+𝜓(𝑏)𝜓(𝑡)−1=𝜓̃(𝑎𝑠)+𝜓̃(𝑏𝑡)

    Finally 𝜓̃(𝜙(𝑎))=𝜓̃(𝑎1)=𝜓(𝑎), so the diagram commutes.

  2. Suppose 𝜓̃(𝑎𝑠)=0 then 𝜓(𝑎)=𝜓(𝑠)𝜓̃(𝑎𝑠)=0, so 𝑎∈ker(𝜓) and 𝑎𝑠∈𝑆−1ker(𝜓). The converse is clear.

 ∎

Corollary 3.5.5 (Uniqueness of Localisation)
Let 𝜙:𝐴→𝑅 and 𝜙′:𝐴→𝑅′ be localisations of 𝐴 at 𝑆. Then there is a unique ring isomorphism 𝜃:𝑅→𝑅′ with 𝜃∘𝜙=𝜙′.

Proof. Drafted by Claude Sonnet, reviewed by David Rufino.

As 𝜙′(𝑆)⊆𝑅′⋆, (3.5.4) applied to 𝜙 and 𝜓=𝜙′ gives a unique 𝜃:𝑅→𝑅′ with 𝜃∘𝜙=𝜙′, and symmetrically a unique 𝜃′:𝑅′→𝑅 with 𝜃′∘𝜙′=𝜙. Then 𝜃′∘𝜃 and 1𝑅 both satisfy (−)∘𝜙=𝜙, so they are equal by uniqueness in (3.5.4) applied to 𝜓=𝜙. Similarly 𝜃∘𝜃′=1𝑅′. ∎

Lemma 3.5.6 (Equality of Fractions)

Let 𝜙:𝐴→𝑅 be a localisation of 𝐴 at 𝑆. Then for 𝑎,𝑏∈𝐴 and 𝑠,𝑡∈𝑆

𝑎𝑠=𝑏𝑡⟺𝑢(𝑎𝑡−𝑏𝑠)=0some𝑢∈𝑆.

Proof. Drafted by Claude Sonnet, reviewed by David Rufino.

Multiplying by the unit 𝜙(𝑠)𝜙(𝑡) shows 𝑎𝑠=𝑏𝑡 in 𝑅 if and only if 𝜙(𝑎𝑡−𝑏𝑠)=0, which holds if and only if 𝑢(𝑎𝑡−𝑏𝑠)=0 for some 𝑢∈𝑆 by the third condition. ∎

Note when 𝐴 is an integral domain and 𝑆 is proper then the equivalence relation may be weakened to 𝑎𝑡−𝑏𝑠=0.

Proposition 3.5.7 (Construction of the Localisation)

Let 𝐴 be a ring and 𝑆 a multiplicative set. Define the set

𝑆−1𝐴={𝑎𝑠|𝑎∈𝐴𝑠∈𝑆}

under the equivalence relation

𝑎𝑠=𝑏𝑡⟺𝑢(𝑎𝑡−𝑏𝑠)=0some𝑢∈𝑆.

Then 𝑆−1𝐴 is a ring under the obvious ring operations, and

𝑖𝑆:𝐴→𝑆−1𝐴𝑎→[𝑎1]

is a localisation of 𝐴 at 𝑆. It is non-zero precisely when 𝑆 is proper.

  1. ker(𝑖𝑆)={𝑎∈𝐴|𝑠𝑎=0for some𝑠∈𝑆}
  2. 𝑆−1𝐴 is the zero-ring if and only if 0∈𝑆 if and only if there exists 𝑠,𝑡∈𝑆 such that 𝑠𝑡=0.
  3. 𝑖𝑆(𝑠) is invertible for all 𝑠∈𝑆
  4. 𝑖𝑆 is injective if and only if 𝑆 has no zero-divisors
  5. This is an isomorphism if and only if 𝑆⊆𝐴⋆ already consists only of invertible elements (e.g. 𝑆={1}).

Proof.

  1. This follows by the definitions
  2. 11=01⟺𝑠=0 for some 𝑠∈𝑆 by the definitions
  3. 𝑠1⋅1𝑠=𝑠𝑠=11
  4. This follows from the first part.
  5. If 𝑆⊆𝐴⋆ then it contains no zero-divisors and 𝑖𝑆 is injective. Further it’s clear that 𝑎𝑠=𝑎𝑠−11 so that the map is surjective. Similarly if the map is bijective 𝑆 does not contain zero-divisors and 1𝑠 is in the image. Therefore there is 𝑎 such that 𝑡𝑎𝑠=1 for some 𝑡, which implies 𝑠 is invertible.

Finally 𝑖𝑆 is a localisation: the first condition is c), every element is 𝑎𝑠=𝑖𝑆(𝑎)𝑖𝑆(𝑠)−1 by c) and the definition of the operations, and the third is a). ∎

Example 3.5.8 (Quotient Field)

Let 𝐴 be an integral domain then 𝐴∖0=𝐴⋆ and we define the quotient field

Frac(𝐴)≔(𝐴∖0)−1𝐴
Proposition 3.5.9 (Quotient Field contains all localisation)

Let 𝐴 be an integral domain, 𝑆 a multiplicative set with 0∉𝑆, and Frac(𝐴) the quotient field. Define another model for 𝑆−1𝐴 as follows

𝑆−1𝐴≔{𝑎𝑠∈Frac(𝐴)|𝑎∈𝐴𝑠∈𝑆}

Proof. It’s injective because 𝐴 has no zero-divisors, and then the kernel 0 is {𝑎∈𝐴|𝑠𝑎=0for some𝑠∈𝑆} as 0∉𝑆. Each 𝑠∈𝑆 is invertible in Frac(𝐴) with inverse 1/𝑠∈𝑆−1𝐴, and every element of 𝑆−1𝐴 is 𝑎𝑠 by definition, so the three conditions of a localisation hold. ∎
Proposition 3.5.10 (Directed Limit)

Let 𝑆𝑖 be a family of multiplicatively closed sets directed by inclusion, such that 𝑆=⋃𝑖𝑆𝑖 is multiplicatively closed. Then there is a canonical isomorphism

lim⟶𝑖𝑆𝑖−1𝐴→𝑆−1𝐴

induced by the canonical maps

𝑆𝑖−1𝐴→𝑆−1𝐴

Proof. The canonical maps 𝑖𝑆𝑖𝑆 induce a unique morphism

lim⟶𝑖𝑆𝑖−1𝐴→𝑆−1𝐴[𝑎𝑖/𝑠𝑖]→𝑎𝑖/𝑠𝑖

by the universal property. An element on the right hand side is written 𝑎/𝑠 for some 𝑠∈𝑆. By hypothesis 𝑠∈𝑆𝑖 for some 𝑖, therefore it is surjective. Suppose we have two elements [𝑎𝑖/𝑠𝑖] and [𝑎𝑗/𝑠𝑗] on the left hand side which become equal in 𝑆−1𝐴. Then by definition 𝑠𝑘(𝑠𝑗𝑎𝑖−𝑎𝑗𝑠𝑖)=0 for some 𝑠𝑘∈𝑆𝑘. Lemma 3.5.11 (Localisation Respects Contraction of Multiplicative Sets)

Let 𝐴⊆𝐵 be subrings of a common ring 𝐶, and 𝑇⊂𝐵 a multiplicative set. Writing 𝑆≔𝑇∩𝐴 (a multiplicative set of 𝐴), and realising both localisations as subrings of 𝐶 (or of a common ring of fractions), 𝑆−1𝐴⊆𝑇−1𝐵.

In particular, for 𝔮 a prime ideal of 𝐵 and 𝔭≔𝔮∩𝐴, taking 𝑇≔𝐵∖𝔮 (so 𝑆=𝐴∖𝔭) gives 𝐴𝔭⊆𝐵𝔮.

Proof. Drafted by Claude Sonnet, reviewed by David Rufino.

For 𝑎/𝑠∈𝑆−1𝐴 (𝑎∈𝐴, 𝑠∈𝑆⊆𝑇), viewing 𝑎,𝑠∈𝐵 (as 𝐴⊆𝐵), 𝑠∈𝑇 directly gives 𝑎/𝑠∈𝑇−1𝐵. ∎

Combining the previous two results, for a directed union of subrings rather than a single fixed ring:
