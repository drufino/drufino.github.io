2.1 Set Theory

2.1.1 Relations

Definition 2.1.1 (Binary Relation)

A binary relation (or just relation) 𝑅 on a pair of sets (𝑋,𝑌) is subset of the cartesian product 𝑋×𝑌.

We write 𝑥𝑅𝑦 to mean precisely (𝑥,𝑦)∈𝑅.

Definition 2.1.2 (Converse Relation)

Let 𝑅 be a binary relation on (𝑋,𝑌) then we the converse relation 𝑅𝑇 on (𝑌,𝑋) given by

𝑦𝑅𝑇𝑥⟺𝑥𝑅𝑦
Definition 2.1.3 (Domain and Range)

Let 𝑅 be a relation on (𝑋,𝑌). We define the domain of 𝑅 to be

dom(𝑅)≔{𝑥∈𝑋|∃𝑦∈𝑌s.t.𝑥𝑅𝑦}

and the range of 𝑅

range(𝑅)≔{𝑦∈𝑋|∃𝑥∈𝑋s.t.𝑥𝑅𝑦}
Definition 2.1.4 (Equivalence Relation)

Let 𝑅 be a binary relation on (𝑋,𝑋). It is said to be

  1. reflexive if 𝑥𝑅𝑥 for all 𝑥∈𝑋
  2. symmetric if 𝑥𝑅𝑦⟹𝑦𝑅𝑥 for all 𝑥,𝑦∈𝑋
  3. transitive if 𝑥𝑅𝑦∧𝑦𝑅𝑧⟹𝑥𝑅𝑧 for all 𝑥,𝑦,𝑧∈𝑋

A relation which satisfies all these properties is called an equivalence relation on 𝑋. In this case we would write

𝑥∼𝑦

instead of 𝑥𝑅𝑦. For an element 𝑥∈𝑋 denote the equivalence class of 𝑥 by

[𝑥]𝑅={𝑦|𝑥𝑅𝑦}

Note that 𝑅𝑇=𝑅.

Definition 2.1.5 (Partition)

Let 𝑋 be a set an ℱ︀ a family of subsets of 𝑋. It is said to be a partition if

  1. 𝑋=⋃𝐴∈ℱ︀𝐴
  2. 𝐴,𝐵∈ℱ︀⟹𝐴=𝐵or𝐴∩𝐵=∅
Proposition 2.1.6 (Equivalence Classes form a Partition)

Let 𝐸 be an equivalence relation on 𝑋. The family

ℱ︀={[𝑥]𝐸|𝑥∈𝑋}

forms a partition of 𝑋. Denote by 𝑋/𝐸 the family of equivalence classes, called the quotient of 𝑋 with respect to 𝐸.

Proof. It’s clear that

𝑋=⋃𝐴∈ℱ︀𝐴

because by reflexive-ness 𝑥∈[𝑥]𝐸 for all 𝑥∈𝑋.

We claim that for any 𝑧∈[𝑥]𝐸 we have [𝑧]𝐸=[𝑥]𝐸. Suppose 𝑦∈[𝑥]𝐸 then 𝑥𝑅𝑧 and 𝑥𝑅𝑦. By symmetry and transitivity we then have 𝑧𝑅𝑦 which implies 𝑦∈[𝑧]𝐸. In other words [𝑥]𝐸⊆[𝑧]𝐸. By symmetry of 𝑅 we have 𝑥∈[𝑧]𝐸, so by the same token [𝑧]𝐸⊆[𝑥]𝐸, which shows they are equal.

Therefore it’s clear that [𝑥]𝐸∩[𝑦]𝐸≠∅⟹[𝑥]𝐸=[𝑦]𝐸 and thus ℱ︀ forms a partition. ∎

Definition 2.1.7 (Composition of Relation)

Suppose 𝑅 is a relation on (𝑋,𝑌) and 𝑆 a relation on (𝑌,𝑍). We define the composition 𝑆∘𝑅 on (𝑋,𝑍)

𝑆∘𝑅={(𝑥,𝑧)|∃𝑦∈𝑌s.t.𝑥𝑅𝑦and𝑦𝑅𝑧}

2.1.2 Functions

Definition 2.1.8 (Function)

A function 𝑓:𝑋→𝑌 consists of a binary relation Γ(𝑓) on (𝑋,𝑌) such that

  • dom(𝑓)=𝑋
  • Γ(𝑓) is single-valued that is 𝑥Γ(𝑓)𝑦∧𝑥Γ(𝑓)𝑦′⟹𝑦=𝑦′

Equivalently for all 𝑥∈𝑋 there exists precisely one 𝑦∈𝑌 such that 𝑥Γ(𝑓)𝑦.

We write 𝑓(𝑥)=𝑦 for the unique element 𝑦∈𝑌 such that 𝑥Γ(𝑓)𝑦.

Proposition 2.1.9 (Equality of Functions)
Two functions 𝑓,𝑔:𝑋→𝑌 are equal if and only if 𝑓(𝑥)=𝑔(𝑥) for all 𝑥∈𝑋.
Proposition 2.1.10 (Composition of Functions)

Let 𝑓:𝑋→𝑌 and 𝑔:𝑌→𝑍 be functions then the composition Γ(𝑔)∘Γ(𝑓) is still a function, which we write 𝑔∘𝑓, and

(𝑔∘𝑓)(𝑥)=𝑔(𝑓(𝑥))

Furthermore composition is associative in the sense that

(ℎ∘𝑔)∘𝑓=ℎ∘(𝑔∘𝑓)
Definition 2.1.11 (Injective, Surjective and Bijective)

Let 𝑓:𝑋→𝑌 be a function then we say

  • 𝑓 is injective if 𝑓(𝑥)=𝑓(𝑥′)⟹𝑥=𝑥′
  • 𝑓 is surjective if for all 𝑦∈𝑌 there exists 𝑥 such that 𝑓(𝑥)=𝑦
  • 𝑓 is bijective if it is both injective and surjective
Definition 2.1.12 (Inverse Function)

Let 𝑓:𝑋→𝑌 and 𝑔:𝑌→𝑋 be functions. We say

  • 𝑔 is a left inverse for 𝑓 if 𝑔∘𝑓=1𝑋
  • 𝑔 is a right inverse for 𝑓 if 𝑓∘𝑔=1𝑌
  • 𝑔 is a two-sided inverse for 𝑓 if it is both a left and right inverse
Proposition 2.1.13

Let 𝑓:𝑋→𝑌 be a function then

  • 𝑓 is injective if and only if it has a left inverse
  • 𝑓 is surjective if and only if it has a right inverse
  • 𝑓 is bijective if and only if it has a two-sided inverse
Definition 2.1.14 (Idempotent Function)
A function 𝑝:𝑋→𝑋 is idempotent 𝑝∘𝑝=𝑝.
Lemma 2.1.15 (Idempotent Criterion)
Let 𝑝:𝑋→𝑋 be a function. Then Fix(𝑝)⊆Im(𝑝) and these are equal if and only if 𝑝 is idempotent.

2.1.3 Partial Orders

Definition 2.1.16 (Preorder)

A binary relation ≤ on (𝑋,𝑋) is a preorder if

  • reflexivity 𝑥≤𝑥
  • transitivity 𝑥≤𝑦and𝑦≤𝑧⟹𝑥≤𝑧

We may refer to (𝑋,≤) as a preordered set or preorder.

Definition 2.1.17 (Poset)

A binary relation ≤ on (𝑋,𝑋) is a partial order if

  • reflexivity 𝑥≤𝑥
  • antisymmetry 𝑥≤𝑦and𝑦≤𝑥⟹𝑦=𝑥
  • transitivity 𝑥≤𝑦and𝑦≤𝑧⟹𝑥≤𝑧

We may refer to (𝑋,≤) as a partially ordered set or poset. Equivalently, a poset is a preorder which is additionally antisymmetric.

Definition 2.1.18 (Dual Poset)
Given a poset (𝑋,≤) denote the set 𝑋 with the converse relation by (𝑋,≤𝑑). This is the dual poset to (𝑋,≤).
Example 2.1.19
Let ℱ︀ be a family of subsets of a fixed set 𝐸. Then (ℱ︀,⊆) is a poset ordered under inclusion.
Definition 2.1.20 (Top and Bottom)
Let (𝑋,≤) we say ⊤ (resp. ⊥) is a top element (resp. bottom element) if it is greater than (resp. less than) every element of 𝑥. In this case it is unique.
Definition 2.1.21 (Monotone/Antitone Function)

Let (𝑋,≤) and (𝑌,≤) be posets. A function 𝑓:𝑋→𝑌 is

  • monotone / order-preserving if 𝑥≤𝑦⟹𝑓(𝑥)≤𝑓(𝑦)
  • antitone / order-reversing if 𝑥≤𝑦⟹𝑓(𝑦)≤𝑓(𝑥)
  • a monotone embedding if 𝑥≤𝑦⟺𝑓(𝑥)≤𝑓(𝑦)
  • an order isomorphism if it is bijective and monotone
  • a dual isomorphism if it is bijective and antitone
Proposition 2.1.22
Let 𝑓:𝑋→𝑌 be a monotone function. Then it is an embedding if and only if it is injective.

In what follows the notion of closure and kernel operator will be important.

Definition 2.1.23 (Closure operator)

Let (𝑋,≤) be a partially ordered set. A function 𝑐:𝑋→𝑋 is a closure operator if it is

  1. extensive 𝑥≤𝑐(𝑥)
  2. monotone 𝑥≤𝑦⟹𝑐(𝑥)≤𝑐(𝑦)
  3. idempotent 𝑐(𝑐(𝑥))=𝑐(𝑥)
Definition 2.1.24 (Kernel operator)

Let (𝑋,≤) be a partially ordered set. A function 𝜅:𝑋→𝑋 is a kernel operator if it is

  • co-extensive 𝜅(𝑥)≤𝑥
  • monotone 𝑥≤𝑦⟹𝜅(𝑥)≤𝜅(𝑦)
  • idempotent 𝜅(𝜅(𝑥))=𝜅(𝑥)

Note these definitions are “dual” with respect to the ordering on 𝑋.

2.1.4 Lattices

Certain families of subsets of algebraic structures (e.g. ideals, subgroups, normal subgroups, submodules) form a “sublattice” of the power set. Certain operations on, and results about, these subsets share common features regardless of the type of algebraic structure. Therefore we detail some elements of “Lattice Theory” (see Birkhoff) which may clarify the exposition.

Definition 2.1.25 (Upper and Lower Bounds)

Let (𝑋,≤) be a poset and 𝑆⊆𝑋. Define the set of upper bounds for 𝑆 by

𝑆↑={𝑥∈𝑋|𝑠≤𝑥∀𝑠∈𝑆}

and the set of lower bounds for 𝑆 by

𝑆↓={𝑥∈𝑋|𝑥≤𝑠∀𝑠∈𝑆}

Note by convention ∅↑=∅↓=𝑋. Furthermore

𝑋↑={{⊤}𝑋has a top element∅otherwise

and

𝑋↓={{⊥}𝑋has a bottom element∅otherwise
Lemma 2.1.26 (Upper/Lower bounds are antitone maps)

Let (𝑋,≤) be a poset and 𝑆,𝑇 subsets of 𝑋 then

  • antitone 𝑆⊆𝑇⟹𝑇↑⊆𝑆↑ and 𝑇↓⊆𝑆↓
  • unit-counit relations 𝑆⊆𝑆↑↓ and 𝑇⊆𝑇↓↑
  • triangular identities 𝑆↑=𝑆↑↓↑ and 𝑇↓=𝑇↓↑↓
Proof. We prove only the first triangular identity as the others are straightforward consequences of the definitions. Firstly 𝑆⊆𝑆↑↓⟹𝑆↑↓↑⊆𝑆↑ by the antitone property. Given the relation 𝑇⊆𝑇↓↑ substitute 𝑇=𝑆↑ to get the reverse inclusion. ∎
Lemma 2.1.27
Let (𝑋,≤) be a poset and 𝑆,𝑇 subsets of 𝑋. Then the intersections 𝑆∩𝑆↑ and 𝑇∩𝑇↓ contain at most one element. When they exist write the elements as ⊤𝑆 and ⊥𝑇 respectively, and are referred to as the maximum and minimum elements respectively.
Proof. Given 𝑥,𝑦∈𝑆∩𝑆↑ then by definition 𝑥≤𝑦 and 𝑦≤𝑥. By anti-symmetry we have 𝑥=𝑦 as required. ∎
Definition 2.1.28 (Supremum and Infimum)

Let (𝑋,≤) be a poset and 𝑆⊆𝑋 a subset. We say a supremum of 𝑆 is the minimal upper bound, i.e. the unique element of

𝑆↑∩𝑆↑↓

when it exists and write this as sup𝑆. Similarly an infimum of 𝑆 is the maximal lower bound, i.e. the unique element of

𝑆↓∩𝑆↓↑

when it exists and write this as inf𝑋.

Lemma 2.1.29 (Maximum = Supremum)
Let (𝑋,≤) be a poset and 𝑆⊆𝑋 a subset. Then ⊤𝑆 exists if and only if sup𝑆 exists and is a member of 𝑆. In this case ⊤𝑆=sup𝑆.
Lemma 2.1.30
Let (𝑋,≤) be a poset. Then {sup𝑆}↑=𝑆↑ and {inf𝑇}↓=𝑇↓ when these exist.
Lemma 2.1.31 (Sup is monotone and Inf is antitone)
Let (𝑋,≤) be a poset and 𝑆,𝑇 subsets of 𝑋. Then 𝑆⊆𝑇⟹sup𝑆≤sup𝑇 and inf𝑇≤inf𝑆 when these exist.

Proof. Note 𝑆⊆𝑇⟹𝑇↑⊆𝑆↑ so sup𝑇∈𝑆↑. By definition sup𝑆∈𝑆↑↓ therefore sup𝑆≤sup𝑇.

Similarly 𝑆⊆𝑇⟹𝑇↓⊆𝑆↓. By definition inf𝑇∈𝑇↓⟹inf𝑇∈𝑆↓. By definition inf𝑆∈𝑆↓↑ therefore inf𝑇≤inf𝑆. ∎

Remark 2.1.32

Note that ∅↑=𝑋 and therefore sup∅=⊥ when it exists. Similarly inf∅=⊤ when it exists.

When ⊤ exists sup𝑋=⊤, otherwse it is not defined. Similarly when ⊥ exists inf𝑋=⊥, otherwise it is not defined.

Definition 2.1.33 (Lattice)

A poset (𝑋,≤) is a lattice if every pair of elements {𝑥,𝑦} admits both a supremum and infimum. In this case we write

𝑎∨𝑏≔sup{𝑎,𝑏}

and

𝑎∧𝑏≔inf{𝑎,𝑏}

These are called the join and meet operations. A subset 𝑌 is called a sub-lattice if

𝑎,𝑏∈𝑌⟹𝑎∧𝑏∈𝑌and𝑎∨𝑏∈𝑌.

Similarly it is a complete lattice if every subset 𝑆 admits both a supremum and infimum. This is written

⋁𝑆≔sup𝑆

and

⋀𝑆≔inf𝑆

Note a complete lattice has both a top and a bottom element (by considering sup∅ and inf∅), and a lattice admits finite joins and meets.

Trivially

⋀{𝑥}=⋁{𝑥}=𝑥
Example 2.1.34 (Power Set)

For a fixed set 𝐸 the collection of subsets 𝒫︀(𝐸) is a complete lattice under the union and intersection operator with the convention that empty intersection is the whole set and empty union is the empty set

In this case ⊤=𝐸 and ⊥=∅.

Proposition 2.1.35 (Principal down-sets are lattices)
Let (𝑋,≤) be a lattice and 𝑥,𝑦∈𝑋. Then the subsets {𝑥}↑, {𝑥}↓ and {𝑥}↑∩{𝑦}↓ are sub-lattices.

Verifying a poset is a lattice is slightly easier than it may first appear.

Lemma 2.1.36 (Supremum is Infimum of upper bounds)

Let (𝑋,≤) be a poset and 𝑆 a subset of 𝑋. Then

sup𝑆=inf𝑆↑

when either exists. Dually

inf𝑆=sup𝑆↓
Proof. By definition sup𝑆 is the unique element of 𝑆↑∩𝑆↑↓ and inf𝑆↑ is the unique element of 𝑆↑↓∩𝑆↑↓↑. By (2.1.26) 𝑆↑↓↑=𝑆↑ so they are equivalent. ∎
Proposition 2.1.37 (Criteria to be a Complete Lattice)

Let (𝑋,≤) be a poset. Then the following are equivalent

  1. 𝑋 is a complete lattice
  2. 𝑋 admits arbitrary infimums (and in particular has ⊤=inf∅)
  3. 𝑋 admits arbitrary supremums (and in particular has ⊥=sup∅)

In this case we have the relationships

⋁𝑆=⋀𝑆↑⋀𝑆=⋁𝑆↓

Proof. a) ⟹ b,c) is clear.

b,c) ⟹ a) follows from the previous Lemma. ∎

Lemma 2.1.38
Let (𝑋,≤) be a poset and (𝑌,≤) a sub-poset. Let 𝑆⊆𝑌 be a subset. Then inf𝑌𝑆 exists if and only if inf𝑋𝑆 exists and belongs to 𝑌. In this case they are equal.

Proof. Note in general that 𝑇↓,𝑌=𝑇↓,𝑋∩𝑌 and 𝑇↑,𝑌=𝑇↑,𝑋∩𝑌. Therefore

𝑆↓,𝑌∩𝑆↓↑,𝑌=𝑆↓,𝑋∩𝑆↓↑,𝑋∩𝑌

Recall inf𝑆 is the unique element of 𝑆↓∩𝑆↓↑ if it exists. Then the result follows easily. ∎

Definition 2.1.39 (Moore Family)

Let (𝑋,≤) be a complete lattice. A sub-poset (𝑌,≤) is a Moore family over 𝑋 if it satisfies the following property

𝑆⊆𝑌⟹⋀𝑋𝑆∈𝑌

In particular this includes the case 𝑆=∅ and so ⊤∈𝑌.

Example 2.1.40 (Moore family of sets)

Given a fixed set 𝐸, then 𝒫︀(𝐸) is a complete lattice ordered under inclusion. Then a family of subsets ℱ︀ is a Moore family precisely when

  • 𝐸∈ℱ︀
  • 𝐴𝑖∈𝐼∈ℱ︀⟹⋂𝑖∈𝐼𝐴𝑖∈ℱ︀
Proposition 2.1.41 (Equivalent Formulations of Complete Sub-lattice)

Let (𝑋,≤) be a complete lattice and (𝑌,≤) a sub-poset. Then the following are equivalent

  1. (𝑌,≤) is a Moore family
  2. (𝑌,≤) is a complete lattice
  3. 𝑌 is the image of some closure operator 𝑐:𝑋→𝑋

In this case the closure operator is given by

𝑐(𝑥)=⋀𝑋{𝑦∈𝑌|𝑥≤𝑦}

For 𝑆⊆𝑌

⋀𝑌𝑆=⋀𝑋𝑆⋁𝑌𝑆=𝑐(⋁𝑋𝑆)

and for 𝑆⊆𝑋 we have

𝑐(⋁𝑋𝑆)=⋀𝑋(𝑆↑∩𝑌)

Proof. a) ⟹ b) By (2.1.38) 𝑆⊆𝑌⟹⋀𝑌𝑆=⋀𝑋𝑆. By (2.1.37) then 𝑌 is a complete lattice.

b) ⟹ c) Suppose that (𝑌,≤) is a complete lattice then define the function 𝑐:𝑋→𝑋 by 𝑐(𝑥)=⋀𝑋Γ𝑥 where Γ𝑥={𝑦∈𝑌|𝑥≤𝑦}. We need to show that it is a closure operator. Evidently 𝑥∈Γ𝑥↓ and 𝑐(𝑥)∈Γ𝑥↓↑ by definition of infimum. Therefore 𝑥≤𝑐(𝑥) and 𝑐 is extensive. Note 𝑥≤𝑦⟹Γ𝑦⊆Γ𝑥. By (2.1.31) we have infΓ𝑥≤infΓ𝑦, whence 𝑐(𝑥)≤𝑐(𝑦) and 𝑐 is monotone.

𝑌 is a complete lattice, so by (2.1.38) we have 𝑐(𝑥)∈𝑌 so that Im(𝑐)⊆𝑌. We claim that 𝑥∈𝑌⟹𝑐(𝑥)=𝑥. In this case 𝑥∈Γ𝑥 and 𝑐(𝑥)∈Γ𝑥↓ whence 𝑐(𝑥)≤𝑥 and therefore 𝑥=𝑐(𝑥) as required. Therefore 𝑌⊆Fix(𝑐)⊆Im(𝑐)⊆𝑌, whence 𝑌=Im(𝑐)=Fix(𝑐) and 𝑐 is idempotent by (2.1.15). As 𝑐 is extensive, monotone and idempotent it is by definition a closure operator.

c) ⟹ a) In order for 𝑌≔Im(𝑐) to be a Moore family, we need to show 𝑆⊆𝑌⟹⋀𝑋𝑆∈𝑌. We claim that by properties of 𝑐 we have

𝑆⊆𝑌⟹𝑐(𝑆↓)⊆𝑆↓𝑇⊆𝑋⟹𝑐(𝑇↑)⊆𝑇↑

Therefore 𝑐 maps the singleton set 𝑆↓∩𝑆↓↑={⋀𝑋𝑆} to itself. In otherwords ⋀𝑋𝑆∈Fix(𝑐)=Im(𝑐)=𝑌 as required.

Define Γ𝑥≔{𝑦∈𝑌|𝑥≤𝑦}. We wish to show that 𝑐(𝑥)=⋀𝑋Γ𝑥. As 𝑥≤𝑐(𝑥) we have 𝑐(𝑥)∈Γ𝑥. Furthermore 𝑦∈Γ𝑥⟹𝑐(𝑥)≤𝑐(𝑦)=𝑦. So 𝑐(𝑥)∈Γ𝑥↓. Therefore 𝑐(𝑥)=⊥Γ𝑥=⋀𝑋Γ𝑥 as required.

Finally by (2.1.30) {⋁𝑋𝑆}↑=𝑆↑ for any 𝑆⊆𝑋. Therefore, as 𝑐(𝑥)=⋀𝑋Γ𝑥 we find

𝑐(⋁𝑋𝑆)=⋀𝑋({⋁𝑋𝑆}↑∩𝑌)=⋀𝑋(𝑆↑∩𝑌)

as required. In particular when 𝑆⊆𝑌 we find by (2.1.41)

⋁𝑌𝑆=⋀𝑌𝑆↑,𝑌=⋀𝑋𝑆↑,𝑌=⋀𝑋(𝑆↑∩𝑌)=𝑐(⋁𝑋𝑆)

 ∎

Remark 2.1.42

For a given complete lattice (𝑋,≤) we have established a correspondence between

Proposition 2.1.44 (Alternative expression for join)

Let (𝑋,≤) be a complete lattice and 𝑐:𝑋→𝑋 a closure operator with image 𝑌. Then for any subset 𝑆⊂𝑋

𝑐(⋁𝑋𝑆)=𝑐(⋁𝑋𝑐(𝑆))=⋁𝑌𝑐(𝑆)=⋀𝑋(𝑆↑∩𝑌)

i.e. it’s the smallest “closed” set containing each element of 𝑆.

Proof. By (2.1.41) the expression for 𝑐(⋁𝑋𝑆) yields

𝑐(⋁𝑋𝑐(𝑆))=⋀𝑋(𝑐(𝑆)↑∩𝑌)=⋀𝑋(𝑆↑∩𝑌)=𝑐(⋁𝑋𝑆)

where the middle equality follows because if 𝑦∈𝑌 then 𝑐(𝑠)≤𝑦⟺𝑠≤𝑦. Furthermore 𝑐(𝑆)⊆𝑌 so the expression for ⋁𝑌 yields

𝑐(⋁𝑋𝑐(𝑆))=⋁𝑌𝑐(𝑆).

as required. ∎

2.1.5 Distributive Lattice

Proposition 2.1.45

Let (𝑋,≤) be a lattice then the following relations hold

  1. 𝑥∧(𝑦∨𝑧)≥(𝑥∧𝑦)∨(𝑥∧𝑧)
  2. 𝑥∨(𝑦∧𝑧)≤(𝑥∨𝑦)∧(𝑥∨𝑧)

Proof. a) By definition 𝑥∧𝑦≤𝑥 and 𝑥∧𝑦≤𝑦≤𝑦∨𝑧. Therefore 𝑥∧𝑦≤𝑥∧(𝑦∨𝑧). By symmetry in 𝑦 and 𝑧 we have 𝑥∧𝑧≤𝑥∧(𝑦∨𝑧). Whence (𝑥∧𝑦)∨(𝑥∧𝑧)≤𝑥∧(𝑦∨𝑧) as required.

b) follows by duality ∎

Definition 2.1.46 (Distributive Lattice)

We say a lattice (𝑋,≤) is distributive if it satisfies the following relations for all 𝑥,𝑦,𝑧∈𝑋

  • 𝑥∧(𝑦∨𝑧)=(𝑥∧𝑦)∨(𝑥∧𝑧)
  • 𝑥∨(𝑦∧𝑧)=(𝑥∨𝑦)∧(𝑥∨𝑧)
Proposition 2.1.47

Let (𝑋,≤) be a lattice then TFAE

  1. (𝑋,≤) is a distributive lattice
  2. 𝑥∧(𝑦∨𝑧)≤(𝑥∧𝑦)∨(𝑥∧𝑧)
  3. 𝑥∨(𝑦∧𝑧)≥(𝑥∨𝑦)∧(𝑥∨𝑧)
Example 2.1.48
Any family of subsets closed under finite intersection and union is a distributive lattice.

2.1.6 Galois Connections

Definition 2.1.49 (Galois Connection)

Let (𝑋,≤𝑋) and (𝑌,≤𝑌) be posets. A pair of functions (𝑓⋆,𝑓⋆)

𝑋⇌𝑓⋆𝑓⋆𝑌

is called an antitone Galois connection if it satisfies the adjoint property

  • 𝑥≤𝑋𝑓⋆(𝑦)⟺𝑦≤𝑌𝑓⋆(𝑥)∀𝑥∈𝑋,𝑦∈𝑌

We say it is a monotone Galois connection if instead

  • 𝑥≤𝑋𝑓⋆(𝑦)⟺𝑓⋆(𝑥)≤𝑌𝑦∀𝑥∈𝑋,𝑦∈𝑌

We will assume that if not otherwise specified the connection is antitone.

Proposition 2.1.50 (Equivalent Condition for Galois Connection)

Let (𝑋,≤𝑋) and (𝑌,≤𝑌) be posets. Consider a pair of functions

𝑋⇌𝑓⋆𝑓⋆𝑌

Then this constitutes an antitone Galois Connection if and only if

  • 𝑓⋆ and 𝑓⋆ are both antitone
  • 𝑥≤𝑋𝑓⋆(𝑓⋆(𝑥)) and 𝑦≤𝑌𝑓⋆(𝑓⋆(𝑦)) for all 𝑥∈𝑋,𝑦∈𝑌 (i.e. 𝑓⋆∘𝑓⋆ and 𝑓⋆∘𝑓⋆ are extensive)

Similarly it constitutes a monotone Galois Connection if and only if

  • 𝑓⋆ and 𝑓⋆ are both monotone
  • 𝑥≤𝑋𝑓⋆(𝑓⋆(𝑥)) and 𝑓⋆(𝑓⋆(𝑦))≤𝑌𝑦 for all 𝑥∈𝑋,𝑦∈𝑌

Proof. We consider only the antitone case, as the monotone follows from duality (flip ≤𝑌).

Suppose that (𝑓⋆,𝑓⋆) satisfies the adjoint property

𝑓⋆(𝑥)=𝑓⋆(𝑥)⟹𝑓⋆(𝑥)≤𝑌𝑓⋆(𝑥)⟹𝑥≤𝑋𝑓⋆(𝑓⋆(𝑥))𝑓⋆(𝑦)=𝑓⋆(𝑦)⟹𝑓⋆(𝑦)≤𝑌𝑓⋆(𝑦)⟹𝑦≤𝑌𝑓⋆(𝑓⋆(𝑦))

whence the extensive property follows. Furthermore

𝑥≤𝑋𝑥′⟹𝑥≤𝑋𝑓⋆(𝑓⋆(𝑥′))⟹𝑓⋆(𝑥′)≤𝑌𝑓⋆(𝑥)𝑦≤𝑌𝑦′⟹𝑦≤𝑌𝑓⋆(𝑓⋆(𝑦′))⟹𝑓⋆(𝑦)≤𝑋𝑓⋆(𝑦′)

which shows that the functions 𝑓⋆ and 𝑓⋆ are antitone.

Conversely suppose they satisfy the given conditions. Then by the antitone and extensive properties in turn

𝑥≤𝑋𝑓⋆(𝑦)⟹𝑓⋆(𝑓⋆(𝑦))≤𝑌𝑓⋆(𝑥)⟹𝑦≤𝑌𝑓⋆(𝑥)

and

𝑦≤𝑌𝑓⋆(𝑥)⟹𝑓⋆(𝑓⋆(𝑥))≤𝑋𝑓⋆(𝑦)⟹𝑥≤𝑋𝑓⋆(𝑦).

which is the adjoint property as required. ∎

Definition 2.1.51 (Closed sets)

Let (𝑓⋆,𝑓⋆) be a Galois connection. Then define the closed sets to be

𝑋⋆≔𝑓⋆(𝑌)𝑌⋆≔𝑓⋆(𝑋)
Proposition 2.1.52 (Isomorphism on closed sets)

Consider an antitone (resp. monotone) Galois connection 𝑋⇌𝑓⋆𝑓⋆𝑌. Then it restricts to a dual isomorphism (resp. order isomorphism) on closed sets

𝑋⋆⇌𝑓⋆𝑓⋆𝑌⋆

Furthermore the following properties hold

  • 𝑓⋆∘𝑓⋆∘𝑓⋆=𝑓⋆
  • 𝑓⋆∘𝑓⋆∘𝑓⋆=𝑓⋆
  • In the antitone case 𝑓⋆∘𝑓⋆ and 𝑓⋆∘𝑓⋆ are closure operators.
  • In the monotone case 𝑓⋆∘𝑓⋆ is a closure operator and 𝑓⋆∘𝑓⋆ is a kernel operator.
  • 𝑋⋆=Fix(𝑓⋆∘𝑓⋆)=Im(𝑓⋆∘𝑓⋆)
  • 𝑌⋆=Fix(𝑓⋆∘𝑓⋆)=Im(𝑓⋆∘𝑓⋆)

Proof. We detail the antitone case as the monotone case follows by duality. We first prove so-called triangular identities, for by the extensive property (2.1.50)

𝑥≤𝑓⋆(𝑓⋆(𝑥))⟹𝑓⋆(𝑓⋆(𝑓⋆(𝑥)))≤𝑓⋆(𝑥)

and by the other extensive property

𝑓⋆(𝑥)≤𝑓⋆(𝑓⋆(𝑓⋆(𝑥)))

whence they are equal. The other case is similar.

It’s immediate that 𝑓⋆∘𝑓⋆ and 𝑓⋆∘𝑓⋆ are idempotent, and they are extensive by (2.1.50). And the composition of two antitone functions is monotone so 𝑓⋆∘𝑓⋆ and 𝑓⋆∘𝑓⋆ are closure operators.

Observe

Im(𝑓⋆∘𝑓⋆)⊆Im(𝑓⋆)⊆Fix(𝑓⋆∘𝑓⋆)

where the first inclusion is trivial and the second inclusion follows from the second triangular identity. However both sides are equal by (2.1.15) and the expression for 𝑋⋆ follows. The expression for 𝑌⋆ follows similarly.

This shows that the maps are mutual inverses as required. ∎

In certain circumstances we may consider a smaller subset of 𝑋, by applying a suitable closure operator which is compatible with the Galois correspondence:

Proposition 2.1.53 (Subordinated Closure Operator)

Let 𝑋⇌𝑓⋆𝑓⋆𝑌 be a Galois connection and 𝑐:𝑋→𝑋 be a closure operator with image 𝑋𝑐. Then

𝑐(𝑥)≤(𝑓⋆∘𝑓⋆)(𝑥)∀𝑥∈𝑋⟺Im(𝑓⋆)⊆Fix(𝑐)⟺𝑋⋆⊆𝑋𝑐

In this case

𝑓⋆(𝑐(𝑥))=𝑓⋆(𝑥)

Proof. Suppose 𝑐(𝑥)≤(𝑓⋆∘𝑓⋆)(𝑥). Substitute 𝑥=𝑓⋆(𝑦) then, because 𝑐 is extensive,

𝑓⋆(𝑦)≤𝑐(𝑓⋆(𝑦))≤(𝑓⋆∘𝑓⋆∘𝑓⋆)(𝑦)=𝑓⋆(𝑦).

Therefore 𝑐(𝑓⋆(𝑦))=𝑓⋆(𝑦) and Im(𝑓⋆)⊆Fix(𝑐) as required. Conversely suppose this holds, then by the monotone property of 𝑐 and extensive property of 𝑓⋆∘𝑓⋆

𝑥≤(𝑓⋆∘𝑓⋆)(𝑥)⟹𝑐(𝑥)≤𝑐((𝑓⋆∘𝑓⋆)(𝑥))=(𝑓⋆∘𝑓⋆)(𝑥).

as required. Finally by the extensive property of 𝑐

𝑥≤𝑐(𝑥)≤(𝑓⋆∘𝑓⋆)(𝑥)

and by the antitone/monotone property of 𝑓⋆ and triangular identity

𝑓⋆(𝑥)≤𝑓⋆(𝑐(𝑥))≤𝑓⋆(𝑥)

whence 𝑓⋆(𝑐(𝑥))=𝑓(𝑥) as required. ∎

Proposition 2.1.55 (Joins under Galois Correspondence)

Let (𝑋,≤𝑋) and (𝑌,≤𝑌) be complete lattices with an antitone Galois connection 𝑋⇌𝑓⋆𝑓⋆𝑌. Then for 𝑆⊆𝑋

𝑓⋆(⋁𝑆)=⋀𝑓⋆(𝑆)

Similarly for 𝑇⊆𝑌 we have

𝑓⋆(⋁𝑇)=⋀𝑓⋆(𝑇)

Proof. Let 𝑎=⋁𝑆 and 𝑏=⋀𝑓⋆(𝑆). Then 𝑠≤𝑎⟹𝑓⋆(𝑎)≤𝑓⋆(𝑠) for all 𝑠∈𝑆, which implies 𝑓⋆(𝑎)≤𝑏. Similarly 𝑏≤𝑓⋆(𝑠)⟹𝑠≤𝑓⋆(𝑏) by the adjoint criterion. Therefore 𝑎≤𝑓⋆(𝑏) by definition of join, which implies 𝑏≤𝑓⋆(𝑎) by the adjoint criterion again. Whence 𝑓⋆(𝑎)=𝑏 as required.

The second statement follows from duality. ∎

2.1.7 Axiom of Choice

Theorem 2.1.56 (Axiom of choice)

There are a number of essentially equivalent forrmulations of the axiom of choice

  1. The Cartesian product of a non-empty family of sets is non-empty
  2. For any set 𝑋 of non-empty sets there exists a function 𝑓:𝑋→⋃𝑋 such that 𝐴∈𝑋⟹𝑓(𝐴)∈𝐴.
  3. Zorn’s Lemma Suppose a partially ordered set (𝑋,≤) is such that every chain in 𝑋 has an upper bound in 𝑋. Then 𝑋 contains at least one maximal element.
  4. Every surjective function has a right inverse.

Let 𝜋:𝑋→𝑌 be a surjective function and 𝑇⊆𝑌 a subset. Then there exists a subset 𝑆⊆𝑋 such that 𝜋|𝑆 is bijective.

2.1.8 Chain Conditions

Definition 2.1.60 (Totally ordered / chains)
A poset (ℱ︀,≤) is totally ordered if 𝑥≤𝑦 or 𝑦≤𝑥 for all 𝑥,𝑦∈ℱ︀.
Definition 2.1.61 (Chain)

A non-empty subset 𝐶 of ℱ︀ is a chain if it is totally ordered under ≤.

The length of the chain is simply ℓ(𝐶)≔|𝐶|−1.

A chain 𝐶 is

  • saturated if 𝑥≤𝑧≤𝑦 and 𝑥,𝑦∈𝐶⟹𝑧∈𝐶.
  • maximal if it’s not contained properly in another chain.
Definition 2.1.62 (Chain-Complete)
A poset (ℱ︀,≤) is chain complete if every chain 𝐶 has a supremum in ℱ︀. It is co-chain complete if every chain 𝐶 has an infimum in ℱ︀.
