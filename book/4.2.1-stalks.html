4.2.1 Stalks

Definition 4.2.5 (Stalk of a presheaf)

Let 𝑋 be a topological space, ℬ︀ a base closed under finite intersections and ℱ︀ a ℬ︀-presheaf.

Let 𝑍 be an irreducible subset of 𝑋, then the family of open subsets 𝑈∈ℬ︀ meeting 𝑍 is closed under finite intersections (4.1.60) and therefore forms a directed preorder (2.6.123) ordered by reverse inclusion.

Therefore we may define the stalk at 𝑍 by the direct limit (2.6.125)

ℱ︀𝑍≔lim⟶𝑈∈ℬ︀,𝑈∩𝑍≠∅ℱ︀(𝑈)

This means there is a family of morphisms {𝜌𝑈𝑍:ℱ︀(𝑈)→ℱ︀𝑍} such that

  1. all 𝑉∈ℬ︀ with 𝑉⊂𝑈 intersecting 𝑍 satisfy 𝜌𝑉𝑍∘𝜌𝑈𝑉=𝜌𝑈𝑍,
  2. any collection of morphisms 𝛼𝑈:ℱ︀(𝑈)→𝒜︀ satisfying 𝛼𝑈=𝛼𝑉∘𝜌𝑈𝑉 factors uniquely through a morphism 𝛼𝑍:ℱ︀𝑍→𝒜︀

When 𝑍={𝑥} we denote this simply by ℱ︀𝑥.

Consider the situation (4.2.5) where the value category 𝒞︀ is algebraic (2.6.184). Then

𝑈(ℱ︀𝑍)=(𝑈∘ℱ︀)𝑍

with morphisms

Proof. By (2.6.189), the forgetful functor 𝑈:𝒞︀→𝐒𝐞𝐭 creates directed colimits, and so the result follows from (2.6.128). ∎

Lemma 4.2.8 (Lifting Stalks)

Suppose we are in the situation of (4.2.6) and 𝜎∈ℱ︀(𝑈), 𝜏∈ℱ︀(𝑉) are sections such that 𝑍∩𝑈∩𝑉≠∅.

  1. Then 𝜎𝑍=𝜏𝑍 if and only if there is a neighbourhood 𝑊∈ℬ︀, 𝑊⊆𝑈∩𝑉, meeting 𝑍 such that 𝜎|𝑊=𝜏|𝑊.
  2. If 𝜎𝑥=𝜏𝑥 for all 𝑥∈𝑈∩𝑉, then there is an open cover 𝑈∩𝑉=⋃𝑖𝑈𝑖 such that 𝜎|𝑈𝑖=𝜏|𝑈𝑖
  3. If in addition ℱ︀ is a sheaf then 𝜎|𝑈∩𝑉=𝜏|𝑈∩𝑉.

Proof. Drafted by Claude Sonnet 5, reviewed by David Rufino.

By (4.2.6), ℱ︀𝑍={(𝑊,𝜌)|𝑊∈ℬ︀,𝜌∈ℱ︀(𝑊)}/∼ with (𝑊,𝜌)∼(𝑊′,𝜌′) iff there is 𝑁∈ℬ︀, 𝑁⊆𝑊∩𝑊′, 𝑁∩𝑍≠∅, with 𝜌|𝑁=𝜌′|𝑁; and 𝜎𝑍=[(𝑈,𝜎)], 𝜏𝑍=[(𝑉,𝜏)]. So 𝜎𝑍=𝜏𝑍 if and only if (𝑈,𝜎)∼(𝑉,𝜏), which is exactly the stated condition, proving a).

For b), suppose 𝜎𝑥=𝜏𝑥 for all 𝑥∈𝑈∩𝑉. For each such 𝑥, a) (applied with 𝑍≔{𝑥}, an irreducible subset meeting 𝑈∩𝑉) gives 𝑊𝑥∈ℬ︀, 𝑊𝑥⊆𝑈∩𝑉, 𝑥∈𝑊𝑥, with 𝜎|𝑊𝑥=𝜏|𝑊𝑥. Then {𝑊𝑥}𝑥∈𝑈∩𝑉 is an open cover of 𝑈∩𝑉 with the required property.

For c), as ℬ︀ is closed under finite intersections and 𝑈,𝑉∈ℬ︀, 𝑈∩𝑉∈ℬ︀, so 𝜎|𝑈∩𝑉,𝜏|𝑈∩𝑉∈ℱ︀(𝑈∩𝑉) are defined. By b) there is an open cover 𝑈∩𝑉=⋃𝑖𝑊𝑖 with 𝜎|𝑊𝑖=𝜏|𝑊𝑖, that is 𝜌(𝑈∩𝑉)𝑊𝑖(𝜎|𝑈∩𝑉)=𝜌(𝑈∩𝑉)𝑊𝑖(𝜏|𝑈∩𝑉) for all 𝑖; as ℱ︀ is a sheaf, the separation condition (4.2.4) gives 𝜎|𝑈∩𝑉=𝜏|𝑈∩𝑉. ∎

Lemma 4.2.10 (Pointwise Injectivity and Injectivity on Stalks)

Let 𝒞︀ be algebraic (2.6.184) and 𝜙:ℱ︀→𝒢︀ a morphism of presheaves such that 𝜙𝑈 is injective for all 𝑈⊂𝑋. Then 𝜙𝑥 is injective for all 𝑥∈𝑋.

Conversely, if 𝜙 is a morphism of sheaves and 𝜙𝑥 is injective for all 𝑥∈𝑋, then 𝜙𝑈 is injective for all 𝑈⊂𝑋.

Proof. Drafted by Claude Sonnet 5, reviewed by David Rufino.

Fix 𝑥∈𝑋 and suppose 𝑎,𝑏∈ℱ︀𝑥 with 𝜙𝑥(𝑎)=𝜙𝑥(𝑏). By (4.2.6), 𝑎=(𝜎1)𝑥, 𝑏=(𝜎2)𝑥 for some 𝜎1∈ℱ︀(𝑉1), 𝜎2∈ℱ︀(𝑉2), 𝑉1,𝑉2∈ℬ︀ containing 𝑥; setting 𝑉≔𝑉1∩𝑉2∈ℬ︀, 𝜎≔𝜎1|𝑉, 𝜏≔𝜎2|𝑉, we have 𝜎,𝜏∈ℱ︀(𝑉) with 𝜎𝑥=𝑎, 𝜏𝑥=𝑏. Then

(𝜙𝑉(𝜎))𝑥=𝜙𝑥(𝜎𝑥)=𝜙𝑥(𝑎)=𝜙𝑥(𝑏)=𝜙𝑥(𝜏𝑥)=(𝜙𝑉(𝜏))𝑥

so by (4.2.8).a) (with both opens taken to be 𝑉) there is 𝑊∈ℬ︀, 𝑊⊆𝑉, 𝑥∈𝑊, with 𝜙𝑉(𝜎)|𝑊=𝜙𝑉(𝜏)|𝑊, that is 𝜙𝑊(𝜎|𝑊)=𝜙𝑊(𝜏|𝑊). As 𝜙𝑊 is injective, 𝜎|𝑊=𝜏|𝑊, so 𝑎=𝜎𝑥=(𝜎|𝑊)𝑥=(𝜏|𝑊)𝑥=𝜏𝑥=𝑏.

Conversely, fix 𝑈⊂𝑋 and 𝜎,𝜏∈ℱ︀(𝑈) with 𝜙𝑈(𝜎)=𝜙𝑈(𝜏). For every 𝑥∈𝑈, 𝜙𝑥(𝜎𝑥)=(𝜙𝑈(𝜎))𝑥=(𝜙𝑈(𝜏))𝑥=𝜙𝑥(𝜏𝑥), so 𝜎𝑥=𝜏𝑥 as 𝜙𝑥 is injective. As ℱ︀ is a sheaf, (4.2.8).c) (taking both opens of the lemma to be 𝑈) gives 𝜎=𝜏. ∎

Proposition 4.2.11 (Isomorphisms of Presheaves and Sheaves)

Let 𝜙:ℱ︀→𝒢︀ be a morphism of presheaves (resp. sheaves). Then the following are equivalent

  1. 𝜙 is an isomorphism
  2. 𝜙𝑈 is an isomorphism for all 𝑈⊂𝑋

If 𝒞︀ is algebraic (2.6.184), then a), b) are further equivalent to

  1. 𝜙𝑈 is bijective for all 𝑈⊂𝑋

If moreover ℱ︀,𝒢︀ are sheaves, a)–c) are equivalent to

  1. 𝜙𝑥:ℱ︀𝑥→𝒢︀𝑥 is an isomorphism for all 𝑥∈𝑋

Proof. Drafted by Claude Sonnet 5, reviewed by David Rufino.

𝑏)⟹𝑎): If each 𝜙𝑈 is an isomorphism, define 𝜓𝑈≔𝜙𝑈−1; for 𝑉⊆𝑈, inverting both sides of the naturality square 𝜙𝑉∘𝜌𝑈𝑉=𝜌𝑈𝑉∘𝜙𝑈 gives 𝜌𝑈𝑉∘𝜓𝑈=𝜓𝑉∘𝜌𝑈𝑉, so 𝜓≔{𝜓𝑈} is a morphism of presheaves (resp. sheaves), and 𝜓𝜙=1ℱ︀, 𝜙𝜓=1𝒢︀ hold pointwise, hence as morphisms of presheaves. So 𝜙 is an isomorphism.

𝑎)⟹𝑏): If 𝜙 is an isomorphism with inverse 𝜓, then 𝜙𝑈𝜓𝑈=1𝒢︀(𝑈) and 𝜓𝑈𝜙𝑈=1ℱ︀(𝑈) for every 𝑈, so 𝜙𝑈 is an isomorphism.

𝑏)⟺𝑐) (when 𝒞︀ is algebraic): an isomorphism is in particular bijective (a functor preserves isomorphisms, and an isomorphism in 𝐒𝐞𝐭 is a bijection), while conversely a bijective morphism is an isomorphism in 𝒞︀ as 𝑈 reflects isomorphisms (2.6.189) apply this pointwise at each 𝑈.

𝑏)⟹𝑑): with 𝜓≔{𝜓𝑈} as in 𝑏)⟹𝑎) above, 𝜓 is a morphism of sheaves with 𝜓𝜙=1ℱ︀, 𝜙𝜓=1𝒢︀. By functoriality of stalks (4.2.7), 𝜓𝑥∘𝜙𝑥=(𝜓𝜙)𝑥=1ℱ︀𝑥 and 𝜙𝑥∘𝜓𝑥=(𝜙𝜓)𝑥=1𝒢︀𝑥, so 𝜙𝑥 is an isomorphism.

𝑑)⟹𝑐): Suppose 𝜙𝑥 is an isomorphism, in particular bijective, for every 𝑥∈𝑋. By (4.2.10), 𝜙𝑈 is injective for every 𝑈⊂𝑋. For surjectivity: fix 𝑈⊂𝑋 and 𝜏∈𝒢︀(𝑈). For each 𝑥∈𝑈, surjectivity of 𝜙𝑥 gives 𝑎𝑥∈ℱ︀𝑥 with 𝜙𝑥(𝑎𝑥)=𝜏𝑥; write 𝑎𝑥=(𝜌𝑥)𝑥 for some 𝜌𝑥∈ℱ︀(𝑊𝑥), 𝑊𝑥∈ℬ︀, 𝑥∈𝑊𝑥⊆𝑈 (shrinking 𝑊𝑥 if necessary). Then (𝜙𝑊𝑥(𝜌𝑥))𝑥=𝜙𝑥((𝜌𝑥)𝑥)=𝜙𝑥(𝑎𝑥)=𝜏𝑥=(𝜏|𝑊𝑥)𝑥, so by (4.2.8).a) there is 𝑊𝑥′∈ℬ︀, 𝑥∈𝑊𝑥′⊆𝑊𝑥, with 𝜙𝑊𝑥(𝜌𝑥)|𝑊𝑥′=𝜏|𝑊𝑥′; write 𝜎𝑥≔𝜌𝑥|𝑊𝑥′∈ℱ︀(𝑊𝑥′), so that 𝜙𝑊𝑥′(𝜎𝑥)=𝜏|𝑊𝑥′ exactly.

The {𝑊𝑥′}𝑥∈𝑈 cover 𝑈; for 𝑥,𝑦∈𝑈, on 𝑊𝑥′∩𝑊𝑦′∈ℬ︀,

𝜙𝑊𝑥′∩𝑊𝑦′(𝜎𝑥|𝑊𝑥′∩𝑊𝑦′)=𝜙𝑊𝑥′(𝜎𝑥)|𝑊𝑥′∩𝑊𝑦′=𝜏|𝑊𝑥′∩𝑊𝑦′=𝜙𝑊𝑦′(𝜎𝑦)|𝑊𝑥′∩𝑊𝑦′=𝜙𝑊𝑥′∩𝑊𝑦′(𝜎𝑦|𝑊𝑥′∩𝑊𝑦′)

so as 𝜙𝑊𝑥′∩𝑊𝑦′ is injective, 𝜎𝑥|𝑊𝑥′∩𝑊𝑦′=𝜎𝑦|𝑊𝑥′∩𝑊𝑦′. As ℱ︀ is a sheaf, the gluing condition (4.2.4) gives 𝜎∈ℱ︀(𝑈) with 𝜎|𝑊𝑥′=𝜎𝑥 for all 𝑥. Then 𝜙𝑈(𝜎)|𝑊𝑥′=𝜙𝑊𝑥′(𝜎|𝑊𝑥′)=𝜙𝑊𝑥′(𝜎𝑥)=𝜏|𝑊𝑥′ for every 𝑥∈𝑈, so as 𝒢︀ is a sheaf, the separation condition (4.2.4) gives 𝜙𝑈(𝜎)=𝜏. So 𝜙𝑈 is surjective; being also injective, 𝜙𝑈 is bijective, that is c). ∎
