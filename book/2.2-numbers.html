2.2 Numbers

Informally we consider the set of integers

ℤ={…,−3,−2,−1,0,1,2,3,…}

and the subset of natural numbers

ℕ={0,1,2,…,}

Although it’s possible to construct the integers painstakingly from a small set of axioms (see …) we instead for brevity simply state the most commonly used results as axioms.

2.2.1 Integers

We suppose the existence of a set ℤ with distinguished elements 0≠1 together with

  • A binary operation

    +:ℤ×ℤ→ℤ

    and an involution

    (−):ℤ→ℤ

    satisfying

    • −0=0
    • −(−𝑥)=𝑥
    • 𝑥=−𝑥⟺𝑥=0
    • 𝑥+0=0=0+𝑥
    • 𝑥+𝑦=𝑦+𝑥
    • (𝑥+𝑦)+𝑧=𝑥+(𝑦+𝑧)
    • 𝑥+(−𝑥)=0=(−𝑥)+𝑥
    • −(𝑥+𝑦)=(−𝑥)+(−𝑦)

  • A subset ℕ such that

    • 0,1∈ℕ
    • 𝑥,𝑦∈ℕ⟹𝑥+𝑦∈ℕ
    • 𝑥∈ℤ⟹(𝑥∈ℕ)∨(−𝑥∈ℕ)
    • 𝑥∈ℕ∧−𝑥∈ℕ⟹𝑥=0

    which also satisfies the principle of induction

  • Let 𝑆⊆ℕ be a set such that

    • 0∈𝑆
    • 𝑥∈𝑆⟹𝑥+1∈𝑆

    then 𝑆=ℕ

It’s possible to use these to show the existence of multiplication

Proposition 2.2.1 (Multiplication exists)

There exists a binary operation

·:ℤ×ℤ→ℤ

such that

  • 𝑥·0=0=0·𝑥
  • 𝑥·1=𝑥=1·𝑥
  • 𝑥𝑦=𝑦𝑥
  • (𝑥𝑦)𝑧=𝑥(𝑦𝑧)
  • 𝑥(𝑦+𝑧)=𝑥𝑦+𝑥𝑧
  • (𝑦+𝑧)𝑥=𝑦𝑥+𝑧𝑥
  • (−𝑥)(𝑦)=−(𝑥𝑦)=𝑥(−𝑦)

We may also show the existence a partial ordering

Proposition 2.2.2 (Order exists)

There exists a relation ≤ on ℤ given by

𝑥≤𝑦⟺𝑦−𝑥∈ℕ

which satisfies

𝑥≤𝑦∨𝑦≤𝑥𝑥≤𝑦∧𝑦≤𝑥⟹𝑥=𝑦

Define 𝑥<𝑦 in the obvious way then it satisfies the usual trichotomy law, namely precisely one of the following holds

𝑥<𝑦,𝑥=𝑦,𝑦<𝑥

and further

  • 𝑧>0 then 𝑥<𝑦⟺𝑥𝑧<𝑦𝑧
  • 𝑧<0 then 𝑥<𝑦⟺𝑦𝑧<𝑥𝑧
  • 𝑦>1 and 𝑥>0 then 𝑥<𝑥𝑦

Finally we can construct an absolute value function

Proposition 2.2.3

There exists an absolute value function

|·|:ℤ→ℕ

such that

|𝑥|={𝑥0<𝑥0𝑥=0−𝑥𝑥<0

It satisfies

  • |𝑥|=0⟺𝑥=0
  • |𝑥|=|𝑦|⟺𝑥=±𝑦
  • |𝑥𝑦|=|𝑥||𝑦|
  • |𝑥+𝑦|≤|𝑥|+|𝑦|

In many cases it may be more convenient to use the following form of induction

Proposition 2.2.4 (Well-Ordering Principle)
Let 𝑆⊂ℕ be a non-empty subset. Then it contains a minimal element 𝑑.

2.2.2 Arithmetic

Proposition 2.2.5 (Division Algorithm)

Let 𝑥,𝑦∈ℤ be non-zero integers then there exists 𝑞,𝑟 such that

𝑥=𝑦𝑞+𝑟

and

0≤𝑟<|𝑦|

Furthermore (𝑞,𝑟) is the unique such pair.

Proof. Suppose first that 𝑥,𝑦>0. Let 𝑆={𝑥−𝑦𝑛|𝑛∈ℤ}∩ℕ. Then 𝑥∈𝑆 so it is non-empty. By the Well-Ordering principle it has a minimal element 𝑟. By assumption

𝑥=𝑦𝑞+𝑟

for some 𝑞∈ℤ and 𝑟≥0. Suppose 𝑟≥𝑦, then 0≤𝑥−𝑦(𝑞+1)<𝑟 contradicting minimality.

The case 𝑥>0,𝑦<0 is then straightforward, as is the case 𝑥<0.

For uniqueness suppose 𝑦𝑞′+𝑟′=𝑦𝑞+𝑟 then |𝑦||𝑞−𝑞′|=|𝑟′−𝑟|<|𝑦| from which it follows |𝑞−𝑞′|=0⟹𝑞=𝑞′⟹𝑟=𝑟′. ∎

Corollary 2.2.6 (Ideals are Principal)

Let 𝑆⊆ℤ be a non-empty set such that

𝑥,𝑦∈𝑆⟹𝑥±𝑦∈𝑆

Then 𝑆=𝑑ℤ for a unique 𝑑≥0.

Proof. First we claim that 0∈𝑆. For if 𝑥∈𝑆 then 0=𝑥−𝑥∈𝑆 by assumption. Furthermore 𝑥∈𝑆⟹−𝑥=0−𝑥∈𝑆.

Consider the set 𝑆′=(𝑆∩ℕ)∖{0}. If it’s empty then 𝑆={0} (for 𝑥∈𝑆⟹−𝑥∈𝑆) and 𝑑=0.

Otherwise it has a minimal element 𝑑>0 by the well-ordering principle. Then by induction 𝑑ℤ⊆𝑆. Conversely suppose 𝑦∈𝑆 then by the division algorithm 𝑦=𝑞𝑑+𝑟 with 0≤𝑟<𝑑. By assumption 𝑟=𝑦−𝑞𝑑∈𝑆 and by minimality must be equal to 0. Therefore 𝑦∈𝑑ℤ and 𝑑ℤ=𝑆 as required. ∎

Definition 2.2.7 (Divisibility)

Let 𝑥,𝑦∈ℤ be two integers. We say that 𝑥 divides 𝑦 if there exists 𝑎 such that 𝑎𝑥=𝑦. In this case we write

𝑥∣𝑦

and

𝑦𝑥

for the unique integer 𝑎 such that 𝑎𝑥=𝑦.

Lemma 2.2.8

Let 𝑥,𝑦∈ℤ be two integers then

𝑥∣𝑦⟹|𝑥|≤|𝑦|

In particular 𝑥∣𝑦∧𝑦∣𝑥⟹𝑥=±𝑦.

Proposition 2.2.9 (Bezout's Theorem)

Let 𝑥,𝑦 be non-zero integers. Then there exists a unique positive integer 𝑑 such that

  • 𝑑 is a common divisor of 𝑥,𝑦
  • For any other common divisor 𝑒 we have 𝑒∣𝑑.

Further there exists integers 𝑎,𝑏 such that 𝑎𝑥+𝑏𝑦=𝑑. We write this as (𝑥,𝑦).

Proof. Let 𝑆={𝑎𝑥+𝑏𝑦|𝑎,𝑏∈ℤ}. Then by (2.2.6) we have 𝑆=𝑑ℤ for a unique 𝑑>0. As 𝑥,𝑦∈𝑆 by definition 𝑑 is a common divisor, and by definition 𝑑=𝑑·1=𝑎𝑥+𝑏𝑦 for some integers 𝑎,𝑏. Suppose 𝑒 is a common divisor then 𝑑=𝑎𝑥+𝑏𝑦=𝑒(𝑎𝑝+𝑏𝑞) and 𝑒∣𝑑 as required.

Any two such common divisors have 𝑑=±𝑑′ by the previous Lemma. Since they are positive and non-zero we have 𝑑=𝑑′. ∎

Proposition 2.2.10

Let 𝑎,𝑥,𝑦 be non-zero integers then

|𝑎|(𝑥,𝑦)=(𝑎𝑥,𝑎𝑦)

In particular

(𝑥𝑥,𝑦,𝑦𝑥,𝑦)=1
Proof. This follows from the characterization of (𝑥,𝑦) as the minimal positive integer in the set {𝑚𝑥+𝑛𝑦}. ∎

2.2.3 Prime Factorization

Definition 2.2.11

Let 𝑥∈ℤ be a non-zero integer. We say that 𝑥

  • is a unit if it’s equal to 1 or −1.
  • is prime if it’s not a unit and 𝑥∣𝑝 implies 𝑥=±1 or 𝑥=±𝑝
  • composite otherwise
Lemma 2.2.12

Let 𝑝 be a positive prime and 𝑎 a non-zero integer. Then precisely one of the following holds

  • (𝑝,𝑎)=1
  • (𝑝,𝑎)=𝑝 and 𝑝∣𝑎
Proof. Note that (𝑝,𝑎) is positive and divides both 𝑝 and 𝑎 so the result follows by definition of prime. ∎
Proposition 2.2.13 (Euclid's Lemma)

Suppose 𝑥∣𝑎𝑏 then 𝑥𝑥,𝑎∣𝑏.

In particular if 𝑝 is a prime and 𝑝∣𝑎𝑏, then 𝑝∣𝑎 or 𝑝∣𝑏.

Proof. First suppose that (𝑥,𝑎)=1. Then by assumption 𝑧𝑥=𝑎𝑏 and by Bezout’s Theorem 𝑚𝑥+𝑛𝑎=1 for some integers 𝑚,𝑛. Multiply by 𝑧 to find that 𝑎𝑏𝑚+𝑛𝑎=𝑎(𝑏𝑚+𝑛)=𝑧. Therefore 𝑎(𝑏𝑚+𝑛)𝑥=𝑎𝑏 and cancel 𝑎 to find 𝑥∣𝑏 as required.

For the general case define 𝑥′=𝑥/(𝑥,𝑎) and 𝑎′=𝑎/(𝑥,𝑎). Then by (2.2.10) (𝑥′,𝑎′)=1. Furthermore it’s clear that 𝑥′∣𝑎′𝑏 so we have 𝑥′∣𝑏 by the special case just proven.

Finally suppose 𝑝∣𝑎𝑏. If (𝑝,𝑎)=1 then 𝑝∣𝑏 by the first result. By (2.2.12) if this does not hold then 𝑝∣𝑎 as required. ∎

Using these results we may show that there exists a unique factorization into primes, unique up to multiplication by a unit.
