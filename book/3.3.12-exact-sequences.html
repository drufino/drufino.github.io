3.3.12 Exact Sequences

Definition 3.3.95 (Vector space)
If 𝑘 is a field and 𝑉 a 𝑘-module, then we say 𝑉 is a vector space over 𝑘.
Remark 3.3.96
We will see that every vector space is free and every 𝑘-submodule is a direct factor.
Proposition 3.3.97 (Kernel)

Let 𝜑:𝑀→𝑁 be an 𝐴-module homomorphism, then the kernel of 𝜑

ker(𝜑)≔{𝑚∈𝑀|𝜑(𝑚)=0}

is an 𝐴-submodule of 𝑀. Observe 𝜑 is injective iff ker(𝜑)=0.

Proposition 3.3.98 (Image)

Let 𝜑:𝑀→𝑁 be an 𝐴-module homomorphism then the image

Im(𝜑)={𝜑(𝑚)|𝑚∈𝑀}

is an 𝐴-submodule of 𝑁.

Definition 3.3.99 (Quotient Module)

Let 𝑁⊆𝑀 be an 𝐴-submodule then define the quotient module 𝑀/𝑁 to be the quotient group with an action of 𝐴 given by

𝑎(𝑚+𝑁)=(𝑎𝑚+𝑁)

When 𝑁⊆𝑃⊆𝑀 is a sequence of submodules then define the 𝐴-submodule 𝑃/𝑁 of 𝑀/𝑁 by

𝑃/𝑁≔{𝑝+𝑁|𝑝∈𝑃}
Proposition 3.3.100 (Quotient Module Properties)

Let 𝑁⊆𝑀 be an 𝐴-submodule then there is a canonical surjective morphism

𝜋:𝑀→𝑀/𝑁

with the following properties

  1. 𝜋(𝑚)=𝑚+𝑁
  2. ker(𝜋)=𝑁

  3. Every homomorphism 𝜓:𝑀→𝑃 such that 𝑁⊆ker(𝜓), factors uniquely through 𝜋

Furthermore there is a bijection of 𝐴-submodules

{𝑃′⊆𝑀/𝑁}↔{𝑃|𝑁⊆𝑃⊆𝑀}

given by 𝑃′=𝑃/𝑁. In the situation above ker(𝜓̃)=ker(𝜓)/𝑁. In particular if ker(𝜓)=𝑁 then 𝜓̃ is injective.

Corollary 3.3.101

Let 𝜓:𝑀→𝑁 be an 𝐴-module homomorphism, then this induces an isomorphism

𝑀/ker(𝜓)≅Im(𝜓)
Definition 3.3.102 (Exact Sequence)

Let 𝑁→𝜑𝑀→𝜓𝑃 be an sequence of 𝐴-module homomorphisms. We say it is exact if

Im(𝜑)=ker(𝜓)

It is equivalent to the following two conditions

  1. 𝜓∘𝜑=0
  2. 𝜓(𝑚)=0⟹𝑚=𝜑(𝑛) for some 𝑛∈𝑁.

An exact sequence of the form

0→𝑁→𝑀→𝑃→0

is said to be short-exact.

Remark 3.3.103

There are a few trivial observations

  • 0→𝑀→𝑁 is exact if and only if the map 𝑀→𝑁 is injective
  • 𝑀→𝑁→0 is exact if and only if the map 𝑀→𝑁 is surjective.
Proposition 3.3.104 (Isomorphism induced by short-exact sequence)

Let 𝑁⊆𝑀 be a 𝐴-submodule then there is a canonical short-exact sequence

0→𝑁→𝑀→𝑀/𝑁→0

Conversely suppose we have a short exact sequence

0→𝑁→𝑖𝑀→𝜋𝑃→0

then this induces an isomorphism

𝑀/𝑖(𝑁)≅𝑃

If 𝑁 is a submodule of 𝑀 then we would simply write 𝑀/𝑁≅𝑃.

Proposition 3.3.105 (Third Isomorphism Theorem)

Let 𝑁⊆𝑁′⊆𝑀 be a chain of modules then there is a short-exact sequence

0→𝑁′/𝑁→𝑀/𝑁→𝑀/𝑁′→0

which then induces an isomorphism

(𝑀/𝑁)/(𝑁′/𝑁)≅𝑀/𝑁′
Proposition 3.3.106 (Product of ideal and quotient module)

Let 𝑁 be a submodule of 𝑀 and 𝔞◃𝐴 an ideal. Then

𝔞(𝑀/𝑁)=(𝑁+𝔞𝑀)/𝑁
Proposition 3.3.107 (Induced module)

Let 𝑀 be an 𝐴-module and 𝔞 an ideal such that 𝔞𝑀=0, then 𝑀 is naturally an 𝐴/𝔞-module with action given by

𝑎―⋅𝑚≔𝑎⋅𝑚
