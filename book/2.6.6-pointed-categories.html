2.6.6 Pointed Categories

Definition 2.6.48 (Initial object)

An initial object of a category 𝒞︀ is an object ∅ such that for all objects 𝑋

Mor(∅,𝑋)={𝜂∅𝑋}

consists of a single element.

In this case an initial object is unique up to unique isomorphism (2.6.49).

Proposition 2.6.49 (Criteria to be Initial)

Let ∅ be an initial object and 𝑋∈𝒞︀. Then the following are equivalent

  1. 𝑋 is an initial object
  2. there is an isomorphism 𝜙:𝑋→∼∅
  3. there exists a morphism 𝜙:𝑋→∅ and only one endomorphism 1𝑋:𝑋→𝑋

In this case the isomorphism is unique.

Proof. a) ⟹ c) by definition

c) ⟹ b) By assumption 𝜂∅𝑋∘𝜙=1𝑋, and by definition of initial 𝜙∘𝜂∅𝑋=1∅.

b) ⟹ a) We have a bijection

Mor(∅,𝑌)⟷Mor(𝑋,𝑌)𝑓→𝑓∘𝜙𝑔∘𝜙−1←𝑔

so as ∅ is initial, Mor(∅,𝑌) is a singleton for every 𝑌, hence so is Mor(𝑋,𝑌), that is 𝑋 is initial. This closes the cycle a) ⟹ c) ⟹ b) ⟹ a), so all three are equivalent.

Finally, since 𝑋 is then initial, Mor(𝑋,∅) is a singleton, so there is at most one morphism 𝑋→∅; in particular the isomorphism 𝜙 is unique. ∎

Definition 2.6.50 (Terminal Object)

A terminal object of a category 𝒞︀ is an object ⋆ such that for all objects 𝑋∈𝒞︀ we have

Mor(𝑋,⋆)={!𝑋}

is a singleton.

In this case a terminal object is unique up to unique isomorphism (2.6.51).

Proposition 2.6.51 (Criteria to be Terminal)

Let ⋆ be a terminal object and 𝑋∈𝒞︀. Then the following are equivalent

  1. 𝑋 is a terminal object
  2. there is an isomorphism 𝜙:⋆→∼𝑋
  3. there exists a morphism 𝜙:⋆→𝑋 and only one endomorphism 1𝑋:𝑋→𝑋

In this case the isomorphism is unique.

Proof. By (2.6.4), Mor𝒞︀op(∅,𝑋)=Mor𝒞︀(𝑋,∅) for all 𝑋, so ⋆ is a terminal object of 𝒞︀ if and only if ⋆ is an initial object of 𝒞︀op; likewise a morphism ⋆→𝑋 (resp. isomorphism, resp. endomorphism of 𝑋) in 𝒞︀ is exactly a morphism 𝑋→⋆ (resp. isomorphism, resp. endomorphism of 𝑋) in 𝒞︀op. So applying (2.6.49) in 𝒞︀op, with ∅≔⋆, gives exactly the stated equivalence of a), b), c), together with the uniqueness of the isomorphism. ∎
Lemma 2.6.52 (Equivalences of Categories Preserve Terminal Objects)
Let 𝐹:𝒞︀→𝒟︀ be an equivalence of categories, with 𝐺 and natural isomorphisms 𝜂:id𝒞︀⇒𝐺𝐹, 𝜖:𝐹𝐺⇒id𝒟︀ as in (2.6.25). Then 𝑇∈𝒞︀ is a terminal object of 𝒞︀ if and only if 𝐹(𝑇) is a terminal object of 𝒟︀.

Proof. Drafted by Claude Sonnet 5, reviewed by David Rufino.

Suppose 𝑇 is terminal. By (2.6.28), 𝐹 is full and faithful, so for every 𝐶∈𝒞︀ the map Mor(𝐶,𝑇)→Mor(𝐹(𝐶),𝐹(𝑇)), 𝑓↦𝐹(𝑓), is a bijection; as 𝑇 is terminal Mor(𝐶,𝑇) is a singleton, so Mor(𝐹(𝐶),𝐹(𝑇)) is too. Now let 𝑌∈𝒟︀ be arbitrary and set 𝐶≔𝐺(𝑌); the isomorphism 𝜖𝑌:𝐹(𝐶)→𝑌 gives a bijection Mor(𝐹(𝐶),𝐹(𝑇))→Mor(𝑌,𝐹(𝑇)), 𝑔↦𝑔∘𝜖𝑌−1, so combining with the above, Mor(𝑌,𝐹(𝑇)) is a singleton. As 𝑌∈𝒟︀ was arbitrary, 𝐹(𝑇) is terminal.

Conversely, 𝐺 is itself an equivalence of categories (with 𝐹, 𝜖−1:id𝒟︀⇒𝐹𝐺 and 𝜂−1:𝐺𝐹⇒id𝒞︀ playing the roles of 𝐹, 𝜂, 𝜖 in (2.6.25)), so if 𝐹(𝑇) is terminal then applying the above (with 𝐹,𝐺,𝑇 replaced by 𝐺,𝐹,𝐹(𝑇)) shows 𝐺𝐹(𝑇) is terminal; as 𝜂𝑇:𝑇→𝐺𝐹(𝑇) is an isomorphism, 𝑇 is then terminal too by (2.6.51). ∎

Definition 2.6.53 (Terminal Category)

The terminal category 𝟏 is the category with a single object ⋆ and a single morphism 1⋆.

For any category 𝒞︀ and object 𝑋∈𝒞︀, we write 𝑋:𝟏→𝒞︀ for the functor with 𝑋(⋆)=𝑋.

Definition 2.6.54 (Zero Object / Pointed Category)

A zero object of a category 𝒞︀ is both an initial and terminal object. We denote this by 𝟎 or 𝟎𝒞︀ when we need to emphasise the category 𝒞︀

For two objects 𝑋,𝑌∈𝒞︀ we denote by 0𝑋,𝑌 the composite morphism 𝑋→0→𝑌. This is independent of the choice of zero object.

A category with a zero object is pointed. A category 𝒞︀ is pointed iff 𝒞︀op is pointed. Further 𝟎𝒞︀=𝟎𝒞︀op.

Proposition 2.6.55

Let 𝒞︀ be a pointed category and 𝑋∈𝒞︀. Then the following are equivalent

  1. 𝑋 is an initial object
  2. 𝑋 is a terminal object
  3. 𝑋 is a zero object
Proposition 2.6.56
Let 𝒞︀ be a pointed category. Then the morphism 0→𝑋 is a monomorphism and the morphism 𝑌→0 is an epimorphism.
Proposition 2.6.57 (Functors Preserve Zeros)

Let 𝐹:𝒞︀→𝒟︀ be a functor of pointed categories for which 𝐹(0𝒞︀) is a zero object of 𝒟︀. Then for all objects 𝑋,𝑌 we have

𝐹(0𝑋,𝑌)=0𝐹(𝑋),𝐹(𝑌)
