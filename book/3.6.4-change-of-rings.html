3.6.4 Change of Rings

For what follows it is useful to have the concept of saturation of a multiplicatively closed set. Essentially taking the saturation 𝑆― of 𝑆 doesn’t change the ring 𝑆−1𝐴.

Proposition 3.6.20 (Saturation)

Let 𝐴 be a ring and 𝑆 a multiplicatively closed set. Then the following sets are equal

  1. (𝑖𝑆)−1((𝑆−1𝐴)⋆)
  2. {𝑥∈𝐴|𝑎𝑥∈𝑆for some𝑎∈𝐴}
  3. ⋂𝑇⊇𝑆:𝑇saturated𝑇

which we denote by 𝑆―. We have the following properties

  • 𝑆― is saturated.
  • 𝑆 is saturated if and only if 𝑆=𝑆―
  • 𝑆――=𝑆―.

Proof. Note 𝑥∈(𝑖𝑆)−1((𝑆−1𝐴)⋆)⟹𝑥1⋅𝑏𝑡=1⟹𝑠(𝑥𝑏−𝑡)=0⟹(𝑠𝑏)𝑥∈𝑆. Similarly if 𝑎𝑥∈𝑆 then 𝑥1⋅𝑎𝑎𝑥=1.

It’s clear from b) that the set thus defined is saturated and multiplicatively closed. Let 𝑇 be another saturated multiplicatively closed set containing 𝑆 and suppose 𝑎𝑥∈𝑆⟹𝑎𝑥∈𝑇⟹𝑥∈𝑇, so we find that the sets are equal.

We’ve proved that 𝑆― is saturated. Clearly 𝑆=𝑆― implies 𝑆 is saturated. Conversely if 𝑆 is saturated then by c) we have 𝑆―⊆𝑆, and clearly 𝑆⊆𝑆―. The final part follows easily. ∎
