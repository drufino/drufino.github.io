3.32 Formal Power Series and Laurent Series

Definition 3.32.1 (Formal Laurent Series)

Let 𝐴 be a commutative ring. Define the formal Laurent series ring 𝐴((𝑋)) to be the set of sequences (𝑐𝑛)𝑛∈ℤ in 𝐴 such that there exists 𝑁 for which 𝑛≤𝑁⟹𝑐𝑛=0. Addition is defined pointwise with product defined as follows

(∑𝑛∈ℤ𝑐𝑛𝑋𝑛)(∑𝑛∈ℤ𝑑𝑛𝑋𝑛)=∑𝑛∈ℤ(∑𝑘∈ℤ𝑐𝑛−𝑘𝑑𝑘)𝑋𝑛

where the inner sum is a sum of a family with all but finitely many terms zero. That this is well-defined and makes 𝐴((𝑋)) into a commutative ring is shown in (3.32.3).

Definition 3.32.2 (Order of a Formal Laurent Series)
Let 𝐴 be a commutative ring. For 0≠ℎ=∑𝑛𝑐𝑛𝑋𝑛∈𝐴((𝑋)) define the order 𝑣(ℎ)≔min{𝑛|𝑐𝑛≠0}, and 𝑣(0)≔∞. The minimum exists since the 𝑐𝑛 vanish for 𝑛 sufficiently negative and ℎ≠0. We call 𝑐𝑣(ℎ) the leading coefficient of ℎ.
Proposition 3.32.3 (𝐴((𝑋)) is a Commutative Ring)
Let 𝐴 be a commutative ring and 𝑐,𝑑∈𝐴((𝑋)). For every 𝑛∈ℤ the family (𝑐𝑛−𝑘𝑑𝑘)𝑘∈ℤ has all but finitely many terms zero, so (𝑐𝑑)𝑛≔∑𝑘∈ℤ𝑐𝑛−𝑘𝑑𝑘 is defined, and (𝑐𝑑)𝑛=0 for 𝑛<𝑣(𝑐)+𝑣(𝑑). In particular 𝑐𝑑∈𝐴((𝑋)). Moreover 𝐴((𝑋)) is a commutative ring under pointwise addition and this product.

Proof. Drafted by Claude Sonnet, reviewed by David Rufino.

𝑣(𝑑)≤𝑘≤𝑛−𝑣(𝑐)

so only finitely many 𝑘∈ℤ give a nonzero term. Hence (𝑐𝑛−𝑘𝑑𝑘)𝑘∈ℤ has all but finitely many terms zero, and the inner sum 𝑒𝑛≔∑𝑘∈ℤ𝑐𝑛−𝑘𝑑𝑘 is defined by (3.2.50). Moreover if 𝑛<𝑣(𝑐)+𝑣(𝑑) then there is no integer 𝑘 with 𝑣(𝑑)≤𝑘≤𝑛−𝑣(𝑐), so every term vanishes and 𝑒𝑛=0. Therefore (𝑒𝑛)𝑛∈ℤ is a sequence in 𝐴 vanishing for 𝑛<𝑣(𝑐)+𝑣(𝑑), that is an element of 𝐴((𝑋)).

Ring axioms. Write (𝑐𝑑)𝑛≔∑𝑘∈ℤ𝑐𝑛−𝑘𝑑𝑘 for the coefficients of the product, an element of 𝐴((𝑋)) by the first part.

Addition. For 𝑐,𝑑∈𝐴((𝑋)) we have 𝑐𝑛+𝑑𝑛=0 and −𝑐𝑛=0 for 𝑛<min(𝑣(𝑐),𝑣(𝑑)), so 𝑐+𝑑 and −𝑐 lie in 𝐴((𝑋)), as does the zero sequence. So 𝐴((𝑋)) is a subgroup of the abelian group 𝐴ℤ under pointwise addition.

Identity. Let 1≔(𝛿𝑛,0)𝑛∈ℤ, which vanishes for 𝑛≤−1 and so lies in 𝐴((𝑋)). For 𝑐∈𝐴((𝑋)) the family (𝛿𝑛−𝑘,0𝑐𝑘)𝑘∈ℤ has 𝑘=𝑛 as its only possibly nonzero term, so (1𝑐)𝑛=𝑐𝑛.

Commutativity. The map 𝑘↦𝑛−𝑘 is a bijection of ℤ, so by (3.2.53) and commutativity of 𝐴,

(𝑐𝑑)𝑛=∑𝑘∈ℤ𝑐𝑛−𝑘𝑑𝑘=∑𝑘∈ℤ𝑐𝑘𝑑𝑛−𝑘=∑𝑘∈ℤ𝑑𝑛−𝑘𝑐𝑘=(𝑑𝑐)𝑛

Distributivity. For 𝑐,𝑑,𝑑′∈𝐴((𝑋)), the families (𝑐𝑛−𝑘𝑑𝑘)𝑘∈ℤ and (𝑐𝑛−𝑘𝑑𝑘′)𝑘∈ℤ have all but finitely many terms zero, so by (3.2.51)

(𝑐(𝑑+𝑑′))𝑛=∑𝑘∈ℤ𝑐𝑛−𝑘(𝑑𝑘+𝑑𝑘′)=∑𝑘∈ℤ𝑐𝑛−𝑘𝑑𝑘+∑𝑘∈ℤ𝑐𝑛−𝑘𝑑𝑘′=(𝑐𝑑)𝑛+(𝑐𝑑′)𝑛

and the other distributive law follows by commutativity.

Associativity. Let 𝑐,𝑑,𝑒∈𝐴((𝑋)) and fix 𝑛∈ℤ; if any of them is 0 both sides are 0, so assume 𝑣(𝑐),𝑣(𝑑),𝑣(𝑒) are finite. Set 𝑔(𝑗,𝑘)≔𝑐𝑛−𝑗−𝑘𝑑𝑗𝑒𝑘 for (𝑗,𝑘)∈ℤ×ℤ. If 𝑔(𝑗,𝑘)≠0 then 𝑗≥𝑣(𝑑), 𝑘≥𝑣(𝑒) and 𝑛−𝑗−𝑘≥𝑣(𝑐), so 𝑣(𝑑)≤𝑗≤𝑛−𝑣(𝑐)−𝑣(𝑒) and 𝑣(𝑒)≤𝑘≤𝑛−𝑣(𝑐)−𝑣(𝑑); hence 𝑔 has all but finitely many terms zero. Recall that (𝑐𝑑)𝑚=∑𝑗∈ℤ𝑐𝑚−𝑗𝑑𝑗 and (𝑑𝑒)𝑚=∑𝑘∈ℤ𝑑𝑚−𝑘𝑒𝑘. Then

Lemma 3.32.4 (Valuation of a Sum and a Product)

Let 𝐴 be a commutative ring and 𝑐,𝑑∈𝐴((𝑋)). Then 𝑣(1)=0, 𝑣(−𝑐)=𝑣(𝑐), and

  1. 𝑣(𝑐+𝑑)≥min(𝑣(𝑐),𝑣(𝑑))
  2. 𝑣(𝑐𝑑)≥𝑣(𝑐)+𝑣(𝑑)
  3. if 𝐴 is an integral domain then so is 𝐴((𝑋)), and 𝑣(𝑐𝑑)=𝑣(𝑐)+𝑣(𝑑)

Proof. Drafted by Claude Sonnet, reviewed by David Rufino.

Clearly 𝑣(1)=0 and 𝑣(−𝑐)=𝑣(𝑐). If 𝑛<min(𝑣(𝑐),𝑣(𝑑)) then 𝑐𝑛=𝑑𝑛=0, so (𝑐+𝑑)𝑛=0, which gives a). For b), if 𝑐=0 or 𝑑=0 then 𝑐𝑑=0 and both sides are ∞. Otherwise (𝑐𝑑)𝑛=0 for 𝑛<𝑣(𝑐)+𝑣(𝑑) by (3.32.3), which means 𝑣(𝑐𝑑)≥𝑣(𝑐)+𝑣(𝑑). For c), let 𝑐,𝑑≠0 with 𝑚≔𝑣(𝑐) and 𝑟≔𝑣(𝑑). A term 𝑐𝑚+𝑟−𝑘𝑑𝑘 of (𝑐𝑑)𝑚+𝑟 is nonzero only if 𝑘≥𝑟 and 𝑚+𝑟−𝑘≥𝑚, that is 𝑘=𝑟, so (𝑐𝑑)𝑚+𝑟=𝑐𝑚𝑑𝑟≠0 as 𝐴 is a domain, while (𝑐𝑑)𝑛=0 for 𝑛<𝑚+𝑟. Hence 𝑐𝑑≠0 and 𝑣(𝑐𝑑)=𝑚+𝑟. ∎

Definition 3.32.5 (Formal Power Series)
Let 𝐴 be a commutative ring. Define the formal power series ring 𝐴[[𝑋]] to be the subring of 𝐴((𝑋)) consisting of those sequences (𝑐𝑛)𝑛∈ℤ for which 𝑛<0⟹𝑐𝑛=0, or equivalently those ℎ∈𝐴((𝑋)) for which 𝑣(ℎ)≥0.

Proof that 𝐴[[𝑋]] is a subring of 𝐴((𝑋)). Drafted by Claude Sonnet, reviewed by David Rufino.

𝐴[[𝑋]]={ℎ∈𝐴((𝑋))|𝑣(ℎ)≥0}, so by (3.32.4) it contains 1 and is closed under negation, addition and multiplication. ∎

Lemma 3.32.6 (Formal Power Series Rings are Separated)
Let 𝐴 be a commutative ring. For 𝑁≥0 we have 𝑋𝑁𝐴[[𝑋]]={ℎ∈𝐴[[𝑋]]|𝑣(ℎ)≥𝑁}, and ⋂𝑁≥0𝑋𝑁𝐴[[𝑋]]=0.
Proof. If ℎ=𝑋𝑁ℎ′ with ℎ′∈𝐴[[𝑋]] then the coefficients of ℎ below 𝑋𝑁 vanish, so 𝑣(ℎ)≥𝑁. Conversely if 𝑣(ℎ)≥𝑁 then ℎ=𝑋𝑁ℎ′ where ℎ′ is ℎ with the coefficients shifted down by 𝑁, an element of 𝐴[[𝑋]]. If ℎ lies in every 𝑋𝑁𝐴[[𝑋]] then 𝑣(ℎ)≥𝑁 for every 𝑁, so every coefficient of ℎ vanishes and ℎ=0. ∎
Definition 3.32.7 (Formal Derivative)
Let 𝐴 be a commutative ring. For 𝑓=∑𝑛𝑐𝑛𝑋𝑛∈𝐴((𝑋)), define 𝑓′≔∑𝑛𝑛𝑐𝑛𝑋𝑛−1∈𝐴((𝑋)), that is (𝑓′)𝑛=(𝑛+1)𝑐𝑛+1.
Lemma 3.32.8 (Valuation of a Derivative)
Let 𝐴 be a commutative ring and 𝑓∈𝐴((𝑋)). Then 𝑣(𝑓′)≥𝑣(𝑓)−1. In particular if 𝑓∈𝐴[[𝑋]] then 𝑓′∈𝐴[[𝑋]].

Proof. Drafted by Claude Sonnet, reviewed by David Rufino.

If 𝑛<𝑣(𝑓)−1 then 𝑛+1<𝑣(𝑓), so 𝑐𝑛+1=0 and (𝑓′)𝑛=(𝑛+1)𝑐𝑛+1=0. This gives 𝑣(𝑓′)≥𝑣(𝑓)−1. If 𝑓∈𝐴[[𝑋]] then 𝑣(𝑓)≥0 and (𝑓′)𝑛=0 for 𝑛<−1; also (𝑓′)−1=0⋅𝑐0=0, so 𝑓′∈𝐴[[𝑋]]. ∎

Definition 3.32.9 (Summable Family in 𝐴((𝑋)))

Let 𝐴 be a commutative ring. A family (ℎ𝑖)𝑖∈𝐼 in 𝐴((𝑋)) is summable if for every 𝑁∈ℤ all but finitely many 𝑖∈𝐼 satisfy 𝑣(ℎ𝑖)≥𝑁. Its sum is the formal Laurent series

∑𝑖∈𝐼ℎ𝑖≔∑𝑛∈ℤ(∑𝑖∈𝐼(ℎ𝑖)𝑛)𝑋𝑛

where (ℎ𝑖)𝑛 denotes the coefficient of 𝑋𝑛 in ℎ𝑖.

Proof that the sum is well-defined. Drafted by Claude Sonnet, reviewed by David Rufino.

Write ℎ𝑖,𝑛≔(ℎ𝑖)𝑛 and fix 𝑛∈ℤ. By hypothesis (with 𝑁=𝑛+1) the set {𝑖∈𝐼|𝑣(ℎ𝑖)≤𝑛} is finite, and it contains every 𝑖 with ℎ𝑖,𝑛≠0. So (ℎ𝑖,𝑛)𝑖∈𝐼 has all but finitely many terms zero and 𝑠𝑛≔∑𝑖∈𝐼ℎ𝑖,𝑛 is defined by (3.2.50). Let 𝐽0≔{𝑖∈𝐼|𝑣(ℎ𝑖)≤0}, which is finite, and 𝑁0≔min(0,min𝑖∈𝐽0𝑣(ℎ𝑖)) (with 𝑁0≔0 if 𝐽0 is empty).
