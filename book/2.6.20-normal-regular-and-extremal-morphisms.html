2.6.20 Normal, Regular and Extremal Morphisms

In a category which is not balanced, monic and epic are not always the “right” notions to characterise isomorphisms; the following refinements repair this.

Definition 2.6.156 (Extremal Epimorphism / Monomorphism)

An epimorphism 𝑒:𝑋→𝑌 is extremal if whenever 𝑒=𝑚∘𝑓 for some monomorphism 𝑚, then 𝑚 is an isomorphism.

Dually, a monomorphism 𝑚:𝑋→𝑌 is extremal if whenever 𝑚=𝑓∘𝑒 for some epimorphism 𝑒, then 𝑒 is an isomorphism.

Proposition 2.6.157

Let 𝑓:𝑋→𝑌 be a morphism. Then the following are equivalent

  1. 𝑓 is an isomorphism
  2. 𝑓 is a monomorphism and an extremal epimorphism
  3. 𝑓 is an extremal monomorphism and an epimorphism

Proof. Drafted by Claude Sonnet 5, reviewed by David Rufino.

Being an isomorphism is a self-dual notion, and monic/epic swap under passing to 𝒞︀op (2.6.33), so condition c) is precisely condition b) applied in 𝒞︀op. Hence it suffices to prove a) ⟺ b); applying this to 𝒞︀op then gives a) ⟺ c).

a) ⟹ b) An isomorphism is trivially monic and epic; if 𝑓 is an isomorphism and 𝑓=𝑚∘𝑔 then by (2.6.37), 𝑚 is an isomorphism, so 𝑓 is an extremal epimorphism.

b) ⟹ a) Suppose 𝑓 is monic and an extremal epimorphism. The trivial factorisation 𝑓=𝑓∘1𝑋 exhibits 𝑓 as a monomorphism through which 𝑓 factors, so by extremality 𝑓 is an isomorphism. ∎

Definition 2.6.158 (Regular Epimorphism / Monomorphism)

An epimorphism 𝑒:𝑋→𝑌 is regular if there exist morphisms 𝛼,𝛽:𝑊⇉𝑋 such that 𝑒 is the coequaliser of (𝛼,𝛽).

Dually, a monomorphism 𝑚:𝑋→𝑌 is regular if there exist morphisms 𝛼,𝛽:𝑌⇉𝑍 such that 𝑚 is the equaliser of (𝛼,𝛽).

Definition 2.6.159 (Normal Epimorphism / Monomorphism)

Let 𝒞︀ be a pointed category (2.6.54). An epimorphism 𝑒:𝑋→𝑌 is conormal if (𝑒,𝑌) is the cokernel of some morphism 𝛼:𝑊→𝑋.

Dually, a monomorphism 𝑚:𝑋→𝑌 is normal if (𝑚,𝑋) is the kernel of some morphism 𝛼:𝑌→𝑍.

Proposition 2.6.160 (Normal, Regular and Extremal Morphisms)

Let 𝒞︀ be a pointed category. Then every normal monomorphism (resp. conormal epimorphism) is regular.

In a general category 𝒞︀ every regular monomorphism (resp. epimorphism) is an extremal monomorphism (resp. epimorphism).

In summary

𝐧𝐨𝐫𝐦𝐚𝐥 (𝐜𝐨𝐧𝐨𝐫𝐦𝐚𝐥) ⟹𝐫𝐞𝐠𝐮𝐥𝐚𝐫⟹𝐞𝐱𝐭𝐫𝐞𝐦𝐚𝐥⟹𝐦𝐨𝐧𝐢𝐜 (𝐞𝐩𝐢𝐜)

Proof. Drafted by Claude Sonnet 5, reviewed by David Rufino.

(Normal ⟹ regular) If 𝑒 is a normal monomorphism, then by (2.6.150) 𝑒 is the equaliser of (𝛼,0) for some 𝛼, so 𝑒 is regular.

(Regular ⟹ extremal) Suppose 𝑚:𝑋→𝑌 is the equaliser of 𝛼,𝛽:𝑌⇉𝑊, and 𝑚=ℎ∘𝑒 for some epimorphism 𝑒:𝑋→𝑍. Since 𝛼∘𝑚=𝛽∘𝑚 we get (𝛼∘ℎ)∘𝑒=(𝛽∘ℎ)∘𝑒, and as 𝑒 is epic, 𝛼∘ℎ=𝛽∘ℎ. Hence ℎ is equalised by (𝛼,𝛽), so by the universal property of the equaliser there is a unique 𝑘:𝑍→𝑋 with 𝑚∘𝑘=ℎ.

Then 𝑚∘(𝑘∘𝑒)=ℎ∘𝑒=𝑚=𝑚∘1𝑋, and since equalisers are monic (2.6.135) we may cancel 𝑚 to get 𝑘∘𝑒=1𝑋, so 𝑒 is split-monic. As 𝑒 is also epic, (2.6.36) gives that 𝑒 is an isomorphism, and 𝑚 is extremal.

Dually, every conormal epimorphism is regular and every regular epimorphism is extremal. ∎

For balanced categories we can reverse the implication

Proposition 2.6.161 (Balanced Categories via Extremal Morphisms)

Let 𝒞︀ be a category. Then the following are equivalent

  1. 𝒞︀ is balanced
  2. every monomorphism in 𝒞︀ is extremal
  3. every epimorphism in 𝒞︀ is extremal

Proof. Drafted by Claude Sonnet 5, reviewed by David Rufino.

Being balanced is a self-dual notion: monic and epic swap under passing to 𝒞︀op (2.6.33) while isomorphisms remain isomorphisms, so 𝒞︀ is balanced iff 𝒞︀op is. Likewise, by the “Dually” clause of (2.6.156), a morphism is an extremal epimorphism in 𝒞︀ iff it is an extremal monomorphism in 𝒞︀op. So it suffices to prove a) ⟺ b); applying this to 𝒞︀op then gives a) ⟺ c).

a) ⟹ b) Suppose 𝒞︀ is balanced and 𝑚:𝑋→𝑌 is monic. If 𝑚=𝑓∘𝑒 for some epimorphism 𝑒:𝑋→𝑊, then 𝑒 is also monic: if 𝑒𝑔1=𝑒𝑔2 for 𝑔1,𝑔2:𝑍→𝑋 then 𝑓∘𝑒∘𝑔1=𝑓∘𝑒∘𝑔2, that is 𝑚𝑔1=𝑚𝑔2, whence 𝑔1=𝑔2 as 𝑚 is monic. As 𝑒 is both monic and epic, balancedness gives that 𝑒 is an isomorphism, so 𝑚 is extremal.

b) ⟹ a) Suppose every monomorphism is extremal and 𝑓 is both monic and epic. Then 𝑓 is an extremal monomorphism, so by (2.6.157) (with 𝑓 extremal monic and epic) 𝑓 is an isomorphism. So 𝒞︀ is balanced. ∎

Lemma 2.6.162

Let 𝒞︀ be a pointed category and 𝑓:𝑋→𝑌 a morphism for which ker(coker(𝑓)) exists. Then the following are equivalent

  1. 𝑓 is normal
  2. 𝑓=ker(coker(𝑓))

Dually, suppose coker(ker(𝑓)) exists then the following are equivalent

  1. 𝑓 is conormal
  2. 𝑓=coker(ker(𝑓))

Proof. b) ⟹ a) immediate.

a) ⟹ b) By assumption 𝜋:𝑌→coker(𝑓) and 𝑖:ker(𝜋)→𝑌 exists so we have a commutative diagram.

By definition of the cokernel 𝜋∘𝑓=0 whence there is a unique 𝜙:𝑋→ker(𝜋) such that 𝑖∘𝜙=𝑓.

As 𝑔∘𝑓=0 then by definition there is a unique 𝜃:coker(𝑓)→𝑍 such that 𝜃∘𝜋=𝑔.

Therefore 𝑔∘𝑖=𝜃∘𝜋∘𝑖=0. So by definition there is a unique 𝜓:ker(𝜋)→𝑋 such that 𝑓∘𝜓=𝑖.

Then 𝑖∘𝜙∘𝜓=𝑓∘𝜓=𝑖 and since 𝑖 is a monomorphism (2.6.135) 𝜙∘𝜓=1ker(𝜋). Similarly 𝑓∘𝜓∘𝜙=𝑖∘𝜙=𝑓 and since 𝑓=ker(𝑔) is a monomorphism (2.6.135) 𝜓∘𝜙=1𝑋. Therefore 𝑋 and ker(𝜋) are isomorphic via 𝜙 and 𝜓, and since 𝑖∘𝜙=𝑓, by (2.6.137) 𝑋 is also a kernel for 𝜋 as required.

Dually, 𝒞︀op is again pointed with the same zero object (2.6.54), monic/epic swap under passing to 𝒞︀op (2.6.33), and ker(𝑓), coker(𝑓) computed in 𝒞︀ are precisely coker(𝑓), ker(𝑓) computed in 𝒞︀op (2.6.154). So applying the equivalence just proved to 𝑓 regarded as a morphism of 𝒞︀op shows 𝑓 is conormal iff 𝑓=coker(ker(𝑓)). ∎

Definition 2.6.163

We say a pointed category 𝒞︀ is

  • normal if every monomorphism is normal (i.e. a kernel of some morphism).
  • conormal if every epimorphism is conormal (i.e. the cokernel of some morphism).
  • binormal if it is both normal and conormal.
Corollary 2.6.164
A normal (resp. conormal, binormal) category is balanced.
Example 2.6.165

We will see that the categories 𝐀𝐛𝐆𝐫𝐩 and 𝐴-𝐌𝐨𝐝 are binormal (and therefore every epi and mono is regular), whereas 𝐆𝐫𝐩 is only conormal. All three are balanced.

We also see may verify directly that in 𝐒𝐞𝐭 every monomorphism and epimorphism is regular.

Proposition 2.6.166

Let 𝒞︀ be a pointed category and 𝑓 a morphism. Then the following are equivalent

  1. ker(𝑓)=0
  2. 𝑓∘𝑔=0⟹𝑔=0

Dually, the following are equivalent

  1. coker(𝑓)=0
  2. 𝑔∘𝑓=0⟹𝑔=0

Proof. Drafted by Claude Sonnet 5, reviewed by David Rufino.

Write 𝑓:𝑋→𝑌 and 𝑖:ker(𝑓)→𝑋 for the kernel of 𝑓, so by (2.6.150), 𝑓∘𝑖=0 and for every 𝑖′:𝑊→𝑋 with 𝑓∘𝑖′=0 there is a unique 𝑒:𝑊→ker(𝑓) with 𝑖∘𝑒=𝑖′.

a) ⟹ b) Suppose ker(𝑓)=0 and 𝑓∘𝑔=0 for some 𝑔:𝑊→𝑋. By the universal property there is a unique 𝑒:𝑊→0 with 𝑖∘𝑒=𝑔; as 𝑖=00,𝑋 (since ker(𝑓)=0) and 𝑒=0𝑊,0 (since 0 is terminal), 𝑔=𝑖∘𝑒=0𝑊,𝑋=0.

b) ⟹ a) Let 𝜄:0→𝑋 be the canonical morphism. Since 0 is initial, 𝑓∘𝜄=0 automatically. Given any 𝑖′:𝑊→𝑋 with 𝑓∘𝑖′=0, the hypothesis gives 𝑖′=0, that is 𝑖′=𝜄∘0𝑊,0, and 0𝑊,0:𝑊→0 is the unique such morphism since 0 is terminal. So (0,𝜄) satisfies the universal property of ker(𝑓) (2.6.150), whence ker(𝑓)=0.

Dually, 𝒞︀op is again pointed with the same zero object (2.6.54), and ker(𝑓), coker(𝑓) computed in 𝒞︀ are precisely coker(𝑓), ker(𝑓) computed in 𝒞︀op (2.6.154), so applying the above to 𝑓 regarded as a morphism of 𝒞︀op gives the dual equivalence. ∎
