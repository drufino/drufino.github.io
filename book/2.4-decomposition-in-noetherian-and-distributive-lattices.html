2.4 Decomposition in Noetherian and Distributive Lattices

An analogue of irreducible factorization in rings (see the Factorisation section) applies to Noetherian Lattices. Furthermore uniqueness holds when the lattice is distributive. For a canonical reference see [Bir40].

Definition 2.4.1 (Meet-Prime and Meet-Irreducible)

Let (𝑋,≤) be a lattice and 𝑥∈𝑋. Then we say that 𝑥 is

  • meet-irreducible if 𝑦∧𝑧=𝑥⟹𝑦=𝑥or𝑧=𝑥
  • meet-prime if 𝑦∧𝑧≤𝑥⟹𝑦≤𝑥or𝑧≤𝑥
  • join-irreducible if 𝑦∨𝑧=𝑥⟹𝑦=𝑥or𝑦=𝑧
  • join-prime if 𝑥≤𝑦∨𝑧⟹𝑥≤𝑦or𝑥≤𝑧

The following result is proven in [Bir40] Ch. IX Lemma 4.1.

Proposition 2.4.2 (Prime = Irreducible)

Let (𝑋,≤) be a lattice. In general meet-prime ⟹ meet-irreducible and join-prime ⟹ join-irreducible. If 𝑋 is a distributive lattice, then the converse holds.

In the distributive case we denote by ℳ︀(𝑋) and 𝒥︀(𝑋) the sub-poset of meet-prime and join-prime elements respectively.

Proof. The first statement is straightforward. Conversely suppose 𝑋 is a distributive lattice and 𝑥 is meet-irreducible. If 𝑦∧𝑧≤𝑥 then 𝑥=𝑥∨(𝑦∧𝑧)=(𝑦∨𝑥)∧(𝑧∨𝑥)⟹𝑥=𝑦∨𝑥 or 𝑥=𝑧∨𝑥, whence the result follows. ∎
Proposition 2.4.3

Let (𝑋,≤) be a distributive lattice and 𝑌 a sub-lattice, then

ℳ︀(𝑌)=ℳ︀(𝑋)∩𝑌𝒥︀(𝑌)=𝒥︀(𝑋)∩𝑌

In particular this holds when 𝑌={𝑥}↑,{𝑦}↓,{𝑥}↑∩{𝑦}↓.

Proposition 2.4.4

Let (𝑋,≤) be a distributive lattice. If it is chain-complete (resp. co-chain-complete) then so is 𝒥︀(𝑋) (resp. ℳ︀(𝑋)).

Every join-prime element is bounded above by a maximal join-prime element, and every meet-prime element is bounded below by a minimal meet-prime element

Proof. Let 𝐶 be a chain of join-prime elements and 𝑥≔⋁𝐶. Suppose that 𝑦∨𝑧≥𝑥 then 𝑦∨𝑧≥𝑤 for all 𝑤∈𝐶. Then 𝑦≥𝑤 or 𝑧≥𝑤 for all 𝑤∈𝐶. Let 𝐶1≔{𝑤∈𝐶|𝑦≥𝑤}. If 𝐶1=𝐶 then we are done as 𝑥≤𝑦. Otherwise suppose 𝑤0∉𝐶1 then by prime-ness 𝑧≥𝑤0. Clearly 𝑤≤𝑤0⟹𝑤≤𝑧. Further 𝑤≥𝑤0⟹𝑤≰𝑦 (as otherwise 𝑤0≤𝑦) whence 𝑤≤𝑧. Therefore 𝑥≤𝑧.

The last statement follows from Zorn’s Lemma by considering the sub-lattices {𝑥}↑ and {𝑦}↓ which inherit the chain complete properties. ∎

Definition 2.4.5

Let (𝑋,≤) be a lattice and 𝑌⊆𝑋 a finite subset. Then we say that 𝑌 is

  • (meet-)irredundant if no proper subset has the same meet
  • incomparable (or an antichain) if no two elements are comparable
Lemma 2.4.6 (incomparable ⟺ irredundant)
Let (𝑋,≤) be a lattice and 𝑌⊆𝑋 then 𝑌 meet-irredundant ⟹ 𝑌 incomparable. Conversely if 𝑌 is a finite incomparable subset of meet-prime elements then 𝑌 is meet-irredundant.

Proof. The first part is straightforward, for if 𝑦1⪇𝑦2 are elements of 𝑌 then ⋀𝑌=⋀𝑌∖{𝑦2}.

Conversely suppose 𝑌′⊊𝑌 is such that ⋀𝑌′=⋀𝑌. Choose 𝑦2∈𝑌∖𝑌′, then ⋀𝑌′≤𝑦2, whence by definition of meet-prime (and induction) 𝑦1≤𝑦2 for some 𝑦1∈𝑌′. ∎

The following is [Bir40] Chapter IX Theorem 9

Proposition 2.4.7 (Decomposition in Noetherian Lattice)

Let (𝑋,≤) be a Noetherian distributive lattice. Then every element 𝑥∈𝑋 has a unique decomposition

𝑥=𝑥1∧…∧𝑥𝑛

where 𝑥𝑖 are meet-prime and meet-irredundant (equivalently incomparable). These are precisely the meet-primes minimal over 𝑥.

Dually, if (𝑋,≤) is an Artinian distributive lattice, then every element 𝑥∈𝑋 has a unique decomposition

𝑥=𝑥1∨…∨𝑥𝑛

where 𝑥𝑖 are join-prime and join-irredundant (equivalently incomparable). These are precisely the join-primes maximal below 𝑥.

Proof. Let 𝑌 be the subset of elements which are not finite meets of meet-prime elements, and suppose it is non-empty. Then by (2.1.63) 𝑌 has a maximal element 𝑥0. It cannot be meet-prime, and therefore not meet-irreducible (2.4.2), so there must exist elements 𝑦0,𝑧0∈𝑋 such that 𝑥0=𝑦0∧𝑧0 but 𝑥0⪇𝑦0 and 𝑥0⪇𝑧0. By maximality 𝑦0,𝑧0 are finite meets of prime elements, and therefore so is 𝑥0 a contradiction.

Therefore we have a decomposition into distinct primes

𝑥=𝑥1∧…∧𝑥𝑛

Consider the family of subsets of {𝑥1,…,𝑥𝑛} which have the same meet. Then there exists a minimal subset which by definition is meet-irredundant and by (2.4.6) incomparable. Suppose there is another such decomposition 𝑥=𝑥1′∧…∧𝑥𝑚′. Then for every 𝑖=1…𝑛 we have 𝑥𝜎(𝑖)′≤𝑥𝑖 and for every 𝑗=1…𝑚 we have 𝑥𝜏(𝑗)≤𝑥𝑗′ whence 𝑥𝜏(𝜎(𝑖))≤𝑥𝜎(𝑖)′≤𝑥𝑖. As the decomposition is incomparable we have 𝜏(𝜎(𝑖))=𝑖 and 𝑥𝜎(𝑖)′=𝑥𝑖. Therefore 𝜎 is injective and 𝑛≤𝑚. By symmetry 𝑚≤𝑛 and 𝜎 is a bijection. In otherwords the decomposition is unique.

Note 𝑥≤𝑧 and 𝑧 meet-prime implies 𝑥𝑗≤𝑧 for some 𝑗. Therefore if 𝑧 is a minimal prime then 𝑥𝑗=𝑧 and all the meet-primes minimal over 𝑥 must occur in the decomposition. Similarly if 𝑧≤𝑥𝑖 then by incomparability 𝑥𝑗=𝑧=𝑥𝑖. Therefore each 𝑥𝑖 is also minimal. ∎
