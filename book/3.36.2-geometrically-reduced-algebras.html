3.36.2 Geometrically Reduced Algebras

Reference is [Bou89] (Section V.15.4). The main results of this section are (3.36.26) and (3.36.28). Observe that if 𝑘 is perfect every extension 𝐾/𝑘 satisfies Maclane’s Criterion and is therefore Geometrically Reduced.

Proposition 3.36.21
Let 𝐴 be a reduced 𝑘-algebra and 𝐵 a geometrically reduced 𝑘-algebra, then 𝐴⊗𝑘𝐵 is reduced.

Proof. By the previous Lemma we have an embedding

𝐴↪︎∏(𝑘(𝔭)⊗𝑘𝐵)

As 𝐵 is geometrically reduced this shows that 𝐴⊗𝑘𝐵 is reduced. ∎

Corollary 3.36.22
Let 𝑘 be a perfect field and 𝐴,𝐵 reduced 𝑘-algebras. Then 𝐴⊗𝑘𝐵 is reduced.
Lemma 3.36.23

Let 𝐴 be a geometrically reduced 𝑘-algebra and 𝐾 the total ring of fractions. Then 𝐾 is geometrically reduced.

Conversely if 𝐴 is integral and 𝐾 is geometrically reduced, then 𝐴 is geometrically reduced.

Proof. Let 𝐿/𝑘 be a field extension and consider a nilpotent element 𝑥∈𝐾⊗𝐿. Then by definition

𝑥=∑𝑖=1𝑛(𝑎𝑖𝑠𝑖−1)⊗𝜆𝑖𝑎𝑖∈𝐴,𝑠𝑖∉𝑍(𝐴),𝜆𝑖∈𝐿

Let 𝑠=𝑠1…𝑠𝑛 then 𝑥⋅(𝑠⊗1)∈𝐴⊗𝐿⊂𝐾⊗𝐿. Then 𝑥⋅(𝑠⊗1) is nilpotent and so by definition zero. As (𝑠⊗1) is invertible we see 𝑥=0 as required.

For the converse 𝐴⊂𝐾 and therefore 𝐴⊗𝑘𝐿⊂𝐾⊗𝑘𝐿. ∎

Lemma 3.36.24
Let 𝐾/𝑘 be a separably generated field extension. Then 𝐾/𝑘 is geometrically reduced.

Proof. Consider first the case 𝐾=𝑘(ℬ︀) is purely transcendental. Then for 𝐿/𝑘 we have 𝑘[ℬ︀]⊗𝐿≅𝐿[ℬ︀] is evidently reduced. We may then demonstrate directly that 𝑘(ℬ︀)⊗𝑘𝐿 is reduced.

For the general case

𝐾⊗𝑘𝐿≅𝐾⊗𝑘(ℬ︀)(𝑘(ℬ︀)⊗𝑘𝐿)

We have shown that 𝑘(ℬ︀)⊗𝑘𝐿 is reduced and by (3.36.19) 𝐾/𝑘(ℬ︀) is geometrically reduced as by assumption it is separable. By (3.36.21) 𝐾⊗𝑘𝐿 is reduced and 𝐾 is geometrically reduced as required. ∎

Lemma 3.36.25
Let 𝐴 be a reduced 𝑘-algebra for which 𝑘 is perfect. Then 𝐴 is geometrically reduced.

Proof. We prove the result in increasing generality

  1. We first consider the case 𝐴=𝐾/𝑘 is a finitely generated field extension. By (3.19.148) 𝐾/𝑘 is separably generated and so by (3.36.24) it is geometrically reduced.

  2. When 𝐴 is a finitely-generated 𝑘-algebra by (3.36.20) there is a canonical embedding

    𝐴⊗𝑘𝐿↪︎∏𝔭(𝑘(𝔭)⊗𝑘𝐿)

    By assumption 𝑘(𝔭) is finitely generated and so by the first part is geometrically reduced. Therefore 𝐴⊗𝑘𝐿 is reduced as required.

  3. The general case follows from b) and the reduction to the finitely generated case (3.36.5).

 ∎

Proposition 3.36.26 (Maclane's Criterion for Algebras)

Let 𝐴 be a 𝑘-algebra. Then the following are equivalent

  1. 𝐴 is geometrically reduced
  2. 𝐴⊗𝑘𝑘― is reduced
  3. 𝐴⊗𝑘𝑘𝑝−∞ is reduced
  4. 𝐴⊗𝑘𝐾 is reduced for some perfect extension 𝐾/𝑘
  5. 𝐴⊗𝑘𝑘𝑝−1 is reduced
  6. 𝐴⊗𝑘𝑘′ is reduced for every finite subextension 𝑘′/𝑘 of 𝑘𝑝−1/𝑘

  7. The following 𝑘-module homomorphism

    𝑚:𝐴⊗𝑘𝑘𝑝−1→𝐴𝑎⊗𝜆→𝜆𝑝𝑎𝑝

    is injective (that is 𝑘𝑝−1 and 𝐴 are linearly disjoint with respect to the 𝑝-th power embedding into 𝐴)

  8. 𝐴 satisfies Maclane’s Criterion (3.19.144)

In particular when 𝑘 is perfect then this is equivalent to 𝐴 being reduced.

Proof. The case 𝑝=1 is simply (3.36.25) because 𝑘𝑝=𝑘=𝑘𝑝−1=𝑘𝑝−∞ is perfect and g) is equivalent to 𝐴 being reduced. Therefore we assume 𝑝>1.

𝑎)⟹𝑏) By definition.

𝑏)⟹𝑐) By (3.19.61) there is an embedding 𝑘𝑝−∞↪︎𝑘― whence an embedding 𝐴⊗𝑘𝑘𝑝−1↪︎𝐴⊗𝑘𝑘―.

𝑐)⟹𝑑) By (3.19.100) 𝑘𝑝−∞ is perfect.

𝑑)⟹𝑒) By (3.19.101) there is an embedding 𝑘𝑝−1↪︎𝐾 whence an embedding 𝐴⊗𝑘𝑘𝑝−1↪︎𝐴⊗𝑘𝐾.

𝑒)⟹𝑓) This is immediate as we have an embedding 𝐴⊗𝑘𝑘′↪︎𝐴⊗𝑘𝑘𝑝−1.

𝑓)⟺𝑔) Suppose 𝑥≔∑𝑖𝜆𝑖⊗𝑎𝑖∈𝐴⊗𝑘𝑘𝑝−1 is a finite sum then we may consider the finite subextension 𝑘′≔𝑘({𝑎𝑖}𝑖). Observe that

𝑥𝑝=∑𝑖𝜆𝑖𝑝⊗𝑎𝑖𝑝=∑𝑖1⊗𝜆𝑖𝑝𝑎𝑖𝑝=1⊗(∑𝑖𝜆𝑖𝑝𝑎𝑖𝑝)≕1⊗𝑚(𝑥)

Therefore we see 𝐴⊗𝑘𝑘′ is reduced for every such 𝑘′ iff 𝑚(𝑥) is injective.

𝑔)⟺ℎ) Consider the Frobenius morphisms 𝑖:𝑘𝑝−1→𝐴 and 𝑗:𝐴→𝐴. Then g) is equivalent to 𝑘𝑝−1 and 𝐴 being linearly disjoint in 𝐴 with respect to 𝑖,𝑗 and the result follows from the characterization of linear disjointness (3.35.55).

ℎ)⟹𝑎) Let {𝑎𝑖}𝑖∈𝐼 be a 𝑘-basis for 𝐴 then by (3.4.26) {𝑎𝑖⊗1}𝑖∈𝐼 is an 𝐿-basis for 𝐴⊗𝑘𝐿. Given 𝑥∈𝐴⊗𝑘𝐿 we have

𝑥=∑𝑖∈𝐼𝑎𝑖⊗𝜆𝑖𝜆𝑖∈𝐿

and

𝑥𝑝=∑𝑖∈𝐼𝜆𝑖𝑝⊗𝑎𝑖𝑝=∑𝑖∈𝐼𝜆𝑖𝑝(𝑎𝑖𝑝⊗1)

By assumption {𝑎𝑖𝑝}𝑖∈𝐼 is 𝑘-linearly independent and therefore {𝑎𝑖𝑝⊗1}𝑖∈𝐼 is 𝐿-linearly independent. Therefore 𝑥𝑝=0⟹𝜆𝑖𝑝=0for all𝑖∈𝐼⟹𝜆𝑖=0for all𝑖∈𝐼⟹𝑥=0, as 𝐿 is reduced. It follows from (3.19.145) that 𝐴⊗𝑘𝐿 is reduced, as we assumed that 𝑝>1. ∎

Corollary 3.36.27 (Maclane's Criterion for Fields)

Let 𝐾/𝑘 be a field extension with characteristic exponent 𝑝. Then the following are equivalent

  1. 𝐾/𝑘 is geometrically reduced
  2. 𝐾⊗𝑘𝑘― is reduced
  3. 𝐾⊗𝑘𝑘𝑝−1 is reduced
  4. 𝐾⊗𝑘𝑘𝑝−∞ is reduced
  5. 𝐾⊗𝑘𝑘′ is reduced for some perfect extension 𝑘′/𝑘
  6. 𝐾 and 𝑘𝑝−1 are linearly disjoint (with respect to some common field extension)
  7. 𝐾⊗𝑘𝑘𝑝−1 is an integral domain
  8. 𝐾⊗𝑘𝑘𝑝−1 is a field
  9. 𝐾/𝑘 satisfies Maclane’s Criterion (3.19.144)

Observe i) has finite character in the sense it holds if and only if it holds for every finitely-generated subextension.

In particular when 𝑘 is perfect every extension is geometrically reduced.

Proof. By (3.36.26) a)-f), i) are equivalent (using (3.35.57) to generalise the linear disjoint condition to any ambient field) and by (3.35.57) again f)-h) are equivalent. ∎
Proposition 3.36.28 (Separable Field Extensions)

Let 𝐾/𝑘 be a field extension. Then the following are equivalent

  1. 𝐾/𝑘 is geometrically reduced
  2. 𝐾⊗𝑘𝑘― is reduced
  3. 𝐾/𝑘 satisfies Maclane’s Criterion (3.19.144)
  4. Every finitely generated subextension 𝐾/𝑘 is separably generated

In particular if 𝑘 is perfect every field extension satisfies these properties.

Proof. By (3.36.27) we have 𝑎)⟺𝑏)⟺𝑐). Further 𝑐)⟹𝑑) is Lemma (3.19.148), since every subextension satisfies Maclane’s Criterion. For 𝑑)⟹𝑎) observe that every finitely generated subextension is geometrically reduced by (3.36.24). We may use (3.36.2) to argue that 𝐾/𝑘 is geometrically reduced. ∎
Corollary 3.36.29

Let 𝐾/𝑘 be a finitely generated field extension. Then the following are equivalent.

  1. 𝐾/𝑘 is geometrically reduced
  2. 𝐾⊗𝑘𝑘― is reduced
  3. 𝐾/𝑘 satisfies Maclane’s Criterion (3.19.144)
  4. Every finitely generated subextension of 𝐾/𝑘 is separably generated
  5. 𝐾/𝑘 is separably generated
Proof. We’ve already shown equivalence of a)-d) and clearly 𝑑)⟹𝑒). Finally 𝑒)⟹𝑎) is simply (3.36.24). ∎
