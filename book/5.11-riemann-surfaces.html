5.11 Riemann Surfaces

I develop the elementary theory of Riemann surface, starting with the more standard concept approach of maximal atlases (see [War13]) and then relating to the notion sheaves (see [Wed16] (Section 4.2)). The language of sheaves is well suited to complex analytic spaces and aligns well with the approach in the algebraic case.

Definition 5.11.1

Let 𝑋 be a topological space. By definition a chart on 𝑋 is a pair (𝑈,𝜑) where 𝑈⊂𝑋 is an open set and 𝜑 is a homeomorphism onto an open subset 𝜑(𝑈) of ℂ.

We say that two charts (𝑈,𝜑) and (𝑉,𝜓) are compatible if either 𝑈∩𝑉=∅ or the composite map (𝜓∘𝜑−1):𝜑(𝑈∩𝑉)→𝜓(𝑈∩𝑉) is biholomorphic.

An atlas 𝒜︀ on 𝑋 is a collection of charts {(𝑈𝛼,𝜑𝛼)} for which 𝑋=⋃𝛼𝑈𝛼 and every pair of charts is compatible.

We say two atlases 𝒜︀,𝒜︀′ are equivalent if 𝒜︀∪𝒜︀′ is an atlas.

Proposition 5.11.2

The notion of compatible charts is an equivalence relation. Similarly for the notion of equivalent atlases.

A union of equivalent atlases is again an atlas, and every atlas is contained in a unique maximal atlas.

We may then use the charts to define what it means for a function on a manifold to be holomorphic.

Lemma 5.11.3

Let 𝑋 be a topological space, 𝑈⊂𝑋 an open subset, 𝑓:𝑈→ℂ a function and (𝑉,𝜑), (𝑉′,𝜓) two compatible charts such that 𝑈∩𝑉∩𝑉′≠∅.

Then 𝑓∘𝜑−1|𝜑(𝑈∩𝑉∩𝑉′) is holomorphic if and only if 𝑓∘𝜓−1|𝜓(𝑈∩𝑉∩𝑉′) is holomorphic.

Lemma 5.11.4

Let 𝑋 be a topological space, 𝑈⊂𝑋 an open subset, 𝑓:𝑈→ℂ a function and (𝑉𝛼,𝜑𝛼)𝛼∈𝒜︀ a family of charts such that 𝑈⊂⋃𝛼∈𝒜︀𝑉𝛼. Further suppose that (𝑉,𝜑) is a chart such that 𝑈∩𝑉≠∅ and is compatible with every (𝑉𝛼,𝜑𝛼). Then the following are equivalent

  1. 𝑓∘𝜑−1|𝜑(𝑉∩𝑈) is holomorphic
  2. 𝑓∘𝜑𝛼−1|𝜑𝛼(𝑉𝛼∩𝑈∩𝑉) is holomorphic for all 𝛼∈𝒜︀ for which 𝑉𝛼∩𝑉≠∅
Proposition 5.11.5 (Holomorphic Function)

Let 𝑋 be a topological space, 𝑈⊂𝑋 an open subset, 𝑓:𝑈→ℂ a function and 𝒜︀ a given atlas. Then the following are equivalent

  1. there exists a collection of charts {(𝑉𝛼,𝜑𝛼)}⊂𝒜︀ such that 𝑉𝛼∩𝑈≠∅, 𝑓∘𝜑𝛼−1|𝜑𝛼(𝑉𝛼∩𝑈) is holomorphic and 𝑈⊂⋃𝛼𝑉𝛼
  2. for every chart (𝑉,𝜑)∈𝒜︀ such that 𝑈∩𝑉≠∅ the function 𝑓∘𝜑−1|𝜑(𝑈∩𝑉) is holomorphic.

When this holds we say that 𝑓 is holomorphic with respect to 𝒜︀.

Proof. 𝑏)⟹𝑎) Straightforward

𝑎)⟹𝑏) As every chart (𝑉,𝜑) is compatible with the collection {(𝑉𝛼,𝜑𝛼)} this follows from (5.11.4). ∎

Proposition 5.11.6
A holomorphic function 𝑓:𝑈→ℂ is continuous.
Proof. For every chart (𝑉,𝜑) the function 𝑓∘𝜑−1|𝜑(𝑈∩𝑉) is holomorphic (5.11.5) and therefore continuous. Further by definition the map 𝜑|𝑈∩𝑉 is continuous whence 𝑓|𝑈∩𝑉 is continuous (4.1.28). As the charts cover 𝑋 we are done by (4.1.29). ∎

We first prove that this definition does not depend on which atlas is chosen.

Proposition 5.11.7

Let 𝑋 be a topological space, 𝑈⊂𝑋 an open subset, 𝑓:𝑈→ℂ a function and 𝒜︀,𝒜︀′ two equivalent atlases.

Then 𝑓 is holomorphic with respect to 𝒜︀ if and only if it is holomorphic with respect to 𝒜︀′.

Proof. Since equivalence of atlases is symmetric we only need to show one direction. So suppose that 𝑓 is holomorphic with respect to 𝒜︀, and let (𝑊,𝜓)∈𝒜︀′ be a chart. Then by (5.11.4) 𝑓∘𝜓−1 is holomorphic, so that 𝑓 is holomorphic with respect to 𝒜︀′. ∎

Further we show that just as in the usual case this is a local condition.

Proposition 5.11.8 (Structure Sheaf associated to an Atlas)

Let 𝑋 be a topological space together with an atlas 𝒜︀. Let 𝑈=⋃𝑖∈𝐼𝑈𝑖 an open cover and 𝑓:𝑈→ℂ a function. Then 𝑓 is holomorphic (with respect to 𝒜︀) if and only if 𝑓|𝑈𝑖 is holomorphic for all 𝑖∈𝐼.

In particular for every atlas the mapping

𝒪︀𝑋(𝑈)≔{𝑓:𝑈→ℂ|𝑓holomorphic }

determines a sheaf of ℂ-algebras, and the pair (𝑋,𝒪︀𝑋) constitutes a space of ℂ-functions, which we call the structure sheaf. It contains an isomorphic copy of ℂ consisting of the constant functions.

Two atlases are equivalent if and only if they determine the same structure sheaf.

A space of functions (𝑋,𝒪︀𝑋) arises in this way if and only if there is an open cover 𝑋=⋃𝑖∈𝐼𝑈𝑖 such that (𝑈𝑖,𝒪︀𝑋|𝑈𝑖)⟶∼(𝑉𝑖,𝒪︀𝑉𝑖) for 𝑉𝑖⊂ℂ an open subset with the usual sheaf of holomorphic functions.

Proof. Suppose that (𝑉,𝜑)∈𝒜︀ is a chart such that 𝑉∩𝑈𝑖≠∅. Then by assumption 𝑓∘𝜑−1|𝜑(𝑉∩𝑈) is holomorphic whence by (…) 𝑓|𝑈𝑖∘𝜑−1|𝜑(𝑉∩𝑈𝑖) is holomorphic. Since the chart (𝑉,𝜑) was arbitrary we conclude 𝑓|𝑈𝑖 is holomorphic with respect to the atlas 𝒜︀.

Conversely suppose 𝑓|𝑈𝑖 is holomorphic with respect to 𝒜︀ for all 𝑖∈𝐼. Consider an arbitrary chart (𝑉,𝜑)∈𝒜︀ such that 𝑉∩𝑈≠∅. Then 𝑉∩𝑈=⋃𝑖∈𝐼𝑉∩𝑈𝑖, where we may restrict to open subsets with 𝑉∩𝑈𝑖≠∅. Then by assumption 𝑓|𝑈𝑖∘𝜑−1|𝜑(𝑉∩𝑈𝑖)=(𝑓∘𝜑−1|𝜑(𝑉∩𝑈))|𝜑(𝑉∩𝑈𝑖) is holomorphic. By (…) 𝑓∘𝜑−1|𝜑(𝑉∩𝑈) is holomorphic. As the chart was arbitrary we conclude that 𝑓 is holomorphic with respect to 𝒜︀.

The holomorphic functions form a ℂ-algebra by (5.5.4), and in particular contain the constant functions. Further 𝐷(𝑓)=𝑋∖𝑓−1({0}) which is an open subset of 𝑋, and (𝑓|𝐷(𝑓))−1 is holomorphic whenever 𝑓 is not identically zero.

By definition then (𝑋,𝒪︀𝑋) is a space of ℂ-functions. By (5.11.7) an equivalent atlas determines the same structure sheaf. Conversely suppose 𝒜︀,𝒜︀′ determine the same structure sheaves. Consider two atlases (𝑉,𝜑)∈𝒜︀ and (𝑉′,𝜑′)∈𝒜︀′. Then by definition we see that 𝜑∘(𝜑′)−1 is holomorphic and (𝜑′)∘𝜑−1 is holomorphic, and therefore they are compatible as required. ∎

Definition 5.11.9 (Riemann Surface)

Let (𝑋,𝒪︀𝑋) be a space of ℂ-functions, which is Hausdorff and second countable. Further suppose there is an open cover 𝑋=⋃𝑖∈𝐼𝑈𝑖 such that there exists isormorphisms

𝜑𝑖:(𝑈𝑖,𝒪︀𝑋|𝑈𝑖)→∼(𝑉𝑖,𝒪︀𝑉𝑖)

for 𝑉𝑖⊂ℂ an open subset. Then we say 𝑋 is a Riemann Surface.

We say 𝒜︀ is a compatible atlas if it determines the same structure sheaf. Further there exists a unique compatible maximal atlas (5.11.8).

Then 𝜑:𝑈→ℂ is a chart for 𝑋 if it lies in at least one compatible atlas (equivalently is in the unique maximal atlas).
