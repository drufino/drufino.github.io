4.1 Topological Spaces

References:

  • General Topology [Kel71] (Chap. 1)
  • General Topology [Wil70]

Topology is useful in algebraic geometry, but often the natural topologies are usually much coarser so the theory looks rather different.

Definition 4.1.1 (Topological Space)

A topological space (𝑋,𝒯︀𝑋) consists of a set 𝑋 and family of open sets 𝒯︀𝑋⊆𝒫︀(𝑋) satisfying the following properties

  • 𝑋,∅∈𝒯︀𝑋
  • 𝑈𝑖∈𝒯︀𝑋⟹⋃𝑖∈𝐼𝑈𝑖∈𝒯︀𝑋
  • 𝑈,𝑉∈𝒯︀𝑋⟹𝑈∩𝑉∈𝒯︀𝑋

A subset 𝑍⊂𝑋 is said to be closed iff 𝑋∖𝑍 is open. We may equivalently define the topology in terms of closed sets.

Proposition 4.1.2
Let 𝑋 be a topological space. Both the open sets and closed sets form a distributive lattice under inclusion.
Definition 4.1.3 (Subspace topology)

Let 𝑌⊂𝑋, then we may define the subspace topology on 𝑌 by

𝒯︀𝑌≔{𝑈∩𝑌|𝑈∈𝒯︀𝑋}

when 𝑌 is open then this is given by

𝒯︀𝑌={𝑈⊆𝑌|𝑈∈𝒯︀𝑋}
Definition 4.1.4 (Base)

We say ℬ︀⊆𝒫︀(𝑋) is a base (of open sets) on 𝑋 if

  • For every 𝑥∈𝑋 there is a 𝑈∈ℬ︀ such that 𝑥∈𝑈
  • Suppose 𝑈,𝑉∈ℬ︀ and 𝑥∈𝑈∩𝑉 then there exists 𝑊∈ℬ︀ such that 𝑥∈𝑊⊆𝑈∩𝑉
Proposition 4.1.5 (Topology generated by a base)

Let ℬ︀ be a base, then the following is a topology on 𝑋

𝒯︀ℬ︀≔{⋃𝑈𝑖∈𝐼𝑈𝑖|𝐼⊆ℬ︀}

i.e. the set of arbitrary unions of sets in ℬ︀.

Proposition 4.1.6 (Base generating topology)

A base ℬ︀ satisfies 𝒯︀ℬ︀=𝒯︀𝑋 if and only if

  1. ℬ︀⊂𝒯︀𝑋
  2. For every 𝑥∈𝑈 and 𝑈∈𝒯︀𝑋 there exists 𝑉∈ℬ︀ such that 𝑥∈𝑉⊆𝑈.

In this case we say ℬ︀ is a base for (the topology on) 𝑋.

Proposition 4.1.7 (Subbase for a topology)

Let 𝑋 be a set and ℬ︀ be an arbitrary family of subsets. Then there exists a topology 𝒯︀ℬ︀ such that

  1. ℬ︀⊂𝒯︀ℬ︀
  2. For every topology 𝒯︀′ containing ℬ︀ we have 𝒯︀ℬ︀⊂𝒯︀′.

We say that ℬ︀ is a subbase for the topology 𝒯︀ℬ︀. Explicitly 𝒯︀ℬ︀ consists of arbitrary unions of finite intersections of elements of ℬ︀.

Proposition 4.1.8 (Base for subspace topology)

Let (𝑋,𝒯︀) be a topological space, and 𝑌⊂𝑋 has the subspace topology 𝒯︀𝑌 (4.1.3). If ℬ︀ is a base for (𝑋,𝒯︀) then

ℬ︀𝑌≔{𝑈∩𝑌|𝑈∈ℬ︀}

is a base for (𝑌,𝒯︀𝑌).

Definition 4.1.9 (Adherent point)

For 𝑌⊂𝑋 we say 𝑥 is an adherent point of 𝑌 if every open neighbourhood of 𝑥 intersects 𝑌.

Similarly we say 𝑥 is a limit point (or accumulation point) for 𝑌 if every open neighbourhood of 𝑥 intersects 𝑌 at a point other than 𝑥.

Proposition 4.1.10 (Closed point)

Let 𝑥∈𝑋 then TFAE

  • {𝑥} is closed
  • For every 𝑦≠𝑥 there is 𝑈∋𝑦 such that 𝑥∉𝑈.
Definition 4.1.11
For a topological space 𝑋 let 𝑋0 denote the subset of closed points.
Definition 4.1.12 (Open Embedding)

Let 𝑓:𝑋→𝑌 be a map of topological spaces. We say it is an open embedding if one of the following equivalent conditions holds

  1. 𝑓(𝑋) is open and 𝑓 is a homeomorphism onto its image
  2. 𝑓 is continuous, open and injective.
