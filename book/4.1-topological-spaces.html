Topology is useful in algebraic geometry, but often the natural topologies are usually much coarser so the theory looks rather different.

Definition 4.1.1 (Topological Space)

A topological space (𝑋,𝒯︀𝑋) consists of a set 𝑋 and family of open sets 𝒯︀𝑋⊆𝒫︀(𝑋) satisfying the following properties

  • 𝑋,∅∈𝒯︀𝑋
  • 𝑈𝑖∈𝒯︀𝑋⟹⋃𝑖∈𝐼𝑈𝑖∈𝒯︀𝑋
  • 𝑈,𝑉∈𝒯︀𝑋⟹𝑈∩𝑉∈𝒯︀𝑋

A subset 𝑍⊂𝑋 is said to be closed iff 𝑋∖𝑍 is open. We may equivalently define the topology in terms of closed sets.

Proposition 4.1.2
Let 𝑋 be a topological space. Both the open sets and closed sets form a distributive lattice under inclusion.
Definition 4.1.3 (Subspace topology)

Let 𝑌⊂𝑋, then we may define the subspace topology on 𝑌 by

𝒯︀𝑌≔{𝑈∩𝑌|𝑈∈𝒯︀𝑋}

when 𝑌 is open then this is given by

𝒯︀𝑌={𝑈⊆𝑌|𝑈∈𝒯︀𝑋}
Definition 4.1.4 (Base)

We say ℬ︀⊆𝒫︀(𝑋) is a base (of open sets) on 𝑋 if

  • For every 𝑥∈𝑋 there is a 𝑈∈ℬ︀ such that 𝑥∈𝑈
  • Suppose 𝑈,𝑉∈ℬ︀ and 𝑥∈𝑈∩𝑉 then there exists 𝑊∈ℬ︀ such that 𝑥∈𝑊⊆𝑈∩𝑉
Proposition 4.1.5 (Topology generated by a base)

Let ℬ︀ be a base, then the following is a topology on 𝑋

𝒯︀ℬ︀≔{⋃𝑈𝑖∈𝐼𝑈𝑖|𝐼⊆ℬ︀}

i.e. the set of arbitrary unions of sets in ℬ︀.

Proposition 4.1.6 (Base generating topology)

A base ℬ︀ satisfies 𝒯︀ℬ︀=𝒯︀𝑋 if and only if

  1. ℬ︀⊂𝒯︀𝑋
  2. For every 𝑥∈𝑈 and 𝑈∈𝒯︀𝑋 there exists 𝑉∈ℬ︀ such that 𝑥∈𝑉⊆𝑈.

In this case we say ℬ︀ is a base for (the topology on) 𝑋.

Proposition 4.1.7 (Subbase for a topology)

Let 𝑋 be a set and ℬ︀ be an arbitrary family of subsets. Then there exists a topology 𝒯︀ℬ︀ such that

  1. ℬ︀⊂𝒯︀ℬ︀
  2. For every topology 𝒯︀′ containing ℬ︀ we have 𝒯︀ℬ︀⊂𝒯︀′.

We say that ℬ︀ is a subbase for the topology 𝒯︀ℬ︀. Explicitly 𝒯︀ℬ︀ consists of arbitrary unions of finite intersections of elements of ℬ︀.

Proposition 4.1.8 (Base for subspace topology)

Let (𝑋,𝒯︀) be a topological space, and 𝑌⊂𝑋 has the subspace topology 𝒯︀𝑌 (4.1.3). If ℬ︀ is a base for (𝑋,𝒯︀) then

ℬ︀𝑌≔{𝑈∩𝑌|𝑈∈ℬ︀}

is a base for (𝑌,𝒯︀𝑌).

Definition 4.1.9 (Adherent point)

For 𝑌⊂𝑋 we say 𝑥 is an adherent point of 𝑌 if every open neighbourhood of 𝑥 intersects 𝑌.

Similarly we say 𝑥 is a limit point (or accumulation point) for 𝑌 if every open neighbourhood of 𝑥 intersects 𝑌 at a point other than 𝑥.

Definition 4.1.11
For a topological space 𝑋 let 𝑋0 denote the subset of closed points.
Definition 4.1.12 (Open Embedding)

Let 𝑓:𝑋→𝑌 be a map of topological spaces. We say it is an open embedding if one of the following equivalent conditions holds

  1. 𝑓(𝑋) is open and 𝑓 is a homeomorphism onto its image
  2. 𝑓 is continuous, open and injective.

4.1.1 Axioms of Countability

Definition 4.1.13 (Neighbourhood)

Let 𝑋 be a topological space and 𝑥∈𝑋. We say a set 𝑉⊂𝑋 is a neighbourhood of 𝑥 if 𝑥∈𝑈⊂𝑉 for some open set 𝑈. We write 𝒰︀𝑥 for the neighbourhoods of 𝑥, and 𝒪︀𝑥 for the open neighbourhoods of 𝑥.

We say that a collection of neighbourhoods ℬ︀𝑥 is a local base for 𝑥 if every neighbourhood 𝑈∈𝒰︀𝑥 contains some neighbourhood 𝑉∈ℬ︀𝑥. For example 𝒪︀𝑥 is a local base.

Definition 4.1.14 (First-Countable)
Let 𝑋 be a topological space. 𝑋 is first countable if every point 𝑥∈𝑋 has a countable local base.
Definition 4.1.15 (Second-Countable)
Let 𝑋 be a topological space. 𝑋 is second countable if there exists a countable basis. Evidently this is stronger than first countability.
Example 4.1.16

For example a metric space is always first countable as we may consider balls of radius 1𝑛.

Further ℝ is second countable as we may consider open intervals with rational endpoints.

Definition 4.1.17 (Adherent Point)

4.1.4 Quasi-Homeomorphism

Let 𝑓:𝑋→𝑌 be a map. The following are equivalent

  2. The map 𝑍→𝑓−1(𝑍) is a bijection between closed sets

4.1.12 Krull Dimension

References:

  • Éléments de géométrie algébrique IV [Gro64] (Chap. 0 §14.4.1)
  • Some remarks on biequidimensionality of topological spaces and Noetherian schemes [Hei17]

For a Noetherian topological space 𝑋 the closed subsets form an Artinian, distributive lattice. Furthermore the irreducible subsets are precisely the join-prime elements by (4.1.61). Therefore we may use the notions of Krull Lattice developed in Foundations.tex’s Krull Dimension section ((2.5.2)).

Definition 4.1.80 (Chain of irreducibles)

Let 𝑋 be a Noetherian topological space. A chain of irreducible closed subsets

𝑍0⊊𝑍1⊊…⊊𝑍𝑛

is said to have length 𝑛. A chain is saturated if there is no proper refinement, that is if 𝑌 is irreducible then

𝑍𝑖⊆𝑌⊆𝑍𝑖+1⟹𝑌=𝑍𝑖or𝑌=𝑍𝑖+1.

If in addition 𝑍𝑛 (resp. 𝑍0) is maximal (resp. minimal) then the chain is maximal.

Definition 4.1.81 (Krull Lattice of Closed Subsets)

Let 𝑋 be a topological space.

  • The Krull dimension dim(𝑋) of 𝑋 is the maximal length of all chains of irreducible closed subsets. Note this may be ∞.
  • The height or codimension of an irreducible closed subset 𝑌⊆𝑋, denoted codim(𝑌,𝑋), is the maximal length of chains of irreducible subsets containing 𝑌.

  • When 𝑌 is not irreducible we write

    codim(𝑌,𝑋)=inf𝛼codim(𝑌𝛼,𝑋)

    where 𝑌𝛼 varies among the irreducible components of 𝑌.

If dim(𝑋)<∞ then we say 𝑋 is finite-dimensional. In this case it’s clear the closed subsets of a topological space form a Krull Lattice where the irreducible closed subsets are precisely the join-prime elements of the lattice.

Note any saturated chain for 𝑌⊂𝑋 must start at 𝑌 and terminate at an irreducible component of 𝑋. In particular if 𝑋 is irreducible then a saturated chain must terminate at 𝑋.

Proposition 4.1.82 (Extending Chains)

Let 𝑋 be a finite-dimensional topological space. Then

  1. Every chain is contained in a saturated chain with the same endpoints
  2. Every chain is contained in a maximal chain
Proposition 4.1.83 (Simple properties of (co-)dimension)

Let 𝑋 be a topological space. Then the following properties hold

  1. dim(𝑋)=sup𝛼dim(𝑋𝛼) where 𝑋𝛼 are the irreducible components of 𝑋
  2. codim(𝑌,𝑋)=sup𝛼codim(𝑌,𝑋𝛼) where 𝑋𝛼 are the irreducible components of 𝑋 containing 𝑌
  3. dim(𝑌)+codim(𝑌,𝑋)≤dim(𝑋) for every closed subset 𝑌⊂𝑋
  4. codim(𝑌,𝑍)+codim(𝑍,𝑇)≤codim(𝑌,𝑇) for 𝑌⊂𝑍⊂𝑇 irreducible closed subsets
  5. 𝑌⊊𝑍 is a saturated chain of irreducible closed subsets if and only if codim(𝑌,𝑍)=1.
  6. Let 𝑌 be a closed subset of 𝑋. Then codim(𝑌,𝑋)=0⟺ every irreducible component of 𝑌 is an irreducible component of 𝑋. In particular if 𝑋 is irreducible then codim(𝑌,𝑋)=0⟺𝑌=𝑋⟺dim(𝑋)=dim(𝑌).

In particular if 𝑋 is finite-dimensional then all codimensions are also finite.

Definition 4.1.85 (Properties)

Let 𝑋 be a topological space of finite dimension. Then we say 𝑋 is

  • Equidimensional if all irreducible components of 𝑋 have the same dimension
  • Equicodimensional if codim(𝑌,𝑋) is constant as 𝑌 varies over minimal irreducible subsets of 𝑋
  • Biequidimensional if all maximal chains of irreducible subsets have the same length.
  • Quasi-Biequidimensional if every irreducible component is biequidimensional
  • Catenary if any two saturated chains with the same endpoints, say 𝑌 and 𝑍, have the same length, namely codim(𝑌,𝑍)

Observe that quasi-biequidimensional + equidimensional ⟺ biequidimensional and irreducible ⟹ equidimensional

4.1.14 Quasi-Compactness

Definition 4.1.100 (Cluster Point of a Sequence)

Let (𝑥𝑛) be a sequence in a topological space 𝑋. We say that 𝑥∈𝑋 is

  1. a cluster point (or accumulation point) of 𝑥𝑛 if for every 𝑈∈𝒪︀𝑥 the set {𝑚∈ℕ|𝑥𝑚∈𝑈} is infinite
  2. a subsequential limit of 𝑥𝑛 if there exists some subsequence 𝑥𝑛𝑘→𝑥

In general the latter implies the former, and if 𝑋 is first countable the concepts are equivalent as we will see.

Lemma 4.1.101 (Cluster Point is Subsequential Limit Point)
Let 𝑋 be a first countable topological space and 𝑥 a cluster point of a sequence (𝑥𝑛). Then there exists some subsequence 𝑥𝑛𝑘 such that 𝑥𝑛𝑘→𝑥.

Proof. Let (𝑈𝑛) be a local base at 𝑥. By replacing it with 𝑈𝑛′≔𝑈1∩…∩𝑈𝑛 we may assume it is without loss of generality decreasing. Define 𝑛0=0 and 𝑛𝑘 inductively by

𝑛𝑘≔min{𝑚>𝑛𝑘−1|𝑥𝑚∈𝑈𝑘}

which is well-defined precisely because 𝑥 is a cluster point. Then 𝑥𝑛𝑘∈𝑈𝑘 which shows that 𝑥𝑛𝑘→𝑥 as required. ∎

Definition 4.1.102

Let 𝑋 be a topological space. We say it is

  • Quasi-Compact if every open cover of 𝑋 has a finite subcover
  • Countably Quasi-Compact if every countable open cover of 𝑋 has a finite subcover
  • Sequentially Quasi-Compact if every sequence (𝑥𝑛) in 𝑋 has a convergent subsequence

If in addition 𝑋 is Hausdorff (e.g. a metric space) we say that 𝑋 is compact (resp. countably compact, sequentially compact).
