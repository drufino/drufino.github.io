5.4.7 Continuous Linear Maps

Proposition 5.4.38 (Continuous Linear Maps)

Let 𝑓:𝑋→𝑌 be a linear map of normed vector spaces. Then the following are equivalent

  1. 𝑓 is continuous

  2. There exists a constant 𝐶>0 such that

    ‖𝑓(𝑥)‖≤𝐶‖𝑥‖

  3. 𝑓 is bounded on the unit sphere

    sup{‖𝑓(𝑥)‖𝑌|‖𝑥‖𝑋=1}<∞

When 𝑋 is finite-dimensional then every linear map is continuous.

Proof. Suppose 𝑏) holds then 𝑓 is even uniformly continuous because

‖𝑥−𝑦‖<𝜀𝐶⟹‖𝑓(𝑥)−𝑓(𝑦)‖<𝜀

Conversely given 𝑎) there exists 𝛿 such that

‖𝑥‖≤𝛿⟹‖𝑓(𝑥)‖<1

Therefore

‖𝑓(𝛿𝑥‖𝑥‖)‖<1⟹‖𝑓(𝑥)‖<1𝛿‖𝑥‖

and we may take 𝐶=1𝛿. Given 𝑏) evidently ‖𝑓‖≤𝐶<∞, and conversely ‖𝑓(𝑥)‖≤‖𝑓‖‖𝑥‖. ∎

Proposition 5.4.39

Let 𝑋,𝑌 be normed vector spaces. Denote by 𝐿(𝑋,𝑌) the set of continuous linear maps. It is a normed vector space, with norm given by

‖𝜃‖≔sup{‖𝜃(𝑥)‖𝑌|‖𝑥‖𝑋=1}

Furthermore if 𝑌 is complete, so is 𝐿(𝑋,𝑌).

Proof. Evidently ‖𝜆𝜃‖=|𝜆|‖𝜃‖ and ‖𝜃1+𝜃2‖≤‖𝜃1‖+‖𝜃2‖<∞. Let {𝜃𝑛} be a cauchy sequence in 𝐿(𝑋,𝑌). Given 𝑥∈𝑋 then

‖𝜃𝑛(𝑥)−𝜃𝑚(𝑥)‖≤‖𝜃𝑛−𝜃𝑚‖‖𝑥‖

whence {𝜃𝑛(𝑥)} is a cauchy sequence, and therefore converges to 𝜃(𝑥). By uniqueness of limits we see that 𝜃 is linear. Furthermore by the reverse triangle inequality (…)

|‖𝜃𝑛‖−‖𝜃𝑚‖|≤‖𝜃𝑛−𝜃𝑚‖

in otherwords ‖𝜃𝑛‖ is a cauchy sequence and converges to some limit 𝐶. Suppose that ‖𝑥‖=1 then

‖𝜃(𝑥)‖≤‖𝜃(𝑥)−𝜃𝑛(𝑥)‖+‖𝜃𝑛(𝑥)‖≤‖𝜃(𝑥)−𝜃𝑛(𝑥)‖+‖𝜃𝑛‖

Choose 𝑁1 such that 𝑛≥𝑁1⟹‖𝜃𝑛‖≤𝐶+𝜀 and 𝑁2 such that 𝑛≥𝑁2⟹‖𝜃(𝑥)−𝜃𝑛(𝑥)‖<𝜀. As 𝜀 was arbitrary we see that ‖𝜃‖≤𝐶 and in particular is finite. ∎

Proposition 5.4.40 (Finite-Dimensional Linear Maps are continuous)
Suppose that 𝜃:𝑋→𝑌 is a linear map of normed vector spaces and 𝑋 is finite-dimensional. Then 𝜃 is continuous.

Proof. Let {𝑒1,⋯,𝑒𝑛} be a basis. By (5.4.22) we know that ‖⋅‖𝑋 is equivalent to the infinity norm ‖⋅‖∞. therefore it is sufficient to show that 𝜃 is continuous with respect to this norm. However

‖𝜃(∑𝑖=1𝑛𝜆𝑖𝑒𝑖)‖≤∑𝑖=1𝑛|𝜆𝑖|‖𝜃(𝑒𝑖)‖≤𝑛‖∑𝑖=1𝑛𝜆𝑖𝑒𝑖‖∞max𝑖‖𝜃(𝑒𝑖)‖

 ∎

Proposition 5.4.41 (Continuous Multilinear Maps)

Let 𝜓:𝑋1×⋯×𝑋𝑝→𝑍 be a multilinear map of normed vector spaces (using the product norm). Then the following are equivalent

  1. 𝜓 is continuous

  2. There exists a constant 𝐶>0 such that

    ‖𝜓(𝑥1,⋯,𝑥𝑝)‖≤𝐶‖𝑥1‖⋯‖𝑥𝑝‖

  3. The following quantity is finite

    sup{‖𝜓(𝑥1,⋯,𝑥𝑝)‖|‖𝑥1‖=⋯=‖𝑥𝑝‖=1}<∞

In this case 𝐿(𝑋1,⋯,𝑋𝑝;𝑍) is a normed vector space with norm given by expression in 𝑐). Furthermore if 𝑍 is complete so is 𝐿(𝑋1,⋯,𝑋𝑝;𝑍).

Finally if 𝑋1,⋯𝑋𝑝 are finite-dimensional then every multilinear map is continuous.

Proof. a) ⟹ b) Suppose there is no such constant 𝐶, then there exists (𝑥𝑛1,⋯,𝑥𝑛𝑝)∈𝑋1×⋯×𝑋𝑝 such that

‖𝜓(𝑥𝑛1,⋯,𝑥𝑛𝑝)‖>𝑛𝑝‖𝑥𝑛‖‖𝑦𝑛‖

Define 𝑥̂𝑛𝑖≔𝑥𝑛𝑖𝑛‖𝑥𝑛‖. Then ‖(𝑥̂𝑛1,⋯,𝑥̂𝑛𝑝)‖=1𝑛→0 but 𝐵(0,⋯,0)=0 by linearity and 𝐵(𝑥̂𝑛1,⋯,𝑥̂𝑛𝑝)>1, which contradicts continuity of limits (…).

b) ⟹ a) Observe by linearity

𝜓(𝑥1,⋯,𝑥𝑝)−𝜓(𝑦1,⋯,𝑦𝑝)=𝜓(𝑥1−𝑦1,𝑥2,⋯,𝑥𝑝)+𝜓(𝑦1,𝑥2−𝑦2,𝑥3,⋯,𝑥𝑝)+⋯+𝜓(𝑦1,⋯,𝑦𝑝−1,𝑥𝑝−𝑦𝑝)≤𝐶‖𝑥1−𝑦1‖‖𝑥2‖⋯‖𝑥𝑝‖+𝐶‖𝑥2−𝑦2‖‖𝑦1‖‖𝑥3‖⋯‖𝑥𝑝‖+⋯+𝐶‖𝑥𝑝−𝑦𝑝‖‖𝑦1‖⋯‖𝑦𝑝−1‖

Fix any 𝜀>0 then it is enough to show that

‖𝑥𝑖−𝑦𝑖‖<min(‖𝑦𝑖‖,𝜀)⟹‖𝜓(𝑥1,⋯,𝑥𝑝)−𝜓(𝑦1,⋯,𝑦𝑝)‖<𝑀𝜀

for some positive constant 𝑀 depending only on 𝑦. For this implies that ‖𝑥𝑖‖<2‖𝑦𝑖‖ so that

‖𝜓(𝑥1,⋯,𝑥𝑝)−𝜓(𝑦1,⋯,𝑦𝑝)‖≤𝜀∑𝑖=1𝑝2𝐶‖𝑦1‖⋯‖𝑦𝑖‖̂⋯‖𝑦𝑝‖

as required.

b) ⟺ c) Straightforward

The supremum is evidently a norm, and the verification of completeness follows as before. ∎

Definition 5.4.42 (Space of Continuous Multilinear Maps)

Let 𝑋1,⋯,𝑋𝑝, 𝑌 be normed vector spaces then let 𝐿(𝑋1,⋯,𝑋𝑝;𝑌) denote the 𝐾-vector space of all continuous multilinear maps.

Denote by 𝐿𝑝(𝑋,𝑌)≔𝐿(𝑋𝑝;𝑌) the vector space of continuous multilinear maps on the 𝑝-fold product of 𝑋.

Proposition 5.4.43 (Alternating Multilinear Maps)

Let 𝐿𝑎(𝑋1,⋯,𝑋𝑝;𝑌) denote the subspace of continuous linear maps 𝐿(𝑋1,⋯,𝑋𝑝;𝑌) which are alternating (3.5.5). Then this is a closed subset. In particular when 𝑌 is complete so is 𝐿𝑎(𝑋1,⋯,𝑋𝑝;𝑌).

As before define 𝐿𝑎𝑝(𝑋,𝑌)≔𝐿𝑎(𝑋𝑝;𝑌).
