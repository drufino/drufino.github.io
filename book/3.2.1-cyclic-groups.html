3.2.1 Cyclic Groups

Definition 3.2.19

A group 𝐺 is said to be cyclic if there is a surjective group homomorphism

(ℤ,+)⟶(𝐺,⋅)

equivalently if there is 𝑔∈𝐺 such that ⟨𝑔⟩=𝐺. Such a 𝑔 is called a generator for 𝐺.

Proposition 3.2.20

Consider the additive group (ℤ,+). Then

  1. Every subgroup is of the form 𝑑ℤ for 𝑑≥0 and is itself cyclic

  2. When 𝑑>0, then 𝑍/𝑑ℤ has a complete set of coset representatives

    𝑆≔{0,1,…,𝑑−1}

  3. In particular [𝑍:𝑑ℤ]=𝑑 when 𝑑>0

  4. 𝑑ℤ⊆𝑒ℤ⟺𝑒∣𝑑 and in this case [𝑒ℤ:𝑑ℤ]=𝑑𝑒

Proof. We prove each in turn

  1. By (2.2.6) every subgroup is of the form 𝑑ℤ. Multiplication map [𝑑]:ℤ→𝑑ℤ shows it is itself cyclic.
  2. By the division algorithm (2.2.5) 𝑆 is a complete set. Given 𝑖,𝑗∈𝑆 we note that |𝑖−𝑗|<𝑑. And 𝑖∼𝑑𝑗⟹𝑑∣|𝑖−𝑗|⟹|𝑖−𝑗|=0⟹𝑖=𝑗. Therefore the set 𝑆 consists of distinct coset representatives.
  3. This is clear from the previous step

  4. The first equivalence is clear. By (3.2.12)

    [ℤ:𝑑ℤ]=[ℤ:𝑒ℤ][𝑒ℤ:𝑑ℤ]

    and the result follows.

 ∎

Proposition 3.2.21

Let 𝐺 be a cyclic group. Then

  • If 𝐺 is infinite it is isomorphic to ℤ
  • If 𝐺 is finite it is isomorphic to ℤ/𝑛ℤ for some 𝑛>0

Proof. By the previous Proposition the kernel of the homomorphism ℤ→𝐺 is of the form 𝑛ℤ for 𝑛≥0. By (…) 𝐺 is isomorphic to ℤ/𝑛ℤ. When 𝑛=0 this is canonically isomorphic to ℤ.

By the previous Proposition ℤ/𝑛ℤ is finite for 𝑛>0 and therefore if 𝐺 is not finite we must have 𝑛=0. Similarly If 𝐺 is finite then we must have 𝑛>0. ∎

We analyse the structure of finite cyclic groups in more detail. First recall the definition of Euler’s Totient Function

Definition 3.2.22 (Euler Totient Function)

Define the function

𝜙(𝑛)=#︎{0<𝑑≤𝑛|(𝑑,𝑛)=1}
Proposition 3.2.23 (Finite Cyclic Groups)

Consider a finite cyclic group 𝐺 of order 𝑛. Then

  1. The order of 𝑔𝑟 is 𝑛𝑛,𝑟 where 0<𝑟≤𝑛.
  2. There are 𝜙(𝑛) generators
  3. For every 𝑑∣𝑛 there is a unique subgroup of order 𝑛𝑑 given by ⟨𝑔𝑑⟩, which is cyclic.
  4. For 𝑑∣𝑛 there are precisely 𝜙(𝑑) elements of order 𝑑
  5. There are precisely 𝑑 elements of order dividing 𝑑

Proof. We prove each in turn

  1. (𝑔𝑟)𝑠=𝑒𝐺⟺𝑔𝑟𝑠=𝑒𝐺⟺(3.2.14)𝑛∣𝑟𝑠⟺(2.2.13)𝑛𝑛,𝑟∣𝑠. Therefore 𝑔𝑟 has order 𝑛𝑛,𝑟 as required.
  2. Note ℎ is a generator iff 𝑜(ℎ)=𝑛. So 𝑔𝑟 is a generator iff (𝑛,𝑟)=1 by the previous step. As 𝐺={𝑔,𝑔2,…,𝑔𝑛} the result follows by definition of the totient function.
  3. Recall there is a canonical surjective morphism 𝜋:ℤ→𝐺 with kernel 𝑛ℤ and 𝜋(1)=𝑔. By (3.2.17) the subgroups 𝐻 of 𝐺 correspond bijectively to subgroups 𝐻′ of ℤ containing 𝑛ℤ, preserving the index. By (3.2.20) these are of the form 𝐻′=𝑑ℤ for 𝑑∣𝑛, which correspond under 𝜋 to subgroups 𝐻=⟨𝑔𝑑⟩. Further [𝐺:⟨𝑔𝑑⟩]=[ℤ:𝑑ℤ]=𝑑 whence #︎⟨𝑔𝑑⟩=𝑛𝑑. By definition ⟨𝑔𝑑⟩ is cyclic.
  4. Let 𝐺[𝑑] be the unique (cyclic) subgroup of order 𝑑. If ℎ has order 𝑑 then ⟨ℎ⟩ has order 𝑑, and therefore by uniqueness is equal to 𝐺[𝑑]. In particular ℎ∈𝐺[𝑑]. Therefore by the previous part there are 𝜙(𝑑) elements of order 𝑑
  5. Suppose ℎ has order 𝑒∣𝑑. Both 𝐺 and 𝐺[𝑑] contain a unique subgroup of order 𝑒 and therefore by uniqueness this is simply 𝐺[𝑒]⊆𝐺[𝑑]. Similarly by uniqueness 𝐺[𝑒]=⟨ℎ⟩. Therefore ℎ∈𝐺[𝑑]. Conversely suppose ℎ∈𝐺[𝑑] then 𝑜(𝑔)∣𝑑 by (3.2.14). Therefore 𝐺[𝑑] consists of all the elements of order dividing 𝑑.

 ∎

Corollary 3.2.24

Let 𝑛 be a positive integer then

𝑛=∑𝑑∣𝑛𝜙(𝑑)
Proof. Consider a cyclic group 𝐺 of order 𝑛. Every element has order dividing 𝑛 so the result follows from the previous Proposition by partitioning the group 𝐺 into subsets consisting of elements of equal order. ∎

For an abelian group 𝐺 define the following subgroup

𝐺[𝑑]≔{𝑔∈𝐺|𝑔𝑑=𝑒}.

We have shown for a cyclic group that #︎𝐺[𝑑]=𝑑 whenever 𝑑∣𝑛 and it is empty otherwise. We claim that this can be used to characterize cyclic groups. NB the following is adapted from this stackexchange answer

Proposition 3.2.25 (Characterization of cyclic group)
Let 𝐺 be a finite abelian group such that #︎𝐺[𝑑]≤𝑑 for all 𝑑∣𝑛. Then 𝐺 is cyclic.

Proof. Let 𝑛=#︎𝐺 and 𝐺𝑑 be the subset of elements of order exactly 𝑑. Then we wish to show that 𝐺𝑛 is non-empty as any element of this set will be a generator. We actually show that #︎𝐺𝑑=𝜙(𝑑)>0 whenever 𝑑∣𝑛.

Note that 𝐺𝑑⊆𝐺[𝑑]. If it’s non-empty then for any 𝑦∈𝐺𝑑, we have ⟨𝑦⟩ is a subgroup of 𝐺[𝑑] of order 𝑑. As #︎𝐺[𝑑]≤𝑑 we have 𝐺[𝑑]=⟨𝑦⟩ is cyclic of order 𝑑. In other words 𝐺𝑑 is equal to the set of generators for 𝐺[𝑑]. By the previous Proposition 𝐺[𝑑] has 𝜙(𝑑) generators. We conclude that for all 𝑑∣𝑛 we have 𝐺𝑑 is either empty or of order 𝜙(𝑑).

Therefore

𝑛=∑𝑑∣𝑛#︎𝐺𝑑≤∑𝑑∣𝑛𝜙(𝑑)=𝑛

Therefore we must have equality everywhere and #︎𝐺𝑑=𝜙(𝑑) as required. ∎
