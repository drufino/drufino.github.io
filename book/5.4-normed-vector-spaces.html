5.4 Normed Vector Spaces

Definition 5.4.1 (Valued Field)

Let 𝐾 be a field. A valuation on 𝐾 is a function

|⋅|:𝐾→ℝ≥0

such that for all 𝑥,𝑦∈𝐾 the following relations are satisfied

  1. |𝑥|=0⟺𝑥=0
  2. |𝑥𝑦|=|𝑥||𝑦|
  3. |𝑥+𝑦|≤|𝑥|+|𝑦|

We say that this valuation is non-archimedean if it satisfies the ultrametric inequality

|𝑥+𝑦|≤max(|𝑥|,|𝑦|)

for all 𝑥,𝑦∈𝐾. Otherwise it is archimedean.

We say the pair (𝐾,|⋅|) is a valued field.

Example 5.4.2
Any subfield of ℂ (and therefore ℝ) is an archimedean valued field, using the complex absolute value |⋅| (5.2.2).
Definition 5.4.3 (Normed Vector Space)

Let (𝐾,|⋅|) be a valued field and 𝑋 a 𝐾-vector space. A norm ‖⋅‖ is a function

‖⋅‖:𝑋→ℝ≥0

satisfying the following properties

  1. ‖𝑥‖=0⟺𝑥=0
  2. ‖𝜆𝑥‖=|𝜆|‖𝑥‖
  3. ‖𝑥+𝑦‖≤‖𝑥‖+‖𝑦‖

We say the pair (𝑋,‖⋅‖) is a normed vector space over the valued field (𝐾,|⋅|).

A normed vector space which is complete as a metric space is called a Banach space.

A Banach space 𝑋 which is also an associative algebra satisfying

‖𝑥⋅𝑦‖≤‖𝑥‖‖𝑦‖

is a Banach Algebra. Note a valued field is naturally a Banach Algebra.

Example 5.4.4

A valued field (e.g. ℂ, ℝ, ℚ) is a normed vector space over itself.

ℂ is a normed vector space over ℝ.

For any valued field 𝐾 the vector space 𝐾𝑛 is a normed vector space with the following definition of norm

‖𝑣‖≔𝑣12+⋯+𝑣𝑛2

(the triangle inequality requires proof).

Proposition 5.4.5

Let (𝑋,‖⋅‖) a normed vector space. Then it is naturally a metric space with induced metric

𝑑(𝑥,𝑦)≔‖𝑥−𝑦‖

and in particular a Hausdorff topological space with base the open balls

𝐵(𝑥;𝜀)≔{𝑦∈𝑋|‖𝑦−𝑥‖<𝜀}

Furthermore the open balls 𝐵(𝑥;𝜀) and 𝐵(𝑥;1𝑛) form a local base at 𝑥.

The same statement applies to valued fields and in particular ℝ.
