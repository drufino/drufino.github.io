3.19.13 Normal Extensions II

We provide some more straightforward criteria based on [𝐾:𝑘]𝑠

Proposition 3.19.106 (Normal Criteria II)

Let 𝐿/𝐾/𝑘 be a tower of algebraic extensions such that 𝐿/𝑘 is normal (e.g. 𝐿=𝑘―). Then 𝐾/𝑘 is normal if and only if the embedding

Mor𝑘(𝐾,𝑖𝐾𝐿):Aut(𝐾/𝑘)→Mor𝑘(𝐾,𝐿)

is a bijection. In particular if 𝐾/𝑘 is finite, then it is normal if and only if

#︎Aut(𝐾/𝑘)=[𝐾:𝑘]𝑠

Proof. Suppose 𝐾/𝑘 is normal and consider 𝜎∈Mor𝑘(𝐾,𝐿). Then by NOR1 𝜎(𝐾)=𝑖𝐾𝐿(𝐾) and we may define 𝜏≔𝑖𝐾𝐿−1∘𝜎 with 𝜏∈Aut(𝐾/𝑘). The converse is similar.

For the final part we’ve already observed (3.19.104) that in the finite case #︎Aut(𝐾/𝑘)≤[𝐾:𝑘]𝑠=#︎Mor𝑘(𝐾,𝐿)≤[𝐾:𝑘]<∞. Therefore the embedding Mor𝑘(𝐾,𝑖𝐾𝐿) is a bijection precisely when the orders are the same. ∎

Corollary 3.19.107 (Galois Criteria)

Let 𝐾/𝑘 be a finite extension. Then

#︎Aut(𝐾/𝑘)≤[𝐾:𝑘]𝑠≤[𝐾:𝑘]

with equalities if and only if 𝐾/𝑘 is Galois.

Proof. We’ve seen the inequalities (3.19.104)

#︎Aut(𝐾/𝑘)≤[𝐾:𝑘]𝑠≤[𝐾:𝑘]<∞

with equality if and only if 𝐾/𝑘 is both normal (3.19.106) and separable (3.19.78) ∎
