3.3.4 Quotient Rings

Proposition 3.3.55 (Quotient Ring)

Let (𝐴,+,⋅) be a ring and 𝔞 an ideal. As 𝔞 is an additive subgroup we may consider the quotient group (𝐴/𝔞,+). For an element 𝑎∈𝐴 write 𝑎+𝔞 for the coset [𝑎]𝔞∈𝐴/𝔞. There is a well-defined multiplicative law of composition

⋅:𝐴/𝔞×𝐴/𝔞→𝐴/𝔞(𝑎+𝔞)⋅(𝑏+𝔞)→(𝑎⋅𝑏+𝔞)

which makes (𝐴/𝔞,+,⋅) into a ring. Further there is a canonical surjective ring homomorphism

𝜋:𝐴→𝐴/𝔞

with the following properties

  • ker(𝜋)=𝔞

  • Every morphism 𝜑:𝐴→𝐵 such that 𝔞⊆ker(𝜑), factors uniquely through 𝜋.

  • ker(𝜑̃)=ker(𝜑)/𝔞
  • 𝜑̃ is injective if and only if ker(𝜑)=𝔞
  • 𝜑̃ is surjective if and only if 𝜑 is surjective

For an ideal 𝔟⊇𝔞 define the corresponding quotient ideal

𝔟/𝔞≔{𝑏+𝔞|𝑏∈𝔟}=𝜋(𝔟)

This induces a bijective, order-preserving correspondence of ideals

{𝔟′◃𝐴/𝔞}⇌𝜋(−)𝜋−1(−){𝔟◃𝐴|𝔞⊆𝔟}

under which maximal (resp. prime, radical) ideals of 𝐴 containing 𝔞 correspond to maximal (resp. prime, radical) ideals of 𝐴/𝔞.

Let 𝜑:𝐴→𝐵 be a ring homomorphism. Then this induces a canonical isomorphism

Proposition 3.3.58 (Criteria for Maximal, Prime and Reduced)

Let 𝔞◃𝐴 then 𝔞 is

  • maximal if and only if 𝐴/𝔞 is a field
  • prime if and only if 𝐴/𝔞 is an integral domain
  • radical if and only if 𝐴/𝔞 is reduced

Proof. Suppose 𝔞 is maximal then it is by definition proper so 𝐴/𝔞 is not the zero-ring. By (3.3.55) then 𝐴/𝔞 has no proper non-zero ideals and so by (3.3.16) is a field.

Conversely if 𝐴/𝔞 is a field it is by definition not the zero ring, and so by (3.3.55) 𝔞 is proper. Furthermore by the same result 𝔞 is maximal.

Suppose 𝔞 is prime and 𝑥―⋅𝑦―=0. Then by definition 𝑥⋅𝑦―=0⟹𝑥⋅𝑦∈𝔞⟹𝑥∈𝔞 or 𝑦∈𝔞⟹𝑥―=0 or 𝑦―=0. This shows that 𝐴/𝔞 is an integral domain. The converse is similar. ∎

Let 𝔞◃𝐴 be a proper ideal, then the following implications hold

Proof. This follows by combining (3.3.10) and (3.3.58). ∎
Corollary 3.3.60 (Field Morphisms are injective)
Let 𝜑:𝑘→𝐵 be a homomorphism from a field to a non-zero ring. Then 𝜑 is injective.
Proof. ker(𝜑) is an ideal. As 𝜑(1𝑘)=1𝐵 and 0𝐵≠1𝐵 then ker(𝜑)≠𝑘. Since the only ideals are (0) and 𝑘 we see ker(𝜑)={0} and 𝜑 is injective. ∎
