3.3.1 Commutative Rings

Definition 3.3.1 (Ring)

A ring consists of a triple (𝐴, +, ⋅) where 𝐴 is a set and + and ⋅ are laws of composition (“additive” and “multiplicative” respectively) such that the following holds

  • (𝐴,+) is an abelian group, whose identity element we refer to as 0𝐴.
  • (𝐴,⋅) is a monoid, whose identity element we refer to as 1𝐴

  • + and ⋅ satisfy the distributive property, that is for all 𝑥,𝑦,𝑧∈𝐴

    𝑥⋅(𝑦+𝑧)=𝑥⋅𝑦+𝑥⋅𝑧(𝑥+𝑦)⋅𝑧=𝑥⋅𝑧+𝑦⋅𝑧

For 𝑥∈𝐴 we write the additive inverse as −𝑥, and abbreviate multiplication 𝑥⋅𝑦≕𝑥𝑦.

We say that 𝐴 is a zero-ring (or trivial) if 0𝐴=1𝐴⟺𝐴={0}.

𝐴 is commutative if in addition 𝑥𝑦=𝑦𝑥 i.e. (𝐴,⋅) is abelian.

Example 3.3.2
The set of integers ℤ (see the Integers subsection) is the canonical example of a ring with operations of addition and multiplication.
Definition 3.3.3 (Subring)

A subring of a ring 𝐴 is a subset 𝐵 such that

  • 0𝐴,1𝐴∈𝐵
  • 𝑥∈𝐵⟹−𝑥∈𝐵
  • 𝑥,𝑦∈𝐵⟹𝑥+𝑦∈𝐵
  • 𝑥,𝑦∈𝐵⟹𝑥⋅𝑦∈𝐵

Then (𝐵,+|𝐵×𝐵,⋅|𝐵×𝐵) is a ring.

Definition 3.3.4 (Multiplicative set)

A subset 𝑆⊂𝐴 is said to be multiplicative if

  • 1∈𝑆
  • 𝑥,𝑦∈𝑆⟹𝑥𝑦∈𝑆

Further it is said to be saturated if in addition

𝑥,𝑦∈𝑆⟺𝑥𝑦∈𝑆
Definition 3.3.5 (Integral Domain)

A commutative ring 𝐴 is said to be an integral domain if it is not a zero-ring and it is cancellative, that is

𝑎𝑏=𝑎𝑐,𝑎≠0⟹𝑏=𝑐.
Definition 3.3.6 (Reduced)

A commutative ring 𝐴 is said to be reduced if for all 𝑎∈𝐴

𝑎𝑛=0⟹𝑎=0
Definition 3.3.7 (Unit / Group of Units)

An element 0≠𝑎 of a ring 𝐴 is called a unit if it has a two-sided multiplicative inverse.

For 𝐴 not a zero-ring, the set of units 𝐴⋆ forms a group under multiplication, called the group of units.

Definition 3.3.8 (Field)
A field 𝐾 is a commutative non-zero ring such that every non-zero element is a unit, so that 𝐾⋆ is a group under multiplication and 𝐾⋆=𝐾∖{0}.
Proposition 3.3.9
Every subring of a field 𝐾 is an integral domain.
Proof. Suppose 𝐴⊂𝐾 is a subring. Suppose that 𝑎,𝑏∈𝐴 such that 𝑎𝑏=0. Suppose 𝑎≠0 then 𝑎−1𝑎𝑏=0⟹𝑏=0. ∎

Definition 3.3.11 (Ring homomorphism)

A ring homomorphism 𝜑:𝐴→𝐵 is a mapping which is both a multiplicative (monoid) and additive (group) homomorphism

  • 𝜑(0𝐴)=0𝐵
  • 𝜑(1𝐵)=1𝐵
  • 𝜑(𝑥+𝑦)=𝜑(𝑥)+𝜑(𝑦)
  • 𝜑(𝑥𝑦)=𝜑(𝑥)𝜑(𝑦)

The kernel of 𝜑 is defined to be

ker(𝜑)={𝑎|𝜑(𝑎)=0𝐵}
Definition 3.3.12 (Ideal)

A (two-sided) ideal 𝔞 of a ring 𝐴 is a subset of 𝐴 which is an additive subgroup and closed under multiplication by 𝐴 :

  • 0𝐴∈𝔞
  • 𝑥,𝑦∈𝔞⟹𝑥+𝑦∈𝔞
  • 𝑥∈𝔞⟹−𝑥∈𝔞
  • 𝑥∈𝔞,𝑎∈𝐴⟹𝑎𝑥,𝑥𝑎∈𝔞

𝔞 is said to be proper if 𝔞≠𝐴.

Lemma 3.3.13 (Proper ideal)

An ideal 𝔞 is proper if and only if 1∉𝔞 if and only if 𝔞∩𝐴⋆=∅.

Alternatively 𝔞=𝐴 if and only if 1∈𝔞 if and only if 𝔞∩𝐴⋆≠∅.

Proposition 3.3.14

Let 𝜑:𝐴→𝐵 be a ring homomorphism, then

  1. The kernel ker(𝜑) is a two-sided ideal of 𝐴
  2. The image 𝜑(𝐴) is a subring of 𝐵
  3. 𝜑 is injective if and only if ker(𝜑)={0}
Proposition 3.3.15 (Krull's Theorem)

Let 𝐴 be a ring and 𝔞 a proper ideal. Then it is contained in a proper maximal ideal 𝔪.

In particular any non-unit 𝑎∉𝐴⋆ is contained in a maximal ideal.

Proposition 3.3.16 (Criteria to be a Field)

Let 𝐴 be a ring. Then the following are equivalent

  1. 𝐴 is a field
  2. 𝐴 is not the zero-ring and the only proper ideal is {0}.

Proof. a) ⟹ b). By definition 𝐴 is not the zero-ring. Let 𝔞 be a proper ideal. By (3.3.13) 𝔞∩𝐴⋆=∅⟹𝔞={0} as required.

b) ⟹ a). Suppose 0≠𝑎∈𝐴 then the ideal 𝐴𝑎=(𝑎) is either {0} or 𝐴. However 𝑎=1⋅𝑎∈(𝑎) which implies (𝑎)≠{0} and therefore (𝑎)=𝐴. In particular there exists 𝑎−1∈𝐴 such that 𝑎−1𝑎=1𝐴 and 𝑎 is invertible. ∎
