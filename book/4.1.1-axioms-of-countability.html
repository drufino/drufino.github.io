4.1.1 Axioms of Countability

Definition 4.1.13 (Neighbourhood)

Let 𝑋 be a topological space and 𝑥∈𝑋. We say a set 𝑉⊂𝑋 is a neighbourhood of 𝑥 if 𝑥∈𝑈⊂𝑉 for some open set 𝑈. We write 𝒰︀𝑥 for the neighbourhoods of 𝑥, and 𝒪︀𝑥 for the open neighbourhoods of 𝑥.

We say that a collection of neighbourhoods ℬ︀𝑥 is a local base for 𝑥 if every neighbourhood 𝑈∈𝒰︀𝑥 contains some neighbourhood 𝑉∈ℬ︀𝑥. For example 𝒪︀𝑥 is a local base.

Definition 4.1.14 (First-Countable)
Let 𝑋 be a topological space. 𝑋 is first countable if every point 𝑥∈𝑋 has a countable local base.
Definition 4.1.15 (Second-Countable)
Let 𝑋 be a topological space. 𝑋 is second countable if there exists a countable basis. Evidently this is stronger than first countability.
Example 4.1.16

For example a metric space is always first countable as we may consider balls of radius 1𝑛.

Further ℝ is second countable as we may consider open intervals with rational endpoints.
