3.1 Magmas and Monoids

Definition 3.1.1 (Magma)

Let 𝑋 be a set. A law of composition on 𝑋×𝑋 is a function

⋅:𝑋×𝑋→𝑋

and we typically write the composition of 𝑥,𝑦∈𝑋 as either

𝑥⋅𝑦

or 𝑥𝑦, or 𝑥+𝑦 in the commutative case.

A pair (𝑋,⋅) consisting of a set 𝑋 and law of composition on 𝑋 is called a magma.

Definition 3.1.2 (Magma/Monoid)

A magma (𝑋,⋅) is said to be

  • associative if (𝑥⋅𝑦)⋅𝑧=𝑥⋅(𝑦⋅𝑧)
  • commutative if 𝑥⋅𝑦=𝑦⋅𝑥 for all 𝑥,𝑦∈𝑋
  • unital if there exists 𝑒∈𝑋 such that 𝑒⋅𝑥=𝑥⋅𝑒=𝑥 for all 𝑥∈𝑋. Such an 𝑒 is called an identity.
  • a monoid if it is both associative and unital
Proposition 3.1.3 (Identity is Unique)

A magma (𝑋,⋅) has at most one element 𝑒 such that

𝑥⋅𝑒=𝑒⋅𝑥=𝑥

for all 𝑥∈𝑋.

Definition 3.1.4 (Invertible / Monoid)

Let (𝑋,⋅) be a unital magma. An element 𝑥∈𝑋 is invertible if there exists 𝑦∈𝑋 such that

𝑥⋅𝑦=𝑦⋅𝑥=𝑒
Proposition 3.1.5 (Inverses are unique)
Let (𝑋,⋅) be a monoid. If 𝑥∈𝑋 is invertible then its inverse is unique and denoted 𝑥−1.

Proof. Suppose that 𝑥𝑦=𝑥𝑦′=𝑒=𝑦𝑥=𝑦′𝑥. Then

𝑥𝑦=𝑒⟹𝑦′(𝑥𝑦)=𝑦′𝑒=𝑦′⟹(𝑦′𝑥)𝑦=𝑦′⟹𝑦=𝑦′

 ∎

Definition 3.1.6 (Homomorphism)

Let (𝑋,⋅), (𝑌,⋅) be magmas. Then a function 𝜑:𝑋→𝑌 is said to be a magma homomorphism if it satisfies

𝜑(𝑥1⋅𝑥2)=𝜑(𝑥1)⋅𝜑(𝑥2)∀𝑥1,𝑥2∈𝑋

If (𝑋,⋅) and (𝑌,⋅) are unital then 𝜑 is unital if

𝜑(𝑒𝑋)=𝑒𝑌

If (𝑋,⋅) and (𝑌,⋅) are monoids then 𝜑 is a monoid morphism if it satisfies both these conditions.

Proposition 3.1.7 (ℕ is an initial object)

Let (𝑋,⋅) be a monoid and 𝑥∈𝑋. Then there is a unique monoid morphism

𝑥(−):(ℕ,+)→(𝑋,⋅)

such that

𝑥1=𝑥

Furthermore if 𝜑:(𝑋,⋅)→(𝑌,⋅) is a monoid morphism then

𝜑(𝑥𝑛)=𝜑(𝑥)𝑛

for all 𝑥∈𝑋 and 𝑥∈ℕ.

Proposition 3.1.8 (ℤ is an initial object)

Let (𝑋,⋅) be a monoid and 𝑥∈𝑋 be an invertible element. Then there is a unique monoid morphism

𝑥(−):(ℤ,+)→(𝑋,⋅)

such that

𝑥1=𝑥

and

Furthermore if 𝜑:(𝑋,⋅)→(𝑌,⋅) is monoid morphism then

𝜑(𝑥𝑛)=𝜑(𝑥)𝑛

for all 𝑥∈𝑋 invertible and 𝑛∈ℤ.
