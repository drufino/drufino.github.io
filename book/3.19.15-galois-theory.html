3.19.15 Galois Theory

We’ve seen that for 𝐾/𝑘 a finite extension

#︎Aut(𝐾/𝑘)≤[𝐾:𝑘]𝑠≤[𝐾:𝑘]

with equality if and only if 𝐾/𝑘 is Galois, by (3.19.107).

Remark 3.19.114
If 𝑘 is perfect then 𝑘―/𝑘 is Galois.

The main result of Galois Theory is

Proposition 3.19.115

Let 𝐾/𝑘 be a finite Galois extension then there is an order-reversing bijection between subgroups and subfields

{𝐻≤Gal(𝐾/𝑘)}⟷{𝐹/𝑘⊆𝐾/𝑘}𝐻⟶𝐾𝐻≔{𝑥∈𝐾|ℎ(𝑥)=𝑥∀ℎ∈𝐻}Gal(𝐾/𝐹)⟵𝐹
Proof. This is proved in a series of Propositions in the rest of this section. Firstly we show it is well-defined in (3.19.116). The maps are mutual inverses by (3.19.117) and (3.19.118). ∎

Such an order reversing map is usually called an (antitone) Galois connection, as the first such type arose from Galois Theory. Note it is well-defined because of the following proposition.

Proposition 3.19.116
If 𝐾/𝑘 is Galois and 𝐹⊂𝐾/𝑘 then 𝐾/𝐹 is Galois.
Proof. This follows from (3.19.65) and (3.19.79). ∎
Proposition 3.19.117 (Fixed field of Galois group)

If 𝐾/𝑘 is Galois and 𝐹⊂𝐾/𝑘 a subfield then

𝐾Gal(𝐾/𝐹)=𝐹
Proof. Clearly 𝐹⊆𝐾Gal(𝐾/𝐹). Conversely given 𝛼∈𝐾∖𝐹, then deg(𝑚𝛼,𝐹)>1. Since 𝛼 is separable it must have another root 𝛽∈𝐾. By (3.19.66) there is an element 𝜎∈Gal(𝐾/𝐹) such that 𝜎(𝛼)=𝛽. In other words 𝛼∉𝐾Gal(𝐾/𝐹), which shows the reverse inclusion. ∎
Proposition 3.19.118

Let 𝐾/𝑘 be a field extension and 𝐻⊆Aut(𝐾/𝑘) a finite subgroup then 𝐾/𝐾𝐻 is a finite Galois extension with

Gal(𝐾/𝐾𝐻)=𝐻

and order equal to [𝐾:𝐾𝐻]. When 𝐾/𝑘 is finite then 𝐻 is automatically finite.

Proof. Firstly observe that trivially 𝐻⊆Aut(𝐾/𝐾𝐻). If we know that [𝐾:𝐾𝐻]<∞, then by (3.19.107) we have

#︎𝐻≤#︎Aut(𝐾/𝐾𝐻)≤[𝐾:𝐾𝐻]𝑠≤[𝐾:𝐾𝐻]

We can prove equality everywhere if we show that [𝐾:𝐾𝐻]≤#︎𝐻, which is shown either by (3.19.119) or (3.19.120). Note equality also shows that 𝐾/𝐾𝐻 is finite Galois by the same result.

Finally when 𝐾/𝑘 is finite, then #︎Aut(𝐾/𝑘)<∞. So in this case 𝐻 is always finite. ∎

We present two approaches to showing the inequality [𝐾:𝐾𝐻]≤#︎𝐻. The first uses independence of characters style argument, and the second which is more straightforward uses the action of 𝐻 to show that every element has degree at most #︎𝐻 (Artin).

Lemma 3.19.119 (Bound degree of fixed field I)

Let 𝐾/𝑘 be a field extension and 𝐻⊂Aut(𝐾/𝑘) a finite subgroup. Then

[𝐾:𝐾𝐻]≤#︎𝐻

Proof. Let 𝐻={𝜎1,…,𝜎𝑛} with 𝜎1=id and {𝛼1,…,𝛼𝑚} a 𝐾𝐻-linearly independent subset of 𝐾.

Consider the vector space 𝐾𝑛 and the elements 𝛼̂𝑗=(𝜎1(𝛼𝑗),…,𝜎𝑛(𝛼𝑗)) for 𝑗=1…𝑚. It’s enough to show that these are linearly independent over 𝐾, as that implies 𝑚≤𝑛 by (3.3.125). Therefore 𝐾/𝐾𝐻 is finite dimensional with dimension at most 𝑛=#︎𝐻.

Let 𝑆(𝐾)≔{𝑣∈𝐾𝑚|∑𝑗=1𝑚𝑣𝑗𝛼̂𝑗=0}, we aim to show that 𝑆(𝐾)={0}. If we also consider 𝑆(𝐾𝐻), any non-zero elements will be a 𝐾𝐻 linear-dependence for 𝛼1,…,𝛼𝑚 by considering the first component (𝜎1=id). Therefore by linear independence of 𝛼𝑖 we see 𝑆(𝐾𝐻)={0}. So it’s enough to show that 𝑆(𝐾)≠{0}⟹𝑆(𝐾𝐻)≠{0}, to prove 𝑆(𝐾)={0} by contradiction.

First observe that 𝐾⋆ and 𝐻 both act on 𝑆(𝐾) component-wise. The first by multiplication and the second by application. This is well-defined because 𝑣∈𝑆(𝐾) if and only if

∑𝑗𝑣𝑗𝜎(𝛼𝑗)=0∀𝜎∈𝐻.

Apply 𝜏 to obtain

∑𝑗𝜏(𝑣𝑗)(𝜏∘𝜎)(𝛼𝑗)=0∀𝜎∈𝐻

and since multiplication by 𝜏 permutes 𝐻 we see 𝜏(𝑣)∈𝑆(𝐾) as required.

If there exists 0≠𝑣∈𝑆(𝐾), consider 𝑣 with a minimal number of non-zero components. By scaling we can assume 𝜆𝑣 has at least one component in 𝐾𝐻. The vector 𝜏(𝜆𝑣)−𝜆𝑣 then has at least one fewer non-zero components, so by minimality must be zero. Since 𝜏 was arbitrary we see 0≠𝜆𝑣∈𝑆(𝐾𝐻) as required. ∎

Lemma 3.19.120 (Bound degree of fixed field II)
Let 𝐾/𝑘 be a field extension and 𝐻 a finite subgroup of Aut(𝐾/𝑘). Then 𝐾/𝐾𝐻 is finite separable, and simple, with [𝐾:𝐾𝐻]≤#︎𝐻

Proof. We show that 𝐾/𝐾𝐻 is separable and every element has degree at most #︎𝐻. For any 𝛼∈𝐾, consider the orbit 𝛼𝐻={𝜎(𝛼)|𝜎∈𝐻}, which is of order at most #︎𝐻. Then the polynomial

𝑓(𝑋)=∏𝛽∈𝛼𝐻(𝑋−𝛽)

has 𝛼 as a root and is separable by (3.19.11). Furthermore 𝑓𝜏=𝑓 because 𝜏 permutes 𝛼𝐻 (it’s injective and hence bijective). Therefore 𝑓∈𝐾𝐻[𝑋] and 𝑚𝛼,𝐾𝐻∣𝑓. We see that 𝛼 has degree at most #︎𝐻 and is separable by (3.17.40).

If 𝐾/𝑘 is finite, then a-fortiori 𝐾/𝐾𝐻 is finite, so we may apply the Primitive Element Theorem (3.19.105) directly to show the result.

More generally let 𝐾𝐻(𝛼) be a simple subfield of 𝐾 of maximal degree. This exists because the degree of 𝛼 is bounded above by #︎𝐻. We claim 𝐾𝐻(𝛼)=𝐾, for if not then 𝐾𝐻⊆𝐾𝐻(𝛼)⊊𝐾𝐻(𝛼,𝛽) is a finite separable extension of 𝐾𝐻, whence it must be simple by the Primitive Element Theorem (3.19.105), contradicting maximality. Finally the degree of [𝐾:𝐾𝐻] is the degree of 𝛼, which we’ve seen is bounded above by #︎𝐻. ∎

Now we may demonstrate straightforward criteria for subfield to be normal

Proposition 3.19.121

Let 𝐾/𝑘 be a finite Galois extension and 𝑘⊂𝐹⊂𝐾 a subfield.

Then 𝐹/𝑘 is Galois if and only if Gal(𝐾/𝐹)⊲Gal(𝐾/𝑘) is normal. In this case we have a canonical isomorphism

Gal(𝐾/𝑘)/Gal(𝐾/𝐹)→Gal(𝐹/𝑘)

Proof. Recall from (3.19.67) we have 𝐹/𝑘 is normal iff 𝜎(𝐹)=𝐹 for all 𝜎∈Gal(𝐾/𝑘). Recall 𝐾/𝐹 is normal for all subfields 𝐹. Furthermore, we observe that

Gal(𝐾/𝜎(𝐹))=𝜎Gal(𝐾/𝐹)𝜎−1

By the correspondence (3.19.115) Gal(𝐾/𝐹)=Gal(𝐾/𝐹′)⟺𝐹=𝐹′. Therefore

𝐹/𝑘normal⟺𝜎(𝐹)=𝐹∀𝜎∈Gal(𝐾/𝑘)⟺Gal(𝐾/𝜎(𝐹))=Gal(𝐾/𝐹)∀𝜎∈Gal(𝐾/𝑘)⟺𝜎Gal(𝐾/𝐹)𝜎−1=Gal(𝐾/𝐹)∀𝜎∈Gal(𝐾/𝑘)⟺Gal(𝐾/𝐹)⊲Gal(𝐾/𝑘)

The result then follows from (3.19.71). ∎
