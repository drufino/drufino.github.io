2.5 Krull Dimension

The purpose of this section is to abstract the notions of Krull Dimension in commutative ring theory and topology. A more standard approach (eg EGA IV) would be to develop the topological notion first, and then link to commutative ring case using the prime spectrum. Generally the concept is not well-behaved, so stronger conditions are defined which generally hold in geometric cases. Principle references are (EGA0 IV 14.3, Heinrich).

Definition 2.5.1 (Finite-Dimensional Poset)

Let (𝒢︀,≤) be a poset, we say that it is finite-dimensional if

dim(𝒢︀)≔sup{ℓ(𝐶)|𝐶⊆𝒢︀a chain}<∞

In this case we define

dim(𝑥)≔dim({𝑥}↓)codim(𝑦)≔dim({𝑦}↑)codim(𝑦,𝑥)≔dim({𝑥}↓∩{𝑦}↑)

Note 𝒢︀ is both Noetherian and Artinian, but finite-dimensionality is a stronger condition. Note also that {𝑥}↓,{𝑦}↑ and {𝑥}↓∩{𝑦}↑ are finite-dimensional posets

Definition 2.5.2 (Krull Lattice)

Let (ℱ︀,≤) be an Artinian distributive lattice. We say it is a Krull Lattice if the poset of join-prime elements 𝒥︀(ℱ︀) is finite-dimensional and define

dim(ℱ︀)≔dim(𝒥︀(ℱ︀))

By (2.4.3) we have ℋ︀={𝑥}↓,{𝑦}↑,{𝑥}↓∩{𝑦}↑ are Krull Lattices such that

𝒥︀(ℋ︀)=𝒥︀(ℱ︀)∩ℋ︀

For 𝑥,𝑦∈ℱ︀ we have a unique decomposition into maximal join-prime elements 𝑥𝑖,𝑦𝑗∈𝒥︀(ℱ︀) (2.4.7)

𝑥=𝑥1∨…∨𝑥𝑛𝑦=𝑦1∨…∨𝑦𝑚

Note that 𝑦≤𝑥⟺ for all 𝑗 we have 𝑦𝑗≤𝑥𝑖 for some 𝑖 and we may define

dim(𝑥)≔max𝑖dim(𝑥𝑖)=dim({𝑥}↓)codim(𝑦)≔min𝑗codim(𝑦𝑗)codim(𝑦,𝑥)≔min𝑗max𝑖{codim(𝑦𝑗,𝑥𝑖)|𝑦𝑗≤𝑥𝑖}=min𝑗codim(𝑦𝑗,𝑥)

note it’s required to be careful in definition of co-dimension in order to have a sensible co-dimension formula. Note also that

dim(𝑦;{𝑥}↓)=dim(𝑦)
Remark 2.5.3
For the topological case, we would define ℱ︀ to be the closed subsets of 𝑋 and 𝒥︀(ℱ︀) would be the collection of irreducible closed subsets.
Proposition 2.5.4 (Extending chains)

Let (𝒢︀,≤) be a finite-dimensional poset

  • Every chain is contained in a saturated chain
  • Every chain is contained in a maximal chain

  • Every maximal chain is of the form

    𝑥0⪇𝑥1…⪇𝑥𝑛

    for 𝑥0 minimal and 𝑥𝑛 maximal in 𝒢︀.

Definition 2.5.5 (Properties)

Let 𝒢︀ be a finite-dimensional poset. Then we say it is

  • Irreducible if it has a top element
  • Equidimensional if every maximal element has the same dimension
  • Equicodimensional if every minimal element has the same codimension
  • Biequidimensional if every maximal chain has the same length
  • Quasi-Biequidimensional if {𝑥}↓ is biequidimensional for all 𝑥 (equivalently all maximal 𝑥)
  • Catenary if for every pair 𝑦≤𝑥, every saturated chain in [𝑦,𝑥]≔{𝑦}↑∩{𝑥}↓ has the same length, namely codim(𝑦,𝑥).

If ℱ︀ is a Krull Lattice then we say it inherits these properties from 𝒥︀(ℱ︀). Note if ℱ︀ is irreducible then it also has (the same) top element.

Trivially irreducible implies equidimensional. Similarly biequidimensional implies both equidimensional and equicodimensional, but not conversely.

Finally quasi-biequidimensional + equidimensional ⟺ biequidimensional.

Proposition 2.5.6 (Simple Properties)

Let 𝒢︀ be a finite-dimensional poset then

  1. If 𝑥 is maximal then codim(𝑥)=0
  2. If 𝑥 is minimal then dim(𝑥)=0
  3. dim(𝒢︀)=sup{dim(𝑥)|𝑥maximal}=sup{codim(𝑥)|𝑥minimal}
  4. For all 𝑧≤𝑦≤𝑥 we have codim(𝑧,𝑦)+codim(𝑦,𝑥)≤codim(𝑧,𝑥)

If ℱ︀ is a Krull Lattice then

  1. For all 𝑦≤𝑥 we have dim(𝑦)+codim(𝑦,𝑥)≤dim(𝑥)
  2. For all 𝑦≤𝑥 we have codim(𝑦,𝑥)=0⟺𝑦𝑗=𝑥𝑖 some 𝑖,𝑗

Alternatively codim(𝑦,𝑥)>0 if and only if (𝑦𝑗≤𝑥𝑖⟹𝑦𝑗≠𝑥𝑖).

Proof. e) The case of a finite-dimensional poset is (relatively) clear. In the general case then we have

dim(𝑦𝑗)+codim(𝑦,𝑥)≤dim(𝑦𝑗)+codim(𝑦𝑗,𝑥)=max𝑖(dim(𝑦𝑗)+codim(𝑦𝑗,𝑥𝑖))≤max𝑖dim(𝑥𝑖)=dim(𝑥)

and taking max over 𝑗 yields the result.

f) The case 𝑥,𝑦∈𝒥︀(ℱ︀) is clear by (2.5.4). For the general case codim(𝑦,𝑥)=0⟺codim(𝑦𝑗,𝑥)=0 for some 𝑗⟺(𝑦𝑗≤𝑥𝑖⟹codim(𝑦𝑗,𝑥𝑖)=0)⟺𝑦𝑗=𝑥𝑖 for some 𝑖,𝑗. ∎

Corollary 2.5.7 (Codimension 1 formula)

Let ℱ︀ be a Krull Lattice with 𝑦∈ℱ︀, 𝑥∈𝒥︀(ℱ︀) and 𝑦≤𝑥. Then

dim(𝑦)=dim(𝑥)−1⟹codim(𝑦,𝑥)=1

Suppose further that ℱ︀ is irreducible then

dim(𝑦)=dim(ℱ︀)−1⟹codim(𝑦)=1

Proof. By (2.5.6) e) codim(𝑦,𝑥)≤1. If codim(𝑦,𝑥)=0 then by f) we see that 𝑦𝑗=𝑥 for some 𝑗, whence 𝑦=𝑥 which contradicts dim(𝑦)=dim(𝑥)−1. Therefore codim(𝑦,𝑥)=1 as required.

If ℱ︀ is irreducible the result follows with 𝑥=⊤. ∎

Remark 2.5.8 (Duality)

We note that the concepts of dimension (of a poset). biequidimensional and catenary are self-dual, in the sense that they are preserved when considering the dual poset (𝒢︀,≤𝑑).

Similarly the concepts of equidimensional and equicodimensional are dual to each other.

Proposition 2.5.9

Let 𝒢︀ be a finite-dimensional poset. Then the following are equivalent

  • 𝒢︀ is catenary

  • For every triplet 𝑧<𝑦<𝑥 in 𝒢︀ we have

    codim(𝑧,𝑥)=codim(𝑧,𝑦)+codim(𝑦,𝑥)

When 𝒢︀ is irreducible this is equivalent to

codim(𝑧)=codim(𝑧,𝑦)+codim(𝑦)

for all 𝑧<𝑦.

Proof. Suppose 𝒢︀ is catenary. Choose saturated chains 𝐶1 in [𝑧,𝑦] and 𝐶2 in [𝑦,𝑥]. One may show that 𝐶1∩𝐶2={𝑦} and 𝐶1∪𝐶2 is a saturated chain in [𝑥,𝑧]. The result follows by definition of catenary.

Conversely, consider a saturated chain between 𝑥 and 𝑦 of length 𝑛

𝑥=𝑥0⪇𝑥1⪇…⪇𝑥𝑛=𝑦

Then clearly codim(𝑥𝑖,𝑥𝑖+1)=1 for all 𝑖=0…𝑛−1. Therefore by repeatedly applying the relation we may show that

codim(𝑥,𝑦)=𝑛

and therefore every saturated chain between 𝑥 and 𝑦 has the same length.

When 𝒢︀ is irreducible we may deduce the second formula by setting 𝑥=⊤. Conversely we may see that

codim(𝑧,𝑥)=codim(𝑧)−codim(𝑥)=codim(𝑧)−codim(𝑦)+codim(𝑦)−codim(𝑥)=codim(𝑧,𝑦)+codim(𝑦,𝑥)

 ∎

Lemma 2.5.10

Let 𝒢︀ be a biequidimensional finite-dimensional poset. Then for 𝑥∈𝒢︀ we have

  1. {𝑥}↓ and {𝑥}↑ are biequidimensional
  2. dim(𝒢︀)=dim(𝑥)+codim(𝑥)
  3. If 𝑥 is maximal then dim(𝑥)=dim(𝒢︀) and in particular 𝒢︀ is equidimensional
  4. If 𝑥 is minimal then codim(𝑥)=dim(𝒢︀) and in particular 𝒢︀ is equicodimensional

In particular 𝒢︀ is quasi-biequidimensional.

Proof. Consider a fixed maximal chain 𝐶 of {𝑥}↑, necessarily containing 𝑥. Any maximal chain 𝐶′ of {𝑥}↓ also contains 𝑥 and combines with 𝐶 to yield a maximal chain of ℱ︀. Whence ℓ(𝐶′)+ℓ(𝐶)=dim(ℱ︀) and {𝑥}↓ is biequidimensional. By duality {𝑥}↑ is biequidimensional and ℓ(𝐶)=codim(𝑥) from which the formula follows.

If 𝑥 is maximal then clearly codim(𝑥)=0, and similarly if 𝑥 is minimal then dim(𝑥)=0, so the last two statements follow immediately. ∎

Proposition 2.5.11 (Equivalent Characterizations of Biequidimensionality)

Let 𝒢︀ be a finite-dimensional poset. Then the following are equivalent

  1. 𝒢︀ is quasi-biequidimensional
  2. 𝒢︀ is catenary and for every maximal 𝑥 we have {𝑥}↓ is equicodimensional
  3. 𝒢︀ satisfies dim(𝑥)=dim(𝑦)+codim(𝑦,𝑥) for 𝑦≤𝑥
  4. 𝒢︀ satisfies c) whenever codim(𝑦,𝑥)=1

Furthermore the following relationship holds

codim(𝑦)=codim(𝑦,𝑥)+codim(𝑥)𝑦≤𝑥

Proof. a) ⟹ c). By assumption {𝑥}↓ is biequidimensional. Then

dim(𝑥)=dim({𝑥}↓)=(2.5.10)dim(𝑦;{𝑥}↓)+codim(𝑦;{𝑥}↓)=dim(𝑦)+codim(𝑦,𝑥)

For c) ⟹ b). Suppose 𝑧<𝑦<𝑥 in 𝒢︀ then by the codimension formula applied twice

codim(𝑧,𝑥)=dim(𝑥)−dim(𝑧)=dim(𝑥)−dim(𝑦)+dim(𝑦)−dim(𝑧)=codim(𝑦,𝑥)+codim(𝑧,𝑦)

so by (2.5.9) 𝒢︀ is catenary. Let 𝑥 be a maximal element and 𝑧 a minimal element of {𝑥}↓, then by the codimension formula

codim(𝑧,𝑥)=dim(𝑥)−dim(𝑧)=dim(𝑥)

whence {𝑥}↓ is equicodimensional.

b) ⟹ a). Let 𝑥 be a maximal element and 𝐶 a maximal chain in {𝑥}↓ with minimum element 𝑦 then, as 𝒢︀ is catenary, we have ℓ(𝐶)=codim(𝑦,𝑥). As {𝑥}↓ is equicodimensional we have codim(𝑦,𝑥)=dim(𝑥) which shows that {𝑥}↓ is biequidimensional.

Clearly c) ⟹ d). Conversely for d) ⟹ a) consider a maximal chain in {𝑥}↓

𝑥0⪇…⪇𝑥𝑛=𝑥

Then clearly codim(𝑥𝑖,𝑥𝑖+1)=1 whence by induction ℓ(𝐶)=dim(𝑥).

The final statement follows from (2.5.9) because {𝑥}↓ is irreducible and catenary. ∎

Remark 2.5.12
This is a corrected version of EGA IV 14.3.3, as noted by Heinrich.
Corollary 2.5.13

When ℱ︀ is a quasi-biequidimensional Krull Lattice then we have the following codimension formulas for all 𝑥∈𝒥︀(ℱ︀) and 𝑦∈ℱ︀ such that 𝑦≤𝑥

dim(𝑥)=dim(𝑦)+codim(𝑦,𝑥)codim(𝑦)=codim(𝑦,𝑥)+codim(𝑥)

Furthermore if ℱ︀ is biequidimensional then for all 𝑦∈ℱ︀

dim(ℱ︀)=dim(𝑦)+codim(𝑦)

Proof. The first two relations hold when 𝑥,𝑦∈𝒥︀(ℱ︀) by (2.5.11). We may generalise this as follows.

For the first relation and fixed 𝑥∈𝒥︀(ℱ︀) we see dim(𝑦𝑗) is maximal precisely when codim(𝑦𝑗,𝑥) is minimal. Therefore it holds for all 𝑦∈ℱ︀.

Similarly for the second relation we see that codim(𝑦𝑗,𝑥) is minimal precisely when codim(𝑦𝑗) is minimal.

The final statement follows from the first relation by taking the supremum over all maximal elements 𝑥. ∎

Corollary 2.5.14

Let 𝒢︀ be an irreducible finite-dimensional poset. Then the following are equivalent

  1. 𝒢︀ is biequidimensional
  2. 𝒢︀ is quasi-biequidimensional
  3. 𝒢︀ is catenary and equicodimensional
  4. dim(𝑥)=dim(𝑦)+codim(𝑦,𝑥)∀𝑦≤𝑥
  5. 𝒢︀ satisfies d) when codim(𝑦,𝑥)=1
Proof. The equivalence follows from (2.5.11) by noting that an irreducible poset has only one maximal element and is in particular equidimensional. ∎
Proposition 2.5.15
Let ℱ︀ be a quasi-biequidimensional Krull Lattice. Then for all 𝑥∈ℱ︀ we have {𝑥}↓ is a quasi-biequidimensional Krull Lattice.
Proof. Consider 𝑦∈𝒥︀({𝑥}↓)=(2.4.3)𝒥︀(ℱ︀)∩{𝑥}↓. Then by definition {𝑦}↓ is biequidimensional, and so {𝑥}↓ is quasi-biequidimensional. ∎
