3.17 Factorisation

For this section we assume 𝐴 is a commutative integral domain.

Definition 3.17.1 (Associates)

We say two non-zero elements 𝑥 and 𝑦 are associates if 𝑥=𝑢𝑦 for some 𝑢∈𝐴⋆. We write 𝑥∼𝑦.

Note this is an equivalence relation on 𝐴∖{0}.

Lemma 3.17.2

Let 𝐴 be a ring and 𝑥,𝑦∈𝐴 non-zero elements then the following are equivalent

  • 𝑥|𝑦
  • (𝑦)⊆(𝑥)
  • 𝑦∈(𝑥)
Lemma 3.17.3

Let 𝐴 be a ring and 𝑥,𝑦∈𝐴 non-zero elements then the following are equivalent

  • 𝑥|𝑦 and 𝑦|𝑥
  • (𝑥)=(𝑦)

If 𝐴 is an integral domain this is equivalent to 𝑥∼𝑦.

Definition 3.17.4 (Irreducible element)

We say 0≠𝑥 is irreducible if it is not invertible and 𝑥=𝑎𝑏⟹𝑎 a unit or 𝑏 a unit.

Equivalently if 𝑦|𝑥 implies either 𝑦 is a unit or 𝑦∼𝑥.

Definition 3.17.5 (Prime element)
We say 0≠𝑝 is prime if 𝑝|𝑎𝑏⟹𝑝|𝑎or𝑝|𝑏.
Example 3.17.6
The units of ℤ are {−1,1} so each equivalence class is of the form {𝑛,−𝑛}.
Example 3.17.7
A number 𝑝∈ℤ is prime in the traditional sense exactly when it is irreducible. It is of course also prime in the ring-theoretic sense but this requires proof (see (2.2.13)).

The concept of associates is important to unique factorization, because we may only hope to have unique factorization upto multiplication by a unit.

Lemma 3.17.8
If 𝑥∼𝑦 are associates then 𝑥 is irreducible iff 𝑦 is
Proof. Suppose 𝑥∼𝑦 and 𝑥 irreducible. If 𝑦=𝑎𝑏 then 𝑥=𝑎𝑏𝑢⟹𝑎 a unit or 𝑏𝑢 a unit ⟹𝑏 a unit. Therefore 𝑦 is irreducible as required. ∎
Lemma 3.17.9 (Criterion for primality)
Suppose 0≠𝑝∈ℤ. Then 𝑝 is prime if and only if (𝑝) is a prime ideal

Proof. Note 𝑥|𝑦⟺𝑦∈(𝑥). So in particular if 𝑝 is prime then 𝑥𝑦∈(𝑝)⟹𝑝|𝑥𝑦⟹𝑝|𝑥or𝑝|𝑦⟹𝑥∈(𝑝)or𝑦∈(𝑝), whence (𝑝) is prime.

Conversely if (𝑝) is prime, then 𝑝|𝑥𝑦⟹𝑥𝑦∈(𝑝)⟹𝑥∈(𝑝)or𝑦∈𝑝⟹𝑝|𝑥or𝑝|𝑦, so that 𝑝 is prime. ∎

Lemma 3.17.10 (Criterion for irreducibility)
Let 𝐴 be an integral domain. Then 𝑓 is irreducible if and only if (𝑓) is maximal amongst proper principal ideals.

Proof. Suppose 𝑓 is irreducible and (𝑓)⊆(𝑔). Then 𝑓=𝑎𝑔 with either 𝑎 a unit or 𝑔 a unit. If 𝑎 is a unit then (𝑓)=(𝑔), and if 𝑔 is a unit (𝑔)=𝐴. So the result follows.

Conversely suppose 𝑓=𝑎𝑏, then 𝑓∈(𝑎)⟹(𝑓)⊆(𝑎). Then by hypothesis either (𝑎)=(𝑓) or (𝑎)=𝐴. In the second case 𝑎 is a unit. In the first case then 𝑓|𝑎⟹𝑏𝑓|𝑓⟹𝑏|1 whence 𝑏 is a unit. ∎

Proposition 3.17.11 (Primes are Irreducible)
Let 𝐴 be an integral domain then 𝑝 prime ⟹𝑝 irreducible
Proof. Suppose 𝑏|𝑝 then 𝑝=𝑎𝑏 and 𝑎|𝑝. By hypothesis 𝑝|𝑎 or 𝑝|𝑏. If 𝑝|𝑎 (resp. 𝑏) then by (3.17.3) 𝑝∼𝑎 (resp. 𝑏) as required. ∎
Definition 3.17.12 (Unique Factorisation Domain (UFD) or Factorial Ring)

We say an integral domain 𝐴 is factorial (or a UFD) if every element 0≠𝑎 may be represented as

𝑎=𝑢∏𝑖=1𝑛𝑝𝑖

for 𝑢 a unit and 𝑝𝑖 irreducible, and moreover this is unique in the sense that given another factorization

𝑎=𝑢′∏𝑖=1𝑚𝑝𝑖′

we have 𝑛=𝑚 and 𝑝𝑖∼𝑝𝜓(𝑖)′, for 𝜓 a permutation on {1,…,𝑛}.

Furthermore it may be convenient in applications to count the multiplicities

Proposition 3.17.13 (Factorisation with multiplicities)

Let 𝐴 be a UFD, then for every element 0≠𝑎∈𝐴 there is a factorization of the form

𝑎=𝑢∏𝑖=1𝑛𝑝𝑖𝑟𝑖

where 𝑟𝑖>0 and none of the 𝑝𝑖 are associate to each other. Furthermore this is essentially unique in the sense that given another such factorization we have 𝑛=𝑛′, 𝑟𝑖=𝑟𝜎(𝑖)′ and 𝑝𝑖∼𝑝𝜎(𝑖)′ for some permutation 𝜎∈𝑆𝑛.

Proof. Given a factorization into irreducible elements

𝑎=𝑢∏𝑖=1𝑛𝑝𝑖

Consider a representative set of irreducibles 𝑞1,…,𝑞𝑚 (under the equivalence relation 𝑥∼𝑦). Then we have 𝑝𝑖=𝑞𝜋(𝑖)𝑢𝑖 for some units 𝑢𝑖 and mapping 𝜋:{1,…,𝑛}→{1,…,𝑚}. Let 𝑟𝑗=#︎𝜋−1(𝑗). Then we have that the set of irreducibles {𝑝1,…,𝑝𝑛} is the disjoint union of the set of equivalence classes with representatives 𝑞𝑗. Therefore

𝑎=𝑢∏𝑗=1𝑚∏𝑝∼𝑞𝑗𝑝=𝑢∏𝑗=1𝑚∏𝑖:𝜋(𝑖)=𝑗𝑢𝑖𝑞𝑗=(𝑢∏𝑗=1𝑚∏𝑖:𝜋(𝑖)=𝑗𝑢𝑖)∏𝑗=1𝑚𝑞𝑗𝑟𝑗

as required. Suppose we have two factorizations

𝑢∏𝑖=1𝑛𝑝𝑖𝑟𝑖=𝑢′∏𝑖=1𝑚(𝑝𝑖′)𝑟𝑖′

Let 𝐼 be the indexing set of 𝑝𝑖 and 𝐽 the set of 𝑝𝑗′. By unique factorization there must be mappings 𝜎:𝐼→𝐽 such that 𝑝𝑖∼𝑝𝜎(𝑖)′, and 𝜏:𝐽→𝐼 such that 𝑝𝑗′∼𝑝𝜏(𝑗). Which means that 𝑝𝑖∼𝑝𝜏(𝜎(𝑖)) and 𝑝𝑗′∼𝑝𝜎(𝜏(𝑗))′. Since none are associate to each other we see that 𝜏 and 𝜎 are mutual inverses, whence 𝑚=𝑛 and we may regard 𝜎∈𝑆𝑛. In the unique factorization 𝑝𝑖 appears 𝑟𝑖 times and 𝑝𝜎(𝑖)′ appears 𝑟𝜎(𝑖)′ times. Since 𝑝𝑖 is associate to 𝑝𝜎(𝑖)′ it is not associate to any 𝑝𝑗′ for 𝑗≠𝜎(𝑖). Unique factorization shows that 𝑟𝑖=𝑟𝜎(𝑖)′. ∎

Definition 3.17.14

Let 𝐴 be a UFD and 𝑥∈𝐴 a non-zero, non-unit such that

𝑥∼∏𝑖=1𝑛𝑝𝑖𝑟𝑖

is an (almost) unique factorization into irreducibles. Then for 𝑝∈𝐴 an irreducible define

𝑣𝑝(𝑥)≔{𝑟𝑖𝑝∼𝑝𝑖0otherwise

If 𝑥∈𝐴 is a unit then simply define 𝑣𝑝(𝑥)=0 for all 𝑝.

Lemma 3.17.15

Let 𝐴 be a UFD then the following are equivalent

  1. 𝑥|𝑦
  2. (𝑦)⊆(𝑥)
  3. 𝑣𝑝(𝑥)≤𝑣𝑝(𝑦) for all 𝑝 irreducible

In particular 𝑥∼𝑦⟺(𝑥)=(𝑦)⟺𝑣𝑝(𝑥)=𝑣𝑝(𝑦) for all 𝑝 irreducible.

Definition 3.17.16 (Atomic Ring)
We say that 𝐴 is atomic if every element has a (not necessarily unique) decomposition into irreducible elements.
Definition 3.17.17 (Ascending Chain Condition for Principal Ideals (ACCP))

We say a ring 𝐴 satisfies ACCP if every ascending chain of principal ideals eventually stabilizes.

Note every Noetherian ring satisfies this condition.

Proposition 3.17.18

An integral domain 𝐴 satisfying ACCP is atomic.

In particular a Noetherian ring is atomic.

Proof. Suppose a ring 𝐴 is not atomic, then choose any non-unit 𝑥1∈𝐴. By repeated application (3.17.10) it’s possible to construct a strictly ascending sequence of proper principal ideals

(𝑥1)⊊(𝑥2)⊊…⊊(𝑥𝑛)⊊…

therefore 𝐴 does not satisfy ACCP. ∎

Remark 3.17.19
The converse is not in general true (…) but see (3.17.21) for a partial converse.

We show a simple criterion for a ring to be a UFD.

Definition 3.17.20
We say an integral domain 𝐴 is AP if 𝑝 irreducible ⟹𝑝 prime.

Roughly speaking, “atomic” ensures the existence of factorization and “AP” ensures the uniqueness.

Proposition 3.17.21 (Atomic + AP ⟺ UFD)

Let 𝐴 be an integral domain. The following are equivalent

  1. 𝐴 is a UFD
  2. 𝐴 is atomic and AP
  3. 𝐴 satisfies ACCP and is AP

Proof. 𝑎)⟹𝑐). Suppose 𝐴 is a UFD. If 𝑝 is an irreducible element and 𝑝|𝑎𝑏, then by uniqueness it must appear in the irreducible factorization of either 𝑎 or 𝑏. Therefore 𝑝 is prime. If we have an ascending chain of principal ideals (𝑥1)⊆(𝑥2)… then by (3.17.15) we have 𝑣𝑝(𝑥𝑖) is a decreasing sequence for all irreducible 𝑝 occuring in the factorization of 𝑥1. Furthermore max𝑝𝑣𝑝(𝑥𝑖) is a finite decreasing sequence. Choose 𝑖=𝑁 such that max𝑝𝑣(𝑥𝑖) is minimal, then all these sequences must stabilise for 𝑖≥𝑁 and therefore by (3.17.15) the chain of principal ideals also stabilises.

𝑐)⟹𝑏). This is (3.17.18).

𝑏)⟹𝑎). We require to show that factorization into irreducibles is unique up to associates. Suppose

∏𝑖=1𝑛𝑝𝑖∼∏𝑗=1𝑚𝑝𝑗′

By convention an empty product is 1 and by hypothesis all the elements are in fact prime. If 𝑛=0, then since 𝑝𝑗′ is irreducible, it is not a unit and hence 𝑚=0. Otherwise consider 𝑝1, then 𝑝1|RHS, so by definition of prime we must have 𝑝1|𝑝𝑗′ for some 𝑗. Since 𝑝𝑗′ is irreducible and 𝑝1 is not a unit, we have 𝑝1∼𝑝𝑗′. Since 𝐴 is integral we may cancel these two to obtain an equivalence of smaller degree and we may proceed by induction. ∎

Lemma 3.17.22 (PID is an AP-domain)

Let 𝐴 be a PID and 𝑎∈𝐴. Then the following are equivalent

  1. 𝑎 is prime
  2. 𝑎 is irreducible
  3. (𝑎) is maximal

Proof. 𝑎)⟹𝑏) This holds for an arbitrary integral domain (3.17.11).

𝑏)⟺𝑐) as all ideals are principal this follows from (3.17.10)

𝑐)⟹𝑎) By (3.3.60) (𝑎) is prime, whence 𝑎 is prime by (3.17.9) ∎

Proposition 3.17.23

A PID is Noetherian UFD.

Furthermore (𝑓 is irreducible ⟺𝑓 is prime), and every prime ideal is maximal.

Proof. 𝐴 is Noetherian by (3.16.2) and atomic by (3.17.18). And by (3.17.22) an irreducible element is prime. Therefore we are done by (3.17.21). ∎

If we take a suitable fixed set of irreducible elements we can obtain completely unique factorization

Definition 3.17.24

Let 𝐴 be a ring we say 𝒫︀ is a representative set of irreducible elements if

  • No two elements 𝑝,𝑞∈𝒫︀ are associate
  • Every irreducible element 𝑝∈𝐴 is associate to (precisely) one in 𝒫︀
Example 3.17.25
For ℤ the positive primes are a canonical set of irreducible elements.
Proposition 3.17.26

Let 𝐴 be a UFD and 𝐾=Frac(𝐴) then for every irreducible 𝑝∈𝐴 there is a unique map

𝑣𝑝:𝐾⋆→ℤ

such that

  • 𝑢∈𝐴⋆⟹𝑣𝑝(𝑢)=0
  • 𝑣𝑝(𝑥𝑦)=𝑣𝑝(𝑥)+𝑣𝑝(𝑦)
  • 𝑣𝑝(𝑝)=1

Furthermore let 𝒫︀ be a set of irreducible representatives then we have a group isomorphism

𝐾⋆/𝐴⋆⟶∼⨁𝑝∈𝒫︀ℤ𝑥⟶(𝑣𝑝(𝑥))𝑝∈𝒫︀∏𝑝∈𝒫︀𝑝𝑛𝑝⟵(𝑛𝑝)𝑝∈𝒫︀

Finally 𝑥∈𝐴⟺𝑣𝑝(𝑥)≥0 for all 𝑝∈𝒫︀.

Proof. By (3.17.13) there is a well-defined map 𝑣𝑝:𝐴∖{0}→ℤ satisfying the given properties. We claim that

𝑣𝑝:𝐾⋆→ℤ𝑥𝑦−1→𝑣𝑝(𝑥)−𝑣𝑝(𝑦)

is well-defined. For suppose 𝑥𝑦−1=𝑤𝑧−1 then 𝑧𝑥=𝑤𝑦 whence 𝑣𝑝(𝑧)+𝑣𝑝(𝑥)=𝑣(𝑤)+𝑣(𝑦) and therefore 𝑣𝑝(𝑥𝑦−1)=𝑣𝑝(𝑤𝑧−1).

It’s clear the multiplicative property also holds and so 𝜙 is well-defined (since by definition 𝐴⋆ is in the kernel of 𝑣𝑝). Denote by 𝜙,𝜓 the proposed maps. By definition of unique factorization 𝜙 and 𝜓 are mutual inverses when restricted as follows

(𝐴∖{0})/𝐴⋆⟷⨁𝑝∈𝒫︀ℤ≥0

We also observe that 𝜙(𝑥−1)=−𝜙(𝑥) and 𝜓(−𝑛)=𝜓(𝑛)−1, so then it’s easy to demonstrate they are mutually inverse over the whole domain.

Suppose 𝑣𝑝(𝑥𝑦−1)≥0 then 𝑣𝑝(𝑥)≥𝑣𝑝(𝑦). If this holds for all 𝑝∈𝒫︀, then by (3.17.15) 𝑦|𝑥 as elements of 𝐴 whence by definition 𝑥𝑦−1∈𝐴 as required. ∎

Proposition 3.17.27
Suppose 𝐴 is an integral domain satisfying ACCP then so is 𝐴[𝑋].

Proof. Suppose we have an ascending chain of principal ideals

(𝑓1)⊆(𝑓2)⊆…(𝑓𝑛)…

Without loss of generality the 𝑓𝑖 are non-zero. Then 𝑓𝑖+1|𝑓𝑖 and by (…) deg(𝑓𝑖+1)≤deg(𝑓𝑖). Choose 𝑁 such that deg(𝑓𝑖) is minimal, and define 𝑎𝑖≔ℓ(𝑓𝑖)∈𝐴. Then by (3.8.3) 𝑎𝑖+1|𝑎𝑖 for 𝑖≥𝑁 as elements of 𝐴. Therefore we have an increasing sequence of principal ideals

(𝑎𝑁)⊆(𝑎𝑁+1)⊆…

which by hypothesis stabilizes, that is 𝑎𝑖∼𝑎𝑗 for all 𝑖,𝑗≥𝑀 for some 𝑀≥𝑁. For 𝑖≥𝑀 we have 𝑢𝑎𝑖=𝑎𝑖+1, consider 𝑢𝑓𝑖−𝑓𝑖+1∈(𝑓𝑖). This has degree strictly smaller than 𝑁, and therefore by minimality must be 0. In particular 𝑓𝑖∼𝑓𝑖+1 and (𝑓𝑖)=(𝑓𝑖+1). ∎

Lemma 3.17.29 (Nagata's Criterion)

Let 𝐴 be a ring and 𝑆 a multiplicative subset generated by prime elements and units. Let 𝑓∈𝐴 be irreducible or a unit, then

  1. 𝑓1 is irreducible or a unit in 𝑆−1𝐴
  2. 𝑓1 prime or a unit in 𝑆−1𝐴⟹𝑓 is a prime or a unit in 𝐴.

Furthermore if 𝑆−1𝐴 is AP then so is 𝐴.

Proof. Note the condition on 𝑆 means every 𝑎∈𝑆 satisfies 𝑎∼𝑝1…𝑝𝑟 for primes 𝑝𝑖∈𝐴.

  1. Suppose 𝑓1=𝑔𝑎ℎ𝑏 for 𝑓,𝑔,ℎ∈𝐴 and 𝑎,𝑏∈𝑆, then 𝑎𝑏𝑓=𝑔ℎ. Further 𝑎𝑏∼𝑝1…𝑝𝑟. Then 𝑝𝑖|𝑎 or 𝑝𝑖|𝑏, whence we can find 𝑓∼𝑔′ℎ′ where 𝑔=𝑐𝑔′, ℎ=𝑑ℎ′ and 𝑐,𝑑∈𝑆. As 𝑓 is irreducible (or a unit), then for example 𝑔′ is invertible, in which case 𝑔𝑎=𝑐𝑔′𝑎 is invertible. Therefore 𝑓1 is either irreducible or a unit.
  2. The case 𝑓 a unit is clear, so assume that 𝑓 is irreducible. Suppose 𝑓1 is prime or a unit and 𝑓|𝑔ℎ. Then 𝑓1|𝑔1ℎ1 and for example 𝑓1|𝑔1. Therefore 𝑓𝑓′=𝑔𝑝1…𝑝𝑟 for some 𝑓′∈𝐴 and 𝑝1,…,𝑝𝑟∈𝐴 prime. If 𝑝𝑖|𝑓 for some 𝑖 then by irreducibility we have 𝑝𝑖∼𝑓, and we see that 𝑓 is prime. Otherwise 𝑝𝑖|𝑓′ for all 𝑖 and we find 𝑓|𝑔. Therefore 𝑓 is prime as required.

The last statement follows immediately from the previous two results. ∎
