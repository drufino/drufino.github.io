3.3.3 Modules I

Definition 3.3.18 (Module)

Let 𝐴 be a ring. A left 𝐴-module (𝑀,+,⋅) is an abelian group (𝑀,+) together with a “multiplication” operation

⋅:𝐴×𝑀→𝑀

which satisfies the following properties

  • (𝑎×𝐴𝑎′)⋅𝑥=𝑎⋅(𝑎′⋅𝑥)
  • (𝑎+𝐴𝑎′)⋅𝑥=𝑎⋅𝑥+𝑎′⋅𝑥
  • 𝑎⋅(𝑥+𝑦)=𝑎⋅𝑥+𝑎⋅𝑦

Similarly a right 𝐴-module (𝑀,+,⋅) is an abelian group (𝑀,+) together with a multiplication operation

⋅:𝑀×𝐴→𝑀
  • (𝑎×𝐴𝑎′)⋅𝑥=(𝑥⋅𝑎′)×𝐴𝑎
  • (𝑎+𝐴𝑎′)⋅𝑥=𝑎⋅𝑥+𝑎′⋅𝑥
  • 𝑎⋅(𝑥+𝑦)=𝑎⋅𝑥+𝑎⋅𝑦

Considering the first property 𝑀 is a left 𝐴-module iff it is a right 𝐴op module in the obvious way. Therefore in the usual case that 𝐴 is commutative the concepts coincide and we may speak simply of an 𝐴-module, though we almost always write the action on the left.

Similarly almost all results for left 𝐴-modules carry over unchanged for right 𝐴-modules. In this case we may simply by refer to 𝐴-modules rather than state the result for both cases separately.

Definition 3.3.19 (Submodule)

Let (𝑀,+,⋅) be a left 𝐴-module. Then a subset 𝑁⊂𝑀 is called an 𝐴-submodule if

  • 𝑁 is a subgroup of (𝑀,+)
  • 𝑚∈𝑁,𝑎∈𝐴⟹𝑎𝑚∈𝑁

Then (𝑁,+|𝑁×𝑁,⋅|𝐴×𝑁) is a left 𝐴-module. Similar definition applies for a right 𝐴-module.

Definition 3.3.20 (Module homomorphism)

Let (𝑀,+,⋅),(𝑁,+,⋅) be left 𝐴-modules. A function 𝑓:𝑀→𝑁 is an 𝐴-module homomorphism if

  • It is an (additive) group homomorphism (𝑀,+)→(𝑁,+).
  • It is 𝐴-linear; ∀𝑎∈𝐴,𝑚∈𝑀𝑓(𝑎⋅𝑚)=𝑎⋅𝑓(𝑚)

It may be verified that 𝑓 is bijective if and only if it’s an isomorphism. In this way we have the following categories

  • 𝐴-𝐌𝐨𝐝 the category of modules over a commutative ring 𝐴
  • 𝐌𝐨𝐝𝐴 the category of left 𝐴-modules
  • 𝐌𝐨𝐝𝐴 the category if right 𝐴-modules

ker(𝑓)≔{𝑚∈𝑀|𝑓(𝑚)=0}

and the image is given by

Im(𝑓)=𝑓(𝑀)

Definition 3.3.26 (Hom Sets)

A module homomorphism 𝜑:𝑀→𝑁 is an additive group homomorphism which commutes with the 𝐴 action

𝜑(𝑎𝑚)=𝑎𝜑(𝑚)∀𝑎∈𝐴𝑚∈𝑀

Denote the abelian group of 𝐴-module homomorphisms

Hom𝐴(𝑀,𝑁)

and the endomorphism ring

End𝐴(𝑀)≔Hom𝐴(𝑀,𝑀)

When 𝐴 is commutative then these have natural 𝐴-module and 𝐴-algebra structures respectively.
