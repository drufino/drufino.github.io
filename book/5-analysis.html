Chapter 5Analysis

The first task is to define the field of real numbers ℝ, having already constructed the rational numbers ℚ=Frac(ℤ). Typically this is done by some axiomatisation as an ordered field containing ℚ for which every bounded subset has a supremum (Dedekind Completeness). We show ℝ is unique such ordered field.
