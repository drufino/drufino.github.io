5.1 Real Numbers

Definition 5.1.1 (Ordered Ring / Field)

An ordered ring is a ring (𝐴,+,⋅) such that the additive group (𝐴,+) is an ordered abelian group with ordering ≤ which also satisfies

𝑥,𝑦≥0⟹𝑥⋅𝑦≥0

An ordered field is a field with the structure of an ordered ring.

Proposition 5.1.2 (Extension to Field of Fractions)

Let 𝐴 be an ordered ring with no zero-divisors. The 𝐾=Frac(𝐴) is an ordered ring with the order given by

𝑥𝑦≤𝑤𝑧⟺𝑥𝑧≤𝑤𝑦
Example 5.1.3
ℤ is an ordered ring and ℚ≔Frac(ℤ) is an ordered field.
Proposition 5.1.4 (Trichotomy Law)

Let 𝐺 be an ordered abelian group. Then 𝐺 is the disjoint union of {0}, 𝐺+ and 𝐺−.

More generally precisely one of 𝑥=𝑦, 𝑥<𝑦 and 𝑥>𝑦 holds.

Lemma 5.1.5 (Elementary Properties)

Let 𝐺 be an ordered abelian group. Then

  1. 𝑥∈𝐺+⟺−𝑥∈𝐺−
  2. 𝑥∈𝐺+and𝑥≤𝑦⟹𝑦∈𝐺+
  3. 𝑥∈𝐺−and𝑦≤𝑥⟹𝑥∈𝐺−
  4. 𝑥,𝑦∈𝐺+⟹𝑥+𝑦∈𝐺+
  5. 𝑥,𝑦∈𝐺−⟹𝑥+𝑦∈𝐺−
  6. 𝑥,𝑦∈𝐺+⟹𝑥𝑦∈𝐺+

Proof.

  1. 𝑥∈𝐺+⟹0≤𝑥⟹−𝑥≤0. Furthermore 𝑥≠0⟹−𝑥≠0 by assumption so −𝑥∈𝐺−.
  2. By transitivity 0≤𝑦. Suppose 𝑦=0 then 0≤𝑥≤0 so 𝑥=0 a contradiction.
  3. Similarly
  4. Follows from b) since 0≤𝑥⟹0≤𝑦≤𝑥+𝑦.
  5. Follows from c) since 𝑥≤0⟹𝑥+𝑦≤𝑦≤0.
  6. If 𝑥𝑦=0⟹𝑥=0 or 𝑦=0 which is a contradiction. Therefore 𝑥𝑦>0.

 ∎

Proposition 5.1.6 (Ordered Rings are Torsion Free)

Let 𝐴 be a non-zero ordered ring. Then the canonical map ℤ→𝐴 is injective, in other words 𝐴 has characteristic 0.

In particular every ordered field 𝐾 contains ℚ as a subring.

Proof. Follows immediately by induction, since if 𝑛.1=0 then (𝑛−1)>𝑛⟹1<0⟹−1>0⟹1=−1∗−1<0 a contradiction. ∎
Proposition 5.1.7 (Archimedean Field)

Let 𝐾 be an ordered field. Then the following are equivalent

  1. ℚ is dense in 𝐾 i.e. for all 𝑥,𝑦∈𝐾 there exists 𝑧∈ℚ such that 𝑥<𝑧<𝑦
  2. For all 𝑥,𝑦∈𝐾 there exists 𝑛∈ℕ such that 𝑛𝑦>𝑥

In this case we say 𝐾 is Archimedean.

In particular for every 𝜀∈𝐾+ there exists 𝑛∈ℕ+ such that 1𝑛<𝜀.

Proof. Suppose the second property is satisfied then choose 𝑛>1𝑦−𝑥. By definition 0<1𝑛<𝑦−𝑥. Let

𝑆={𝑚∈ℤ|𝑚𝑛≤𝑥}

By the Archimedean property (applied to 1𝑛 and −𝑥) 𝑆 is non-empty. By the well-ordering principle it has a maximal element. By maximality 𝑚+1𝑛>𝑥. Furthermore

𝑥<𝑚+1𝑛≤𝑥+1𝑛<𝑥+(𝑦−𝑥)=𝑦

and therefore 𝑧≔𝑚+1𝑛 satisfies the required property.

Conversely suppose 𝐾 satisfies the first property and assume wlog that 𝑥,𝑦>0. Choose 𝑚𝑛 such that

0<𝑚𝑛<𝑦𝑥

which implies 𝑛𝑦>𝑚𝑥≥𝑥. ∎

Definition 5.1.8 (Absolute Value)

Let 𝐺 be an ordered abelian group. Define the absolute value as

|𝑥|≔{𝑥𝑥∈𝐺+−𝑥𝑥∈𝐺−0𝑥=0

Then this satisfies the following properties

  1. |𝑥|≥0
  2. |−𝑥|=|𝑥|
  3. |𝑥|=0⟺𝑥=0
  4. ||𝑥|−|𝑦||≤|𝑥+𝑦|≤|𝑥|+|𝑦|
Proposition 5.1.9 (Topology of Ordered Abelian Group)

Let 𝐺 be an ordered abelian group. Then 𝑈⊂𝐺 is open in the order topology iff

∀𝑥∈𝑈∃𝜀∈𝐺+s.t.|𝑦−𝑥|<𝜀⟹𝑦∈𝑈
Proof. Let ℬ︀ be the basis defined in (4.1.120). Recall (…) that 𝑈 is open iff for all 𝑥∈𝑈 there exists 𝑉∈ℬ︀ such that 𝑥∈𝑉⊆𝑈. If 𝑈⊂𝐺 satisfies the given condition holds then evidently 𝑥∈{𝑔∈𝐺|𝑦−𝜀<𝑔<𝑦+𝜀} which is an element of ℬ︀. Conversely if 𝑥∈𝑉 with 𝑉={𝑔∈𝐺|𝑦<𝑔<𝑧}, then we may define 𝜀=min(𝑧−𝑥,𝑥−𝑦). ∎
