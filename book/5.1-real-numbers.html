5.1 Real Numbers

Definition 5.1.1 (Ordered Ring / Field)

An ordered ring is a ring (𝐴,+,⋅) such that the additive group (𝐴,+) is an ordered abelian group with ordering ≤ which also satisfies

𝑥,𝑦≥0⟹𝑥⋅𝑦≥0

An ordered field is a field with the structure of an ordered ring.

Proposition 5.1.2 (Extension to Field of Fractions)

Let 𝐴 be an ordered ring with no zero-divisors. The 𝐾=Frac(𝐴) is an ordered ring with the order given by

𝑥𝑦≤𝑤𝑧⟺𝑥𝑧≤𝑤𝑦
Example 5.1.3
ℤ is an ordered ring and ℚ≔Frac(ℤ) is an ordered field.
Proposition 5.1.4 (Trichotomy Law)

Let 𝐺 be an ordered abelian group. Then 𝐺 is the disjoint union of {0}, 𝐺+ and 𝐺−.

More generally precisely one of 𝑥=𝑦, 𝑥<𝑦 and 𝑥>𝑦 holds.

Lemma 5.1.5 (Elementary Properties)

Let 𝐺 be an ordered abelian group. Then

  1. 𝑥∈𝐺+⟺−𝑥∈𝐺−
  2. 𝑥∈𝐺+and𝑥≤𝑦⟹𝑦∈𝐺+
  3. 𝑥∈𝐺−and𝑦≤𝑥⟹𝑥∈𝐺−
  4. 𝑥,𝑦∈𝐺+⟹𝑥+𝑦∈𝐺+
  5. 𝑥,𝑦∈𝐺−⟹𝑥+𝑦∈𝐺−
  6. 𝑥,𝑦∈𝐺+⟹𝑥𝑦∈𝐺+

Proof.

  1. 𝑥∈𝐺+⟹0≤𝑥⟹−𝑥≤0. Furthermore 𝑥≠0⟹−𝑥≠0 by assumption so −𝑥∈𝐺−.
  2. By transitivity 0≤𝑦. Suppose 𝑦=0 then 0≤𝑥≤0 so 𝑥=0 a contradiction.
  3. Similarly
  4. Follows from b) since 0≤𝑥⟹0≤𝑦≤𝑥+𝑦.
  5. Follows from c) since 𝑥≤0⟹𝑥+𝑦≤𝑦≤0.
  6. If 𝑥𝑦=0⟹𝑥=0 or 𝑦=0 which is a contradiction. Therefore 𝑥𝑦>0.

 ∎

Proposition 5.1.6 (Ordered Rings are Torsion Free)

Let 𝐴 be a non-zero ordered ring. Then the canonical map ℤ→𝐴 is injective, in other words 𝐴 has characteristic 0.

In particular every ordered field 𝐾 contains ℚ as a subring.

Proof. Follows immediately by induction, since if 𝑛.1=0 then (𝑛−1)>𝑛⟹1<0⟹−1>0⟹1=−1∗−1<0 a contradiction. ∎
Proposition 5.1.7 (Archimedean Field)

Let 𝐾 be an ordered field. Then the following are equivalent

  1. ℚ is dense in 𝐾 i.e. for all 𝑥,𝑦∈𝐾 there exists 𝑧∈ℚ such that 𝑥<𝑧<𝑦
  2. For all 𝑥,𝑦∈𝐾 there exists 𝑛∈ℕ such that 𝑛𝑦>𝑥

In this case we say 𝐾 is Archimedean.

In particular for every 𝜀∈𝐾+ there exists 𝑛∈ℕ+ such that 1𝑛<𝜀.

Proof. Suppose the second property is satisfied then choose 𝑛>1𝑦−𝑥. By definition 0<1𝑛<𝑦−𝑥. Let

𝑆={𝑚∈ℤ|𝑚𝑛≤𝑥}

By the Archimedean property (applied to 1𝑛 and −𝑥) 𝑆 is non-empty. By the well-ordering principle it has a maximal element. By maximality 𝑚+1𝑛>𝑥. Furthermore

𝑥<𝑚+1𝑛≤𝑥+1𝑛<𝑥+(𝑦−𝑥)=𝑦

and therefore 𝑧≔𝑚+1𝑛 satisfies the required property.

Conversely suppose 𝐾 satisfies the first property and assume wlog that 𝑥,𝑦>0. Choose 𝑚𝑛 such that

0<𝑚𝑛<𝑦𝑥

which implies 𝑛𝑦>𝑚𝑥≥𝑥. ∎

Definition 5.1.8 (Absolute Value)

Let 𝐺 be an ordered abelian group. Define the absolute value as

|𝑥|≔{𝑥𝑥∈𝐺+−𝑥𝑥∈𝐺−0𝑥=0

Then this satisfies the following properties

  1. |𝑥|≥0
  2. |−𝑥|=|𝑥|
  3. |𝑥|=0⟺𝑥=0
  4. ||𝑥|−|𝑦||≤|𝑥+𝑦|≤|𝑥|+|𝑦|
Proposition 5.1.9 (Topology of Ordered Abelian Group)

Let 𝐺 be an ordered abelian group. Then 𝑈⊂𝐺 is open in the order topology iff

∀𝑥∈𝑈∃𝜀∈𝐺+s.t.|𝑦−𝑥|<𝜀⟹𝑦∈𝑈
Proof. Let ℬ︀ be the basis defined in (4.1.120). Recall (…) that 𝑈 is open iff for all 𝑥∈𝑈 there exists 𝑉∈ℬ︀ such that 𝑥∈𝑉⊆𝑈. If 𝑈⊂𝐺 satisfies the given condition holds then evidently 𝑥∈{𝑔∈𝐺|𝑦−𝜀<𝑔<𝑦+𝜀} which is an element of ℬ︀. Conversely if 𝑥∈𝑉 with 𝑉={𝑔∈𝐺|𝑦<𝑔<𝑧}, then we may define 𝜀=min(𝑧−𝑥,𝑥−𝑦). ∎

5.1.1 Sequences in an Ordered Field

Proposition 5.1.10
The order topology on an ordered field 𝐾 is Hausdorff.
Proposition 5.1.11 (Convergent Sequence)

Let 𝐾 be an ordered field and (𝑎𝑛) in 𝐾 a sequence. Then the following are equivalent

  1. 𝑎𝑛→𝛼 in the sense of (4.1.49)
  2. For all 𝜀∈𝐾+ there exists 𝑁(𝜀)∈ℕ such that 𝑛≥𝑁(𝜀)⟹|𝑎𝑛−𝛼|<𝜀

As 𝐾 is Hausdorff limits are unique. When 𝐾 is Archimedean it is sufficient to consider the case 𝜀≔1𝑁 for all positive integers 𝑁.

Definition 5.1.12 (Convergent Sequence)

Let 𝐾 be an ordered field. We say that a sequence (𝑎𝑛)𝑛∈ℕ+ is cauchy if for all 𝜀>0 there exists 𝑁(𝜀)>0 such that

∀𝑚,𝑛∈ℕ:(𝑚,𝑛≥𝑁(𝜀)⟹|𝑎𝑛−𝑎𝑚|<𝜀)

If 𝐾 is Archimedean then it is sufficient to demonstrate this only for 𝜀 of the form 1𝑁.

Proposition 5.1.13
Let 𝐾 be an ordered field. Then every convergent sequence is cauchy.

Proof. Given 𝜀>0 then 𝜀2>0. Therefore there exists 𝑁 such that

𝑛≥𝑁⟹|𝑎𝑛−𝛼|<𝜀2

Then by the triangle inequality

𝑛,𝑚≥𝑁⟹|𝑎𝑛−𝑎𝑚|<𝜀

 ∎

Definition 5.1.14 (Sequentially Completeness)
We say an ordered field 𝐾 is sequentially complete if every cauchy sequence is convergent.
Proposition 5.1.15 (Completeness)

Let 𝐾 be an ordered field. The following conditions are equivalent

  1. Every non-empty subset 𝑋⊂𝐾 bounded above admits a supremum sup𝑋∈𝐾
  2. Every non-empty subset 𝑋⊂𝐾 bounded below admits an infimum inf𝑋∈𝐾

In this case we say that 𝐾 is complete.

Proof. inf𝑋=−sup(−𝑋) and vice versa. ∎
Lemma 5.1.16
Let 𝐾 be a complete ordered field. Then 𝐾 is also Archimedean
Proof. Suppose 𝐾 is not Archimedean then ℤ+ is bounded above and in particular has a supremum 𝛼. Then for every 𝑛∈ℤ+ we have 𝑛+1≤𝛼⟹𝑛≤𝛼−1, which contradicts maximality. ∎
Lemma 5.1.17

Let 𝑋⊂𝐾 be a subset of an Archimedean ordered field which is “upwards closed” and bounded below (resp. “downwards closed” and bounded above).

Then for every 𝜀∈𝐾+ there exists an 𝑥∈𝑋 such that 𝑥−𝜀∉𝑋 (resp. 𝑥+𝜀∉𝑋)

Proof. By (5.1.7) there is some 𝑛∈ℕ+ such that 0<1𝑛<𝜀. Consider the set

𝒮︀≔{𝑘∈ℤ|𝑘𝑛∈𝑋}

As 𝑋 is bounded below then so is 𝒮︀. By the well ordering principle it has a minimal element, say 𝑘. Define 𝑥≔𝑘𝑛 and then 𝑥−𝜀<𝑥−1𝑛=𝑘−1𝑛 which by minimality is not in 𝑋, whence neither is 𝑥−𝜀. ∎

Lemma 5.1.18
Let 𝑋⊂𝐾 be a non-empty subset for which 𝑥≔sup𝑋 exists. Then there exists a sequence (𝑎𝑛) in 𝑋 such that 𝑎𝑛↑𝑥.

Proof. For every 𝑛∈ℕ+ there exists some 𝑎𝑛∈𝑋 such that 𝑎𝑛>𝑥−1𝑛 (otherwise 𝑥−1𝑛 would be a smaller upper bound). Then evidently 𝑎𝑛 is increasing. For every 𝜀∈𝐾+ there exists some 𝑁 such that 0<1𝑁<𝜀 by (5.1.7). Consequently

𝑛≥𝑁⟹𝑎𝑛>𝑥−1𝑁⟹𝑥≥𝑎𝑛>𝑥−𝜀⟹|𝑎𝑛−𝑥|<𝜀

 ∎

Definition 5.1.19 (Extended Real Line)

Let 𝐾 be an ordered field and define the set

𝐾♯≔𝐾∪{−∞}∪{∞}

with the obvious total ordering and induced order topology. 𝐾⊂𝐾♯ has the subspace topology and every open subset is of the form

𝑈,𝑈∪(𝑥,∞],𝑈∪[−∞,𝑥),𝑈∪[−∞,𝑥)∪(𝑦,∞].

If 𝑋⊂𝐾 is a subset which is unbounded above (resp. below) then define sup𝑋 (resp. inf𝑋) to be ∞ (resp. −∞).

Proposition 5.1.20 (Convergence to infinity)

Let 𝐾 be an ordered field and 𝑎𝑛∈𝐾♯ a sequence. Then the following are equivalent

  1. 𝑎𝑛→∞
  2. For all 𝜆∈𝐾 there exists 𝑁 such that 𝑛≥𝑁⟹𝑎𝑛≥𝜆

A similar statement holds for −∞.

Lemma 5.1.21 (Limit of Bounded Sequence)

Let 𝑎𝑛≤𝑏𝑛 be sequences in 𝐾♯ converging to 𝛼 and 𝛽 respectively. Then 𝛼≤𝛽.

In particular if 𝑎𝑛↓𝛼 then 𝛼≤𝑎𝑛.

Proof. If 𝛽=∞ then the result is vacuously true. If 𝛽=−∞ then evidently 𝛼=−∞ also. Therefore we may assume that 𝛽 is finite without loss of generality.

Suppose 𝛼>𝛽 and define 𝜀=(𝛼−𝛽). By assumption there exists some 𝑁 such that

𝑛≥𝑁⟹|𝑎𝑛−𝛼|<𝜀2∧|𝑏𝑛−𝛽|<𝜀2

Then 𝑎𝑛>𝛼+𝛽2 and 𝑏𝑛<𝛼+𝛽2 which is a contradiction. ∎

Proposition 5.1.22 (Subsequence of a Convergent Sequence)
Let 𝐾 be an ordered field, (𝑎𝑛) a sequence in 𝐾♯ and (𝑛𝑘)𝑘∈ℕ+ a strictly increasing sequence in ℕ+. If 𝑎𝑛→𝛼 then 𝑎𝑛𝑘→𝛼 as 𝑘→∞.

Proof. By induction 𝑛𝑘≥𝑘 for all 𝑘. Let 𝑉 be a neighbourhood of 𝛼 in 𝐾♯, then by (4.1.49) there exists 𝑁 such that 𝑛≥𝑁⟹𝑎𝑛∈𝑉. Consequently

𝑘≥𝑁⟹𝑛𝑘≥𝑘≥𝑁⟹𝑎𝑛𝑘∈𝑉

and the result follows. ∎

5.1.2 Sequential Completeness

Lemma 5.1.23 (Monotone Convergence Theorem)
Let 𝐾 be a complete ordered field and (𝑎𝑛) an increasing (resp. decreasing) sequence in 𝐾♯. Then 𝑎𝑛→sup{𝑎𝑛}. This is finite if and only if 𝑎𝑛 is bounded above (resp. below).

Proof. Suppose first that (𝑎𝑛) is bounded above and define 𝛼≔sup{𝑎𝑛}. Then for every 𝜀∈𝐾+ there exists 𝑁 such that 𝑎𝑁>𝛼−𝜀 (for otherwise 𝛼−𝜀 would be an upper bound). By assumption 𝑛≥𝑁⟹𝛼−𝜀<𝑎𝑛≤𝛼 whence |𝛼−𝑎𝑛|<𝜀. Therefore 𝑎𝑛→𝛼.

The case that (𝑎𝑛) is unbounded above is trivial. ∎

Proposition 5.1.24 (Complete ⟹ Sequentially Complete)
Let 𝐾 be an ordered field which is complete. Then it is sequentially complete.

Proof. Let (𝑎𝑛) be a cauchy sequence. There exists 𝑁 such that 𝑛≥𝑁⟹|𝑎𝑛−𝑎𝑁|<1⟹|𝑎𝑛|≤1+|𝑎𝑁|. Then |𝑎𝑛| is bounded by max(|𝑎1|,⋯,|𝑎𝑁|+1). Consider the sequence

𝑎𝑛−≔inf𝑘≥𝑛𝑎𝑘

Then 𝑎𝑛− is bounded and increasing. Therefore 𝑎𝑛−↑𝛼≔sup𝑎𝑛−<∞ by (5.1.23). For every 𝜀∈𝐾+ there exists 𝑁1 such that 𝑛≥𝑁1⟹𝛼−𝑎𝑛−<𝜀. There exists 𝑁2 such that 𝑛,𝑚≥𝑁2⟹|𝑎𝑛−𝑎𝑚|<𝜀. By definition of 𝑎𝑛−, for every 𝑛≥𝑁1 there exists 𝑚≥𝑁1 such that |𝑎𝑚−𝑎𝑛−|<𝜀. Consequently every 𝑛≥max(𝑁1,𝑁2) there is some 𝑚 such that

|𝛼−𝑎𝑛|≤|𝛼−𝑎𝑛−|+|𝑎𝑛−𝑎𝑛−|≤|𝛼−𝑎𝑛−|+|𝑎𝑛−𝑎𝑚|+|𝑎𝑚−𝑎𝑛−|<3𝜀

As this is independent of 𝑚 we see that 𝑎𝑛→𝛼 as required. ∎

Proposition 5.1.25 (Sequentially Complete ⟹ Complete)
Let 𝐾 be an Archimedean ordered field which is sequentially complete. Then 𝐾 is complete.

Proof. Let 𝑋⊂𝐾 be a non-empty subset bounded above, and 𝒰︀ the set of upper bounds for 𝑋, which in particular is bounded below. By assumption 𝒰︀ is non-empty. For each 𝑛∈ℕ+ we may choose 𝑎𝑛∈𝒰︀ such that 𝑎𝑛−12𝑛∉𝒰︀ by (5.1.17). We may assume without loss of generality that 𝑎𝑛 is decreasing by setting 𝑎𝑛≔min𝑛′≤𝑛𝑎𝑛′. We argue that

𝑎𝑛−𝑎𝑛+1<12𝑛

for otherwise we see that 𝑎𝑛+1≤𝑎𝑛−12𝑛 which implies 𝑎𝑛+1∉𝒰︀. Therefore by the triangle inequality applied repeatedly

𝑚≥𝑛⟹|𝑎𝑛−𝑎𝑚|≤∑𝑖=𝑛𝑚−112𝑖<12𝑛−1<1𝑛−1

By the Archimedean property we see that the sequence is cauchy and therefore convergences to 𝛼∈𝐾. By (5.1.21) 𝛼≤𝑎𝑛. We claim that 𝛼∈𝒰︀. For suppose not then there exists 𝑥∈𝑋 such that 𝑥>𝛼. Then there exists 𝑛 such that 𝑎𝑛−𝛼<𝑥−𝛼⟹𝑎𝑛<𝑥 which contradicts 𝑎𝑛∈𝒰︀. Suppose ∃𝛼′∈𝒰︀ such that 𝛼′<𝛼. Then for some 𝑛 we have 1𝑛<𝛼−𝛼′ therefore 𝑎𝑛−12𝑛≥𝑎𝑛−1𝑛≥𝛼−1𝑛>𝛼′. This would imply 𝑎𝑛−12𝑛∈𝒰︀, a contradiction. Therefore 𝛼′≥𝛼 and 𝛼=sup𝑋 as required. ∎

5.1.3 Uniqueness of Reals

Lemma 5.1.26

Let 𝐾 be a complete ordered field. Then every 𝑥∈𝐾 satisfies

𝑥=sup{𝑚𝑛∈ℚ|𝑚𝑛≤𝑥}

Similarly for every 𝑥∈𝐾 there is a sequence 𝑎𝑛∈ℚ such that 𝑎𝑛↑𝑥.

Proof. By assumption the supremum 𝛼 exists. By definition 𝑥 is an upper bound for the set so 𝛼≤𝑥. Suppose 𝛼<𝑥 then by (5.1.7) there exists 𝑚𝑛 such that 𝛼<𝑚𝑛<𝑥. On the other hand by definition 𝑚𝑛≤𝛼, which is a contradiction. Therefore 𝛼=𝑥 as required.

The final statement follows from (5.1.18). ∎

Lemma 5.1.27
Let 𝜏:𝐾1↪︎𝐾2 be an embedding of ordered fields with 𝐾2 Archimedean. Suppose 𝑥=sup𝑋 for some subset 𝑋⊂𝐾1. Then 𝜏(𝑥)=sup𝜏(𝑋).
Proof. Clearly 𝑥′∈𝑋⟹𝑥′≤𝑥⟹𝜏(𝑥′)≤𝜏(𝑥)⟹𝜏(𝑥)∈𝜏(𝑋)↑. Suppose 𝑦∈𝜏(𝑋)↑ and 𝑦<𝜏(𝑥). Then by (5.1.7) there exists 𝑧∈ℚ such that 𝑦<𝑧<𝜏(𝑥). By the order preserving property we have 𝑧∈𝑋↑ and 𝑧<𝑥 which is a contradiction. Therefore 𝑦∈𝜏(𝑋)↑⟹𝑦≥𝜏(𝑥) and 𝜏(𝑥)=sup𝜏(𝑋). ∎
Proposition 5.1.28 (Uniqueness of Reals)
Let 𝐾1,𝐾2 be complete ordered fields. Then there exists a unique ordered field embedding 𝐾1↪︎𝐾2, which is an isomorphism.

Proof. Let 𝜏,𝜏′:𝐾1→𝐾2 be order embeddings. Then they agree on ℚ. By (5.1.26) every 𝑥 is the supremum of a set 𝑋⊂ℚ. Then uniqueness follows from (5.1.27). The same result shows it is surjective.

For existence we claim that

𝜏(𝑥)≔sup{𝑚𝑛⋅1𝐾2|𝑚𝑛⋅1𝐾1≤𝑥}

is a well-defined, order-preserving field isomorphism. Firstly 𝑥 is bounded by some integer 𝑁 so the supremum is well-defined. Similarly suppose 𝑥′>𝑥 then by (5.1.7) we have 𝑥<𝑚𝑛<𝑥′. This shows that 𝜏(𝑥)≤𝑚′𝑛′≤𝜏(𝑥′) as required, whence 𝜏 is order preserving.

By (5.1.26) there exists 𝑎𝑛,𝑏𝑛∈ℚ such that 𝑎𝑛↑𝑥, 𝑏𝑛↑𝑦 and by the triangle inequality 𝑎𝑛+𝑏𝑛↑𝑥+𝑦. We may show using the definition of 𝜏 that 𝑎𝑛↑𝜏(𝑥),𝑏𝑛↑𝜏(𝑦),𝑎𝑛+𝑏𝑛↑𝜏(𝑥+𝑦). Uniqueness of limits shows that 𝜏(𝑥+𝑦)=𝜏(𝑥)+𝜏(𝑦). Similarly we may show that 𝜏(𝑥𝑦)=𝜏(𝑥)𝜏(𝑦). ∎

5.1.5 𝑛-th Root

For technical reasons it is convenient to introduce the 𝑛-th root function at an early stage in an elementary fashion. Other special functions may be defined by similar considerations but it is convenient to wait until there is more machinery available.

Lemma 5.1.30 (Binomial Theorem)

Let 𝐾 be a field of characteristic 0 and 𝑥,𝑦∈𝐾. Then

(𝑥+𝑦)𝑛=∑𝑘=0𝑛(𝑛𝑘)𝑥𝑛−𝑘𝑦𝑘

where (𝑛𝑘) is a positive integer given by the formula

(𝑛𝑘)≔𝑛(𝑛−1)⋯(𝑛−𝑘+1)𝑘(𝑘−1)⋯1

In particular if 𝐾 is an ordered field and 𝑥≥0 then for every 0≤𝑘≤𝑛

(1+𝑥)𝑛≥(𝑛𝑘)𝑥𝑘
Lemma 5.1.31

Let 𝐾 be a field of characteristic zero, 𝑎,𝑏∈𝐾 and 𝑛 a positive integer. Then

𝑎𝑛−𝑏𝑛=(𝑎−𝑏)(𝑎𝑛−1𝑏+𝑎𝑛−2𝑏2+⋯+𝑎𝑏𝑛−2+𝑏𝑛−1)

In particular if 𝑎>𝑏≥0 then

(𝑎−𝑏)𝑛𝑏𝑛−1<𝑎𝑛−𝑏𝑛<(𝑎−𝑏)𝑛𝑎𝑛−1
Proposition 5.1.32 ($n$-th root over the Reals)

Let 𝑛 be a positive integer. Then there exists a function

⋅𝑛:ℝ≥0→ℝ≥0

such that

𝑥𝑛𝑛=𝑥𝑛𝑛=𝑥

It is bijective and strictly increasing.

Proof. Let 𝑎>0 be a positive real number. There can be at most one solution because 𝑥>𝑦⟹𝑥𝑛>𝑦𝑛. Let

𝑋={𝑦∈ℝ≥0|𝑦𝑛≤𝑎}

then we may see that 𝑋 is bounded by max(1,𝑎), for 𝑦>max(1,𝑎)⟹𝑦𝑛≥𝑦>𝑎.

Define 𝛼=sup𝑋. Suppose 𝛼𝑛>𝑎 then we claim there is an ℎ>0 such that (𝛼−ℎ)𝑛>𝑎. Then 𝑦>𝛼−ℎ⟹𝑦𝑛>𝑎, or contrapositively 𝑦𝑛≤𝑎⟹𝑦≤𝛼−ℎ, and 𝛼−ℎ is an upper bound of 𝑋, which is a contradiction. By (5.1.31) we have

𝛼𝑛−(𝛼−ℎ)𝑛≤ℎ𝑛𝛼𝑛−1

therefore we may choose ℎ such that

0<ℎ<𝛼𝑛−𝑎𝑛𝛼𝑛−1.

Suppose 𝛼𝑛<𝑎 then we claim there is ℎ>0 such that (𝛼+ℎ)𝑛<𝑎, which is a contradiction. As before

(𝛼+ℎ)𝑛−𝛼𝑛≤ℎ𝑛(𝛼+ℎ)𝑛−1

therefore we may choose ℎ such that

0<ℎ<𝑎−𝛼𝑛𝑛(𝛼+ℎ)𝑛−1

to demonstrate the required property.

By the trichotomy law we deduce that 𝛼𝑛=𝑎 as required, and the 𝑛-th root function is well-defined and satisfies 𝑥𝑛𝑛=𝑥.

Suppose that 𝑎𝑛=𝑏𝑛=𝑥>0 then evidently 𝑎,𝑏>0 and we deduce from (5.1.31) that 𝑎=𝑏. Therefore the function is unique and injective. It is evidently surjective as 𝑎𝑛𝑛=𝑎 by uniqueness. Finally we may deduce from (5.1.31) that for 𝑦>𝑥≥0

𝑦𝑛−𝑥𝑛>𝑦−𝑥𝑛𝑦𝑛𝑛−1>0

and so the function is strictly increasing. ∎

5.1.6 Limsup and Liminf

Proposition 5.1.33 (Limsup and Liminf)

Let 𝐾 be a complete ordered field and (𝑎𝑛) a sequence. Define the associated sequences in 𝐾♯

𝑎𝑛+≔sup𝑛′≥𝑛𝑎𝑛′𝑎𝑛−≔inf𝑛′≥𝑛𝑎𝑛′

which are decreasing and increasing sequences respectively. Define

lim sup𝑎𝑛=lim𝑛→∞𝑎𝑛+lim inf𝑎𝑛≔lim𝑛→∞𝑎𝑛−

Then

  1. 𝑎𝑛is bounded above⟺𝑎𝑛+is bounded above⟺lim sup𝑎𝑛+<∞
  2. 𝑎𝑛is bounded below⟺𝑎𝑛−is bounded above⟺lim inf𝑎𝑛−>−∞
  3. lim sup𝑎𝑛≥lim inf𝑎𝑛
  4. 𝑎𝑛→𝛼⟺lim sup𝑎𝑛=lim inf𝑎𝑛=𝛼

Proof. Clearly 𝑎𝑛+ is decreasing and 𝑎𝑛− is increasing. Therefore by (5.1.23) the definition of lim sup𝑎𝑛 and lim inf𝑎𝑛 is well-defined, the same result also demonstrates a) and b). By definition 𝑎𝑛+≥𝑎𝑛≥𝑎𝑛− so the inequality c) follows from (5.1.21).

Suppose 𝛼→∞ then for every 𝐿>0 there exists 𝑁 such that

𝑛≥𝑁⟹𝑎𝑛>𝐿⟹𝑎𝑛−≥𝐿

whence lim inf𝑎𝑛=∞. Conversely suppose lim inf𝑎𝑛=∞ we see by definition that 𝑎𝑛→∞ as required. The case of −∞ follows similarly.

Suppose that 𝛼=lim sup𝑎𝑛=lim inf𝑎𝑛 is finite, then there exists 𝑁1 such that

𝑛≥𝑁1⟹𝑎𝑛≥𝑎𝑛−>𝛼−𝜀2

and 𝑁2 such that

𝑛≥𝑁2⟹𝑎𝑛≤𝑎𝑛+<𝛼+𝜀2

Then

𝑛≥max(𝑁1,𝑁2)⟹|𝑎𝑛−𝛼|<𝜀

and we conclude lim𝑛→∞𝑎𝑛=𝛼.

Conversely suppose 𝑎𝑛→𝛼. Then for every 𝜀>0 there exists some 𝑁 such that

𝑛≥𝑁⟹𝛼−𝜀<𝑎𝑛<𝛼+𝜀

and therefore

𝑛≥𝑁⟹𝛼−𝜀≤𝑎𝑛−≤𝑎𝑛≤𝑎𝑛+≤𝛼+𝜀

Evidently then

𝛼−𝜀≤lim inf𝑎𝑛≤lim sup𝑎𝑛≤𝛼+𝜀

As 𝜀 was arbitrary then this shows 𝛼=lim inf𝑎𝑛=lim sup𝑎𝑛. ∎

Proposition 5.1.34 (Arithmetic Properties of limsup and liminf)

Let 𝐾 be a complete ordered field and (𝑎𝑛),(𝑏𝑛) bounded sequences. Then

  1. lim sup(𝑎𝑛+𝑏𝑛)≤lim sup𝑎𝑛+lim sup𝑏𝑛
  2. lim inf(𝑎𝑛+𝑏𝑛)≤lim inf𝑎𝑛+lim inf𝑏𝑛

If 𝑏𝑛→𝑏 then

  1. lim sup(𝑎𝑛+𝑏𝑛)=lim sup𝑎𝑛+𝑏
  2. lim inf(𝑎𝑛+𝑏𝑛)=lim inf𝑎𝑛+𝑏

and if in addition 𝑏≥0 then

  1. lim sup(𝑎𝑛𝑏𝑛)=𝑏lim sup𝑎𝑛
  2. lim inf(𝑎𝑛𝑏𝑛)=𝑏lim inf𝑎𝑛

Proof. We prove each in turn

  1. By definition 𝑛′≥𝑛⟹𝑎𝑛′+𝑏𝑛′≤𝑎𝑛++𝑏𝑛+, whence (𝑎𝑛+𝑏𝑛)+≤𝑎++𝑏𝑛+. The result follows from (5.1.21).
  2. Similarly
  3. By a) we have lim sup(𝑎𝑛+𝑏𝑛)≤lim sup𝑎𝑛+𝑏. Furthermore lim sup(𝑎𝑛)=lim sup(𝑎𝑛+𝑏𝑛+(−𝑏𝑛))≤lim sup(𝑎𝑛+𝑏𝑛)+lim sup(−𝑏𝑛)=lim sup(𝑎𝑛+𝑏𝑛)−𝑏, and the result follows.
  4. Similarly

e), f) Suppose first that 𝑏=0. Then for sufficiently large 𝑛

0≤𝑏𝑛≤𝜀⟹−𝜀|𝑎𝑛−|≤(𝑎𝑛𝑏𝑛)+≤|𝑎𝑛+|𝜀⟹|(𝑎𝑛𝑏𝑛)+|≤max(|sup𝑘𝑎𝑘+|,|inf𝑘𝑎𝑘−|)𝜀

as (𝑎𝑛) is assumed bounded then this shows that (𝑎𝑛𝑏𝑛)+→0 as required. In this case f) follows similarly. For the general case then

𝑎𝑛𝑏𝑛=𝑎𝑛(𝑏𝑛−𝑏)+𝑎𝑛𝑏

Obviously 𝑏𝑛−𝑏→0, so by the case already proven we have

lim sup(𝑎𝑛(𝑏𝑛−𝑏))=lim inf(𝑎𝑛(𝑏𝑛−𝑏))=0

and in particular 𝑎𝑛(𝑏𝑛−𝑏)→0 by (5.1.33).d). Consequently by c)

lim sup(𝑎𝑛𝑏𝑛)=lim sup(𝑎𝑛𝑏)=𝑏lim sup(𝑎𝑛)

as required. The case f) follows similarly. ∎

Proposition 5.1.35

Let 𝐾 be a complete ordered field and (𝑎𝑛) a bounded sequence. Then every subsequence (𝑎𝑛𝑘) satisfies

lim sup𝑘𝑎𝑛𝑘≤lim sup𝑛𝑎𝑛

and there in fact exists a convergent subsequence 𝑎𝑛𝑘 such that

𝑎𝑛𝑘↓lim sup𝑛𝑎𝑛

A similar statement applies to lim inf𝑎𝑛.

Proof. Define 𝑏𝑘≔sup𝑘′≥𝑘𝑎𝑛𝑘′, then by definition

𝑏𝑘+≤𝑎𝑛𝑘+

Taking limits as 𝑘→∞ and considering we find that

lim sup𝑘𝑎𝑛𝑘≤(5.1.21)lim𝑘→∞𝑎𝑛𝑘+=(5.1.22)lim𝑛→∞𝑎𝑛+≕lim sup𝑛𝑎𝑛

Recall that 𝑎𝑛+↓lim sup𝑎𝑛. Therefore for every 𝑘>0 there exists 𝑁𝑘 such that 𝑎𝑁𝑘+≤lim sup𝑎𝑛+12𝑘. Then by definition there exists some 𝑛𝑘≥𝑁𝑘 such that 𝑎𝑛𝑘≤𝑎𝑁𝑘++12𝑘≤lim sup𝑎𝑛+1𝑘. We see that 𝑎𝑛𝑘 has the required property. ∎
