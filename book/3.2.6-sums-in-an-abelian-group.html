3.2.6 Sums in an Abelian Group

Definition 3.2.47 (Finitely Supported Functions)

Let 𝐺 be an abelian group, written additively, and 𝐼 a set. A function 𝑔:𝐼→𝐺, also called a family (𝑔𝑖)𝑖∈𝐼, has support supp(𝑔)≔{𝑖∈𝐼|𝑔𝑖≠0}, and is finitely supported if supp(𝑔) is finite. The finitely supported functions form an abelian group 𝐺(𝐼) under pointwise addition, since supp(𝑔+ℎ)⊆supp(𝑔)∪supp(ℎ) and supp(−𝑔)=supp(𝑔). If 𝐼 is finite then 𝐺(𝐼)=𝐺𝐼.

For 𝑖∈𝐼 and 𝑥∈𝐺 let 𝛿𝑖𝑥∈𝐺(𝐼) be the function with value 𝑥 at 𝑖 and 0 elsewhere.

Proposition 3.2.48 (Sum of a Finitely Supported Family)

Let 𝐺 be an abelian group and 𝐼 a set. There is a unique group homomorphism

Σ𝐼:𝐺(𝐼)→𝐺withΣ𝐼(𝛿𝑖𝑥)=𝑥for all𝑖∈𝐼,𝑥∈𝐺.

We write ∑𝑖∈𝐼𝑔𝑖≔Σ𝐼(𝑔), and drop the subscript from Σ𝐼 when 𝐼 is fixed. Moreover for every 𝑠∈supp(𝑔)

∑𝑖∈𝐼𝑔𝑖=𝑔𝑠+∑𝑖∈𝐼(𝑔−𝛿𝑠𝑔𝑠)𝑖

where 𝑔−𝛿𝑠𝑔𝑠 has support supp(𝑔)∖{𝑠}.

Proof. Drafted by Claude Sonnet, reviewed by David Rufino.

Uniqueness. Write 𝛿𝑠≔𝛿𝑠𝑔𝑠. For 𝑠∈supp(𝑔) we have 𝑔=𝛿𝑠+(𝑔−𝛿𝑠) with |supp(𝑔−𝛿𝑠)|=|supp(𝑔)|−1, so any homomorphism Σ′ with Σ′(𝛿𝑖𝑥)=𝑥 satisfies Σ′(𝑔)=𝑔𝑠+Σ′(𝑔−𝛿𝑠), and Σ′(0)=0. By induction on |supp(𝑔)| this determines Σ′(𝑔).

Existence. We define Σ(𝑔) by induction on |supp(𝑔)| by Σ(0)=0 and Σ(𝑔)≔𝑔𝑠+Σ(𝑔−𝛿𝑠) for some 𝑠∈supp(𝑔), and show by the same induction that the value does not depend on the choice of 𝑠. Suppose 𝑠≠𝑡 in supp(𝑔) and put 𝑔″≔𝑔−𝛿𝑠−𝛿𝑡, so |supp(𝑔″)|=|supp(𝑔)|−2. Both 𝑔−𝛿𝑠 and 𝑔−𝛿𝑡 have smaller support, so by induction we may compute their values with any element of their supports: Σ(𝑔−𝛿𝑠)=𝑔𝑡+Σ(𝑔″) and Σ(𝑔−𝛿𝑡)=𝑔𝑠+Σ(𝑔″). The two possible values of Σ(𝑔) are therefore 𝑔𝑠+(𝑔𝑡+Σ(𝑔″)) and 𝑔𝑡+(𝑔𝑠+Σ(𝑔″)), which agree by associativity and commutativity in 𝐺. Also Σ(𝛿𝑖𝑥)=𝑥: for 𝑥=0 both sides are 0, and for 𝑥≠0 we have Σ(𝛿𝑖𝑥)=𝑥+Σ(0)=𝑥.

It remains to show additivity. First we claim Σ(ℎ+𝛿𝑠𝑥)=Σ(ℎ)+𝑥 for all ℎ∈𝐺(𝐼), 𝑠∈𝐼, 𝑥∈𝐺. For 𝑥=0 this is clear. Let 𝑥≠0.

  • If 𝑠∉supp(ℎ) then 𝑠∈supp(ℎ+𝛿𝑠𝑥) and, computing with 𝑠, Σ(ℎ+𝛿𝑠𝑥)=𝑥+Σ(ℎ).
  • If 𝑠∈supp(ℎ) and ℎ𝑠+𝑥≠0 then, computing with 𝑠, Σ(ℎ+𝛿𝑠𝑥)=(ℎ𝑠+𝑥)+Σ(ℎ−𝛿𝑠ℎ𝑠)=𝑥+(ℎ𝑠+Σ(ℎ−𝛿𝑠ℎ𝑠))=𝑥+Σ(ℎ).
  • If 𝑠∈supp(ℎ) and ℎ𝑠+𝑥=0 then ℎ+𝛿𝑠𝑥=ℎ−𝛿𝑠ℎ𝑠, so Σ(ℎ+𝛿𝑠𝑥)=Σ(ℎ−𝛿𝑠ℎ𝑠), while Σ(ℎ)+𝑥=ℎ𝑠+Σ(ℎ−𝛿𝑠ℎ𝑠)+𝑥=Σ(ℎ−𝛿𝑠ℎ𝑠).

Now we show Σ(𝑔+ℎ)=Σ(𝑔)+Σ(ℎ) by induction on |supp(𝑔)|. For 𝑔=0 this is clear. Otherwise choose 𝑠∈supp(𝑔) and write 𝑔=𝑔′+𝛿𝑠𝑔𝑠 with 𝑔′ of smaller support. By the claim applied twice and by the induction hypothesis

Σ(𝑔+ℎ)=Σ(𝑔′+(ℎ+𝛿𝑠𝑔𝑠))=Σ(𝑔′)+Σ(ℎ+𝛿𝑠𝑔𝑠)=Σ(𝑔′)+Σ(ℎ)+𝑔𝑠=Σ(𝑔)+Σ(ℎ).

 ∎

Proposition 3.2.49 (Properties of Sums)

Let 𝐺 be an abelian group, 𝐼 a set and 𝑔,ℎ∈𝐺(𝐼).

  1. ∑𝑖∈𝐼(𝑔𝑖+ℎ𝑖)=∑𝑖∈𝐼𝑔𝑖+∑𝑖∈𝐼ℎ𝑖 and ∑𝑖∈𝐼(−𝑔𝑖)=−∑𝑖∈𝐼𝑔𝑖.
  2. If 𝜑:𝐺→𝐻 is a group homomorphism to an abelian group 𝐻 then 𝜑∘𝑔∈𝐻(𝐼) and ∑𝑖∈𝐼𝜑(𝑔𝑖)=𝜑(∑𝑖∈𝐼𝑔𝑖).
  3. If 𝐼=𝐽⊔𝐾 then 𝑔|𝐽∈𝐺(𝐽), 𝑔|𝐾∈𝐺(𝐾) and ∑𝑖∈𝐼𝑔𝑖=∑𝑖∈𝐽𝑔𝑖+∑𝑖∈𝐾𝑔𝑖. In particular ∑𝑖∈𝐼𝑔𝑖=∑𝑖∈𝐽𝑔𝑖 whenever 𝐽⊆𝐼 contains supp(𝑔).
  4. If 𝜎:𝐼′→𝐼 is a bijection then 𝑔∘𝜎∈𝐺(𝐼′) and ∑𝑖′∈𝐼′𝑔𝜎(𝑖′)=∑𝑖∈𝐼𝑔𝑖.

  5. If 𝐼=⨆𝜆∈Λ𝐼𝜆 is a partition of 𝐼 then (∑𝑖∈𝐼𝜆𝑔𝑖)𝜆∈Λ∈𝐺(Λ) and

    ∑𝑖∈𝐼𝑔𝑖=∑𝜆∈Λ∑𝑖∈𝐼𝜆𝑔𝑖.
  6. If 𝑔∈𝐺(𝐼×𝐾) then ∑(𝑖,𝑘)∈𝐼×𝐾𝑔(𝑖,𝑘)=∑𝑘∈𝐾∑𝑖∈𝐼𝑔(𝑖,𝑘)=∑𝑖∈𝐼∑𝑘∈𝐾𝑔(𝑖,𝑘), all the intermediate families being finitely supported.

Proof. Drafted by Claude Sonnet, reviewed by David Rufino.

Each part is proved the same way: both sides are, as functions of 𝑔, group homomorphisms out of 𝐺(𝐼), and they agree on every 𝛿𝑖𝑥, so they are equal by the uniqueness in (3.2.48). Write Σ𝐼 for the homomorphism of that proposition on 𝐺(𝐼).

a) Σ𝐼 is a homomorphism.

b) The map 𝜑∗:𝐺(𝐼)→𝐻(𝐼), 𝑔↦𝜑∘𝑔, is well defined since 𝜑(0)=0 gives supp(𝜑∘𝑔)⊆supp(𝑔), and is a homomorphism. Both 𝜑∘Σ𝐼 and Σ𝐼∘𝜑∗ are homomorphisms 𝐺(𝐼)→𝐻 sending 𝛿𝑖𝑥 to 𝜑(𝑥).

c) Extension by zero 𝜄𝐽:𝐺(𝐽)→𝐺(𝐼) is a homomorphism with 𝜄𝐽(𝛿𝑗𝑥)=𝛿𝑗𝑥, so Σ𝐼∘𝜄𝐽 and Σ𝐽 agree on the 𝛿𝑗𝑥, hence Σ𝐼∘𝜄𝐽=Σ𝐽. Since 𝑔=𝜄𝐽(𝑔|𝐽)+𝜄𝐾(𝑔|𝐾) we get Σ𝐼(𝑔)=Σ𝐽(𝑔|𝐽)+Σ𝐾(𝑔|𝐾). If supp(𝑔)⊆𝐽 then 𝑔|𝐾=0.

d) The map 𝜎∗:𝐺(𝐼)→𝐺(𝐼′), 𝑔↦𝑔∘𝜎, is a homomorphism with 𝜎∗(𝛿𝑖𝑥)=𝛿𝜎−1(𝑖)𝑥, so Σ𝐼′∘𝜎∗ sends 𝛿𝑖𝑥 to 𝑥, hence equals Σ𝐼.

e) The component 𝑔↦Σ𝐼𝜆(𝑔|𝐼𝜆) is a homomorphism for each 𝜆, and it vanishes unless 𝐼𝜆 meets the finite set supp(𝑔), so 𝑃:𝐺(𝐼)→𝐺(Λ), 𝑔↦(Σ𝐼𝜆(𝑔|𝐼𝜆))𝜆, is a well-defined homomorphism. For 𝑖∈𝐼𝜆 we have 𝑃(𝛿𝑖𝑥)=𝛿𝜆𝑥, so ΣΛ∘𝑃 is a homomorphism sending 𝛿𝑖𝑥 to 𝑥, and equals Σ𝐼.

f) Apply e) to the partition 𝐼×𝐾=⨆𝑘∈𝐾𝐼×{𝑘}. By d) along 𝑖↦(𝑖,𝑘), the sum over the block 𝐼×{𝑘} is ∑𝑖∈𝐼𝑔(𝑖,𝑘), and e) shows that the family of these sums over 𝑘 is finitely supported. The other order is the same argument with the partition 𝐼×𝐾=⨆𝑖∈𝐼{𝑖}×𝐾. ∎

Remark 3.2.50
If 𝐼={1,…,𝑛} then ∑𝑖∈𝐼𝑔𝑖=𝑔1+…+𝑔𝑛, by induction on 𝑛 using c) of (3.2.49) with 𝐽={1,…,𝑛−1} and 𝐾={𝑛}, and Σ(𝛿𝑛𝑔𝑛)=𝑔𝑛. In particular the sum over the empty set is 0, the sum over a singleton {𝑖} is 𝑔𝑖, and by d) a finite sum does not depend on the order of its terms.
