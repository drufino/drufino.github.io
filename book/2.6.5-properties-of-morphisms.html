2.6.5 Properties of Morphisms

Definition 2.6.30 (Injective, Surjective and Bijective)

Let (𝒞︀,𝑈) be a concrete category (2.6.9) and 𝑓:𝑋→𝑌 a morphism. Then we say

  • 𝑓 is injective if 𝑈(𝑓) is injective
  • 𝑓 is surjective if 𝑈(𝑓) is surjective
Remark 2.6.31
Note if 𝑓 is both surjective and injective it need not be an isomorphism.

The concepts of monic/split-monic, epic/split-epic, iso generalize the notion of injective, surjective and bijective to general categories as we shall see.

Definition 2.6.32 (Monomorphism / Epimorphism)

A morphism 𝑓:𝑋→𝑌 is said to be a monomorphism (or monic) if

𝑓∘𝑔1=𝑓∘𝑔2⟹𝑔1=𝑔2

for all 𝑔1,𝑔2:𝑍→𝑋.

Dually, 𝑓 is said to be an epimorphism (or epic) if

𝑔1∘𝑓=𝑔2∘𝑓⟹𝑔1=𝑔2

for all 𝑔1,𝑔2:𝑌→𝑍.

Remark 2.6.33 (Monic/Epic Duality)
A morphism 𝑓:𝑋→𝑌 of 𝒞︀ is monic if and only if 𝑓op:𝑌→𝑋 is epic in 𝒞︀op, and dually 𝑓 is epic if and only if 𝑓op is monic in 𝒞︀op (2.6.4): composition in 𝒞︀op reverses the order of composition in 𝒞︀, so the defining cancellation property of monic in 𝒞︀ is precisely the defining cancellation property of epic in 𝒞︀op, and vice versa.
Definition 2.6.34 (Split-monic / Split-epic)

A morphism 𝑓:𝑋→𝑌 is split-monic if it has a left inverse, 𝑔:𝑌→𝑋

𝑔∘𝑓=1𝑋

We say 𝑔 is a section of 𝑓.

Dually, 𝑓 is split-epic if it has a right inverse, 𝑔:𝑌→𝑋

𝑓∘𝑔=1𝑌

We say 𝑔 is a retraction of 𝑓.

Proposition 2.6.35 (Split Monic⇒Monic)

For a general category 𝒞︀ we have

  • split-monic ⟹ monic
  • split-epic ⟹ epic

We say an isomorphism is a morphism with a two-sided inverse. We can refine the criteria for 𝑓 to be an isomorphism using the notions just defined

Proposition 2.6.36 (Isomorphism Criteria)

Let 𝑓:𝑋→𝑌 be a morphism. Then the following are equivalent

  1. 𝑓 is an isomorphism
  2. 𝑓 is both split-epic and split-monic
  3. 𝑓 is split-epic and monic
  4. 𝑓 is split-monic and epic

In this case a morphism 𝑔 is a retraction if and only if it is a section. And such a 𝑔 is unique, so we denote it by 𝑓−1

Proof. This is mostly formal

a) ⟹ b) Clear.

b) ⟹ c,d) This follows from (2.6.35).

c) ⟹ b) Suppose 𝑔 is a retraction of 𝑓, that is 𝑓𝑔=1𝑌. Then 𝑓(𝑔𝑓)=(𝑓𝑔)𝑓=1𝑌∘𝑓=𝑓=𝑓∘1𝑋. As 𝑓 is monic we conclude that 𝑔𝑓=1𝑋 and 𝑔 is a section of 𝑓.

d) ⟹ b) Analogous

b) ⟹ a) We’ve shown that any retraction is a section and vice-versa. Furthermore by monic/epic-ness a retraction or section is unique. ∎

Lemma 2.6.37 (Factors of an Isomorphism)

Let 𝑓:𝑋→𝑌 be an isomorphism.

  1. If 𝑓=𝑚∘𝑔 for some monomorphism 𝑚, then 𝑚 and 𝑔 are both isomorphisms.
  2. If 𝑓=ℎ∘𝑒 for some epimorphism 𝑒, then ℎ and 𝑒 are both isomorphisms.

Proof. Drafted by Claude Sonnet 5, reviewed by David Rufino.

a) Since 𝑓 is an isomorphism, 𝑚∘(𝑔∘𝑓−1)=𝑓∘𝑓−1=1𝑌, so 𝑚 is split-epic. As 𝑚 is also monic, (2.6.36) gives that 𝑚 is an isomorphism, and so 𝑔=𝑚−1∘𝑓 is also an isomorphism, being a composite of isomorphisms.

b) Dually, since 𝑓 is an isomorphism, (𝑓−1∘ℎ)∘𝑒=𝑓−1∘𝑓=1𝑋, so 𝑒 is split-monic. As 𝑒 is also epic, (2.6.36) gives that 𝑒 is an isomorphism, and so ℎ=𝑓∘𝑒−1 is also an isomorphism. ∎

Proposition 2.6.38

For the category 𝐒𝐞𝐭 we have

  • split-monic ⟺ monic ⟺ injective
  • split-epic ⟺ epic ⟺ surjective
  • isomorphism ⟺ bijective
Definition 2.6.39 (Balanced Category)
A category 𝒞︀ is balanced if every morphism which is both monic and epic is an isomorphism.
Example 2.6.40

𝐒𝐞𝐭 is balanced: by (2.6.38), the monic and epic morphisms are precisely the injective and surjective ones, so a morphism which is both is bijective, hence an isomorphism. The category of groups is balanced for the same reason, a bijective group homomorphism has a group homomorphism as its (set-theoretic) inverse.

Not every category is balanced. In 𝐓𝐨𝐩 the map [0,2𝜋)→𝑆1, 𝑡↦𝑒𝑖𝑡 is continuous and bijective, hence monic and epic, but its inverse is not continuous, so it is not an isomorphism. Likewise in 𝐑𝐧𝐠 the inclusion ℤ↪︎ℚ is monic and epic (any two ring homomorphisms out of ℚ agreeing on ℤ agree everywhere) but is not an isomorphism.

Definition 2.6.41 (Preserves/Reflects)

Let 𝒫︀ be a property of morphisms and 𝐹:𝒞︀→𝒟︀ be a functor then we say

  • 𝐹 preserves 𝒫︀ if (𝑓 satisfies 𝒫︀⟹𝐹(𝑓) satisfies 𝒫︀)
  • 𝐹 reflects 𝒫︀ if (𝐹(𝑓) satisfies 𝒫︀⟹𝑓 satisfies 𝒫︀)
Proposition 2.6.42

Let 𝐹:𝒞︀→𝒟︀ be a covariant functor then

  • 𝐹 preserves split-monic, split-epic and iso morphisms.

If in addition 𝐹 is faithful then

  • 𝐹 reflects monic and epic morphisms.

and if 𝐹 is full and faithful then

  • 𝐹 reflects split-epic, split-monic and isomorphisms.

Similar statements apply when 𝐹 is contravariant.

Proof. The first statement is easy, for example if 𝑔𝑓=1𝑋 then 𝐹(𝑔)∘𝐹(𝑓)=1𝐹(𝑋).

Suppose 𝐹 is faithful, 𝐹(𝑓) is monic and 𝑓𝑔1=𝑓𝑔2. Then 𝐹(𝑓)𝐹(𝑔1)=𝐹(𝑓)𝐹(𝑔2)⟹𝐹(𝑔1)=𝐹(𝑔2) by assumption. As 𝐹 is faithful 𝑔1=𝑔2 as required. The other statement is similar.

Suppose 𝐹 is full and faithful and 𝐹(𝑓) is split-monic. Then ℎ𝐹(𝑓)=1𝐹(𝑋). As 𝐹 is full ℎ=𝐹(𝑔) and 1𝐹(𝑋)=𝐹(𝑔𝑓). As 𝐹 is faithful then 𝑔𝑓=1𝑋. the other statements are similar. ∎

Proposition 2.6.43

Let (𝒞︀,𝑈) be a concrete category (2.6.9) then

  • 𝑓 split-monic ⟹𝑓 injective ⟹𝑓 monic
  • 𝑓 split-epic ⟹𝑓 surjective ⟹𝑓 epic
  • 𝑓 isomorphism ⟹𝑓 bijective

Proof. Suppose 𝑓 is split-monic, then 𝑈(𝑓) is split-monic by (2.6.42) and so by (2.6.38) 𝑈(𝑓) is injective.

Suppose 𝑈(𝑓) injective, then by (2.6.38) 𝑈(𝑓) is monic. By (2.6.42) 𝑈 reflects monics and so 𝑓 is monic.

The other statements are similar. ∎

We can restate the criteria for split-epic/split-monic

Proposition 2.6.44

Let 𝑓:𝑋→𝑌 be a morphism then

  • 𝑓 is split-monic if and only if Mor(𝑓,𝑍) is surjective for all 𝑍∈𝒞︀
  • 𝑓 is epic if and only if Mor(𝑓,𝑍) is injective for all 𝑍∈𝒞︀

dually

  • 𝑓 is split-epic if and only if Mor(𝑍,𝑓) is surjective for all 𝑍∈𝒞︀
  • 𝑓 is monic if and only if Mor(𝑍,𝑓) is injective for all 𝑍∈𝒞︀

Proof. 𝑓 is epic (resp. monic) iff Mor(𝑓,𝑍) (resp. Mor(𝑍,𝑓)) is injective precisely by the definitions.

Suppose 𝑓 is split-monic, then 𝑔𝑓=1𝑋⟹(ℎ𝑔)𝑓=ℎ for any ℎ. That is Mor(𝑓,𝑍) is surjective. Conversely if it’s surjective then let 𝑍=𝑋 and choose 𝑔 such that 𝑔𝑓=Mor(𝑓,𝑋)(𝑔)=1𝑋.

A similar statement follows dually for 𝑓 split-epic, and 𝑓 monic. ∎

Corollary 2.6.45 (Isomorphism Criteria)

Let 𝑓:𝑋→𝑌 be a morphism then TFAE

  • 𝑓 is an isomorphism
  • Mor(𝑓,𝑍) is bijective for all 𝑍∈𝒞︀
  • Mor(𝑍,𝑓) is bijective for all 𝑍∈𝒞︀
Proof. This follows from combining (2.6.44) with (2.6.36). ∎
Definition 2.6.46 (Conservative)

We say a functor 𝐹:𝒞︀→𝒟︀ is conservative if it reflects isomorphisms.

We say a concrete category (𝒞︀,𝑈) is conservative if the functor 𝑈:𝒞︀→𝐒𝐞𝐭 is conservative.

Proposition 2.6.47

Let (𝒞︀,𝑈) be a conservative concrete category which admits directed limits. Then the following are equivalent

  1. 𝑈 preserves directed colimits
  2. 𝑈 reflects directed colimits
