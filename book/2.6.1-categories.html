2.6.1 Categories

Definition 2.6.1 (Category)

A (locally small) category 𝒞︀ consists of

  • a class ob(𝒞︀) of objects
  • for every pair of objects 𝑋,𝑌∈ob(𝒞︀) a set of morphisms Mor(𝑋,𝑌)

  • for every three objects 𝑋,𝑌,𝑍 a law of composition

    Mor(𝑋,𝑌)×Mor(𝑌,𝑍)→Mor(𝑋,𝑍)(𝑔,𝑓)→𝑔∘𝑓

such that the following conditions hold

  • ℎ∘(𝑔∘𝑓)=(ℎ∘𝑔)∘𝑓 (associativity)
  • There exists 1𝑋∈Mor(𝑋,𝑋) such that 1𝑋∘𝑓=𝑓 and 𝑔∘1𝑋=𝑔.
Example 2.6.2
The category of sets is 𝐒𝐞𝐭 with maps in the usual way. Note associativity is automatically satisfied.
Example 2.6.3 (𝑛-pointed category)
Given a category 𝒞︀ where objects are sets, we may consider the pointed category (𝒞︀,⋆𝑛) consisting of pairs (𝐴,𝑎) where 𝐴∈ob(𝒞︀) and 𝑎∈𝐴𝑛. We consider only morphisms 𝑓:𝐴→𝐵 such that 𝑓(𝑎𝑖)=𝑏𝑖.
Definition 2.6.4 (Opposite Category)

Given a category 𝒞︀ the opposite category is denoted 𝒞︀op and given by

  • The same class of objects ob(𝒞︀op)=ob(𝒞︀)

  • For every pair of objects 𝑋,𝑌∈ob(𝒞︀) the morphisms are reversed

    Morop(𝑋,𝑌)≔Mor(𝑌,𝑋)

  • The law of composition is reversed

    Morop(𝑋,𝑌)×Morop(𝑌,𝑍)→Morop(𝑋,𝑍)(𝑔,𝑓)→𝑓∘𝑔
Example 2.6.5
The polynomial ring 𝐴[𝑋] is an initial object in the category of pointed 𝐴-algebras.
Definition 2.6.6 (Isomorphism)

A morphism 𝑓:𝑋→𝑌 is an isomorphism if there exists 𝑔:𝑌→𝑋 such that

𝑔∘𝑓=1𝑋and𝑓∘𝑔=1𝑌.
Definition 2.6.7 (Functor)

A covariant functor 𝐹:𝒞︀→𝒟︀ consists of a mapping of objects

𝐹:ob(𝒞︀)→ob(𝒟︀)

together with a mapping of morphisms

𝐹(−):Mor(𝑋,𝑌)→Mor(𝐹(𝑋),𝐹(𝑌))

which satisfies

  • 𝐹(1𝑋)=1𝐹(𝑋)
  • 𝐹(𝑓∘𝑔)=𝐹(𝑓)∘𝐹(𝑔)

A contravariant functor 𝒞︀→𝒟︀ is equivalent to a covariant functor on the opposite category 𝒞︀op→𝒟︀, namely where arrows are reversed.

Definition 2.6.8 (Full and faithful)

A functor 𝐹 is said to be

  • Faithful if 𝐹(−) is injective.
  • Full if 𝐹(−) is surjective.
Definition 2.6.9 (Concrete Category)
A concrete category is a pair (𝒞︀,𝑈) where 𝒞︀ and a “forgetful functor” 𝑈:𝒞︀→𝐒𝐞𝐭 which is faithful.
Example 2.6.10 (Forgetful Functor)
The category of groups (resp. rings, modules, …) is a concrete category in the obvious way.
Definition 2.6.11 (Mor functor)

For any objects 𝑋,𝑌,𝑍∈ob(𝒞︀), there is a canonical covariant functor

Mor(𝑋,−):𝒞︀⟶𝐒𝐞𝐭𝑌⟶Mor(𝑋,𝑌)

which acts on a morphism 𝑓:𝑌→𝑍 by

Mor(𝑋,𝑓):Mor(𝑋,𝑌)→Mor(𝑋,𝑍)𝑔→𝑓∘𝑔

It’s a functor precisely because composition of functions is associative. Similarly there’s a canonical contravariant functor Mor(−,𝑌).

Definition 2.6.14 (Functor Category)

Let 𝐼 be a small category and 𝒟︀ a category. The functor category 𝒟︀𝐼 has

  • objects: functors 𝐹:𝐼→𝒟︀;
  • morphisms 𝐹→𝐺: natural transformations 𝜂:𝐹⇒𝐺 (2.6.12);

  • composition: for 𝜂:𝐹⇒𝐺 and 𝜃:𝐺⇒𝐻, (𝜃∘𝜂)𝑍≔𝜃𝑍∘𝜂𝑍 for 𝑍∈ob(𝐼) – again a natural transformation, since for 𝑓:𝑍→𝑍′ in 𝐼, using naturality of 𝜃 then of 𝜂,

    𝐻(𝑓)∘𝜃𝑍∘𝜂𝑍=𝜃𝑍′∘𝐺(𝑓)∘𝜂𝑍=𝜃𝑍′∘𝜂𝑍′∘𝐹(𝑓);
  • identities: 1𝐹, with (1𝐹)𝑍≔1𝐹(𝑍) (trivially natural).

Associativity and the identity laws hold pointwise at each 𝑍∈ob(𝐼), being inherited from those of 𝒟︀; so 𝒟︀𝐼 is indeed a category.

Definition 2.6.15

We say 𝒞︀′⊂𝒞︀ is a subcategory if

  • ob(𝒞︀′)⊆ob(𝒞︀)
  • Mor𝒞︀′(𝑍,𝑊)⊆Mor𝒞︀(𝑍,𝑊)
  • Composition agrees when it is well-defined

We say 𝒞︀′ is a full subcategory if additionally Mor𝒞︀′(𝑍,𝑊)=Mor𝒞︀(𝑍,𝑊).
