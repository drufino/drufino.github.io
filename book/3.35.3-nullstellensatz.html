3.35.3 Nullstellensatz

Definition 3.35.18 (Zeros of an ideal)

Let 𝔞◃𝑘[𝑋1,…,𝑋𝑛] be an ideal and 𝐾/𝑘 a field extension. Then a point 𝑥∈𝐾𝑛 is a zero of 𝔞 if

𝑓∈𝔞⟹𝑓(𝑥)=0

We define the residue field to be

𝑘(𝑥)≔𝑘(𝑥1,…,𝑥𝑛)

and also denote

𝑘[𝑥]≔𝑘[𝑥1,…,𝑥𝑛]

We say it is algebraic if 𝑘(𝑥)/𝑘 is algebraic (necessarily finite).

The following observation is useful

Proposition 3.35.19 (Zeros are homomorphisms)

Let 𝔞◃𝑘[𝑋1,…,𝑋𝑛] be an ideal then there is a bijection

AlgHom𝑘(𝑘[𝑋1,…,𝑋𝑛]/𝔞,𝐾)⟷{zeros of𝔞in𝐾𝑛}𝜙⟶(𝜙(𝑋―1),…,𝜙(𝑋―𝑛))

The following notion is useful in future

Definition 3.35.20 (Generic Point)

Let 𝔞◃𝑘[𝑋1,…,𝑋𝑛] be a prime ideal. then a point 𝜉∈𝐿𝑛 is a generic point of 𝔞 if ker(ev𝜉)=𝔞. Note one always exists, because we may take 𝐿=Frac(𝐴) and 𝜉𝑖=𝑋―𝑖.

When 𝑥 is another zero of 𝔞 this induces a 𝑘-algebra homomorphism

𝑘[𝜉]→𝑘[𝑥]

which is an isomorphism precisely when 𝑥 is a generic point.

Generally we are interested in the relationship between ideals of 𝑘[𝑋1,…,𝑋𝑛] and corresponding zeros in an extension field 𝐾/𝑘. The following proposition is fundamental

Proposition 3.35.21 (Correspondence between ideals and zeros)

Let 𝐾/𝑘 be a field extension and 𝑥∈𝐾𝑛. Define 𝔪𝑥 to be the kernel of the homomorphism

ev𝑥:𝑘[𝑋1,…,𝑋𝑛]→𝐾

Then

  • 𝔪𝑥 is a prime ideal
  • If 𝐾/𝑘 is an algebraically closed field of transcendence degree ≥𝑛 then every prime ideal is of this form.
  • If 𝑥𝑖 are algebraic over 𝑘 (e.g. if 𝐾/𝑘 is algebraic) then 𝔪𝑥 is maximal

In this case we have a canonical isomorphism

𝑘[𝑋1,…,𝑋𝑛]/𝔪𝑥⟶∼𝑘[𝑥]⊂𝐾

and when each 𝑥𝑖 is algebraic then 𝑘[𝑥]=𝑘(𝑥) is a finite extension of 𝑘.

Proof. The canonical isomorphism follows from (3.11.3). Any subring of a field is an integral domain, which means 𝔭𝑥 is prime by (3.3.58).

By (3.19.44) 𝑥𝑖 are algebraic over 𝑘 if and only if 𝑘(𝑥1,…,𝑥𝑛)/𝑘 is algebraic (and even finite). By the same result 𝑘[𝑥1,…,𝑥𝑛]=𝑘(𝑥1,…,𝑥𝑛) and therefore 𝔪𝑥 is maximal by (3.3.58).

Let 𝔭 be a prime ideal and define 𝑘(𝑥)≔Frac(𝑘[𝑥]) and 𝑘[𝑥]≔𝑘[𝑋1,…,𝑋𝑛]/𝔭. If 𝐾 has transcendence degree ≥𝑛 then there is an embedding 𝑘(𝑥)/𝑘→𝐾/𝑘 by (3.19.61). This restricts to an isomorphism 𝑘[𝑥]→∼𝑘[𝑥―] for some 𝑥―𝑖∈𝐾. It’s clear that 𝔭=𝔪𝑥. ∎

We may show that all maximal ideals correspond to zero-loci.

Lemma 3.35.22 (Zariski's Lemma)
Let 𝑘 be an infinite field and 𝐴 a finitely-generated 𝑘-algebra which is a field. Then 𝐴 is a finite extension of 𝑘.
Proof. By Normalisation Lemma (3.35.11) there is an injective, integral map 𝑘[𝑋1,…,𝑋𝑑]↪︎𝐴 for some 𝑑≥0. By (3.24.14) then 𝑘[𝑋1,…,𝑋𝑑] is a field which implies 𝑑=0. We conclude that 𝐴 is algebraic over 𝑘, and by (3.19.44) finite over 𝑘. ∎
Proposition 3.35.23 (Weak Nullstellensatz I)

Every maximal ideal of 𝑘[𝑋1,…,𝑋𝑛]/𝔞 is of the form 𝔪𝑥/𝔞 for 𝑥∈𝑘―𝑛 a zero of 𝔞.

In addition the conclusion of Zariski’s Lemma holds for all (possibly finite) coefficient fields 𝑘.

Proof. Observe that 𝑥∈𝑘―𝑛 is a zero of 𝔞 if and only if 𝔞⊂𝔪𝑥. Therefore we may reduce to the case 𝔞=(0) by results on quotient rings (3.3.55).

We’ve already shown that 𝔪𝑥 is maximal when 𝑥∈𝑘―𝑛 is algebraic (3.35.21). Conversely if 𝔪 is a maximal ideal, then 𝔪𝑘―[𝑋1,…,𝑋𝑛] is a proper ideal contained in some maximal ideal 𝔪′◃𝑘―[𝑋1,…,𝑋𝑛]. If 𝔪′ has an algebraic zero then so does 𝔪 and 𝔪⊂𝔪𝑥 for some 𝑥, which are equal by maximality.

However 𝑘―[𝑋1,…,𝑋𝑛]/𝔪′ is a finitely-generated 𝑘―-algebra which is a field and 𝑘― is infinite. Therefore by (3.35.22) it is 𝑘―, and this yields an algebraic zero of 𝔪′ as required.

We may generalise Zariski’s Lemma to the case 𝑘 is not necessarily infinite. If 𝐴 is a finitely-generated 𝑘-algebra which is a field then we have shown it is isomorphic to 𝑘[𝑋1,…,𝑋𝑛]/𝔪𝑥 for some algebraic point 𝑥. By (3.35.21) is a finite extension of 𝑘, as required. ∎

We may make the correspondence between maximal ideals and algebraic points more precise

Proposition 3.35.24 (Weak Nullstellensatz II)

There is a bijective map

𝑘―𝑛/Aut(𝑘―/𝑘)⟶{𝔪◃𝑘[𝑋1,…,𝑋𝑛]maximal}𝑥⟶𝔪𝑥

When 𝑥∈𝑘𝑛 then

𝔪𝑥=(𝑋1−𝑥1,…,𝑋𝑛−𝑥𝑛)

Proof. The map is surjective by (3.35.23). It’s well-defined because 𝔪𝜎(𝑥)=𝔪𝑥.

By (3.35.21) we have an isomorphism 𝑘[𝑋1,…,𝑋𝑛]/𝔪𝑥→∼𝑘[𝑥1,…,𝑥𝑛]⊂𝑘―. If 𝔪𝑥=𝔪𝑦 then these compose to yield an isomorphism 𝜎:𝑘[𝑥1,…,𝑥𝑛]→∼𝑘[𝑦1,…,𝑦𝑛]⊂𝑘― such that 𝜎(𝑥𝑖)=𝑦𝑖. By (3.19.69) this extends to 𝜎∈Aut(𝑘―/𝑘). Therefore the given mapping is injective. ∎
