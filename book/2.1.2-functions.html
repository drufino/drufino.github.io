2.1.2 Functions

Definition 2.1.8 (Function)

A function 𝑓:𝑋→𝑌 consists of a binary relation Γ(𝑓) on (𝑋,𝑌) such that

  • dom(𝑓)=𝑋
  • Γ(𝑓) is single-valued that is 𝑥Γ(𝑓)𝑦∧𝑥Γ(𝑓)𝑦′⟹𝑦=𝑦′

Equivalently for all 𝑥∈𝑋 there exists precisely one 𝑦∈𝑌 such that 𝑥Γ(𝑓)𝑦.

We write 𝑓(𝑥)=𝑦 for the unique element 𝑦∈𝑌 such that 𝑥Γ(𝑓)𝑦.

Proposition 2.1.9 (Equality of Functions)
Two functions 𝑓,𝑔:𝑋→𝑌 are equal if and only if 𝑓(𝑥)=𝑔(𝑥) for all 𝑥∈𝑋.
Proposition 2.1.10 (Composition of Functions)

Let 𝑓:𝑋→𝑌 and 𝑔:𝑌→𝑍 be functions then the composition Γ(𝑔)∘Γ(𝑓) is still a function, which we write 𝑔∘𝑓, and

(𝑔∘𝑓)(𝑥)=𝑔(𝑓(𝑥))

Furthermore composition is associative in the sense that

(ℎ∘𝑔)∘𝑓=ℎ∘(𝑔∘𝑓)
Definition 2.1.11 (Injective, Surjective and Bijective)

Let 𝑓:𝑋→𝑌 be a function then we say

  • 𝑓 is injective if 𝑓(𝑥)=𝑓(𝑥′)⟹𝑥=𝑥′
  • 𝑓 is surjective if for all 𝑦∈𝑌 there exists 𝑥 such that 𝑓(𝑥)=𝑦
  • 𝑓 is bijective if it is both injective and surjective
Definition 2.1.12 (Inverse Function)

Let 𝑓:𝑋→𝑌 and 𝑔:𝑌→𝑋 be functions. We say

  • 𝑔 is a left inverse for 𝑓 if 𝑔∘𝑓=1𝑋
  • 𝑔 is a right inverse for 𝑓 if 𝑓∘𝑔=1𝑌
  • 𝑔 is a two-sided inverse for 𝑓 if it is both a left and right inverse
Proposition 2.1.13

Let 𝑓:𝑋→𝑌 be a function then

  • 𝑓 is injective if and only if it has a left inverse
  • 𝑓 is surjective if and only if it has a right inverse
  • 𝑓 is bijective if and only if it has a two-sided inverse
Definition 2.1.14 (Idempotent Function)
A function 𝑝:𝑋→𝑋 is idempotent 𝑝∘𝑝=𝑝.
Lemma 2.1.15 (Idempotent Criterion)
Let 𝑝:𝑋→𝑋 be a function. Then Fix(𝑝)⊆Im(𝑝) and these are equal if and only if 𝑝 is idempotent.
